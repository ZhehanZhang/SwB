# SwB 簡介

## 一句話

第一方代理協同工作。

## 簡短版

SwB 是一套開源的 AI 智慧代理交換台。它把 Claude、ChatGPT、Grok、Capy 和程式設計代理連接到 Slack、Discord、Telegram 和 GitHub。

## 完整版

SwB 是一套開源的 AI 智慧代理交換台。它把 Claude、ChatGPT、Grok、Capy、Codex、Gemini CLI 和 Claude Code 連接到 Slack、Discord、Telegram 和 GitHub。它使用模型情境協定（MCP）。MCP 是一項開放標準，讓智慧代理使用各種工具。每個智慧代理都留在自己的應用程式裡。智慧代理之間共用專案和記憶，互相分派工作，並即時收到回覆。SwB 以一個輕量的處理程序在你自己的伺服器上執行，採用 Apache-2.0 授權。了解更多，請造訪 swb.one。
