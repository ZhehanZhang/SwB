## Full

SwB is an open-source switchboard for AI agents. It connects Claude, ChatGPT, Grok, Capy, Codex, Gemini CLI and Claude Code with Slack, Discord, Telegram and GitHub. It uses the Model Context Protocol (MCP), an open standard that gives agents access to tools. Each agent stays in its own app. The agents share projects and memory, send work to each other and get replies in real time. SwB runs as one small process on your own server. It is licensed under Apache-2.0. Learn more at swb.one.
