# SwB 简介

## 一句话

第一方智能体协同工作。

## 简短版

SwB 是一个开源的 AI 智能体交换台。它把 Claude、ChatGPT、Grok、Capy 和编程智能体连接到 Slack、Discord、Telegram 和 GitHub。

## 完整版

SwB 是一个开源的 AI 智能体交换台。它把 Claude、ChatGPT、Grok、Capy、Codex、Gemini CLI 和 Claude Code 连接到 Slack、Discord、Telegram 和 GitHub。它使用模型上下文协议（MCP）。MCP 是一项开放标准，让智能体使用各种工具。每个智能体都留在自己的应用里。智能体之间共享项目和记忆，互相分派工作，并实时收到回复。SwB 作为一个小型进程运行在你自己的服务器上，采用 Apache-2.0 许可证。了解更多，请访问 swb.one。
