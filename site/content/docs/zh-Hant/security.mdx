## 一位擁有者

SwB 只有一位擁有者。只有擁有者能核准代理登入、開啟 SwB 頁面並貼上權杖。擁有者自己的代理代表擁有者行動。

## 代理登入

SwB 是服務單一擁有者的 OAuth 2.1 伺服器。它使用 S256 的 PKCE，並把每個權杖綁定到你的 `/mcp` 位址。存取權杖的有效時間是一小時。更新權杖的有效時間是 30 天，而且每次使用都會輪換。SwB 只儲存權杖的 SHA-256 雜湊。其他代理使用 bearer 金鑰或配對碼。

## 信任等級

SwB 依平台本身的 id 設定每則訊息的信任等級（trust）。只有 id 決定信任等級。

| 信任等級 | 對象 |
| - | - |
| `owner` | 你與你自己已登入的代理 |
| `known` | 你列在 `known` 的人與機器人 |
| `external` | 其他所有人 |

SwB 原樣傳遞擁有者的文字。對於其他寄件者，SwB 會改寫文字中的標頭或標記。接著，SwB 加上自己的標頭與標記 `<<<swb-untrusted` 和 `swb-untrusted>>>`。代理把標記內的文字視為資訊。

## 可見度

每項資源是私人或共用。資源包括目標、頻道、記憶範圍、路由與工具。每項資源起初都是私人，只有擁有者能連到。你可以與工作區或一份人員名單共用資源。其他人只有在頻道與目標都已共用時，才能連到目標。其他人傳來的訊息會變成情境項目。情境項目以資訊形式進入收件匣，代理維持休眠。

## 受限金鑰

bearer 金鑰可以設定限制。`auth.key_scopes` 限制金鑰的記憶範圍。`auth.key_tools` 限制它的工具。`auth.key_targets` 限制它能傳送的對象。

## 權杖

權杖只經由領取連結進入。SwB 用資料夾中的金鑰封存已儲存的權杖。狀態顯示缺少的變數名稱，並隱藏變數的值。Capy 金鑰只在標頭中送到 `api.capy.ai`。

## 限制

| 限制 | 數值 |
| - | - |
| 錯誤的 bearer 權杖 | 每個位址 10 分鐘內 20 次，之後回應 429 |
| `/register` | 每個位址每小時 20 次 |
| `/token` | 每個位址 10 分鐘內 120 次 |
| `/authorize` | 每個位址 10 分鐘內 60 次 |
| 請求本文 | 1 MiB，`/mcp` 為 16 MiB |
| 每個代理對話的回合數 | 200 |

Bearer 權杖限額按位址計算。同一位址的所有金鑰都受影響，有效金鑰也相同。限額解除前，受 bearer 權杖保護的端點會回傳 `429`。

對話達到回合上限時會暫停。SwB 會通知擁有者。

Capy 和 Muse 收到重複的請求時，可以回傳先前的對話。Capy 用 `duplicate_window_s` 設定比對的時間範圍，預設是 600 秒。Muse 的比對範圍是 600 秒。

## 稽核記錄

每項變更與每次拒絕都會進入稽核記錄。SwB 頁面在 Audit 下顯示它。`swb log` 會印出最近的項目。

## 回報問題

請透過 [SwB 程式碼庫](https://github.com/ZhehanZhang/SwB/security)的 GitHub 私人漏洞回報功能，回報安全性問題。
