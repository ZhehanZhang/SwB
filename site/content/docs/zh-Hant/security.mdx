## 一位擁有者

SwB 只有一位擁有者。只有擁有者能核准代理登入、開啟 SwB 頁面並貼上權杖。擁有者自己的代理代表擁有者行動。

## 代理登入

SwB 是服務單一擁有者的 OAuth 2.1 伺服器。它使用 S256 的 PKCE，並把每個權杖綁定到你的 `/mcp` 位址。存取權杖的有效時間是一小時。更新權杖的有效時間是 30 天，而且每次使用都會輪換。SwB 只儲存權杖的 SHA-256 雜湊。其他代理使用 bearer 金鑰或配對碼。

## 信任等級

SwB 依平台提供的寄件者 ID 判定訊息的信任等級。

| 信任等級 | 對象 |
| - | - |
| `owner` | 你和以你的身分登入的代理 |
| `external` | 其他寄件者，包括 `known` 中的人員和機器人 |

在 Slack、Discord 和 Telegram 中，`known` 是接收設定。SwB 用它判斷接受哪些寄件者的訊息。擁有者以外的寄件者即使透過 `known` 獲准，訊息的信任等級仍是 `external`。GitHub 依每段文字的作者判斷信任等級，詳見[擁有者帳號](/zh-Hant/docs/blocks/github#擁有者帳號)。

**信任框**由 SwB 為外部文字加上的標頭與一對標記組成。SwB 先改寫內容中仿造的標頭與標記，再加上信任框。標記為 `<<<swb-untrusted` 和 `swb-untrusted>>>`。代理只把標記內的文字當成參考資訊。

觀察模式的摘要標為 `external`。每則摘錄的外部文字也有信任框。GitHub 依各文字欄位的作者判定。

[夥伴裝置](/zh-Hant/docs/companion)的金鑰僅用於該裝置的連線。SwB 只保留金鑰的雜湊，用來驗證金鑰。SwB 將裝置傳回的結果標為 `external`，並為結果中的自由文字加上信任框。

## 可見度

每項資源是私人或共用。資源包括目標、頻道、記憶範圍、路由與工具。每項資源起初都是私人，只有擁有者能連到。你可以與工作區或一份人員名單共用資源。其他人只有在頻道與目標都已共用時，才能連到目標。其他人傳來的訊息會變成情境項目。情境項目以資訊形式進入收件匣，代理維持休眠。

## 受限金鑰

`auth.key_scopes` 限制路由、訊息和對話的存取範圍。配對金鑰只能在這些範圍內讀取所屬代理的訊息和對話。

SwB 為每把配對金鑰單獨儲存記憶授權。升級時，原本可存取全部記憶的有效配對金鑰會取得 `general` 和當時已有的每個專案範圍。金鑰若有明確的 `auth.key_scopes` 清單，SwB 會複製該清單。SwB 在升級時儲存這組授權。其他專案須另外授權。

擁有者核准的 OAuth 用戶端和設定金鑰預設擁有完整的記憶存取權。`auth.key_scopes` 中對應名稱的項目會限制這項權限。

`auth.key_tools` 限制金鑰可呼叫的工具。`auth.key_targets` 限制傳送對象。

## 權杖

權杖只透過領取連結提交。SwB 用資料夾內的金鑰加密已儲存的權杖。狀態只顯示缺少的變數名稱。Capy 金鑰只透過要求標頭傳給 api.capy.ai。

擁有者可以在權杖頁面查看各配對金鑰的記憶授權。選取某個範圍旁的移除按鈕，即可撤銷該範圍的授權。

配對金鑰在兌換配對碼時一次取得授權。要擴大某個金鑰的存取範圍，請設定 `auth.key_scopes.<agent>`，或在配對碼中指定專案，再配對一個新金鑰。權杖頁面只能縮小存取範圍。

## 限制

| 限制 | 數值 |
| - | - |
| 錯誤的 bearer 權杖 | 每個位址 10 分鐘內 20 次，之後回應 429 |
| SwB 為擁有者以外的寄件者轉送的 GitHub 事件 | 每位寄件者在最近 10 分鐘內最多 5 個事件 |
| `/register` | 每個位址每小時 20 次 |
| `/token` | 每個位址 10 分鐘內 120 次 |
| `/authorize` | 每個位址 10 分鐘內 60 次 |
| `/companion/pair` 配對碼錯誤 | 每個位址 10 分鐘內可輸錯 10 次，之後傳回 HTTP `429` |
| `/connect` 配對碼錯誤 | 每個位址 10 分鐘內可輸錯 10 次，之後傳回 HTTP `429` |
| 請求本文的預設上限 | 1 MiB |
| `/mcp` 與 `/companion/results` 的請求本文 | 16 MiB |
| `/companion/emit` 的請求本文 | 16,640 位元組 |
| `/auth/setup` 的請求本文 | 1,024 位元組 |
| 每個代理對話的回合數 | 200 |

Bearer 權杖限額按位址計算。同一位址的所有金鑰都受影響，有效金鑰也相同。限額解除前，受 bearer 權杖保護的端點會回傳 `429`。

對話達到回合上限時會暫停。SwB 會通知擁有者。

Capy 收到重複的請求時，可以回傳先前的對話。用 `duplicate_window_s` 設定比對的時間範圍，預設是 600 秒。

## 用戶端位址

SwB 預設依連線位址限制請求次數並記錄操作。將代理加入 `trusted_proxies` 或 `SWB_TRUSTED_PROXIES` 後，SwB 會採用代理提供的用戶端位址。請讓代理用已驗證的位址替換請求標頭中的用戶端位址。

參考[自行代管指南](/zh-Hant/docs/self-hosting)，加入 Docker 網路中的 Cloudflare 通道連接器或反向代理。

## 稽核記錄

工具呼叫因存取規則遭拒時，SwB 會寫入稽核記錄。瀏覽器登入失敗也會留下記錄，涵蓋設定碼、已用連結、過期連結、無效連結、通行金鑰、CSRF 檢查和 OIDC。

GitHub webhook 缺少簽章或簽章有誤時，SwB 會記下原因。部分瀏覽器錯誤和 webhook 拒絕記錄會限制重複次數。設定碼、權杖與簽章保持私密。

在 SwB 頁面開啟 **Audit** 查看記錄。執行 `swb log` 可印出最近的記錄。傳送到收件匣的動作記為 `send`。訊息傳送遭捨棄時的稽核記錄請見[頻道模式](/zh-Hant/docs/channel-modes#檢查訊息傳送)。
