---
title: Muse
description: 從 SwB 喚醒 Meta Muse。
---

SwB 把文字傳給 [Meta Muse](https://muse.ai/)，再把答案交回傳送者。新的 Muse 連線即將推出。連線就緒後，本頁會提供設定步驟。新連線將取代 `swb muse-bridge`。

## 設定

| 設定鍵 | 用途 |
| - | - |
| `blocks.muse` | Muse 連線設定 |
| `blocks.muse.use` | 模組類型，填 `muse` |
| `blocks.muse.enabled` | 設為 `true` 或省略此欄位即可載入模組。設為 `false` 可略過 |
