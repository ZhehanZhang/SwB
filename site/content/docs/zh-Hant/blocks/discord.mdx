## 建立機器人

在 [Discord Developer Portal](https://discord.com/developers/applications) 建立 New Application。在 Bot 之下開啟 Message Content Intent。重設機器人權杖。

請代理連接 Discord。代理呼叫 `discord_provision` 並給你一個領取連結。開啟連結並貼上機器人權杖。你也可以在伺服器環境中設定 `DISCORD_BOT_TOKEN`。

## 把機器人加到伺服器

`discord_status` 會回傳 `setup.invite_url`。開啟它，把機器人加到你的伺服器。連結會要求 bot 範圍，以及你所用功能需要的權限。

SwB 從 Discord 讀取機器人的擁有者，並記錄機器人加入的伺服器。`discord_status` 把它們列在 `discovered` 之下。把伺服器加入設定檔，就能路由它的訊息。

```yaml
blocks:
  discord:
    use: discord
    spaces:
      home:
        guild_id: "100000000000000001"
        owner_ids: ["100000000000000002"]
        default_target: helper
    agents: {claude: [home]}
```

若要複製 id，請在 User Settings → Advanced 開啟 Developer Mode。然後在伺服器或使用者上按右鍵。

## 從 Discord 傳送

提及機器人並加上目標 slug，例如 `@swb helper check the build`。SwB 從你的訊息開啟討論串，並把你加入其中。答案回到討論串。討論串中的後續訊息送給同一個目標。角色身分的貼文每個頻道使用一個 webhook，所以每個代理顯示自己的名稱與圖片。

## 與其他人共用

頻道與目標起初是私人。若要讓其他人連到目標，請共用頻道與目標。使用 `channel:<space>/<channel id>` 與 `target:<slug>`。清單可用 `discord:<user id>` 指定單一使用者。

## 模組設定

| 設定鍵 | 用途 |
| - | - |
| `blocks.discord` | 設定 Discord 機器人及其空間 |
| `blocks.discord.use` | 載入 `discord` 模組 |
| `blocks.discord.enabled` | 設為 `true` 啟用模組，設為 `false` 關閉模組 |
| `blocks.discord.token_env` | 存放機器人權杖的環境變數名稱。預設值為 `DISCORD_BOT_TOKEN` |
| `blocks.discord.application_id` | 用於產生邀請連結的 Discord 應用程式 ID。SwB 也可以從 Discord 讀取這個 ID |
| `blocks.discord.connect` | 設為 `true` 後接收 Discord 即時事件。設為 `false` 可單獨測試 API 呼叫 |
| `blocks.discord.message_content` | 設為 `true` 可讀取訊息內容，包括討論串中的後續訊息。在開發者入口網站開啟 Message Content Intent |
| `blocks.discord.threads` | 設為 `true` 後，會在伺服器的文字頻道開公開討論串來回覆 |
| `blocks.discord.personas` | 設為 `true` 後，透過 Webhook 發到伺服器的貼文會顯示代理的名稱與圖片。授予機器人 Manage Webhooks 權限 |
| `blocks.discord.avatar` | 機器人個人資料的圖片檔名 |
| `blocks.discord.ack_reaction` | 收到傳給機器人的訊息時用來確認的表情符號。設為 `null` 可關閉這項反應 |
| `blocks.discord.dm_space` | 指定私訊所用的路由與擁有者設定來自哪個空間。預設使用設定中的第一個空間 |
| `blocks.discord.dm_mode` | 其他人傳來私訊時的處理模式。設為 `watch` 收集訊息以製作摘要，設為 `off` 略過訊息 |
| `blocks.discord.daily_cap` | 透過工具貼文或回覆時，各自的每日次數上限。設為 `null` 可取消上限 |
| `blocks.discord.refresh_minutes` | 目標清單的更新間隔，單位為分鐘。預設值為 `30` |
| `blocks.discord.target_aliases` | 替現有目標加上其他可用的名稱 |
| `blocks.discord.agents` | 各代理可貼文與接收事件的空間。用 `*` 選取所有空間 |

使用[頻道模式](/zh-Hant/docs/channel-modes)，可透過專案路由喚醒代理。

## 空間與頻道

| 設定鍵 | 用途 |
| - | - |
| `blocks.discord.spaces` | 替 SwB 中的各個空間設定 Discord 伺服器 |
| `blocks.discord.spaces.*.guild_id` | Discord 伺服器 ID。可在一個空間省略這一項。當這個空間的擁有者只有一部可用伺服器時，SwB 會自動配對 |
| `blocks.discord.spaces.*.owner_ids` | 視為擁有者的 Discord 使用者 ID。預設使用 Discord 應用程式擁有者 |
| `blocks.discord.spaces.*.known` | 替已登記的 Discord 使用者 ID 設定顯示名稱 |
| `blocks.discord.spaces.*.default_target` | 傳給 SwB 的新訊息省略目標名稱時使用的目標 |
| `blocks.discord.spaces.*.project` | 這個空間的預設 SwB 專案 |
| `blocks.discord.spaces.*.channel_projects` | 依頻道 ID 或以 `#` 開頭的名稱設定 SwB 專案 |
| `blocks.discord.spaces.*.mode` | 空間的處理模式。頻道或討論串的模式可以覆寫這項設定 |
| `blocks.discord.spaces.*.channels` | 依頻道或討論串的 ID 設定處理模式，也可以填寫詳細設定 |
| `blocks.discord.spaces.*.channels.*.mode` | 單一頻道或討論串的處理模式 |
| `blocks.discord.spaces.*.channels.*.actions` | `triage` 模式允許的動作，例如 `reply` 與 `notify_owner` |
| `blocks.discord.spaces.*.listen` | 舊版設定。讓指定 ID 的頻道或討論串使用 `assist` 模式 |
| `blocks.discord.spaces.*.bot_posts_per_hour` | 機器人每小時可在同一討論串貼文的次數上限。預設值為 `20` |
