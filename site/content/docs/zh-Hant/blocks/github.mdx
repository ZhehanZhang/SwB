## 建立應用程式

在你的帳號下建立 GitHub App。將 SwB 公開位址加上 `/github/webhook` 作為 webhook 位址，例如 `https://swb.example.com/github/webhook`。產生 webhook 金鑰。

```bash
openssl rand -hex 32
```

請代理連接 GitHub。SwB 給你一個領取連結，用來填入 App ID、私密金鑰檔案與 webhook 密鑰。你可以在那個頁面上傳 `.pem` 檔案。

## 權限

為你需要的事件授予唯讀權限。

| 權限 | 事件 |
| - | - |
| Issues | `issues`、`issue_comment` |
| Pull requests | `pull_request`、`pull_request_review`、`pull_request_review_comment`、`pull_request_review_thread` |
| Contents | `push` |
| Checks | `check_run`、`check_suite` |
| Actions | `workflow_run` |

把應用程式安裝到你想要的程式碼庫。

## 路由事件

```yaml
blocks:
  github:
    use: github
    secret_env: GITHUB_WEBHOOK_SECRET
    sinks:
      team: {url_env: TEAM_GITHUB_SINK_URL}
    routes:
      "acme/app": [team]
      "acme/*": [team]
```

**接收端**（sink）是取得每個事件副本的位址。每個相符的接收端取得一份精簡的 JSON 事件。事件包含程式碼庫、操作者、編號、標題、狀態與簡短本文。每次傳遞都帶有 `Idempotency-Key`。SwB 會重試網路錯誤與伺服器錯誤。

若 Cloudflare Access 保護你的主機，請放行 `/github/webhook`。GitHub 簽章保護這個路徑。

## 設定

| 設定鍵 | 用途 |
| - | - |
| `blocks.github` | GitHub 事件與操作設定 |
| `blocks.github.use` | 模組類型，填 `github` |
| `blocks.github.enabled` | 設為 `false` 可略過此模組 |
| `blocks.github.app_id_env` | 存放應用程式 ID 的變數名稱，預設為 `GITHUB_APP_ID` |
| `blocks.github.private_key_env` | 存放應用程式私密金鑰的變數名稱，預設為 `GITHUB_APP_PRIVATE_KEY` |
| `blocks.github.token_env` | 存放細粒度權杖的變數名稱。此權杖可替代應用程式憑證。預設為 `GITHUB_TOKEN` |
| `blocks.github.secret_env` | 存放 webhook 金鑰的變數名稱，預設為 `GITHUB_WEBHOOK_SECRET` |
| `blocks.github.sinks` | 依接收端名稱設定事件接收端 |
| `blocks.github.sinks.*.url_env` | 存放接收端位址的變數名稱 |
| `blocks.github.routes` | 為程式碼庫名稱或 `owner/*` 指定接收端清單 |
| `blocks.github.spaces` | 共用設定的程式碼庫群組。使用 `acme/app` 這類名稱可選取該程式碼庫 |
| `blocks.github.spaces.*.mode` | 這個空間內各程式碼庫的預設[頻道模式](/docs/channel-modes) |
| `blocks.github.spaces.*.project` | 這個空間的事件預設歸入的 SwB 專案 |
