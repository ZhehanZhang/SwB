## 建立應用程式

在你的帳號下建立 GitHub App。將 SwB 公開位址加上 `/github/webhook` 作為 webhook 位址，例如 `https://swb.example.com/github/webhook`。將 webhook 金鑰產生到私用檔案中。SwB 接受至少 16 個字元的金鑰。

```bash
(umask 077; set -C; openssl rand -hex 32 > "$HOME/.swb-github-secret")
```

將金鑰填入 **Webhook secret**。請代理連接 GitHub。使用領取連結儲存同一組 webhook 金鑰。儲存金鑰後刪除私用檔案。重新啟動 SwB 以載入金鑰。請代理再次呼叫 `connect`，取得尚待填寫的 App ID 或私密金鑰連結。填寫私密金鑰時，請貼上 `.pem` 檔案的完整內容。

## 權限

在 **Repository permissions** 中，依下表設定權限。

| 儲存庫資源 | 存取權限 | 事件 |
| - | - | - |
| **Issues** | **Read & write** | `issues`、`issue_comment` |
| **Pull requests** | **Read & write** | `pull_request`、`pull_request_review`、`pull_request_review_comment`、`pull_request_review_thread` |
| **Contents** | **Read-only** | `push` |
| **Checks** | **Read-only** | `check_run`、`check_suite` |
| **Actions** | **Read-only** | `workflow_run` |
| **Metadata** | 自動設為 **Read-only** | |

把應用程式安裝到你想要的程式碼庫。

## 路由事件

```yaml
blocks:
  github:
    use: github
    secret_env: GITHUB_WEBHOOK_SECRET
    sinks:
      team: {url_env: TEAM_GITHUB_SINK_URL}
    routes:
      "acme/app": [team]
      "acme/*": [team]
```

**接收端**（sink）是取得每個事件副本的位址。每個相符的接收端取得一份精簡的 JSON 事件。事件包含程式碼庫、操作者、編號、標題、狀態與簡短本文。每次傳遞都帶有 `Idempotency-Key`。SwB 會重試網路錯誤與伺服器錯誤。

若 Cloudflare Access 保護你的主機，請放行 `/github/webhook`。GitHub 簽章保護這個路徑。

## 設定

| 設定鍵 | 用途 |
| - | - |
| `blocks.github` | GitHub 事件與操作設定 |
| `blocks.github.use` | 模組類型，填 `github` |
| `blocks.github.enabled` | 設為 `false` 可略過此模組 |
| `blocks.github.app_id_env` | 存放應用程式 ID 的變數名稱，預設為 `GITHUB_APP_ID` |
| `blocks.github.private_key_env` | 存放應用程式私密金鑰的變數名稱，預設為 `GITHUB_APP_PRIVATE_KEY` |
| `blocks.github.token_env` | 存放細粒度權杖的變數名稱。此權杖可替代應用程式憑證。預設為 `GITHUB_TOKEN` |
| `blocks.github.secret_env` | 存放 webhook 金鑰的變數名稱，預設為 `GITHUB_WEBHOOK_SECRET` |
| `blocks.github.sinks` | 依接收端名稱設定事件接收端 |
| `blocks.github.sinks.*.url_env` | 存放接收端位址的變數名稱 |
| `blocks.github.routes` | 為程式碼庫名稱或 `owner/*` 指定接收端清單 |
| `blocks.github.spaces` | 共用設定的程式碼庫群組。使用 `acme/app` 這類名稱可選取該程式碼庫 |
| `blocks.github.spaces.*.repo` | `owner/repo` 格式的儲存庫名稱 |
| `blocks.github.spaces.*.mode` | 這個空間內各程式碼庫的預設[頻道模式](/zh-Hant/docs/channel-modes) |
| `blocks.github.spaces.*.mode.target` | 模式設定中的目標，填入 `agent:beta` 這類位址 |
| `blocks.github.spaces.*.project` | 這個空間的事件預設歸入的 SwB 專案 |

呼叫 `space_mode(block="github", space="acme/app", mode="triage", target="agent:beta")`，將代理繫結至儲存庫。使用 `mode="assist"` 可切換至協助模式。請從 `targets` 回傳的清單中選擇目標。連結的專案路由是備用選項。

若要接收外部使用者的事件，請開放 `channel:github/acme/app` 和 `target:beta`。詳情請參閱[頻道可見度](/zh-Hant/docs/channel-modes#允許外部-github-使用者存取)。

觀察模式會依 `modes.digest_minutes` 的間隔將摘要送至目標信箱。累積到 50 個事件時，SwB 提前傳送摘要。查看方式請參閱[觀察摘要](/zh-Hant/docs/channel-modes#查看觀察摘要)。
