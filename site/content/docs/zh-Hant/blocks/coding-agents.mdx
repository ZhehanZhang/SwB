## 取得設定

```bash
swb connect coding-agent --choose agent=codex
```

指令會印出該用戶端的設定。每種設定都把 SwB 加為遠端 MCP 伺服器，用戶端支援 OAuth 時就使用 OAuth。

| 用戶端 | 設定 |
| - | - |
| Claude Code | `claude mcp add` |
| Codex | `config.toml` |
| Gemini CLI 與 Qwen Code | `settings.json` |
| Goose | `config.yaml` |
| OpenCode | `opencode.json` |
| Cline 與 Kiro | 它們的 MCP 設定 |
| 其他用戶端 | 搭配配對碼的 Streamable HTTP |

## Claude Code 頻道

頻道把 SwB 訊息推送到開啟中的 Claude Code 工作階段。它是研究預覽版。

請在伺服器的 `.env` 中建立名為 `SWITCHBOARD_KEY_CHANNEL` 的金鑰。這把金鑰只能讀取 `claude-code` 收件匣。請安裝 [Bun](https://bun.sh)。然後在 Claude Code 中新增外掛。

```text
/plugin marketplace add ZhehanZhang/SwB
/plugin install switchboard@switchboard
```

外掛詢問時，請輸入 SwB 位址與頻道金鑰。用頻道啟動 Claude Code。

```bash
claude --dangerously-load-development-channels plugin:switchboard@switchboard
```

工作階段開啟期間，頻道持續運作。工作階段之間到達的訊息，會在下次啟動時出現。Claude 用 `reply` 工具回答。
