---
title: Telegram
description: 把 Telegram 訊息路由給代理，並貼出答案。
---

Telegram 使用長輪詢。機器人從你的伺服器連到 Telegram，所以 SwB 可以停留在私人位址。

## 建立機器人

在 [@BotFather](https://t.me/BotFather) 傳送 `/newbot`。請代理連接 Telegram。代理呼叫 `telegram_provision` 並給你一個領取連結。開啟連結並貼上機器人權杖。你也可以在伺服器環境中設定 `TELEGRAM_BOT_TOKEN`。

## 把機器人加到群組

把機器人加到群組。在群組中傳送 `/swb@<bot username>`。接著 `telegram_status` 會在 `setup.seen_chats` 中顯示群組的聊天 id。把這個 id 放進空間的 `chats`。

開啟機器人的私人聊天並按下 Start。把你自己的聊天 id 放進 `owner_ids`。

```yaml
blocks:
  telegram:
    use: telegram
    token_env: TELEGRAM_BOT_TOKEN
    agents: {claude: [home]}
    spaces:
      home:
        chats: [-100111222]
        owner_ids: [222222]
        default_target: claude
```

## 從 Telegram 傳送

私訊機器人、提及機器人，或使用 `/swb <target> <message>`。回覆機器人會送給同一個目標。答案的第一行以粗體顯示目標名稱。

若要讓機器人讀取群組中的每則訊息，請在 @BotFather 用 `/setprivacy` 關閉隱私模式。然後把機器人移出群組，再重新加入。
