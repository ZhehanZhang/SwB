模組為 SwB 提供連線或功能。請在設定檔中設定模組。使用預設設定時，SwB 會依環境變數找出部分模組。執行 `swb status` 查看模組狀態和設定提示。以擁有者身分登入後，在 `/healthz` 查看詳情。

| 連線 | 連線方式 | 訊息傳遞方式 |
| - | - | - |
| [Claude](/zh-Hant/docs/blocks/claude) | 自訂連接器與 Claude routine | `wait`、`inbox` 與 routine 喚醒 |
| [ChatGPT](/zh-Hant/docs/blocks/chatgpt) | 自訂 MCP 伺服器與 ChatGPT dot | MCP Events |
| [Capy](/zh-Hant/docs/blocks/capy) | Capy API 金鑰 | Capy 討論串事件流 |
| [Grok](/zh-Hant/docs/blocks/grok) | MCP 連接器與 Grok Bot routine | `wait`、`inbox` 和 routine 喚醒 |
| [程式開發代理](/zh-Hant/docs/blocks/coding-agents) | OAuth 或配對碼 | `wait`、`inbox` 與 Claude Code 頻道 |
| [本機工作階段](/zh-Hant/docs/blocks/local-sessions) | 已配對的裝置 | 信箱或直接送達開啟的工作階段 |
| [Slack](/zh-Hant/docs/blocks/slack) | 透過 Socket Mode 的 Slack 應用程式 | 討論串中的回覆 |
| [Discord](/zh-Hant/docs/blocks/discord) | 機器人權杖 | 討論串中的回覆 |
| [Telegram](/zh-Hant/docs/blocks/telegram) | 機器人權杖 | 討論串中的回覆 |
| [GitHub](/zh-Hant/docs/blocks/github) | Webhook 金鑰 | 已簽章的 Webhook |
| [Webhook](/zh-Hant/docs/blocks/webhooks) | 簽章金鑰或共用金鑰 | 接收事件並傳送已簽章的訊息 |
| [Muse](/zh-Hant/docs/setup/muse) | MCP 連接器和已配對的 Muse 裝置 | 信箱和裝置喚醒 |
| [其他 MCP 用戶端](/zh-Hant/docs/setup/mcp-client) | OAuth 或配對碼 | `wait` 和 `inbox` |

## 信任與存取

SwB 依平台的寄件者 ID 標示訊息的信任等級。在 Slack、Discord 和 Telegram 中，`known` 是接收設定。SwB 用它判斷接受哪些寄件者的訊息。擁有者以外的寄件者即使透過 `known` 獲准，訊息的信任等級仍是 `external`。詳見[信任](/zh-Hant/docs/security#信任等級)。

目標、頻道和記憶範圍預設為私人資源，由擁有者存取。共用資源後，其他人也能存取。

## 加入你自己的模組

模組是含有資訊清單的 Python 類型。清單說明模組能執行的動作、訊息目標和所需金鑰。在 `switchboard.blocks` 進入點群組註冊模組。執行 `swb blocks list` 查看伺服器上已設定的模組。
