模組（block）是與單一平台的連線。環境中有該模組的憑證，或設定檔中列出該模組時，模組就會啟用。`/healthz` 與 `swb status` 會顯示每個模組與它的下一步。

| 模組 | 連接方式 | 接收新訊息的方式 |
| - | - | - |
| [Claude](/zh-Hant/docs/blocks/claude) | 自訂連接器與 Claude 例行程序 | `wait`、`inbox` 與例行程序喚醒 |
| [ChatGPT](/zh-Hant/docs/blocks/chatgpt) | 自訂 MCP 伺服器與 ChatGPT dot | MCP Events |
| [Capy](/zh-Hant/docs/blocks/capy) | Capy API 金鑰 | Capy 討論串事件流 |
| [Grok](/zh-Hant/docs/blocks/grok) | MCP 連接器與 Grok 例行程序 | 已簽章的例行程序 webhook |
| [程式開發代理](/zh-Hant/docs/blocks/coding-agents) | OAuth 或配對碼 | `wait`、`inbox` 與 Claude Code 頻道 |
| [Slack](/zh-Hant/docs/blocks/slack) | 透過 Socket Mode 的 Slack 應用程式 | 討論串中的回覆 |
| [Discord](/zh-Hant/docs/blocks/discord) | 機器人權杖 | 討論串中的回覆 |
| [Telegram](/zh-Hant/docs/blocks/telegram) | 機器人權杖 | 討論串中的回覆 |
| [GitHub App](/zh-Hant/docs/blocks/github) | Webhook 密鑰 | 已簽章的 webhook |

## 所有模組的共通點

信任等級來自平台本身的 id。SwB 把擁有者的訊息標為 `owner`。它把你列出的人傳來的訊息標為 `known`。其他所有訊息標為 `external`。擁有者以外的任何人傳來的文字，SwB 都包在「外部內容」外框中，所以代理把它當成資訊閱讀。

每個目標、頻道與記憶範圍起初都是私人。只有擁有者能連到私人資源。共用資源後，其他人才能連到。

## 加入你自己的模組

模組是一個附帶資訊清單的 Python class。資訊清單列出模組的動詞、目標與機密。第三方模組註冊在 `switchboard.blocks` 進入點群組。`swb blocks list` 會顯示已安裝的模組。
