---
title: 本機工作階段
description: 向已配對裝置上的程式開發代理傳送訊息。
---

本機工作階段是程式開發代理在已配對裝置上開啟的工作環境。SwB 會將工作階段列為目標。目標是可接收訊息的位址。

## 配對裝置

依照[配對裝置](/zh-Hant/docs/companion#配對裝置)的說明操作。使用下方對應代理的指令。把 `https://swb.example.com` 換成你的 SwB 位址。每啟用一項功能，加入一個 `--cap` 選項。若要變更已配對裝置的功能，請先[中斷連線](/zh-Hant/docs/companion#中斷連線)。

請以擁有者身分登入的代理呼叫 `targets(block="local")`，確認設定結果。複製工作階段的位址。位址格式為 `local:session:<companion>:<harness>:<session>`。其中 `harness` 是執行代理的程式。

## 傳送訊息

使用 `send` 時，將工作階段位址填入 `to`。SwB 會嘗試把訊息送到已開啟的工作階段。寄件者有權使用代理信箱時，SwB 會將副本放進信箱。若工作階段缺少對應代理，擁有者傳送的訊息會留在自己的信箱。將傳回的對話 ID 傳給 `result`，讀取回覆。

| 狀態 | 含義 |
| --- | --- |
| `working` | 代理正在處理工作 |
| `blocked` | 代理正在等候核准或輸入 |
| `idle` | 代理可以接收工作 |
| `done` | 代理已完成工作 |
| `unknown` | 狀態待確認 |

若工作階段正在等候處理，請在該工作階段回應要求。寄件者有權使用信箱時，SwB 會將訊息留在信箱。

夥伴裝置會向 SwB 伺服器回報工作階段的狀態，也可回報工作階段和資料夾的名稱。對於每則直接送達的訊息，夥伴裝置可傳回一則回覆。其餘內容留在裝置上。

## 狀態掛鉤

代理回報變化時，掛鉤會執行指令。macOS 與 Linux 支援狀態掛鉤。

```sh
swb companion connect https://swb.example.com --cap hooks
```

用 [pipx](/zh-Hant/docs/install) 安裝 `swb` 指令。確認代理能找到 `swb` 指令。若有設定 `SWB_COMPANION_HOME`，請讓代理與夥伴裝置使用同一個資料夾。

| 代理 | 事件指令 | 設定方式 |
| --- | --- | --- |
| Claude Code | `swb hook claude-code` | 將 `channel/hooks/hooks.json` 的 `hooks` 合併到 `~/.claude/settings.json` |
| Gemini CLI | `swb hook gemini` | 用下方指令從本機副本安裝 SwB 擴充功能 |
| Codex | `swb hook codex` | 將 `integrations/codex/hooks.json` 的 `hooks` 合併到 `~/.codex/hooks.json` |

請使用 [SwB 發行分支的本機副本](/zh-Hant/docs/self-hosting#docker-compose)中的檔案。Claude Code 的 SwB 外掛也包含這些掛鉤。若 Codex 使用自訂設定資料夾，請使用該資料夾中的 `hooks.json`。

```sh
gemini extensions install /path/to/SwB/integrations/gemini
```

設定掛鉤後，開啟新的工作階段。用 `targets(block="local")` 確認工作階段的位址已列出。單獨啟用狀態掛鉤時，工作階段由信箱接收訊息。

## Herdr

在 Herdr 的窗格開啟程式開發代理。窗格是終端機中的一塊區域。夥伴裝置透過 Herdr 的通訊端接收工作階段事件。通訊端讓同一台裝置上的程式互相通訊。

若使用具名工作階段或自訂通訊端路徑，請參閱 [Herdr 夥伴裝置設定](https://github.com/ZhehanZhang/SwB/blob/release/1.0/src/switchboard/companion/caps/herdr.py#L36-L48)。

```sh
swb companion connect https://swb.example.com --cap herdr --cap hooks
```

若要接收窗格中的回覆，請設定對應的[狀態掛鉤](#狀態掛鉤)。確認目標中列出 `local:session:<companion>:herdr:<session>` 位址。傳送一則簡短的測試訊息到該位址。確認訊息出現在窗格中。若有設定狀態掛鉤，請用 `result` 檢視回覆。

## Codex

Codex 應用程式伺服器是一個程序，可讓其他程式存取已開啟的 Codex 工作階段。請在一個終端機啟動它。

```sh
codex app-server --listen unix://
```

在另一個終端機開啟工作階段。

```sh
codex --remote unix://
```

另開一個終端機執行夥伴裝置。在所有終端機中使用同一個 Codex 設定資料夾。使用自訂通訊端時，請在上面兩個指令中都填入 `unix://<path>`。在執行夥伴裝置的終端機中，將 `SWB_CODEX_SOCKET` 設為該路徑。

```sh
swb companion connect https://swb.example.com --cap codex
```

夥伴裝置從應用程式伺服器讀取工作階段事件。確認目標中列出 `local:session:<companion>:codex:<session>` 位址。傳送一則簡短的測試訊息到該位址。用 `result` 檢視回覆。

## OpenCode

在裝置上啟動 OpenCode 伺服器。

```sh
opencode serve --hostname 127.0.0.1 --port 4096
```

在該伺服器開啟工作階段。將 `SWB_OPENCODE_URL` 設為伺服器的本機位址。若伺服器設有密碼，請參閱 [OpenCode 夥伴裝置設定](https://github.com/ZhehanZhang/SwB/blob/release/1.0/src/switchboard/companion/caps/opencode.py#L225-L228)。

```sh
SWB_OPENCODE_URL=http://127.0.0.1:4096 swb companion connect https://swb.example.com --cap opencode
```

夥伴裝置從 OpenCode 伺服器讀取工作階段事件。確認目標中列出 `local:session:<companion>:opencode:<session>` 位址。傳送一則簡短的測試訊息到該位址。用 `result` 檢視回覆。

## DeepSeek Harness

使用 DeepSeek Harness `0.2.2-rc.5`。設定檔是一組應用程式設定。將 SwB 橋接外掛裝到 `web` 設定檔。外掛會將工作階段事件傳給夥伴裝置。

請使用 `release/1.0` 分支的本機副本。將 `/path/to/SwB` 換成副本的完整路徑。

```sh
dsh plugin --profile web add /path/to/SwB/integrations/dsh
```

使用 `web` 設定檔重新啟動 DeepSeek Harness。開啟一個工作階段。若有設定 `SWB_COMPANION_HOME`，請讓 DeepSeek Harness 與夥伴裝置使用相同的絕對路徑。

```sh
swb companion connect https://swb.example.com --cap dsh
```

確認目標中列出 `local:session:<companion>:dsh:<session>` 位址。傳送一則簡短的測試訊息到該位址。用 `result` 檢視回覆。
