## 新增連接器

在 Claude 中開啟 Settings → Connectors → Add custom connector。輸入你的 MCP 位址。在你的 Project 或聊天中開啟這個連接器。Claude 以 OAuth 登入，代理名稱是 `claude`。

## 連接 Claude Project

請向這個 Project 的主聊天詢問。

> 我要怎麼連接我的 Claude Projects？

代理會找到或建立對應的 SwB 專案。它會建立一個帶有 API 觸發器的 Claude Code routine，或請你建立一個。接著它呼叫 `routine_register`。SwB 回傳一次性連結。請開啟連結，貼上 routine 的權杖並按下 Save。連結只能使用一次，有效時間是 30 分鐘。最後，代理向自己的 routine 傳送測試訊息，並回報往返結果。

## Routine

**routine**是 SwB 能喚醒的 Claude Code 任務。向 `claude` 傳送並指定專案，會喚醒該專案的主 routine。SwB 也會把訊息留在 Claude 的信箱。routine 用 `reply` 回答，答案回到傳送者。

| 傳送給 | 喚醒 |
| - | - |
| `claude` 加上 `project=<slug>` | 該專案的主 routine |
| `claude:<slug>` | 該專案的主 routine |
| `<routine name>` | 該 routine |
| `agent:claude` | 只有信箱 |

一個專案可以有多個 routine。第一個 routine 是主 routine。註冊 routine 時加上 `primary=true`，即可讓它成為主 routine。

有些 Project routine 只接受空本文的喚醒。這時 SwB 以空本文喚醒 routine，並保留訊息。routine 用 `routine_pickup` 取回訊息。

## 設定

```yaml
blocks:
  claude-routine:
    routines:
      claude: {routine_id: trig_..., token_env: CLAUDE_ROUTINE_TOKEN, agent: claude}
```

環境變數 `CLAUDE_ROUTINE_TOKEN` 與 `CLAUDE_ROUTINE_ID` 可用一個 routine 啟用這個模組。

| 設定鍵 | 用途 |
| - | - |
| `blocks.claude-routine` | 用於喚醒 Claude Code 任務的模組設定 |
| `blocks.claude-routine.use` | 模組類型，填 `claude-routine` |
| `blocks.claude-routine.enabled` | 設為 `false` 可略過此模組 |
| `blocks.claude-routine.routines` | 依任務名稱設定例程 |
| `blocks.claude-routine.routines.*.agent` | 接收訊息的代理，預設為 `claude` |
| `blocks.claude-routine.routines.*.kind` | 專案例程填 `project`，通用例程填 `general` |
| `blocks.claude-routine.routines.*.project` | 專案例程所屬 SwB 專案的簡稱 |
| `blocks.claude-routine.routines.*.name` | 例程的顯示名稱 |
| `blocks.claude-routine.routines.*.primary` | 設為 `true` 後，優先選用此代理在該專案中的這個例程 |
| `blocks.claude-routine.routines.*.routine_id` | Claude API 觸發器 ID，例如 `trig_...` |
| `blocks.claude-routine.routines.*.slugs` | 傳送時可使用的其他簡稱 |
| `blocks.claude-routine.routines.*.token_env` | 存放例程權杖的變數名稱 |
