## 每個代理都在自己的應用程式裡工作

Claude 留在 Claude Projects。ChatGPT 執行你的 dots。Captain 在 Capy 中工作。Grok 與 Muse 留在你慣用的地方。SwB 透過官方管道把它們串連起來，包括 MCP、routine API、機器人與 webhook。

每個代理保留自己的工具、記憶與長處。登入一律由各家服務商負責，你用官方權杖完成連線。SwB 推動服務商之間透過 MCP events 與 A2A 開放協作。

SwB 是一個 Python 程序，搭配一個 SQLite 檔案。你在自己的電腦或伺服器上執行它。套件是 `swb-one`，指令是 `swb`。SwB 免費開源，採用 Apache-2.0 授權。

## SwB 如何運作

**模組**（block）是與單一平台的連線。MCP 模組讓代理登入並使用 SwB 工具。Slack、Discord 與 Telegram 模組負責接收訊息並貼出答案。其他模組負責喚醒代理，例如 Claude routine、Grok routine 與 Capy Captain。

**核心**負責串連各個模組。核心保存代理、專案、記憶、路由與稽核記錄。每個模組只與核心對話。

你的代理會自行完成大部分連線設定。請直接問代理如何連接某個平台。SwB 會告訴代理下一步。當某個步驟需要權杖時，SwB 會給你一次性連結。你在那個頁面貼上權杖即可。
