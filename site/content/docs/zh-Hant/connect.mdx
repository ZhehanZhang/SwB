## 把 SwB 加到代理

用戶端和 SwB 在同一台電腦上執行時，請選擇[擁有者權限或配對](/zh-Hant/docs/setup/mcp-client)。若應用程式由服務商代管，請將 SwB 加為遠端 MCP 伺服器。使用公開的 MCP 位址，例如 `https://swb.example.com/mcp`。在 SwB 頁面核准應用程式的 OAuth 登入。

| 應用程式 | 加入 SwB 的位置 |
| - | - |
| [本機 MCP 用戶端](/zh-Hant/docs/setup/mcp-client) | 使用擁有者金鑰，或用配對碼配對。在執行 SwB 的電腦上使用 `http://localhost:8870/mcp`。 |
| Claude 與 Claude Project | Customize → Connectors → Add → Add custom connector |
| ChatGPT | [chatgpt.com/plugins](https://chatgpt.com/plugins) → Add a custom MCP server |
| Grok | [grok.com](https://grok.com) → Connectors → New Connector → Custom |
| Capy | 以 Automatic OAuth 用戶端新增 MCP 伺服器 |
| Claude Code | `claude mcp add --transport http --scope user switchboard https://swb.example.com/mcp` |
| Codex、Gemini CLI 與其他程式開發代理 | `swb connect coding-agent --choose agent=codex` |

對於程式開發代理，請把 `codex` 換成你的用戶端名稱。單獨執行 `swb connect coding-agent` 可以看到清單。清單包含 Claude Code、Codex、Gemini CLI、Qwen Code、Goose、OpenCode、Cline 與 Kiro。

## 詢問你的代理

具備擁有者權限的代理可以設定其他連線。若使用配對金鑰，代理會為每個限擁有者執行的步驟提供終端機指令。

擁有者權限需要擁有者核准的 OAuth 登入，或來自 `SWITCHBOARD_KEY_<NAME>` 的金鑰。請使用可存取所有範圍、工具和目標的憑證。`auth.key_scopes`、`auth.key_tools` 和 `auth.key_targets` 會限制存取權限。

| 你說的話 | 代理的動作 |
| - | - |
| 我要怎麼連接我的 Claude Project？ | 為專案登記 Claude routine，並給你一個領取連結 |
| 幫我把 Slack 連到 SwB。 | 引導你查看 [Slack 設定](/zh-Hant/docs/setup/slack#應用程式資訊清單)中的 YAML 資訊清單，並在需要時提供領取連結 |
| 幫我連接我的 Discord 機器人。 | 給你領取連結與機器人邀請連結 |
| 把這件事交給我的 Capy Captain。 | 傳送任務並等待答案 |
| 你可以傳送給哪些對象？ | 列出 SwB 能連到的所有目標 |

代理會呼叫 `connect` 工具。SwB 回覆該平台的下一步。當某個步驟需要權杖時，SwB 會給出一次性的領取連結（claim link）。請開啟連結並在那裡貼上權杖。[憑證](/zh-Hant/docs/credentials)說明領取連結。

## 從終端機連接

在 SwB 執行個體的資料夾內執行 `swb connect`。這項指令使用 `.env` 中的擁有者金鑰，預設連到本機 SwB 位址。用 `--dir` 指定執行個體的資料夾。用 `--url` 指定 SwB 位址。執行 `swb login-link` 可取得一次性擁有者登入連結。

```bash
swb connect mcp-client
swb connect capy-captain
swb connect grok
```

## 用配對碼連接

請以擁有者身分登入的代理呼叫 `connect_code`。告訴它新代理的名稱。配對碼的有效期限是 10 分鐘，只能使用一次。新代理透過 `POST /connect`，用配對碼換取自己的金鑰。完整的配對方式請見 [MCP 用戶端](/zh-Hant/docs/setup/mcp-client)。

你也可以在權杖頁面建立配對碼。SwB 透過 `POST /pairing/code` 送出表單。

配對金鑰可存取 `agent:<name>` 的記憶，以及 `auth.key_scopes` 中為該代理設定的範圍。配對碼指定專案時，金鑰也會取得該專案的記憶授權。

`POST /connect` 會在 `project` 傳回配對碼指定的專案。請將它設為用戶端的預設專案。呼叫工具需要指定專案時，將該值填入 `project`。

配對金鑰可在[對話範圍](/zh-Hant/docs/security#受限金鑰)內讀取該代理收發的訊息。

使用配對金鑰時，`tools/list` 會回傳已配對代理角色的工具。用 `auth.key_tools` 可縮小清單範圍。呼叫擁有者工具時，請以擁有者身分登入。詳情請參閱[配對金鑰](/zh-Hant/docs/tools#配對金鑰)。

## 收件匣事件串流

`POST /connect` 傳回 `inbox_events_url`，也就是 `GET /inbox/events` 的網址。連線時，請在 `Authorization: Bearer <key>` 中帶入配對取得的代理金鑰。SwB 只提供該代理在金鑰授權範圍內的收件匣更新。更新以伺服器傳送事件（SSE）的方式透過同一條連線傳送。

連線建立後，SwB 先傳送 `ready` 事件。`item` 事件的 JSON 資料包含游標 `cursor`、對話代碼 `handle` 和訊息資料。事件 ID 採用游標值，代表事件在串流中的位置。

串流預設從最新位置開始。若要接續上次的位置，請將最後收到的事件 ID 填入 `Last-Event-ID` 標頭或 `after` 查詢參數。`reply` 和 `get_message` 的參數請見[訊息](/zh-Hant/docs/tools#訊息)。

## 本機裝置

請以擁有者身分登入的代理呼叫 `companion_code`。在裝置上執行 `swb companion connect https://swb.example.com`。依提示輸入配對碼，輸入內容會隱藏。

各項裝置功能預設為關閉。加上 `--cap notify` 允許傳送通知。加上 `--cap drop` 允許存取裝置上的 SwB Drop 資料夾。

執行 `swb companion run` 重新連線。執行 `swb companion status` 查看裝置編號。執行 `swb companion disconnect` 移除裝置。

加上 `--cap mcp` 允許代理呼叫裝置上的工具。每台伺服器使用一個 `--mcp` 參數。本機位址範例為 `--mcp notes=http://127.0.0.1:8000/mcp`。如果填入指令，請加上引號，例如 `--mcp 'notes=uvx notes-mcp'`。呼叫 `companion_invoke` 查看伺服器和工具，或執行工具。
