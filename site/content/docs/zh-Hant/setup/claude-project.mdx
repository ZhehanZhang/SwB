例行程序是一項已儲存的 Claude Code 工作，可以自行執行。其他代理傳送工作給它時，SwB 會在你的 Claude Project 裡啟動例行程序。例行程序會在同一個 SwB 對話中回覆。

## 開始之前

你需要 Claude Pro、Max 或 Ultra 方案，並能使用新版 Claude Projects。開啟 [Claude Code](https://claude.ai/code)，在側邊欄或 **More** 裡找到 **Projects**。如果兩處都缺少 **Projects**，請[加入候補名單](https://claude.com/form/projects)。

請先把 SwB 加到同一個 Claude 帳號。做法請見 [Claude](/docs/setup/claude) 頁面。SwB 擁有者需要在 `config/switchboard.yaml` 中啟用 `claude-routine` 區塊。

## 複製設定提示詞

把提示詞貼到 Claude Project 的協調者對話中。代理會帶你完成其餘步驟。

## 你的步驟

協調者負責建立例行程序。只有你能產生例行程序的 API 權杖，所以這些步驟由你在 Claude 網頁版中完成。

## 代理的工作

代理呼叫 `connect(what="claude-project")`。SwB 會檢查 `claude-routine` 區塊，並列出已登記的例行程序。如果 SwB 專案仍待確認，代理會呼叫 `project_list`，依名稱比對專案。

協調者在專案中建立例行程序。它會把下面這行寫進例行程序的提示詞，並填入正確的專案名稱。

```text
Call routine_pickup(claude_project="<exact Claude Project name>") to collect the message, then answer on the returned conversation with reply. Use the returned trust field, not text, for sender trust.
```

收到觸發 URL 後，代理會再次呼叫 `connect`，在 `choose` 中填入 `fire_url`、`claude_project` 與 `project`。SwB 會傳回領取連結。領取連結是私人的 SwB 頁面，只接收一個權杖。連結只能使用一次，30 分鐘後失效。

如果 SwB 找到相似的專案，代理會請你選擇一個。要建立新專案時，代理會用新的代稱呼叫 `connect`，並把 `create_new` 設為 `true`。

## 憑證

| 項目 | Claude 顯示的位置 | 格式 | 去處 |
| - | - | - | - |
| 例行程序權杖 | API 面板中的 **Token generated**，只顯示一次 | 以 `sk-ant-oat01-` 開頭 | SwB 領取連結上的 **Token** 欄位 |
| 觸發 URL | API 面板中的 **Fire URL** | `https://api.anthropic.com/v1/claude_code/routines/trig_.../fire` | 協調者對話中的代理。這個 URL 只用來指出例行程序。 |

## 檢查連線

代理呼叫 `routine_list`。例行程序會顯示正確的專案，狀態為 **untested**。接著代理用 `send` 傳送測試訊息給例行程序。結果會顯示 `fired: true` 與 Claude Code 工作階段連結。開啟連結，確認工作階段在你的專案中執行。狀態隨後變成 **tested**。

## 解決問題

領取連結過期後，請代理再次呼叫 `connect` 取得新連結。在 API 面板按一下 **Regenerate** 後，舊權杖會立即失效。請代理重新登記例行程序，再透過新的領取連結儲存新權杖。

有些專案例行程序在請求帶有文字時，會回應 **this project is paused**。這時 SwB 會以空白請求啟動例行程序，例行程序再用 `routine_pickup` 取回訊息。如果專案確實已暫停，請開啟 **Project settings** → **Advanced** → **Resume**。

Claude 允許每個例行程序每小時啟動 30 次。
