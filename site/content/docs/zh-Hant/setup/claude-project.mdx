routine 是一項已儲存的 Claude Code 工作，可以自行執行。其他代理派送工作時，SwB 會在你的 Claude Project 裡啟動 routine。routine 會在同一個 SwB 對話中回覆。

## 開始之前

請使用 Claude Pro、Max 或 Ultra 方案，並確認帳號已開通 Claude Code Projects。在 [Claude Code](https://claude.ai/code) 選取 **Projects**。你可以[加入候補名單](https://claude.com/form/projects)申請使用。

先把 SwB 加到同一個 Claude 帳號。做法請見 [Claude](/zh-Hant/docs/setup/claude)。在 `config/switchboard.yaml` 啟用 `claude-routine` 模組。

## 複製設定提示詞

<SetupPrompt name="claude-project" lang="zh-Hant" />

把提示詞貼到 Claude Project 的協調對話。

## 建立 routine

在 [Claude Code](https://claude.ai/code) 開啟專案。開啟專案中的 routine，或建立一項。加入協調代理提供的 routine 提示詞。

## 新增 API 觸發條件

開啟 routine。你也可以在[排程工作頁面](https://claude.ai/code/routines)找到它。

開啟 routine 名稱旁的選單。選取 **Edit**。在 **Trigger** 這一列按一下 **+**。選取 **API**。

複製 **Fire URL**。把網址交給協調代理。按一下 **Generate token**。趁 **Token generated** 對話方塊開著時複製權杖。

## 儲存權杖

開啟協調代理提供的領取連結。在 **Claude routine token** 頁面核對專案和 routine ID。把權杖貼到 **Token**。按一下 **Save token**。

SwB 會顯示 **Routine saved** 或 **Routine and project saved**。儲存後通知協調代理。

## 代理的工作

協調代理呼叫 `connect(what="claude-project")`。SwB 會檢查 `claude-routine` 模組並列出已登記的 routine。協調代理可以用 `project_list` 找到你的 SwB 專案。

協調代理會傳回 routine 的提示詞。其中包含下列指示和正確的專案名稱。

```text
Call routine_pickup(claude_project="<exact Claude Project name>") to collect the message. Answer on the returned conversation with reply. Read sender trust only from the trust field.
```

協調代理再次呼叫 `connect`，在 `choose` 填入 `fire_url`、`claude_project` 和 `project`。SwB 會傳回領取連結。領取連結是用來提交憑證的私人頁面。這個連結可用一次，30 分鐘後失效。

如果 SwB 找到相似的專案，代理會請你選擇一個。要建立新專案時，代理會用新的代稱呼叫 `connect`，並把 `create_new` 設為 `true`。

## 憑證

| 項目 | Claude 顯示的位置 | 格式 | 去處 |
| - | - | - | - |
| routine 權杖 | API 面板中的 **Token generated** | 以 `sk-ant-oat01-` 開頭 | 領取連結的 **Token** 欄位 |
| 觸發網址 | API 面板中的 **Fire URL** | `https://api.anthropic.com/v1/claude_code/routines/trig_.../fire` | Claude Project 的協調對話 |

## 檢查連線

協調代理呼叫 `routine_list`，核對專案和 `untested` 狀態。它用 `send` 傳送測試訊息。成功啟動時，SwB 回傳 `fired: true`，並將狀態改為 `tested`。如果 Claude 回傳工作階段連結，請開啟連結並確認工作階段在你的專案中。

## 解決問題

領取連結過期後，請協調代理呼叫 `connect` 取得新連結。在 API 面板按一下 **Regenerate** 就會換掉舊權杖。請協調代理重新登記 routine，再透過新連結儲存權杖。

如果 Claude 收到含文字的請求時回應 **this project is paused**，SwB 會以空白請求重試。routine 接著用 `routine_pickup` 取回訊息。如果專案已暫停，請在 Claude 恢復專案。
