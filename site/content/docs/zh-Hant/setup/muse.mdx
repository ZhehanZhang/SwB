SwB 以名為 **SwB** 的文字小工具與 Muse 配對。小工具是 Muse App 透過藍牙連線的裝置。一台 Linux 裝置執行 SwB 橋接程式，在 Muse 和 SwB 之間傳遞訊息。

## 開始之前

你需要一個 Muse 帳號，以及 iOS 或 Android 上的 Muse App。請使用支援低功耗藍牙的 Linux 裝置。確認這台裝置可以連到你的 SwB 伺服器。在 Ubuntu 24.04 上安裝 `bluez`、`git`、`python3-dbus`、`python3-gi` 和 `python3-venv`。

`config/switchboard.yaml` 的 `blocks` 下必須有 `muse: {use: muse}`。你也需要以擁有者身分登入 SwB。

## 複製設定提示詞

<SetupPrompt name="muse" lang="zh-Hant" />

把提示詞貼給你的代理。代理會帶你完成其餘步驟。

## 你的步驟

<Steps>
<Step>
### 產生橋接權杖

在密碼管理工具中產生 64 個隨機英文字母和數字。這就是橋接權杖。
</Step>
<Step>
### 儲存橋接權杖

在代理給你的 SwB 領取連結中，把橋接權杖貼到 **Token**。點選 **Save token**。
</Step>
<Step>
### 開啟 Meta 權杖頁面

開啟 [https://gadgets.muse.ai/settings/sdk-tokens](https://gadgets.muse.ai/settings/sdk-tokens)。點選 **Log in**，使用 Muse App 的帳號。
</Step>
<Step>
### 產生 Meta 權杖

點選 **I agree to the Gadget SDK Terms** → **Generate token** → **Copy**。把權杖存進密碼管理工具。
</Step>
{/* unverified */}
<Step>
### 安裝橋接程式

在 Linux 裝置上執行下方的指令。將最後一條指令中的位址換成你的 SwB 位址。
</Step>
<Step>
### 輸入兩個權杖

在 **SwB bridge token from the claim** 輸入橋接權杖。在 **Personal Meta Gadget SDK token** 輸入 Meta 權杖。
</Step>
<Step>
### 開啟開發人員模式

在 Muse App 中點選 **Settings** → **Devices** → **Developer mode**。將它開啟。
</Step>
<Step>
### 新增裝置

在 **Devices** 中點選 **Add Device**。選擇 SwB 在 Linux 裝置上顯示的藍牙名稱。
</Step>
<Step>
### 確認配對

確認關於社群裝置的提醒。如果 App 詢問 Wi-Fi，請選擇 SwB 顯示的網路。
</Step>
{/* unverified */}
</Steps>

```sh
/usr/bin/python3 -m venv --system-site-packages .venv-muse
.venv-muse/bin/pip install swb-one 'musegadget @ git+https://github.com/facebookincubator/muse-gadget-sdk.git@a5f809f621c4cbdbd37336fe17e7cdb74cebf3fe#subdirectory=linux'
.venv-muse/bin/swb muse-bridge --url https://swb.example.com --setup
```

讓橋接程式持續執行。橋接就緒後，終端機會顯示 **SwB is ready for Muse messages.**。

## 代理的工作

代理呼叫 `connect`，參數為 `what="muse"`。SwB 回傳橋接權杖的領取連結和你的步驟。它會追蹤權杖、橋接狀態和 Muse 的第一則回覆。

橋接上線後，代理再次呼叫 `connect`。它用 `send` 傳送測試給 `muse:gadget:muse`，再用 `result` 讀取答覆。之後的訊息用 `send` 加上 `to="muse"` 傳給 Muse，或透過指向 `muse:gadget:muse` 的路由傳送。

要更換橋接權杖，代理呼叫 `connect`，參數為 `what="muse"` 和 `choose={"replace":true}`。

## 憑證

| 權杖 | 顯示位置 | 格式 | 填寫位置 |
| --- | --- | --- | --- |
| 橋接權杖 | 你在密碼管理工具中產生 | 64 個英文字母和數字 | SwB 領取連結，接著是 Linux 裝置上的隱藏提示 |
| Meta Gadget SDK 權杖 | [https://gadgets.muse.ai/settings/sdk-tokens](https://gadgets.muse.ai/settings/sdk-tokens)，只顯示一次 | 以 `mgst_` 開頭 | 只填在 Linux 裝置上的隱藏提示 |

Meta 權杖只留在 Linux 裝置上。SwB 只保存橋接權杖。

## 檢查連線

確認 Muse App 的 **Devices** 中有 **SwB**。請代理再次呼叫 `connect` 並傳送測試。`result` 中出現真正的回覆，就代表連線正常。

## 排解問題

裝置重新啟動後，在原目錄執行 `.venv-muse/bin/swb muse-bridge --url https://swb.example.com`。要重新配對，請加上 `--setup --pair-again`。

Meta 的配對時限是十分鐘。請在你信任的網路中配對。

裝置離線時，SwB 會保留訊息，等裝置回來再傳送。重新傳送訊息前，請先在 Muse 中查看。
