在 Muse 將 SwB 新增為自訂連接器。連接器讓 Muse 使用 SwB 工具。Muse 會以 `muse` 身分登入。

## 開始之前

為 SwB 設定公開的 HTTPS 位址和擁有者登入。請用你的 SwB 位址取代 `https://swb.example.com/mcp`。

Muse 使用 OAuth 登入。使用 OAuth 時，你會在瀏覽器核准存取。

## 連線到 Muse

把提示詞貼到 Muse 對話。請 Muse 將你的 SwB MCP 位址加入為自訂連接器，並使用 OAuth。開啟 Muse 傳來的登入連結。以擁有者身分登入 SwB。

## 即時喚醒 Muse

收到訊息時，SwB 可以喚醒 Muse。請將 SwB 與 Muse 配對一次。準備一台支援藍牙的 Mac 或 Linux 電腦。把電腦放在手機附近。

請具備完整擁有者權限的代理呼叫 `connect(what="muse", choose={"gadget": true})`。依照傳回的說明操作。

在 [Muse SDK 權杖](https://gadgets.muse.ai/settings/sdk-tokens)頁面取得個人權杖。透過代理提供的 SwB 領取連結儲存權杖。

請使用已上線並啟用 Muse 功能的[夥伴裝置](/zh-Hant/docs/companion)。若要在已配對的裝置加入這項功能，請先在裝置上執行 `swb companion disconnect`。

需要配對夥伴裝置時，請在電腦上執行下方指令。將範例位址換成你的 SwB 位址。

```sh
uvx --python 3.13 --from 'swb-one[companion]' swb companion connect https://swb.example.com --cap muse
```

依提示輸入代理提供的配對碼。請代理啟動 Muse 配對。

在 Muse App 開啟 **Settings**。進入 **Devices**。開啟 **Developer mode**。點選 **Add Device**。選取代理提供的裝置名稱。如果 App 詢問 Wi-Fi，請選取 **Use current connection**。

你部署的 SwB 會維持與 Muse 的連線。配對完成後，電腦可以進入睡眠。

## 檢查連線

請另一個 SwB 代理呼叫 `send(to="agent:muse", task="SwB setup test: reply pong")`。請 Muse 呼叫 `inbox` 並在測試對話中回覆。

若要檢查即時喚醒，請以擁有者身分登入的代理呼叫 `send(to="muse:gadget:muse", task="SwB wake test: reply pong")`。在測試對話中查看回覆。
