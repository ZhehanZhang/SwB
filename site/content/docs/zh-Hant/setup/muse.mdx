Muse 以代理 `muse` 的身分登入 SwB。它的收件匣位址是 `agent:muse`。

## 開始之前

為 SwB 設定公開的 HTTPS 位址與擁有者登入。Muse 透過 Streamable HTTP 連線到 `https://swb.example.com/mcp`。請將範例位址換成你的 SwB 位址。

Muse 使用 OAuth 2.1 登入，採用 PKCE S256 與動態用戶端註冊。回呼網址是 `https://agent.meta.ai/api/hatch/oauth/callback`。

## 連線到 Muse

在 Muse 對話中，請 Muse 將你的 SwB MCP 位址加入為自訂連接器，並使用 OAuth。開啟 Muse 傳來的登入連結。以擁有者身分登入 SwB。

## Muse 的工作

Muse 自行保管 OAuth 權杖。每次開始對話時，Muse 會呼叫 `inbox` 查看 SwB 收件匣。它用 `get_message` 讀取訊息，再用 `reply(..., final=true)` 回覆。它用 `send` 將工作交給其他代理。

## 即時喚醒 Muse

收到訊息時，SwB 可以喚醒 Muse。請將 SwB 與 Muse 配對一次。準備一台支援藍牙的 Mac 或 Linux 電腦。把電腦放在手機附近。

請以擁有者身分登入的代理呼叫 `connect(what="muse", choose={"gadget": true})`。依照代理提供的說明操作。

在 [Muse SDK 權杖](https://gadgets.muse.ai/settings/sdk-tokens)頁面取得個人權杖。透過代理提供的 SwB 領取連結儲存權杖。

請使用已上線且啟用 Muse 功能的[夥伴裝置](/zh-Hant/docs/companion)。若要在已配對的裝置加入這項功能，請先中斷該裝置的連線。

需要配對夥伴裝置時，請在電腦上執行下方指令。將範例位址換成你的 SwB 位址。

```sh
uvx --python 3.13 --from 'swb-one[companion]' swb companion connect https://swb.example.com --cap muse
```

依提示輸入代理提供的配對碼。請代理啟動 Muse 配對。

在 Muse App 中開啟 **Settings**。進入 **Devices**。開啟 **Developer mode**。點選 **Add Device**。選取代理告訴你的裝置名稱，例如 `MuseGadget5C9C67`。如果 App 詢問 Wi-Fi，請選取 **Use current connection**。

你部署的 SwB 會維持與 Muse 的連線。配對完成後，電腦可以進入睡眠。

## 檢查連線

若要檢查連接器，請另一個 SwB 代理呼叫 `send(to="agent:muse", task="SwB setup test: reply pong")`。在 Muse 對話中，請 Muse 呼叫 `inbox`。在測試對話中查看回覆。

若要檢查即時喚醒，請以擁有者身分登入的代理呼叫 `send(to="muse:gadget:muse", task="SwB wake test: reply pong")`。在測試對話中查看回覆。
