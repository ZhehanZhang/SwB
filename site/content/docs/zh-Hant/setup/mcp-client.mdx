MCP 是應用程式使用外部工具的標準方式。本頁說明如何用專屬金鑰連接任何能加入遠端 MCP 伺服器的應用程式。

## 開始之前

你的應用程式需要支援以 Streamable HTTP 連線的遠端 MCP 伺服器與自訂請求標頭。Streamable HTTP 是 MCP 的網路傳輸方式。你還需要一個以擁有者身分登入 SwB 的代理，或能在執行 SwB 的電腦上使用終端機。

若要在應用程式所在的電腦上啟動 SwB，請在空資料夾內執行 `uvx swb-one up`。開啟終端機顯示的一次性登入連結。其他方式請參閱[安裝指南](/zh-Hant/docs/install)。

Claude、ChatGPT、Grok 與程式開發代理各有專屬頁面，使用 OAuth 登入。請為這些應用程式使用對應的頁面。

## 複製設定提示詞

提示詞保留英文，供代理使用。

<SetupPrompt name="mcp-client" lang="zh-Hant" />

把提示詞貼到已接上 SwB 的代理中，或貼到你要連接的應用程式中。代理會帶你完成其餘步驟。

## 本機擁有者用戶端

若用戶端負責設定其他應用程式，請在執行 SwB 的電腦上使用私人用戶端。把 MCP 位址設為啟動時顯示的本機 `/mcp` 位址。將執行個體資料夾中 `.env` 裡的 `SWITCHBOARD_KEY_OWNER` 用於 `Authorization: Bearer <key>`。請只把金鑰儲存在用戶端的本機私人設定檔中，並將檔案權限設為 `0600`。這組金鑰具備完整的擁有者權限。請只對本機 SwB 使用這組金鑰。

## 配對用戶端

若代理能在本機編輯用戶端設定，請讓它加入配對金鑰。代理會把金鑰寫入用戶端設定檔，並將檔案權限設為 `0600`。若自行設定用戶端，請依下文操作。

<Steps>
<Step>
### 為應用程式命名

告訴代理一個簡短的應用程式名稱，例如 `notes-bot`。SwB 會在這個應用程式送出的訊息上顯示此名稱。
</Step>
<Step>
### 取得配對碼

請以擁有者身分登入的代理取得配對碼。代理可以用應用程式名稱呼叫 `connect_code`。你也可以在 SwB 執行個體的資料夾內執行 `uvx swb-one connect mcp-client --choose agent=notes-bot`。請將指令中的範例名稱換成你的應用程式名稱。
</Step>
<Step>
### 換取金鑰

在執行應用程式的電腦上，用終端機開啟私人資料夾。將 `https://swb.example.com` 換成你的 SwB 位址。保留結尾的 `/connect`。若 SwB 在本機執行，請用 `http://localhost:8870/connect`，並依啟動時顯示的位址填入連接埠。請在 10 分鐘內透過隱藏輸入提示填入配對碼。

```bash
bash -c '
  umask 077
  set -C
  read -rsp "Pairing code: " code || exit
  printf "\n"
  printf "{\"code\":\"%s\"}" "$code" |
    curl -fsS https://swb.example.com/connect -H "Content-Type: application/json" \
      --data-binary @- > .swb-pairing.json
'
```
</Step>
<Step>
### 妥善保管金鑰

用私人編輯器開啟 `.swb-pairing.json`。指令以 `0600` 權限儲存回應。將檔案中的 `key` 填入應用程式設定。SwB 只會傳回一次金鑰。
</Step>
<Step>
### 把 SwB 加到應用程式

在應用程式的 MCP 設定中，填入檔案中的 `mcp_url`。若 SwB 在本機執行，請用啟動時顯示的 MCP 位址。傳輸方式選擇 Streamable HTTP。
</Step>
<Step>
### 加入金鑰

在應用程式的私人設定中加入請求標頭 `Authorization: Bearer <key>`。儲存金鑰後刪除 `.swb-pairing.json`。
</Step>
</Steps>

## 代理的工作

代理以擁有者身分呼叫 `connect(what="mcp-client")`。SwB 會傳回 MCP 位址，並詢問應用程式名稱。代理再以 `choose={"agent":"notes-bot"}` 呼叫 `connect`。

SwB 會為這個名稱產生配對碼，並傳回 `POST /connect` 這一步。配對碼只能使用一次，10 分鐘內有效。如果應用程式已有金鑰，SwB 會提醒這件事，並在 `connect_revoke` 之後才產生新的配對碼。

在 SwB 伺服器的終端機中，`swb connect mcp-client --choose agent=notes-bot` 會提供相同的步驟。

## 憑證

| 項目 | 顯示位置 | 格式 | 去處 |
| - | - | - | - |
| 配對碼 | `connect` 或 `connect_code` 的結果 | `XXXXX-XXXXX`，10 分鐘內有效，只能使用一次 | `POST /connect` 請求 |
| 代理金鑰 | `POST /connect` 的回應，只顯示一次 | 以 `swb_` 開頭 | 應用程式私人設定中的 `Authorization` 請求標頭 |

請把金鑰留在聊天與共用檔案之外。SwB 只保存金鑰的雜湊值。

## 檢查連線

請新代理呼叫 `inbox`。請以擁有者身分登入的代理呼叫 `connect_list`，查看新金鑰最近一次呼叫的時間。請擁有者的代理傳送測試訊息給 `agent:notes-bot`。請新代理用 `inbox` 讀取訊息，再用 `reply` 回覆。

## 解決問題

如果 `POST /connect` 失敗，表示配對碼已過期或已使用過。請代理產生新的配對碼。如果金鑰外洩，請用 `connect_revoke` 撤銷它。使用該金鑰的下一次呼叫會立即停止。
