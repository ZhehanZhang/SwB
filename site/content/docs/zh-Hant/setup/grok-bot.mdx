Grok Bot 是 xAI 的桌面代理應用程式。routine 是儲存好的工作。這項連線使用 Webhook。Webhook 是 SwB 用來啟動 routine 的網址。

## 開始之前

在支援的電腦上安裝 [Grok Bot](https://x.ai/bot)。使用包含 Grok Bot 的方案登入。

為 SwB 設定公開的 HTTPS 位址和擁有者登入。啟用 `grok-routine` 模組。選擇一個 SwB 專案。使用 OAuth 時，你會在瀏覽器核准存取。

加入 SwB 後，把提示詞貼到 Bot 對話。

## 連線到 Grok Bot

### 建立 Bot

使用新手引導建立的 Bot，或在側邊欄用 **+** 選擇 **New Bot**。輸入名稱。選擇 **Create**。

### 開啟 Connect apps

在側邊欄開啟 **Connect apps**。選擇 **Add a custom connector**。

### 輸入位址

在 **Name** 填入 `SwB`。在 **Type** 下方選擇 **Remote HTTPS**。在 **Server URL** 填入 `https://swb.example.com/mcp`。選擇 **Add plugin**。

### 登入

請將 OAuth 用戶端選填欄位留空。若 Grok Bot 開啟 SwB 登入頁面，請以擁有者身分登入。接著核准存取。

### 開啟 routine

在 Bot 對話的 **Details** 開啟 routine。檢查 **Webhook** 觸發條件。

### 儲存 Webhook URL

開啟 Webhook 位址的領取連結。從 routine 複製 **POST to**。把位址貼到 **Webhook URL**。選取 **Save webhook url**。

### 儲存金鑰

開啟 Webhook 金鑰的領取連結。從 routine 複製 **key**。把金鑰貼到 **Token**。選取 **Save token**。

### 告訴 Grok Bot

在 Bot 對話中說已完成。Grok Bot 接著會測試該 routine。

## 代理的工作

請具備擁有者權限的代理呼叫 `connect(what="grok-bot")`。SwB 會傳回 MCP 位址、OAuth 狀態和 routine 提示詞。提示詞會用 Webhook 的 `trust` 欄位判斷哪些請求可以執行。routine 用 `reply` 回覆。

請 Grok Bot 用提示詞建立 routine。在擁有者用戶端呼叫 `connect(what="grok-bot", choose={"name":"<routine>","project":"<project>","auth":"key"})` 登記。SwB 會為位址和金鑰各建立一個領取連結。儲存兩項後，請執行 `connect` 傳回的 `send` 呼叫。

傳送訊息時，SwB 會呼叫 webhook 來啟動 routine。

## 憑證

| 權杖 | 顯示位置 | 格式 | 存放位置 |
| - | - | - | - |
| Webhook URL | routine **Details** 中 **Webhook** 下方的 **POST to** | HTTPS 位址 | 對應 SwB 領取連結的 **Webhook URL** |
| Webhook 金鑰 | routine **Details** 中 **Webhook** 下方的 **key** | 隨機文字 | 對應 SwB 領取連結的 **Token** |
| SwB 登入權杖 | 你登入時由 Grok Bot 取得 | 隨機文字 | 由 Grok Bot 保存 |

領取連結是 SwB 上的一次性私人頁面，一個頁面對應一個權杖。每項內容只貼到對應的領取連結。

## 檢查連線

開啟 routine 的 **Details**。檢查 **Webhook** 觸發條件。在擁有者用戶端再次呼叫 `connect(what="grok-bot")`。狀態列會顯示該 routine。在傳送測試的用戶端呼叫 `inbox` 查看回覆。

## 排除問題

若 OAuth 登入失敗，請用另一個具備擁有者權限的 SwB 用戶端登記 routine。若連接器接受 bearer 金鑰，請使用[配對金鑰](/zh-Hant/docs/setup/mcp-client#配對用戶端)。

複製 **key** 的值。使用預設標頭時，SwB 會加上 `Authorization: Bearer`。

用 `grok-routine:routine:<routine>` 啟動 routine。用 `agent:grok` 傳送到 Grok 信箱。

領取連結只能使用一次，30 分鐘後失效。若要取得新連結，請再次呼叫 `connect`。若要更換已儲存的內容，請呼叫 `connect`，並把 `choose.replace` 設為 `url` 或 `secret`。
