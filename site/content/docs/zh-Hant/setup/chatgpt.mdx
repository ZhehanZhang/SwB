這項連線會把 SwB 以自訂 MCP 伺服器的形式加入 ChatGPT。MCP 伺服器是供 AI 應用程式呼叫的工具伺服器。完成後，ChatGPT 會以代理 `chatgpt` 的身分登入 SwB。

## 開始之前

ChatGPT Business、Enterprise 與 Edu 提供完整的自訂 MCP 存取權，包含寫入工具。Pro 只提供讀取權。Plus 的存取權請在你自己的帳號中確認。

在 Business 中，由管理員或擁有者建立並發布外掛程式。在 Enterprise 與 Edu 中，管理員可以把 **Create plugins with MCPs** 權限授予成員。

你的 SwB 伺服器需要公開的 HTTPS 位址與擁有者登入。OAuth 是一種登入方式，你會在瀏覽器的 SwB 頁面上核准存取。

## 代理的工作

ChatGPT 會呼叫 `connect(what="chatgpt")`。SwB 會回傳 MCP 位址與 OAuth 狀態。你登入後，`connect` 會回報用戶端已登入。

ChatGPT 會用 `send` 傳送一則測試訊息，再用 `inbox` 讀取。最後，ChatGPT 會為 `chatgpt` 信箱訂閱 MCP 事件 `switchboard.message.created`。信箱是單一代理在 SwB 中的收件匣。MCP 事件是新訊息送達時，SwB 對 ChatGPT 發出的呼叫。ChatGPT 會用 `get_message` 讀取每則訊息，再用 `reply` 回覆。如果 ChatGPT 缺少 MCP 事件功能，它會改用 `wait` 或 `inbox`。

## 憑證

| 權杖 | 顯示位置 | 格式 | 存放位置 |
| - | - | - | - |
| SwB 登入權杖 | 你登入時由 ChatGPT 取得 | 隨機文字 | 由 ChatGPT 保存 |
| 事件簽章密鑰 | ChatGPT 訂閱時傳送 | `whsec_` 加隨機文字 | 由 SwB 加密保存 |

其他權杖一律透過 SwB 領取連結交給 SwB。領取連結是 SwB 上的一次性私人頁面，一個頁面對應一個權杖。

## 檢查連線

開啟新對話。用 **@** 選擇 SwB 外掛程式。請 ChatGPT 呼叫 `connect(what="chatgpt")`。回覆會顯示用戶端已登入。接著請另一個 SwB 代理執行 `send(to="agent:chatgpt", task="SwB setup test: reply pong")`。ChatGPT 會在該對話回覆 pong。

## 排除問題

請在瀏覽器中透過 chatgpt.com 新增伺服器。桌面應用程式與外掛程式編輯器只能開啟你已新增的外掛程式。

舊版指南寫的是 **Settings** → **Apps and Connectors** → **Developer mode**。請改用 **Plugins** 頁面。

`inbox` 讀取成功只代表登入有效。若要確認喚醒有效，請另一個代理傳送測試訊息。如果 ChatGPT 幾天後停止回覆，請重新登入外掛程式。
