SwB 可以只用環境變數執行。MCP 模組預設啟用。部分模組會在設定對應變數後啟用。其他設定可寫入 YAML 檔。

## 執行個體

| 變數 | 用途 |
| - | - |
| `SWITCHBOARD_KEY_OWNER` | `swb` 指令使用的擁有者金鑰 |
| `SWITCHBOARD_PUBLIC_URL` | 公開的 HTTPS 位址，例如 `https://swb.example.com` |
| `SWITCHBOARD_DATA_DIR` | 資料夾。`swb up` 的預設值是 `~/.local/share/switchboard`。映像檔使用 `/data` |
| `SWITCHBOARD_OWNER_EMAILS` | OIDC 與 Cloudflare Access 的擁有者電子郵件，以逗號分隔 |
| `SWITCHBOARD_KEY_<NAME>` | 代理 `<name>` 的 bearer 金鑰 |
| `SWITCHBOARD_CONFIG` | 基礎 YAML 檔的路徑 |
| `SWITCHBOARD_OVERLAY` | 私人覆寫檔的路徑 |
| `PORT` | HTTP 連接埠 |

## 模組

| 模組 | 變數 |
| - | - |
| Capy | `CAPY_API_KEY`，傳送時另可使用 `CAPY_API_KEY_SERVICE` 或 `CAPY_API_KEY_AS_<AGENT>` |
| Slack | `SLACK_BOT_TOKEN` 或 `SLACK_USER_TOKEN`、`SLACK_TEAM_ID`，以及 Socket Mode 使用的 `SLACK_APP_TOKEN` |
| Discord | `DISCORD_BOT_TOKEN` |
| Telegram | `TELEGRAM_BOT_TOKEN` |
| GitHub | `GITHUB_WEBHOOK_SECRET` |
| Claude routine | `CLAUDE_ROUTINE_TOKEN` 與 `CLAUDE_ROUTINE_ID` |
| Grok routine | `GROK_ROUTINE_SECRET` 與 `GROK_ROUTINE_URL` |

具名的 Slack 工作區，請把名稱放在 `SLACK_` 之後，例如 `SLACK_SUPPORT_BOT_TOKEN`。具名的 routine 用相同方式處理，例如 `CLAUDE_ROUTINE_TOKEN_DOCS`。

## 設定檔

```bash
swb init
```

`swb init` 會寫入 `config/switchboard.yaml` 與一把擁有者金鑰。這個檔案是選用的。SwB 在 `config/switchboard.yaml` 存在時讀取它。

```yaml
version: 2
public_url: https://swb.example.com
auth:
  owner_emails: [owner@example.com]
blocks:
  mcp: {use: mcp}
  capy: {use: capy, identity: service}
targets:
  aliases: {}
routes:
  - {match: {}, to: capy:captain:<Captain id>}
```

`blocks` 一節優先決定載入哪些模組。省略 `blocks` 時，SwB 依環境變數選擇模組。

## 覆寫檔

覆寫檔是一個私人的 YAML 檔，用來放你自己的名稱、id 與路徑。請放在 `config/local.yaml`，或用 `SWITCHBOARD_OVERLAY` 指定。覆寫檔優先於基礎檔，基礎檔優先於環境變數。對應表會合併。清單會被取代。

鍵中的 `*` 代表一個名稱或清單項目。

## 核心設定

| 設定鍵 | 用途 |
| - | - |
| `version` | YAML 設定格式版本。使用 `blocks` 時設為 `2` |
| `public_url` | SwB 用於 MCP 與 OAuth 的公開 HTTPS 位址 |
| `data_dir` | 資料目錄的路徑。可在此設定，也可用 `SWITCHBOARD_DATA_DIR` |
| `timezone` | 每日計數與限額使用的時區，預設為 `UTC` |
| `turn_cap` | 對話暫停前的輪數，預設為 `200`。設為 `null` 可關閉上限 |
| `blocks` | 要載入的模組，可用模組類型或自訂名稱命名 |
| `agents` | 依名稱設定代理 |
| `agents.*.label` | 代理的顯示名稱 |
| `targets` | 傳送目標的名稱與優先順序 |
| `targets.aliases` | 將簡稱指向目標名稱或位址 |
| `targets.priority` | 目標同名時的選擇順序，例如 `[capy:captain, agent, project]` |
| `routes` | 初始路由。SwB 保留已設定的路由 |
| `routes.*.match` | 要比對的代理或專案。全域路由使用 `{}` |
| `routes.*.to` | 路由相符時的傳送位址 |

## 登入與金鑰

| 設定鍵 | 用途 |
| - | - |
| `auth` | 登入與金鑰設定 |
| `auth.owner_emails` | 可透過 OIDC 或 Cloudflare Access 以擁有者身分登入的電子郵件位址 |
| `auth.cloudflare_access` | Cloudflare Access 登入設定。填寫下方兩項並設定 `auth.owner_emails` |
| `auth.cloudflare_access.team_domain` | Cloudflare Access 團隊網域，也可用 `CLOUDFLARE_ACCESS_TEAM_DOMAIN` 設定 |
| `auth.cloudflare_access.aud` | Access 應用程式的對象標記，也可用 `CLOUDFLARE_ACCESS_AUD` 設定 |
| `auth.redirect_uris` | 允許的 OAuth 回呼位址。這份清單會取代內建清單。用 `/*` 比對路徑及其子路徑 |
| `auth.source_names` | 將 OAuth 主機名稱或用戶端名稱的片段對應到登入時使用的代理名稱 |
| `auth.key_scopes` | 依金鑰名稱設定可存取的記憶範圍，例如 `[project:example]` |
| `auth.inbox_keys` | 為每把金鑰指定唯一可讀取的代理收件匣。內建項目為 `channel: claude-code` |

## 存取權限

| 設定鍵 | 用途 |
| - | - |
| `visibility` | 決定誰能存取各項資源。工具一律維持私有 |
| `visibility.defaults` | 依資源類型設定預設規則。各類型的初始值均為 `private` |
| `visibility.defaults.channel` | 頻道的預設規則 |
| `visibility.defaults.memory` | 記憶範圍的預設規則 |
| `visibility.defaults.route` | 路由的預設規則 |
| `visibility.defaults.target` | 傳送目標的預設規則 |
| `visibility.resources` | 針對指定資源設定規則，例如 `channel:home/#agents`。這些規則優先於該類型的預設規則 |

用 `private` 將存取權限限於擁有者及其代理。用 `shared` 開放存取。填入使用者 ID 或 `workspace:home` 這類項目，即可指定共用對象。透過 `visibility_set` 所做的變更優先於此檔。

## MCP

| 設定鍵 | 用途 |
| - | - |
| `blocks.mcp` | 為 MCP 用戶端提供服務的模組設定 |
| `blocks.mcp.use` | 模組類型，填 `mcp` |
| `blocks.mcp.legacy_aliases` | 保留 `agent_send`、`capy_delegate`、`capy_wait` 和 `capy_reply` 等舊版 MCP 工具名稱。預設為 `true` |
| `blocks.mcp.wait` | 等待回覆的工具呼叫時限 |
| `blocks.mcp.wait.default_s` | 呼叫端省略等待時間時使用的秒數，預設為 `60` |
| `blocks.mcp.wait.max_s` | 最長等待秒數，預設為 `200` |
| `blocks.mcp.wait.agents` | 依代理設定等待時限。Claude Code 預設等待 `45` 秒，最長 `55` 秒 |
| `blocks.mcp.wait.agents.*.default_s` | 該代理預設等待的秒數 |
| `blocks.mcp.wait.agents.*.max_s` | 該代理最長等待的秒數 |

## 記憶與頻道模式

| 設定鍵 | 用途 |
| - | - |
| `memory` | 記憶的 Markdown 副本設定 |
| `memory.mirror` | 控制 Markdown 副本。設為 `false` 可停止更新 |
| `memory.mirror_dir` | 存放 Markdown 副本的目錄 |
| `memory.mirror_debounce_s` | 記憶更新後，寫入副本前等待的秒數，預設為 `2` |
| `modes` | 設定 SwB 如何處理傳入事件 |
| `modes.default` | 預設模式，初始值為 `off` |
| `modes.projects` | 各專案下空間的預設模式 |
| `modes.assist_max_chars` | SwB 為代理指定的 `assist` 回覆字元上限，預設為 `1500` |
| `modes.digest_minutes` | `watch` 模式彙整事件前的等待分鐘數，預設為 `60`。累計 `50` 則事件時也會傳送摘要 |

## 品牌

```yaml
branding:
  display_name: SwB
  accent_color: "#64748b"
```

| 設定鍵 | 用途 |
| - | - |
| `branding` | 設定 SwB 顯示的名稱、圖示與色彩 |
| `branding.display_name` | 顯示名稱，預設為 `SwB` |
| `branding.accent_color` | 主題強調色，格式為 `#RRGGBB` |
| `branding.icon` | 自訂圖示 |
| `branding.logo_assets_dir` | 存放自訂標誌的目錄 |
| `branding.public_identity` | 內部欄位。本版本固定為 `swb` |
