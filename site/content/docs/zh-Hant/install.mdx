title: 安裝
description: 用 uvx、pipx 或 Docker 安裝 SwB。
---

SwB 可在 Linux、macOS 與 Windows 上執行。uvx 與 pipx 安裝方式需要 Python 3.12 或更新版本。Docker 安裝方式需要 Docker。

## 安裝並啟動

使用空資料夾存放 SwB 執行個體。`swb` 指令會用擁有者金鑰以你的身分登入。

<Tabs items={['uvx', 'pipx', 'Docker']}>
  <Tab value="uvx">
    ```bash
    uvx swb-one up
    ```

    uvx 會下載並啟動 SwB。請在五分鐘內開啟終端機顯示的一次性登入連結。執行其他範例時，將開頭的 `swb` 換成 `uvx swb-one`。
  </Tab>
  <Tab value="pipx">
    ```bash
    pipx install swb-one
    swb up
    ```

    pipx 會為目前的使用者安裝 `swb` 指令。請在五分鐘內開啟終端機顯示的一次性登入連結。

    若 pipx 使用較舊的 Python，請執行 `pipx install --python 3.12 swb-one`。
  </Tab>
  <Tab value="Docker">
    ```bash
    (umask 077; set -C; printf 'SWB_KEY_OWNER=%s\nSWB_PUBLIC_URL=http://localhost:8870\n' "$(openssl rand -hex 32)" > .env)
    docker run -d --name swb --env-file .env \
      -e PORT=8870 -p 127.0.0.1:8870:8870 -v swb-data:/data \
      ghcr.io/zhehanzhang/swb:latest
    ```

    這組指令會先建立私有的 `.env`，再啟動容器。映像檔將資料存放在 `/data`。執行 `docker exec swb swb login-link` 取得登入連結。執行其他範例時，將開頭的 `swb` 換成 `docker exec swb swb`。
  </Tab>
</Tabs>

首次在本機執行 `swb up` 時，SwB 會在執行個體的資料夾內建立 `.env`、`config/switchboard.yaml` 和 `data/`。日後可執行 `swb login-link` 取得新連結。

若要在啟動前建立檔案，請先執行 `swb init`。接著執行 `swb up`。另開終端機，在同一個資料夾內執行 `swb login-link`。

`swb up` 預設在 `127.0.0.1` 的 `8870` 連接埠接收連線。預設的本機 MCP 位址是 `http://localhost:8870/mcp`。若要改用其他連接埠，請在終端機或 `.env` 設定 `SWB_PORT`。

用 `swb up --dir ./my-swb` 指定執行個體的資料夾。執行其他指令時，請傳入相同的 `--dir`。連線位址、設定檔與資料夾請參閱[設定](/zh-Hant/docs/config)。

## 檢查伺服器

```bash
curl -fsS http://127.0.0.1:8870/healthz
```

這條指令會以登出狀態查詢，顯示 `status` 和 `version`。執行 `swb status`，或用擁有者金鑰存取 `/healthz`，即可查看模組、運作狀態和缺少的變數。

## 伺服器指令

執行 `swb --help` 可查看各類指令。在任一指令後加上 `--help` 即可查看該指令的選項。

| 指令 | 用途 |
| - | - |
| `swb init` | 寫入私有的擁有者金鑰與基本設定。 |
| `swb up` | 在本機啟動 SwB。 |
| `swb connect` | 取得連線至平台的步驟。 |
| `swb status` | 查看狀態與下一步。 |
| `swb login-link` | 建立一次性的擁有者登入連結。 |
| `swb claim` | 使用領取連結或領取碼儲存憑證。 |
| `swb serve` | 依照設定的主機位址與連接埠執行伺服器。 |
| `swb export DIR` | 將已儲存的記憶匯出為 Markdown 檔案，存入輸出資料夾 `DIR`。 |
| `swb log [--limit N]` | 印出最近的稽核記錄。預設上限為 `50` 筆。 |
| `swb config migrate` | 將第 1 版設定轉為第 2 版格式並印出。 |
| `swb blocks list` | 列出已設定的模組。 |
| `swb blocks show BLOCK` | 顯示指定模組的設定。 |
| `swb blocks check` | 檢查模組設定。 |
| `swb targets` | 列出 `send` 可用的目的地。 |

## 版本

版本發布後，可從 PyPI 取得 `swb-one` 套件，或從 GitHub Container Registry 取得 `ghcr.io/zhehanzhang/swb` 映像檔。若要固定使用某個版本，請指定版本號碼，例如 `1.0.0`。映像檔的 `latest` 標籤指向最新的穩定版本。
