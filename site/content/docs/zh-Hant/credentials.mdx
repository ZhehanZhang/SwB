代理負責設定連線。SwB 需要權杖時，代理會給你**領取連結**。連結會開啟 SwB 主機上的一次性頁面。開啟連結後，將權杖貼到指定欄位。按一下 Save。權杖只會從瀏覽器送到 SwB。

## 領取連結如何運作

代理請求一個連線，例如 Discord。SwB 回傳類似 `https://swb.example.com/claim/...` 的連結。代理把連結交給你。連結只能使用一次，有效時間是 30 分鐘。你必須以擁有者身分登入才能使用它。

![單一權杖的領取頁面](/shots/token-handoff-light.webp)

SwB 在儲存每個值之前會先檢查。它用資料夾中的金鑰封存這個值。之後 SwB 把該值視為模組所需的環境變數。伺服器上的環境變數優先於已儲存的值。

| 頁面 | 用途 |
| - | - |
| `/claim/{code}` | 儲存連線所需的憑證。 |
| `/routines/claim/{code}` | 使用一次性領取連結儲存 Claude 例行程序的權杖。 |
| `/routines/claim/owner/{registration}` | 從代理頁面儲存待領取的 Claude 例行程序權杖。 |

## GitHub 和 Slack 的領取連結

設定 GitHub App 時，每個缺少的值都有自己的領取連結。App ID、私密金鑰和 webhook 密鑰各有一個連結。填寫私密金鑰時，請貼上 `.pem` 檔案的完整內容。

Slack 工作區缺少權杖時，SwB 會提供一個領取連結。表單會依工作區的需要顯示欄位。

## 從終端機領取

```bash
swb claim 'https://swb.example.com/claim/...'
```

指令會用隱藏的提示詢問權杖。它把權杖送到你本機的 SwB 伺服器，或送到你用 `--url` 指定的伺服器。

## 更換憑證

請依模組選擇更換方式。

| 模組 | 更換方式 |
| - | - |
| Grok Bot | 請代理對 `grok-bot` 呼叫 `connect`。指定例行程序名稱，再選用 `replace=url` 或 `replace=secret`。 |
| Muse | 請代理對 `muse` 呼叫 `connect`，用 `replace=true` 更換橋接權杖。 |
| Slack | 工作區設定的權杖有缺漏時，SwB 會提供該工作區的領取連結。 |
| GitHub | SwB 會檢查已儲存的值，並為設定所缺少的每個值提供一個領取連結。 |

若憑證來自伺服器的環境變數，請更新該變數，再重新啟動 SwB。
