---
title: 憑證
description: 在一次性頁面儲存連線憑證。
---

SwB 需要憑證時，代理會給你一個**領取連結**。連結會開啟 SwB 上的一次性表單。瀏覽器會將憑證直接送給 SwB。

## 領取連結如何運作

請以擁有者身分登入後使用連結。連結的有效期限為 30 分鐘，可使用一次。

![單一權杖的領取頁面](/shots/token-handoff-light.webp)

SwB 使用資料夾中的金鑰加密憑證。模組可以用已儲存的值代替環境變數。伺服器上的環境變數優先於已儲存的值。

| 頁面 | 用途 |
| - | - |
| `/claim/{code}` | 儲存連線所需的憑證。 |
| `/routines/claim/{code}` | 使用一次性領取連結儲存 Claude routine 的權杖。 |
| `/routines/claim/owner/{registration}` | 從代理頁面儲存待領取的 Claude routine 權杖。 |

## 儲存憑證

在 Discord、Telegram、Claude routine 和 Grok Bot 的權杖表單中，貼上權杖後選取 **Save token**。在 Grok Bot 的 webhook 表單中，輸入網址後選取 **Save webhook url**。

設定 GitHub App 時，SwB 會為每項待填的憑證提供專用連結。請在對應的表單填寫 **App ID**、**Private key** 或 **Webhook secret**。填寫 **Private key** 時，選取 **Upload .pem file**，或貼上 `.pem` 檔案的完整內容。填寫完畢後選取 **Save**。

更改 GitHub webhook 金鑰後，請重新啟動 SwB。

Slack 工作區缺少權杖時，SwB 會提供一個領取連結。請在同一份表單填寫各個欄位。選取 **Save**。

## 從終端機領取

```bash
swb claim 'https://swb.example.com/claim/...'
```

指令會用隱藏的提示詢問權杖。它把權杖送到你本機的 SwB 伺服器，或送到你用 `--url` 指定的伺服器。

## 更換憑證

請依模組選擇更換方式。

| 模組 | 更換方式 |
| - | - |
| Grok Bot | 請代理對 `grok-bot` 呼叫 `connect`。指定 routine 名稱，再選用 `replace=url` 或 `replace=secret`。 |
| Muse | 請代理對 `muse` 呼叫 `connect`，用 `replace=true` 更換橋接權杖。 |
| Slack | 工作區設定的權杖有缺漏時，SwB 會提供該工作區的領取連結。 |
| GitHub | 請代理呼叫 `connect(what="github", choose={"replace":"secret"})` 更換 webhook 金鑰。`webhook_secret` 的效果相同。用 `all` 一併更換應用程式憑證或個人存取權杖 |

透過伺服器環境變數提供的值，請在環境變數中更新。若透過 `blocks.github.app_id` 設定 App ID，請更新設定檔。更新設定或更換 GitHub webhook 金鑰後，重新啟動 SwB。
