---
title: 工具
description: SwB 提供给你的智能体的 MCP 工具。
---

智能体看到其登录身份允许使用的工具。模块启用时，该模块的工具随之出现。

## 消息

| 工具 | 用途 |
| - | - |
| `send` | 把工作或消息发送给一个目标，或让路由选择目标 |
| `agent_send` | 已弃用的工具名，仅本版本保留。`blocks.mcp.legacy_aliases` 默认启用此名称。新调用请用 `send` 并指定 `to="agent:<name>"` |
| `wait` | 等待你的会话中的下一条答复 |
| `inbox` | 读取你的收件箱并立即返回 |
| `reply` | 回答一条消息，或向会话添加一条消息 |
| `status` | 显示一个会话的状态。查看 Capy 会话时，用 `messages` 指定返回的近期消息条数。用 `include_tools=true` 一并查看工具调用记录 |
| `switchboard_status` | 显示你的登录身份、等待时限、模块和实例运行状况 |
| `result` | 获取一个会话的最终答复。支持 `tail` 的会话可用它指定返回的近期回复或消息条数 |
| `cancel` | 停止跟踪一个会话 |
| `targets` | 列出 `send` 能访问的所有对象 |
| `get_message` | 按 id 读取一条已存储的消息 |

### 发送选项

| 选项 | 用途 |
| - | - |
| `wait_s` | 如果模块返回会话 ID，按指定的秒数等待首条回复。等待上限因客户端而异。智能体收件箱使用 `wait` |
| `forward` | 填入收到的会话 ID。会话须允许转交，且发送方的信任标记须为 `owner`。SwB 会把最终答复交给原发送方 |
| `new_conversation` | 设为 `true` 时，在 Capy Captain 的项目中开启新话题串。设为 `false` 时，发到 Captain 的话题串 |
| `files` | 为 Capy 任务添加附件。每个文件填写 `name`，内容填入 `text` 或 `base64`。用 `media_type` 指定文件类型 |
| `repos` | 用 `owner/repo` 格式指定 Capy 任务涉及的仓库。请选择已关联到 SwB 项目的仓库 |
| `in_reply_to` | 回复消息时，调用 `reply` 并填写 `conversation`。`send` 会拒绝 `in_reply_to` |

## 记忆与项目

| 工具 | 用途 |
| - | - |
| `context_pack` | 获取一个项目的简报 |
| `memory_write` | 保存记忆时，填写 `scope`、`namespace`、`title` 和 `body`。`namespace` 用于在同一范围内归类条目，最多三级，使用小写，例如 `notes/meetings`。保存项目记忆时，将项目简称填入 `project`，并设置 `scope="project:<slug>"`。保存通用记忆时，在所有者同意后设置 `confirm_general=true` |
| `memory_search` | 用 `query` 搜索记忆。默认搜索 `general`。将项目简称填入 `project` 后，优先搜索项目记忆，再搜索 `general`。设为 `include_general=false` 时，只搜索该项目 |
| `memory_list` | 列出记忆条目 |
| `memory_read` | 读取一条记忆及其历史 |
| `memory_delete` | 删除一条记忆 |
| `memory_move` | 把一条记忆移到另一个项目 |
| `memory_promote` | 把一条记忆移到 general |
| `project_list` | 列出项目及其链接 |
| `project_create` | 创建项目 |
| `project_update` | 重命名、链接、归档项目，或把项目设为私有 |
| `project_sync` | 重新把项目链接到它们的匹配项 |

| `connect_code` | 为新智能体生成配对码 |
| `connect_list` | 列出智能体密钥 |

## 路由

路由为 `send` 选择目标。请选择支持路由的模块，例如 `capy`、`claude-routine`、`grok-routine` 或 `muse`。要直接发到智能体的收件箱，请调用 `send` 并指定 `to="agent:<name>"`。

| 工具 | 用途 |
| - | - |
| `routes_list` | 列出所有路由，包括邮箱路由 |
| `routes_set` | 保存路由。将智能体邮箱（例如 `agent:<name>`）或模块地址（例如 `capy:captain:<name>`）填入 `target`。用 `agent` 或 `project` 限定路由的适用范围 |
| `routes_resolve` | 查看某个目的地匹配的路由。将名称填入 `block`，例如 `grok-routine` 或 `agent` |
| `routes_remove` | 按 `agent` 和 `project` 删除指定 `block` 中完全匹配的路由 |

`routes_resolve` 和 `routes_remove` 默认使用首个目的地。它是首个支持路由的模块。没有这类模块时，它是 `agent`。用 `block` 选择其他目的地。

## 模块工具

### Capy

| 工具 | 用途 |
| - | - |
| `capy_captains` | 列出当前 Capy 连接有权访问的 Captain |
| `capy_captain_digest` | 读取 Captain 的摘要并查看正在处理或需要所有者介入的话题串 |
| `capy_list` | 列出通过 SwB 发送的任务。也可查看 Captain 团队或已关联 Capy 项目中的话题串 |
| `capy_delegate` | 将任务发给 Capy。新调用请用 `send` 并指定 `to="capy"` |
| `capy_inbox` | 立即读取 Capy 收件箱。新调用请用 `inbox` 并指定 `block="capy"` |
| `capy_wait` | 等待收件箱中的下一条消息。新调用请用 `wait` |
| `capy_status` | 查看 Capy 话题串的状态和近期消息。新调用请用 `status` |
| `capy_reply` | 向 Capy 话题串发消息。新调用请用 `reply` |
| `capy_result` | 获取 Capy 话题串的最新答复以及可用的文件和拉取请求链接。新调用请用 `result` |
| `capy_cancel` | 停止跟踪发给 Capy 的任务。Capy 仍可继续处理任务。新调用请用 `cancel` |

### Claude Code routine

启用 `claude-routine` 模块后可使用这些工具。routine 是 SwB 可以启动的 Claude Code 任务。

| 工具 | 用途 |
| - | - |
| `routine_register` | 注册 routine，并获取供所有者输入令牌的领取链接 |
| `routine_list` | 列出 SwB 可以启动的 routine |
| `routine_pickup` | 在 routine 的启动提示为空时，领取待处理的消息 |
| `routine_add` | 以所有者身份使用令牌添加 routine |
| `routine_remove` | 以所有者身份删除通过 SwB 保存的 routine |

### Slack

| 工具 | 用途 |
| - | - |
| `slack_workspaces` | 列出可用的 Slack 工作区、每个工作区的可用账号及发消息的规则 |
| `slack_channels` | 列出所选 Slack 账号可见的频道。结果会标明 SwB 正在关注的频道 |
| `slack_search` | 使用所有者的 Slack 账号搜索工作区中的消息 |
| `slack_history` | 读取频道近期的消息。最新消息排在前面 |
| `slack_thread` | 按时间顺序读取话题串的首条消息及其回复 |
| `slack_watched` | 列出会将新消息送到你的 SwB 收件箱的频道 |
| `slack_events` | 查看关注频道中的近期消息、对机器人的提及和私信。最新消息排在前面 |
| `slack_wait` | 等待你的收件箱收到下一条 Slack 消息 |
| `slack_personas` | 查看机器人发消息时可用的名称和头像以及默认选项 |
| `slack_targets` | 列出在 Slack 提及机器人后可填写的目标名称 |
| `slack_post` | 以机器人或所有者的 Slack 账号发消息。用 `thread_ts` 在话题串中回复。发消息的规则可能要求所有者审批 |
| `slack_react` | 用表情回应消息。此操作遵循与 `slack_post` 相同的规则 |
| `slack_request_write` | 将拟发送的 Slack 消息提交给所有者审批 |
| `slack_write_requests` | 查看你的 Slack 审批申请状态。用 `request_id` 查看单条申请 |
