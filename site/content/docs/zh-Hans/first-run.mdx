## 在本机运行

在空目录中运行 `uvx swb-one up`。请在五分钟内打开终端显示的一次性登录链接。SwB 默认使用 `http://localhost:8870`。如果设置了 `PORT`，SwB 会在地址中使用该端口。其他启动方式见[安装指南](/zh-Hans/docs/install)。

## 获取公网地址

Claude、ChatGPT 和 Grok 在云端运行。它们需要公网 HTTPS 地址来访问 SwB。隧道为本机的 SwB 提供公网地址。

安装 [cloudflared](https://developers.cloudflare.com/tunnel/downloads/)。确认终端可以运行 `cloudflared --version`。如果 SwB 正在运行，请先停止。在 SwB 实例目录中运行以下命令。

```bash
uvx swb-one up --tunnel cloudflare
```

SwB 会启动 Cloudflare Quick Tunnel，并显示公网 MCP 地址。使用此选项重新启动时，地址每次都会变更。请更新各应用中的地址。

如需使用 Tailscale，请[安装并登录 Tailscale](https://tailscale.com/download)。启用 [Funnel](https://tailscale.com/docs/features/tailscale-funnel)。确认终端可以运行 `tailscale version`。将上方命令的选项改为 `--tunnel tailscale`。

要在自己的域名上使用固定地址，请阅读[自托管](/zh-Hans/docs/self-hosting)。

## 查看下一步

```bash
swb status
```

命令会显示服务器状态，以及每个模块是否开启。所有后续操作都列在 **Next steps** 下。`switchboard_status` 工具还会提供各模块的下一步。

要查询其他地址上的服务器，请加上 `--url`，例如 `swb status --url http://127.0.0.1:8871`。命令用终端或实例 `.env` 中的 `PORT` 组成默认本机地址。若启动时用了 `--dir`，查询时也请指定同一实例目录。

## 登录 SwB 页面

SwB 页面显示你的项目、智能体、收件箱、记忆和审计日志。它也是粘贴令牌的安全位置。

![SwB 登录页面](/shots/login-light.webp)

如需获取新链接，请另开一个终端，在同一实例目录中运行以下命令。

```bash
swb login-link
```

命令会打印一次性登录链接。请在五分钟内用浏览器打开。和 `swb status` 一样，这条命令也接受 `--url` 和 `--dir`。首次登录后请添加通行密钥。之后用通行密钥登录。设置码及其他方式见[所有者登录](/zh-Hans/docs/owner-login)。

## 网页控制台

| 页面 | 用途 |
| - | - |
| `/` | 查看服务器状态和项目列表。 |
| `/agents/*` | 查看已注册的智能体和各自的详情。 |
| `/audit` | 按类型筛选变更记录和其他事件。 |
| `/inbox` | 查看会话和待处理的请求。 |
| `/inbox/:handle` | 阅读单个会话中的消息。 |
| `/memory/*` | 浏览和搜索已保存的笔记。 |
| `/projects/:slug` | 查看单个项目的路由、历史、会话和记忆。 |
| `/connections/:platform` | 查看 Slack、Discord、Telegram 或 GitHub 的连接状态和 [**Channel modes**](/zh-Hans/docs/channel-modes)。 |
| `/settings` | 查看服务器设置并管理通行密钥。 |
| `/tokens` | 查看令牌请求和已保存的凭据。 |
| `/about` | 查看 SwB 版本和已启用的模块。 |

## 连接第一个智能体

如果要让第一个智能体设置其他应用，请给它所有者权限。对于托管应用，请在 SwB 页面批准 OAuth 登录。OAuth 让你在浏览器中批准应用访问。请选择可访问所有范围、工具和目标的应用。

也可以在运行 SwB 的电脑上设置[本机所有者客户端](/zh-Hans/docs/setup/mcp-client#本机所有者客户端)。将实例目录中 `.env` 里的 `SWITCHBOARD_KEY_OWNER` 用作客户端的 bearer 密钥。请只把密钥发送到本机的 `/mcp` 地址。

如果第一个智能体用的是配对密钥，请让它为每个仅限所有者的步骤提供对应的终端命令。在 SwB 实例目录中运行该命令。例如，运行 `swb connect slack`。[连接你的智能体](/zh-Hans/docs/connect)介绍其他应用的连接方法。
