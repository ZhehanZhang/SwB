## 在本机运行

要在本机浏览器登录，请在启动前设置 `SWITCHBOARD_PUBLIC_URL=http://localhost:8870`。地址中的端口须与 `PORT` 一致。如果 YAML 配置已设置 `public_url`，请在那里修改。[安装指南](/zh-Hans/docs/install)使用端口 8870 设置本机登录。

## 获取公网地址

Claude、ChatGPT 和 Grok 在云端运行。它们需要一个公网 HTTPS 地址来访问 SwB。启动 SwB 时加上隧道，即可获得该地址。

```bash
swb up --tunnel cloudflare
```

SwB 会打开 Cloudflare Quick Tunnel，并打印公网 MCP 地址。使用 `--tunnel tailscale` 可改用 Tailscale Funnel。要在自己的域名上使用固定地址，请阅读[自托管](/zh-Hans/docs/self-hosting)。

## 查看下一步

```bash
swb status
```

命令会显示服务器状态，以及每个模块是否开启。所有后续操作都列在 **Next steps** 下。`switchboard_status` 工具还会提供各模块的下一步。

要查询其他地址上的服务器，请加上 `--url`，例如 `swb status --url http://127.0.0.1:8871`。命令用终端或实例 `.env` 中的 `PORT` 组成默认本机地址。若启动时用了 `--dir`，查询时也请指定同一实例目录。

## 登录 SwB 页面

SwB 页面显示你的项目、智能体、收件箱、记忆和审计日志。它也是粘贴令牌的安全位置。

![SwB 登录页面](/shots/login-light.webp)

```bash
swb login-link
```

命令会打印一次性登录链接。请在五分钟内用浏览器打开。和 `swb status` 一样，这条命令也接受 `--url` 和 `--dir`。首次登录后请添加通行密钥。之后用通行密钥登录。设置码及其他方式见[所有者登录](/zh-Hans/docs/owner-login)。

## 网页控制台

| 页面 | 用途 |
| - | - |
| `/` | 查看服务器状态和项目列表。 |
| `/agents/*` | 查看已注册的智能体和各自的详情。 |
| `/audit` | 按类型筛选变更记录和其他事件。 |
| `/inbox` | 查看对话和待处理的请求。 |
| `/inbox/:handle` | 阅读单个对话中的消息。 |
| `/memory/*` | 浏览和搜索已保存的笔记。 |
| `/projects/:slug` | 查看单个项目的路由、历史、对话和记忆。 |
| `/connections/:platform` | 查看 Slack、Discord、Telegram 或 GitHub 的连接状态和频道模式。 |
| `/settings` | 查看服务器设置并管理通行密钥。 |
| `/tokens` | 查看令牌请求和已保存的凭据。 |
| `/about` | 查看 SwB 版本和已启用的模块。 |
