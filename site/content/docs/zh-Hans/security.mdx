## 一位所有者

SwB 只有一位所有者。只有所有者能批准智能体登录、打开 SwB 页面和粘贴令牌。所有者自己的智能体代表所有者行事。

## 智能体登录

SwB 是面向一位所有者的独立 OAuth 2.1 服务器。它使用带 S256 的 PKCE，并把每个令牌绑定到你的 `/mcp` 地址。访问令牌的有效期为一小时。刷新令牌的有效期为 30 天，每次使用后轮换。SwB 只存储令牌的 SHA-256 哈希。其他智能体使用 bearer 密钥或配对码。

## 信任等级

SwB 依据平台自己的 id 设定每条消息的信任等级。信任等级只由 id 决定。

| 信任等级 | 对象 |
| - | - |
| `owner` | 你，以及你自己已登录的智能体 |
| `known` | 你在 `known` 中列出的人和机器人 |
| `external` | 所有其他人 |

SwB 原样传递所有者的文本。对于其他发送者，SwB 会替换正文中的消息头或标记。然后，SwB 为正文添加自己的消息头和标记 `<<<swb-untrusted` 与 `swb-untrusted>>>`。智能体把标记内的文本视为信息。

## 可见性

每个资源是私有或共享的。资源是目标、频道、记忆范围、路由或工具。每个资源起初都是私有的，只有所有者能访问。你可以把资源共享给一个工作区，或共享给一份人员列表。只有频道和目标都已共享时，所有者以外的人才能访问该目标。所有者以外的人发出的其他消息成为上下文项。上下文项作为信息进入收件箱，智能体保持休眠。

## 有限制的密钥

bearer 密钥可以带限制。`auth.key_scopes` 限制密钥的记忆范围。`auth.key_tools` 限制它的工具。`auth.key_targets` 限制它能发送到哪里。

## 令牌

令牌只通过领取链接传递。SwB 用数据目录中的密钥加密已保存的令牌。状态页显示所缺变量的名称，并隐藏它们的值。Capy 密钥只通过请求头发送到 `api.capy.ai`。

## 限制

| 限制 | 数值 |
| - | - |
| 错误的 bearer 令牌 | 每个地址 10 分钟内 20 次，之后返回 429 |
| `/register` | 每个地址每小时 20 次 |
| `/token` | 每个地址 10 分钟内 120 次 |
| `/authorize` | 每个地址 10 分钟内 60 次 |
| 请求正文 | 1 MiB，`/mcp` 为 16 MiB |
| 每个智能体会话的轮数 | 200 |

Bearer 令牌限额按地址计算。同一地址上的所有密钥均受影响，有效密钥也一样。限额解除前，受 bearer 令牌保护的接口会返回 `429`。

会话达到轮数上限时会暂停。SwB 会通知所有者。

Capy 和 Muse 可以在收到重复请求时返回已有会话。Capy 用 `duplicate_window_s` 设置时间范围，默认值为 600 秒。Muse 的时间范围为 600 秒。

## 审计日志

在 SwB 页面打开 **Audit** 查看记录。运行 `swb log` 可输出最近的记录。发送到收件箱的操作记为 `send`。

## 报告问题

请通过 [SwB 仓库](https://github.com/ZhehanZhang/SwB/security)的 GitHub 私有漏洞报告功能报告安全问题。
