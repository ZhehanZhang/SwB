## 一位所有者

SwB 有一位所有者。所有者批准智能体登录，并在 SwB 控制台管理访问权限和保存令牌。

## 智能体登录

OAuth 让应用在所有者批准后登录。SwB 用采用 S256 算法的 PKCE 确认登录由同一个应用发起并完成。每个 OAuth 令牌都绑定到一个 `/mcp` 地址。访问令牌默认有效一小时，刷新令牌默认有效 30 天。SwB 在刷新令牌使用后发放新令牌。SwB 保存 OAuth 令牌的 SHA-256 哈希，并用它核对令牌。智能体也可以使用预先配置的密钥，或用配对码换取密钥。

## 信任等级

SwB 根据平台提供的发送者 ID 判定消息的信任等级。

| 信任等级 | 对象 |
| - | - |
| `owner` | 你和以你的身份登录的智能体 |
| `external` | 其他发送者，包括 `known` 中的人员和机器人 |

Slack、Discord 和 Telegram 用 `known` 帮助 SwB 判断接收哪些发送者的消息。这些外部发送者的消息仍标为 `external`。GitHub 作者的判断规则见[所有者账号](/zh-Hans/docs/blocks/github#所有者账号)。

**信任框**由 SwB 为外部文字添加的消息头和一对标记组成。SwB 先替换正文中仿写的消息头和标记，再加上信任框。标记是 `<<<swb-untrusted` 和 `swb-untrusted>>>`。智能体仅把标记内的文字当作参考信息。

观察模式的摘要标为 `external`。每条摘录里的外部文字都带有信任框。SwB 按 GitHub 各字段的作者判断信任等级。

[伴侣设备](/zh-Hans/docs/companion)的密钥仅用于该设备的连接。SwB 只保留密钥的哈希，用来验证密钥。SwB 将设备返回结果标记为 `external`，并为结果中的自由文本加上信任框。

## 可见性

目标、频道、记忆范围、路由和工具都属于资源。访问规则默认为 `private`，供所有者及其智能体使用。你可以将资源共享给指定工作区或人员。工具始终为私有。频道和目标的规则都放行时，外部发送者可联系该目标。SwB 将作为背景资料保存的消息发到收件箱。智能体保持休眠。

## 有限制的密钥

`auth.key_scopes` 限制路由、消息和会话的访问范围。配对密钥只能在这些范围内读取所属智能体的消息和会话。

SwB 按配对密钥保存记忆授权。迁移旧授权时，SwB 为原本权限较宽的有效配对密钥授予 `general` 和当时已有的项目权限。如在 `auth.key_scopes` 中指定了范围，SwB 会复制这些范围。

权限完整的 OAuth 客户端或配置密钥可用所有者权限访问全部记忆。用 `auth.key_scopes` 按智能体名称限制记忆访问。受限凭据需要针对私有项目的授权。

`auth.key_tools` 限制密钥可调用的工具。`auth.key_targets` 限制发送目标。

## 令牌

在领取页面输入令牌。SwB 用数据目录里的密钥加密保存的令牌。状态只列出缺少的变量名，隐藏变量值。默认情况下，Capy 密钥随请求头发给 `api.capy.ai`。

打开 **Tokens** 查看各配对密钥的记忆授权。在对应范围旁选择 **Remove scope** 撤销该项授权。

配对码兑换成功后，新密钥可访问所属智能体的记忆。它也可访问配对码指定的项目及 `auth.key_scopes.<agent>` 指定的范围。要扩大访问权限，先设置额外的范围，或在配对码中指定项目。然后配对一个新密钥。

## 限制

| 限制 | 数值 |
| - | - |
| bearer 密钥验证失败 | 每个地址 10 分钟内可失败 20 次，之后返回 HTTP `429` |
| SwB 为所有者之外的发送者转发的 GitHub 事件 | 每个发送者在最近 10 分钟内最多 5 个事件 |
| `/register` | 每个地址每小时 20 次 |
| `/token` | 每个地址 10 分钟内 120 次 |
| `/authorize` | 每个地址 10 分钟内 60 次 |
| `/companion/pair` 配对码错误 | 每个地址 10 分钟内可输错 10 次，之后返回 HTTP `429` |
| `/connect` 配对码错误 | 每个地址 10 分钟内可输错 10 次，之后返回 HTTP `429` |
| 请求正文的默认上限 | 1 MiB |
| `/mcp` 和 `/companion/results` 的请求正文 | 16 MiB |
| `/companion/emit` 的请求正文 | 16,640 字节 |
| `/auth/setup` 的请求正文 | 1,024 字节 |
| 每个智能体会话的轮数 | 200 |

同一地址的有效密钥也会受到 bearer 密钥限额的影响。限额解除前，受影响的接口返回 HTTP `429`。

会话达到轮数上限时，SwB 暂停会话并写入审计日志。Slack 启用时，SwB 会向所有者发送私信。

同一任务发往同一目标时，Capy 模块可返回之前的会话。用 `blocks.capy.duplicate_window_s` 设置比对时间，默认值为 600 秒。

## 客户端地址

SwB 默认按连接地址限制请求次数并记录操作。把代理加入 `trusted_proxies` 或 `SWB_TRUSTED_PROXIES`。SwB 随后会使用该代理提供的客户端地址。请配置代理，让它用核实过的地址填写客户端地址请求头。

参照[自托管指南](/zh-Hans/docs/self-hosting#受信任的代理)添加 Docker 网络中的 Cloudflare 隧道连接器或反向代理。

## 审计日志

工具调用因访问规则被拒时，SwB 会记入审计日志。浏览器登录失败也会留下记录，涵盖设置码、已用链接、过期链接、无效链接、通行密钥、CSRF 检查和 OIDC。

GitHub webhook 缺少签名或签名有误时，SwB 会记录原因。部分浏览器错误和 webhook 拒绝记录会限制重复次数。设置码、令牌和签名保持私密。

在 SwB 控制台打开 **Audit** 查看记录。运行 `swb log` 可输出近期记录。发往收件箱的操作记为 `send`。关于丢弃的消息，请参阅[频道模式](/zh-Hans/docs/channel-modes#检查消息投递)。
