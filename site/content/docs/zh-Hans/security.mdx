## 一位所有者

SwB 只有一位所有者。只有所有者能批准智能体登录、打开 SwB 页面和粘贴令牌。所有者自己的智能体代表所有者行事。

## 智能体登录

SwB 是面向一位所有者的独立 OAuth 2.1 服务器。它使用带 S256 的 PKCE，并把每个令牌绑定到你的 `/mcp` 地址。访问令牌的有效期为一小时。刷新令牌的有效期为 30 天，每次使用后轮换。SwB 只存储令牌的 SHA-256 哈希。其他智能体使用 bearer 密钥或配对码。

## 信任等级

SwB 根据平台提供的发送者 ID 判定消息的信任等级。

| 信任等级 | 对象 |
| - | - |
| `owner` | 你和以你的身份登录的智能体 |
| `external` | 其他发送者，包括 `known` 中的人员和机器人 |

在 Slack、Discord 和 Telegram 中，`known` 是接收设置。SwB 用它判断接收哪些发送者的消息。所有者之外的发送者即使通过 `known` 获准，消息的信任等级仍为 `external`。GitHub 按每段文字的作者判断信任等级，详见[所有者账号](/zh-Hans/docs/blocks/github#所有者账号)。

**信任框**由 SwB 为外部文字添加的消息头和一对标记组成。SwB 先替换正文中仿写的消息头和标记，再加上信任框。标记是 `<<<swb-untrusted` 和 `swb-untrusted>>>`。智能体仅把标记内的文字当作参考信息。

观察模式的摘要标为 `external`。每条摘录中的外部文字也带有信任框。GitHub 按每个文字字段的作者判定。

## 可见性

每个资源是私有或共享的。资源是目标、频道、记忆范围、路由或工具。每个资源起初都是私有的，只有所有者能访问。你可以把资源共享给一个工作区，或共享给一份人员列表。只有频道和目标都已共享时，所有者以外的人才能访问该目标。所有者以外的人发出的其他消息成为上下文项。上下文项作为信息进入收件箱，智能体保持休眠。

## 有限制的密钥

`auth.key_scopes` 限制路由、消息和会话的访问范围。配对密钥只能在这些范围内读取所属智能体的消息和会话。

SwB 为每把配对密钥单独保存记忆授权。升级时，原先可访问全部记忆的有效配对密钥会获得 `general` 和当时已有的每个项目范围。密钥若有明确的 `auth.key_scopes` 列表，SwB 会复制该列表。SwB 在升级时保存这组授权。其他项目需要单独授权。

所有者批准的 OAuth 客户端和配置密钥默认拥有全部记忆访问权限。`auth.key_scopes` 中对应名称的条目会限制这项权限。

`auth.key_tools` 限制密钥可调用的工具。`auth.key_targets` 限制发送目标。

## 令牌

令牌仅通过领取链接提交。SwB 使用数据目录中的密钥加密保存的令牌。状态只显示缺失的变量名。Capy 密钥仅通过请求头发送到 api.capy.ai。

所有者可在令牌页面查看各配对密钥的记忆授权。点击某个范围旁的移除按钮，即可撤销该范围的授权。

配对密钥在兑换配对码时一次性获得授权。要扩大某个密钥的访问范围，请设置 `auth.key_scopes.<agent>`，或在配对码中指定项目，然后配对一个新密钥。令牌页面只能缩小访问范围。

## 限制

| 限制 | 数值 |
| - | - |
| 错误的 bearer 令牌 | 每个地址 10 分钟内 20 次，之后返回 429 |
| SwB 为所有者之外的发送者转发的 GitHub 事件 | 每个发送者在最近 10 分钟内最多 5 个事件 |
| `/register` | 每个地址每小时 20 次 |
| `/token` | 每个地址 10 分钟内 120 次 |
| `/authorize` | 每个地址 10 分钟内 60 次 |
| 请求正文 | 1 MiB，`/mcp` 为 16 MiB |
| 每个智能体会话的轮数 | 200 |

Bearer 令牌限额按地址计算。同一地址上的所有密钥均受影响，有效密钥也一样。限额解除前，受 bearer 令牌保护的接口会返回 `429`。

会话达到轮数上限时会暂停。SwB 会通知所有者。

Capy 收到重复请求时可以返回已有会话。用 `duplicate_window_s` 设置时间范围，默认值为 600 秒。

## 审计日志

工具调用因访问规则被拒时，SwB 会记入审计日志。浏览器登录失败也会留下记录，涵盖设置码、已用链接、过期链接、无效链接、通行密钥、CSRF 检查和 OIDC。

GitHub webhook 缺少签名或签名有误时，SwB 会记录原因。部分浏览器错误和 webhook 拒绝记录会限制重复次数。设置码、令牌和签名保持私密。

在 SwB 页面打开 **Audit** 查看记录。运行 `swb log` 可输出最近的记录。发送到收件箱的操作记为 `send`。消息投递被丢弃时的日志记录见[频道模式](/zh-Hans/docs/channel-modes#检查消息投递)。
