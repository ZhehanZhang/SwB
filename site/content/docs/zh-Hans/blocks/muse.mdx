---
title: Muse
description: 从 SwB 唤醒 Meta Muse。
---

SwB 把文字发给 [Meta Muse](https://muse.ai/)，再把答复交回发送者。新的 Muse 连接即将推出。连接就绪后，本页会提供设置步骤。新连接将取代 `swb muse-bridge`。

## 配置

| 配置键 | 用途 |
| - | - |
| `blocks.muse` | Muse 连接设置 |
| `blocks.muse.use` | 模块类型，填 `muse` |
| `blocks.muse.enabled` | 设为 `true` 或省略此字段即可加载模块。设为 `false` 可跳过 |
