## 添加连接器

按 [Claude 设置](/zh-Hans/docs/setup/claude)添加自定义连接器，并填入 SwB 的 MCP 地址。在 Claude Project 或聊天中启用连接器。Claude 通过 OAuth 以 `claude` 身份登录。

## 连接 Claude Project

将 [Claude Project 设置提示词](/zh-Hans/docs/setup/claude-project)粘贴到该 Project 的聊天中。

智能体查找 SwB 项目，并设置带 API 触发器的 routine。它调用 `connect` 获取领取链接。链接可用一次，30 分钟后失效。打开链接。将 routine 的令牌粘贴到表单中。保存令牌。智能体会发送测试消息并检查回复。

## Routine

**routine**是 SwB 可以启动的 Claude Code 任务。SwB 同时把消息留在 Claude 的邮箱中。routine 用 `reply` 答复发送者。

| 发送给 | 去向 |
| - | - |
| `claude` 并带 `project=<slug>` | 该项目的主 routine |
| `claude:<slug>` | 该项目的主 routine |
| `<routine name>` | 该 routine |
| `agent:claude` | 只写入邮箱 |

一个项目可以有多个 routine。SwB 默认选择该智能体在此项目中的第一个 routine。注册时设为 `primary=true`，即可优先使用该 routine。

如果 Claude 报告项目已暂停，SwB 会用空请求重试。routine 用 `routine_pickup` 读取消息。

## 配置

```yaml
blocks:
  claude-routine:
    routines:
      claude: {routine_id: trig_..., token_env: SWB_EXAMPLE_CLAUDE_TOKEN, agent: claude}
```

手动配置时，用 `token_env` 指定存放 routine 令牌的变量。示例使用 `SWB_EXAMPLE_CLAUDE_TOKEN`。

| 配置键 | 用途 |
| - | - |
| `blocks.claude-routine` | 用于唤醒 Claude Code 任务的模块设置 |
| `blocks.claude-routine.use` | 模块类型，填 `claude-routine` |
| `blocks.claude-routine.enabled` | 设为 `false` 可跳过此模块 |
| `blocks.claude-routine.routines` | 按任务名称设置 routine |
| `blocks.claude-routine.routines.*.agent` | 接收消息的智能体，默认为 `claude` |
| `blocks.claude-routine.routines.*.kind` | 项目 routine 填 `project`，通用 routine 填 `general` |
| `blocks.claude-routine.routines.*.project` | 项目 routine 所属 SwB 项目的简称 |
| `blocks.claude-routine.routines.*.name` | routine 的显示名称 |
| `blocks.claude-routine.routines.*.primary` | 设为 `true` 后，优先选用此智能体在该项目中的这条 routine |
| `blocks.claude-routine.routines.*.routine_id` | Claude API 触发器 ID，例如 `trig_...` |
| `blocks.claude-routine.routines.*.slugs` | 发送时可以使用的其他简称 |
| `blocks.claude-routine.routines.*.token_env` | 存放 routine 令牌的变量名 |
