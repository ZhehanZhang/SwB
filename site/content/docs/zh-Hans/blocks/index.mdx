模块是与一个平台的连接。每个模块在凭据出现在环境变量中，或出现在配置文件中时启用。`swb status` 显示各模块及其下一步。以所有者身份登录后，可在 `/healthz` 查看详情。

| 模块 | 连接方式 | 接收新消息的方式 |
| - | - | - |
| [Claude](/zh-Hans/docs/blocks/claude) | 自定义连接器和 Claude routine | `wait`、`inbox` 和 routine 唤醒 |
| [ChatGPT](/zh-Hans/docs/blocks/chatgpt) | 自定义 MCP 服务器和 ChatGPT dot | MCP Events |
| [Capy](/zh-Hans/docs/blocks/capy) | Capy API 密钥 | Capy 话题串的事件流 |
| [Grok](/zh-Hans/docs/blocks/grok) | MCP 连接器和 Grok routine | 带签名的 routine webhook |
| [编程智能体](/zh-Hans/docs/blocks/coding-agents) | OAuth 或配对码 | `wait`、`inbox` 和 Claude Code 频道 |
| [Slack](/zh-Hans/docs/blocks/slack) | 经 Socket Mode 的 Slack 应用 | 话题串中的回复 |
| [Discord](/zh-Hans/docs/blocks/discord) | 机器人令牌 | 话题串中的回复 |
| [Telegram](/zh-Hans/docs/blocks/telegram) | 机器人令牌 | 话题串中的回复 |
| [GitHub App](/zh-Hans/docs/blocks/github) | webhook 密钥 | 带签名的 webhook |

启用 Capy 模块后，使用 MCP 2026-07-28 的客户端可通过 `server/discover` 发现 [MCP Tasks](/zh-Hans/docs/how-it-works#会话) 扩展。客户端在每次向 Capy 发送时选择启用。MCP 2025-11-25 客户端和发往收件箱的消息都使用普通会话。

## 所有模块的共同点

SwB 根据平台的发送者 ID 标记消息的信任等级。在 Slack、Discord 和 Telegram 中，`known` 是接收设置。SwB 用它判断接收哪些发送者的消息。所有者之外的发送者即使通过 `known` 获准，消息的信任等级仍为 `external`。详见[信任](/zh-Hans/docs/security#信任)。

每个目标、频道和记忆范围起初都是私有的。只有所有者能访问私有资源。共享资源后，其他人才能访问它。

## 添加你自己的模块

模块是带清单的 Python 类。清单列出模块的动词、目标和密钥。第三方模块注册在 `switchboard.blocks` 入口点组中。`swb blocks list` 列出当前实例配置的模块。
