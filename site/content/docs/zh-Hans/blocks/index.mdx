模块是与一个平台的连接。每个模块在凭据出现在环境变量中，或出现在配置文件中时启用。`/healthz` 和 `swb status` 显示每个模块及其下一步。

| 模块 | 连接方式 | 接收新消息的方式 |
| - | - | - |
| [Claude](/zh-Hans/docs/blocks/claude) | 自定义连接器和 Claude routine | `wait`、`inbox` 和 routine 唤醒 |
| [ChatGPT](/zh-Hans/docs/blocks/chatgpt) | 自定义 MCP 服务器和 ChatGPT dot | MCP Events |
| [Capy](/zh-Hans/docs/blocks/capy) | Capy API 密钥 | Capy 话题串的事件流 |
| [Grok](/zh-Hans/docs/blocks/grok) | MCP 连接器和 Grok routine | 带签名的 routine webhook |
| [编码智能体](/zh-Hans/docs/blocks/coding-agents) | OAuth 或配对码 | `wait`、`inbox` 和 Claude Code 频道 |
| [Slack](/zh-Hans/docs/blocks/slack) | 经 Socket Mode 的 Slack 应用 | 话题串中的回复 |
| [Discord](/zh-Hans/docs/blocks/discord) | 机器人令牌 | 话题串中的回复 |
| [Telegram](/zh-Hans/docs/blocks/telegram) | 机器人令牌 | 话题串中的回复 |
| [GitHub App](/zh-Hans/docs/blocks/github) | webhook 密钥 | 带签名的 webhook |

## 所有模块的共同点

信任等级来自平台自己的 id。SwB 把所有者的消息标记为 `owner`。它把你列出的人的消息标记为 `known`。所有其他消息标记为 `external`。SwB 把所有者以外任何人的文本包在一个低信任框架中，智能体因此把它当作信息来读。

每个目标、频道和记忆范围起初都是私有的。只有所有者能访问私有资源。共享资源后，其他人才能访问它。

## 添加你自己的模块

模块是带清单的 Python 类。清单列出模块的动词、目标和密钥。第三方模块注册在 `switchboard.blocks` 入口点组中。`swb blocks list` 显示已安装的模块。
