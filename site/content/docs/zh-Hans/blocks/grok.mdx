## 添加连接器

在 [grok.com](https://grok.com) 中打开 Connectors → New Connector → Custom。输入你的公网 MCP 地址，并用 OAuth 登录。

## 用 routine 唤醒 Grok Bot

请智能体连接 Grok Bot，或在终端运行 `swb connect grok-bot` 获取 routine 提示词。

用这段提示词和自定义 webhook 触发器创建 Grok Bot routine。用下方命令向 SwB 注册 routine。把 `example` 换成你的项目名。

```bash
swb connect grok-bot --choose name=project-triage project=example auth=key
```

Webhook 地址和密钥各有一个领取链接。打开对应链接，粘贴各自的值。再次运行同一条命令，获取测试命令。收到 `pong` 就表示 routine 可以正常使用。

## 唤醒如何工作

SwB 发送 webhook 请求来启动 routine。使用 `auth=key` 时，SwB 默认把密钥作为 bearer 令牌发送。使用 `auth=signature` 时，SwB 对请求签名。请求中包含正文、会话、项目、发送者和信任等级。routine 通过 SwB 连接器回复。

```yaml
blocks:
  grok-routine:
    routines:
      project-triage: {project: example, url_env: GROK_ROUTINE_URL, auth: key, secret_env: GROK_ROUTINE_SECRET}
```

按名称发送给 routine，或发送给 `grok:<slug>` 以唤醒项目的主 routine。

## 配置

| 配置键 | 用途 |
| - | - |
| `blocks.grok-routine` | 用于唤醒 Grok Bot routine 的模块设置 |
| `blocks.grok-routine.use` | 模块类型，填 `grok-routine` |
| `blocks.grok-routine.enabled` | 设为 `false` 可跳过此模块 |
| `blocks.grok-routine.routines` | 按名称设置 routine |
| `blocks.grok-routine.routines.*.project` | SwB 项目的简称。通用 routine 填 `null` |
| `blocks.grok-routine.routines.*.primary` | 设为 `true` 后优先选用此 routine 处理所属项目的消息 |
| `blocks.grok-routine.routines.*.auth` | 用 `key` 发送密钥，或用 `signature` 为请求签名。默认为 `key` |
| `blocks.grok-routine.routines.*.header` | 携带密钥或签名的 HTTP 请求头。`key` 默认用 `Authorization`，`signature` 默认用 `Webhook-Signature` |
| `blocks.grok-routine.routines.*.url_env` | 存放公网 HTTPS webhook 地址的变量名 |
| `blocks.grok-routine.routines.*.secret_env` | 存放密钥或签名密钥的变量名 |
