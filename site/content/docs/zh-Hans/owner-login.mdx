---
title: 所有者登录
description: 用通行密钥、一次性链接、设置码或身份提供方登录 SwB。
---

SwB 只有一位所有者。所有者登录 SwB 页面，查看实例、批准智能体登录并粘贴令牌。SwB 用通行密钥、一次性链接和 OIDC 取代密码。

| 页面 | 用途 |
| - | - |
| `/login` | 以所有者身份登录。 |
| `/authorize` | 审核智能体发起的 OAuth 连接请求。 |

## 一次性链接

```bash
swb login-link
```

命令会打印形如 `https://swb.example.com/login#t=...` 的链接。请在五分钟内用浏览器打开。链接用过一次就会失效。以所有者身份登录的智能体也能用 `login_link` 工具生成链接。令牌在链接的 `#` 后面。

在本机运行时，启动前将 `SWITCHBOARD_PUBLIC_URL` 设为 `http://localhost:8870`。地址中的端口须与 `PORT` 一致。如果 YAML 配置已设置 `public_url`，请在那里修改。用 `--url` 指定其他服务器。用 `--dir` 从其他实例目录读取所有者密钥。

## 设置码

设置码仅用于所有者首次登录，用过即失效。由 SwB 直接处理登录时，可使用设置码。[云平台和 Docker 部署脚本](/zh-Hans/docs/deploy)会生成设置码。

要自行设置，请生成 32 个随机字节。将它们编码为 64 个小写十六进制字符，或使用标准 Base64 编码。下面的命令把十六进制设置码追加到私有文件 `.env`。先运行 `swb init`，再在实例目录中运行此命令。

```bash
(umask 077; printf 'SWB_SETUP_CODE=%s\n' "$(openssl rand -hex 32)" >> .env)
```

设置好 `SWB_SETUP_CODE` 后启动 SwB。在浏览器中打开 `/login`。把设置码粘贴到 **Setup code**。

## 通行密钥

首次登录后，页面会请你添加通行密钥。按设备为通行密钥命名，例如 MacBook。之后的登录使用该通行密钥。在你使用的每台设备上各添加一个通行密钥。Settings 显示你的通行密钥，并允许你删除其中任何一个。

## OIDC

使用你自己的身份提供方，例如 Google、Okta 或 Authentik。把它加入配置文件。

```yaml
public_url: https://swb.example.com
auth:
  owner_emails: [owner@swb.example.com]
  oidc:
    name: Google
    issuer: https://accounts.google.com
    client_id: 1234.apps.googleusercontent.com
    client_secret_env: OIDC_CLIENT_SECRET
```

在你的提供方中，把重定向地址设为 `https://swb.example.com/auth/oidc/callback`。登录页随后会显示你的提供方的按钮。SwB 接受地址已验证的所有者邮箱。你也可以在 `owner_subjects` 中列出提供方的 subject id。

## Cloudflare Access

如果 Cloudflare Access 保护你的主机，SwB 会读取 Access 令牌并立即让你登录。设置 `CLOUDFLARE_ACCESS_TEAM_DOMAIN`、`CLOUDFLARE_ACCESS_AUD` 和 `SWITCHBOARD_OWNER_EMAILS`。SwB 自己检查令牌的签名、受众、签发者和邮箱。

## 登录状态

登录状态保存在 SwB 主机的安全 cookie 中。页面上的每次变更都带有 CSRF 令牌。在 Settings 中退出登录。
