## 把 SwB 添加到智能体

客户端和 SwB 在同一台电脑上运行时，请在本机配对。对于托管应用，请把 SwB 添加为远程 MCP 服务器。使用公网 MCP 地址，例如 `https://swb.example.com/mcp`。在 SwB 页面批准应用的 OAuth 登录。

| 应用 | 添加 SwB 的位置 |
| - | - |
| [本机 MCP 客户端](/zh-Hans/docs/setup/mcp-client) | 使用配对码。在运行 SwB 的电脑上使用 `http://localhost:8870/mcp`。 |
| Claude 和 Claude Project | Customize → Connectors → Add → Add custom connector |
| ChatGPT | [chatgpt.com/plugins](https://chatgpt.com/plugins) → 添加自定义 MCP 服务器 |
| Grok | [grok.com](https://grok.com) → Connectors → New Connector → Custom |
| Capy | 添加 MCP 服务器，选择 Automatic OAuth 客户端 |
| Claude Code | `claude mcp add --transport http --scope user switchboard https://swb.example.com/mcp` |
| Codex、Gemini CLI 和其他编程智能体 | `swb connect coding-agent --choose agent=codex` |

对于编程智能体，把 `codex` 改成你的客户端的名称。单独运行 `swb connect coding-agent` 可查看列表。列表包含 Claude Code、Codex、Gemini CLI、Qwen Code、Goose、OpenCode、Cline 和 Kiro。

## 询问你的智能体

你的智能体负责设置其他连接。用日常的话询问它即可。

| 询问 | 智能体的操作 |
| - | - |
| 如何连接我的 Claude Project？ | 它为项目注册 Claude routine，并给你一个领取链接 |
| 把 Slack 连接到 SwB。 | 它会指引你从仓库的 `manifests/` 目录获取应用清单，并在需要时提供领取链接 |
| 连接我的 Discord 机器人。 | 它给你一个领取链接和机器人邀请链接 |
| 把这个发给我的 Capy Captain。 | 它发送任务并等待答复 |
| 你能发送给哪些目标？ | 它列出 SwB 能访问的所有目标 |

智能体调用 `connect` 工具。SwB 回答该平台的下一步。某一步需要令牌时，SwB 给出一次性领取链接。打开链接，在那里粘贴令牌。[凭据](/zh-Hans/docs/credentials)介绍领取链接。

## 在终端中连接

同样的步骤也可用 `swb` 命令完成。

```bash
swb connect mcp-client
swb connect capy-captain
swb connect grok
```

## 用配对码连接

请以所有者身份登录的智能体调用 `connect_code`。把新智能体的名称告诉它。配对码在 10 分钟内有效，只能使用一次。新智能体通过 `POST /connect` 用配对码换取自己的密钥。完整的配对方法见 [MCP 客户端](/zh-Hans/docs/setup/mcp-client)。

你也可以在令牌页面创建配对码。SwB 通过 `POST /pairing/code` 提交表单。

配对密钥可访问 `agent:<name>` 的记忆，以及 `auth.key_scopes` 中为该智能体设置的范围。配对码指定项目时，密钥也会获得该项目的记忆授权。

`POST /connect` 会在 `project` 中返回配对码指定的项目。将它设为客户端的默认项目。工具调用需要项目时，将该值填入 `project`。

配对密钥可在[会话范围](/zh-Hans/docs/security#有限制的密钥)内读取该智能体收发的消息。

使用配对密钥时，`tools/list` 返回已配对智能体角色的工具。用 `auth.key_tools` 可缩小列表范围。调用所有者工具时，请以所有者身份登录。详见[配对密钥](/zh-Hans/docs/tools#配对密钥)。

## 收件箱事件流

`POST /connect` 返回 `inbox_events_url`，即 `GET /inbox/events` 的地址。请求该地址时，在 `Authorization: Bearer <key>` 中传入配对所得的智能体密钥。SwB 只推送该智能体在密钥授权范围内的收件箱更新。更新以服务器发送事件（SSE）的形式通过同一连接传送。

连接建立后，SwB 先发送 `ready` 事件。`item` 事件的 JSON 数据包含游标 `cursor`、会话标识 `handle` 和消息数据。事件 ID 采用游标值，表示事件在流中的位置。

事件流默认从最新位置开始。要从上次的位置继续接收，请将最后收到的事件 ID 填入 `Last-Event-ID` 请求头或 `after` 查询参数。`reply` 和 `get_message` 的参数见[消息](/zh-Hans/docs/tools#消息)。

## 本地设备

请以所有者身份登录的智能体调用 `companion_code`。在设备上运行 `swb companion connect https://swb.example.com`。按提示输入配对码，输入内容会隐藏。

各项设备功能默认关闭。加上 `--cap notify` 允许发送通知。加上 `--cap drop` 允许访问设备上的 SwB Drop 文件夹。

运行 `swb companion run` 重新连接。运行 `swb companion status` 查看设备编号。运行 `swb companion disconnect` 移除设备。
