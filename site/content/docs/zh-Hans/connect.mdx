## 把 SwB 添加到智能体

把 SwB 添加为远程 MCP 服务器。使用你的公网 MCP 地址，例如 `https://swb.example.com/mcp`。智能体通过 OAuth 登录。你在 SwB 页面上批准该登录。

| 应用 | 添加 SwB 的位置 |
| - | - |
| Claude 和 Claude Project | Settings → Connectors → Add custom connector |
| ChatGPT | [chatgpt.com/plugins](https://chatgpt.com/plugins) → 添加自定义 MCP 服务器 |
| Grok | grok.com → Connectors → New Connector → Custom |
| Capy | 添加 MCP 服务器，选择 Automatic OAuth 客户端 |
| Claude Code | `claude mcp add --transport http swb https://swb.example.com/mcp` |
| Codex、Gemini CLI 和其他编码智能体 | `swb connect coding-agent --choose agent=codex` |

对于编码智能体，把 `codex` 改成你的客户端的名称。单独运行 `swb connect coding-agent` 可查看列表。列表包含 Claude Code、Codex、Gemini CLI、Qwen Code、Goose、OpenCode、Cline 和 Kiro。

## 询问你的智能体

你的智能体负责设置其他连接。用日常的话询问它即可。

| 询问 | 智能体的操作 |
| - | - |
| 如何连接我的 Claude Project？ | 它为该项目注册一个 Claude routine，并给你一个用于令牌的链接 |
| 把 Slack 连接到 SwB。 | 它会指引你从仓库的 `manifests/` 目录获取应用清单，并在需要时提供领取链接 |
| 连接我的 Discord 机器人。 | 它给你一个令牌链接和机器人邀请链接 |
| 把这个发给我的 Capy Captain。 | 它发送任务并等待答复 |
| 你能发送给哪些目标？ | 它列出 SwB 能访问的所有目标 |

智能体调用 `connect` 工具。SwB 回答该平台的下一步。某一步需要令牌时，SwB 给出一次性领取链接。打开链接，在那里粘贴令牌。[凭据](/zh-Hans/docs/credentials)介绍领取链接。

## 在终端中连接

同样的步骤也可用 `swb` 命令完成。

```bash
swb connect mcp-client
swb connect capy-captain
swb connect grok
```

## 用配对码连接

请以所有者身份登录的智能体调用 `connect_code`。把新智能体的名称告诉它。配对码在 10 分钟内有效，只能使用一次。新智能体通过 `POST /connect` 用配对码换取自己的密钥。完整的配对方法见 [MCP 客户端](/zh-Hans/docs/setup/mcp-client)。

你也可以在令牌页面创建配对码。SwB 通过 `POST /pairing/code` 提交表单。
