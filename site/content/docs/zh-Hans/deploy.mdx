## 在电脑上运行

按[安装指南](/zh-Hans/docs/install)启动 SwB。运行 `swb login-link`，生成一次性所有者登录链接。在浏览器中打开链接。部署提示词也适用于本机运行。

## 部署 SwB

[![Deploy to Render](https://render.com/images/deploy-to-render-button.svg)](https://render.com/deploy?repo=https://github.com/ZhehanZhang/SwB)

<Steps>
<Step>
### 开始部署

点击 **Deploy to Render**。登录 Render。保留默认设置，点击 **Deploy**。{/* unverified */}
</Step>
<Step>
### 等待服务就绪

Render 会在几分钟内构建 SwB。SwB 就绪后，服务页面显示 **Live**。
</Step>
<Step>
### 复制地址

复制页面顶部的服务 URL。在末尾加上 `/mcp`，就是 MCP 地址。
</Step>
</Steps>

## 登录

<Steps>
<Step>
### 复制设置码

在 Render 服务中打开 **Environment**。复制 `SWB_SETUP_CODE` 的值。
</Step>
<Step>
### 打开登录页面

在 Render 服务中打开 **Logs**。打开日志中显示的登录页面地址。{/* unverified */}
</Step>
<Step>
### 输入设置码

把设置码粘贴到 **Setup code**。添加通行密钥，以后用它登录。设置码只能使用一次。
</Step>
</Steps>

## 部署 SwB

把提示词粘贴给 Claude Code 或 Codex 等编程智能体。智能体可在你的电脑上运行 SwB，也可部署到 Fly.io、Koyeb 或装有 Docker 的服务器。

<SetupPrompt name="deploy" lang="zh-Hans" />

## 登录

部署到服务器后，打开服务日志中的登录地址。把私有文件中的设置码粘贴到 **Setup code**。设置码仅用于所有者首次登录。添加通行密钥供以后登录。

</DeployHeld>
