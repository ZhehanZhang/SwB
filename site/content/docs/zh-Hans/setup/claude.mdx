连接器让 Claude 使用外部服务的工具。添加 SwB 连接器后，Claude 可以读取你的项目，把工作发给其他智能体，并回复消息。

## 开始之前

你需要一个 Claude 账号。Free、Pro、Max、Ultra、Team 和 Enterprise 套餐都可以使用。Free 套餐有一个自定义连接器名额。在 Team 和 Enterprise 中，由 Owner 或 Primary Owner 为组织添加连接器。

你的 SwB 服务器需要公开的 HTTPS 地址和所有者登录。Claude 从互联网访问 `https://swb.example.com/mcp`，所以本地地址或 VPN 地址会连接失败。

## 复制设置提示词

提示词保留英文，供智能体使用。

把提示词粘贴到 Claude 会话中。智能体会带你完成其余步骤。

## 你的步骤

<Tab value="个人套餐">
<Steps>
<Step>
### 打开 Connectors

在 Claude 中打开 [Customize → Connectors](https://claude.ai/customize/connectors)。有些界面的路径是 **Settings** → **Connectors**。 {/* unverified */}
</Step>
<Step>
### 添加自定义连接器

点击 **Add**，再点击 **Add custom connector**。如果菜单显示 **Custom**，请选择 **Custom** → **Web**。
</Step>
<Step>
### 填写地址

名称填写 `SwB`。地址填写你的 SwB MCP 地址，例如 `https://swb.example.com/mcp`。
</Step>
<Step>
### 保留默认登录方式

在 **OAuth client** 下，保留 **Use Claude’s published identity (Recommended)**。客户端 ID、客户端密钥和 **Request headers** 保持空白。
</Step>
<Step>
### 添加并连接

点击 **Add**。如果列表中的 SwB 显示 **Connect**，请点击 **Connect**。
</Step>
<Step>
### 在 SwB 中批准

在 **Sign in to SwB** 页面登录。在 **Connect to SwB** 页面核对名称，然后点击 **Approve**。
</Step>
</Steps>
</Tab>
<Tab value="Team 或 Enterprise">
<Steps>
<Step>
### 打开管理页面

以 Claude 管理员身份打开 [Organization settings → Connectors](https://claude.ai/admin-settings/connectors)。
</Step>
<Step>
### 添加网页连接器

点击 **Add**。把鼠标移到 **Custom** 上，再点击 **Web**。
</Step>
<Step>
### 填写地址

名称填写 `SwB`，并填写你的 SwB MCP 地址。点击 **Continue**，再点击 **Add**。

<Step>
### 连接你的席位

打开 **Customize** → **Connectors**。找到 `SwB`，点击 **Connect**。
</Step>

### 在 SwB 中批准

在 **Sign in to SwB** 页面登录。在 **Connect to SwB** 页面点击 **Approve**。
</Step>
</Steps>
</Tab>

## 智能体的工作

智能体调用 `connect(what="claude")`。SwB 返回 MCP 地址，并告诉智能体 OAuth 登录的状态。OAuth 是一种登录方式，你在浏览器中批准访问。

智能体给你点击路径和地址。你批准后，它再次调用 `connect`。SwB 回复客户端已登录。

## 凭据

| 项目 | 显示位置 | 格式 | 去向 |
| - | - | - | - |
| MCP 地址 | SwB 设置和 `connect` 的结果 | `https://swb.example.com/mcp` | Claude 连接器的 URL 字段 |
| SwB 访问令牌 | 你点击 **Approve** 后由 Claude 保存 | 随机文本 | Claude 自动保存 |

## 检查连接

打开 **Customize** → **Connectors**，确认 `SwB` 显示为已连接。请 Claude 调用 `project_list`。看到你的 SwB 项目列表，就说明连接成功。

## 解决问题

请确认 SwB 地址以 `/mcp` 结尾。请确认 Claude 可以通过公网访问该地址。`/mcp` 前面的浏览器验证页面会挡住 Claude。更换 SwB 地址后，请删除连接器并重新添加。旧会话在你发送下一条消息后才会用上连接器。
