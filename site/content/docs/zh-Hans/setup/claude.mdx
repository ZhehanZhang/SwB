连接器让 Claude 使用外部服务的工具。添加 SwB 连接器后，Claude 可以读取你的项目，把工作发给其他智能体，并回复消息。

## 开始之前

Claude 免费套餐支持一个自定义连接器。Pro、Max、Ultra、Team 和 Enterprise 套餐也支持自定义连接器。

先为 SwB 设置所有者登录。使用 443 端口上的公网 HTTPS 地址，让 Claude 能访问 `/mcp`。

把提示词粘贴到 Claude 会话。

## 在 Claude 中添加 SwB

<Tabs items={['个人套餐', 'Team 或 Enterprise']}>
<Tab value="个人套餐">
### 添加自定义连接器

在 Claude 中打开 [Customize → Connectors](https://claude.ai/customize/connectors)。
点击 **+ Add**。选择 **Add custom connector**。
### 填写地址

名称填写 `SwB`。地址填写你的 SwB MCP 地址，例如 `https://swb.example.com/mcp`。
### 保留默认登录方式

点击 **Continue** 查看登录设置。在 **Authentication** 下选择 **Sign in now**。在 **OAuth client** 下选择 **Use Claude’s published identity (Recommended)**。将 **Request headers** 留空。
### 添加并连接

点击 **Add**。如果列表中的 SwB 显示 **Connect**，请点击 **Connect**。
### 在 SwB 中批准

在 **Sign in to SwB** 页面登录。在 **Connect to SwB** 页面核对名称，然后点击 **Approve**。
</Tab>
<Tab value="Team 或 Enterprise">
### 打开管理页面

使用有权添加自定义连接器的账号打开 [Organization settings → Connectors](https://claude.ai/admin-settings/connectors)。Team 需要 Owner 或 Primary Owner。
### 添加网页连接器

点击 **Add**。把鼠标移到 **Custom** 上，再点击 **Web**。
### 填写地址

名称填写 `SwB`。输入 SwB 的 MCP 地址。点击 **Continue**。检查登录设置。选择 **Sign in now** 或 **Sign in when needed**。选择 **Use Claude’s published identity (Recommended)**。点击 **Add**。
### 连接你的账号

打开 **Customize** → **Connectors**。找到 `SwB`。点击 **Connect**。
### 在 SwB 中批准

在 **Sign in to SwB** 页面登录。在 **Connect to SwB** 页面点击 **Approve**。
</Tab>
</Tabs>

### 在会话中启用 SwB

在会话中点击 **+** → **Connectors**。开启 SwB。连接 Claude Project 时，请使用协调会话。

## 智能体的工作

智能体调用 `connect(what="claude")`。SwB 返回 MCP 地址和 OAuth 的可用状态。使用 OAuth 时，你会在浏览器中批准访问。

智能体给你点击路径和地址。你批准后，它再次调用 `connect`。SwB 回复客户端已登录。

## 凭据

| 项目 | 显示位置 | 格式 | 去向 |
| - | - | - | - |
| MCP 地址 | SwB 设置和 `connect` 的结果 | `https://swb.example.com/mcp` | Claude 连接器的 URL 字段 |
| SwB 访问令牌 | 你点击 **Approve** 后由 Claude 保存 | 随机文本 | Claude 自动保存 |

## 检查连接

打开 **Customize** → **Connectors**，确认 `SwB` 显示为已连接。请 Claude 调用 `project_list`。看到你的 SwB 项目列表，就说明连接成功。

## 解决问题

请使用以 `/mcp` 结尾的公网 HTTPS 地址。让 Claude 直接访问 `/mcp`。更换 SwB 地址时，请移除原连接器，再用新地址添加。
