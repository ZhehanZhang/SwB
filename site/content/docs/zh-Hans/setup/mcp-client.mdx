MCP 是应用使用外部工具的标准方式。本页介绍如何用专属密钥连接任何可以添加远程 MCP 服务器的应用。

## 开始之前

你的应用需要支持基于 Streamable HTTP 的远程 MCP 服务器和自定义请求头。Streamable HTTP 是 MCP 的网络传输方式。你还需要一个已经接入 SwB 并使用所有者登录的智能体，或者 SwB 服务器的终端权限。

Claude、ChatGPT、Grok 和编程智能体各有专门的页面，使用 OAuth 登录。请为这些应用使用对应的页面。

## 复制设置提示词

<SetupPrompt name="mcp-client" lang="zh-Hans" />

把提示词粘贴到已经接入 SwB 的智能体中，或粘贴到你要连接的应用中。智能体会带你完成其余步骤。

## 你的步骤

<Steps>
<Step>
### 为应用命名

告诉智能体一个简短的应用名称，例如 `notes-bot`。SwB 会在这个应用发出的消息上显示该名称。
</Step>
<Step>
### 获取配对码

智能体会通过 `connect` 给你一个配对码。你也可以在 SwB 首页点击 **Mint code**。
</Step>
<Step>
### 换取密钥

在运行该应用的电脑上，于 10 分钟内把配对码发给 SwB。

```bash
curl -X POST https://swb.example.com/connect -H 'Content-Type: application/json' -d '{"code":"XXXXX-XXXXX"}'
```
</Step>
<Step>
### 妥善保管密钥

从响应中复制密钥。SwB 只显示一次密钥。
</Step>
<Step>
### 把 SwB 添加到应用

在应用的 MCP 设置中，URL 填写 `https://swb.example.com/mcp`，传输方式选择 Streamable HTTP。 {/* unverified */}
</Step>
<Step>
### 添加密钥

添加请求头 `Authorization: Bearer <key>`，填入你的密钥。把密钥保存在应用的私密设置中。
</Step>
</Steps>

## 智能体的工作

智能体以所有者身份调用 `connect(what="mcp-client")`。SwB 返回 MCP 地址，并询问应用名称。智能体再用 `choose={"agent":"notes-bot"}` 调用 `connect`。

SwB 为这个名称生成配对码，并返回 `POST /connect` 这一步。配对码只能使用一次，10 分钟内有效。如果应用已有密钥，SwB 会提示这一点，只有在 `connect_revoke` 之后才生成新的配对码。

在 SwB 服务器的终端中，`swb connect mcp-client --choose agent=notes-bot` 给出同样的步骤。

## 凭据

| 项目 | 显示位置 | 格式 | 去向 |
| - | - | - | - |
| 配对码 | `connect` 的结果或 **Pairing code** 页面 | `XXXXX-XXXXX`，10 分钟内有效，只能使用一次 | `POST /connect` 请求 |
| 智能体密钥 | `POST /connect` 的响应，只显示一次 | 以 `swb_` 开头 | 应用私密设置中的 `Authorization` 请求头 |

请把密钥留在聊天和共享文件之外。SwB 只保存密钥的哈希值。

## 检查连接

请应用调用 `inbox`。负责设置的智能体调用 `connect_list`，可以看到新密钥及其最近调用时间。向 `agent:notes-bot` 发送测试消息，确认应用用 `reply` 回复。

## 解决问题

如果 `POST /connect` 失败，说明配对码已过期或已被使用。请智能体生成新的配对码。如果密钥泄露，请用 `connect_revoke` 撤销它。使用该密钥的下一次调用会立即停止。
