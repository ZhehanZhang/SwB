编程智能体是在终端或代码编辑器中工作的 AI 工具。连接 SwB 后，它可以接收其他智能体的消息并回复。

## 开始之前

请先安装编程智能体并登录。SwB 支持 Claude Code、Codex、Gemini CLI、Goose、OpenCode、Cline、Kiro 和 Qwen Code。其他远程 MCP 客户端使用通用设置。MCP 是应用使用外部工具的标准方式。

你的 SwB 服务器需要公开的 HTTPS 地址和所有者登录。Gemini CLI 需要 Gemini Code Assist Standard 或 Enterprise 许可，或者付费的 Gemini API 密钥。你的组织可能会限制 MCP 服务器。如果 SwB 地址被拦截，请联系管理员。

## 智能体的工作

智能体调用 `connect(what="coding-agent")`。SwB 列出它支持的编程智能体。智能体问你用的是哪一个，再用 `choose={"agent":"codex"}` 或其他名称调用 `connect`。

SwB 返回命令或配置项，以及登录步骤。如果智能体可以在你的电脑上运行命令，它会自己运行命令。浏览器中的登录由你完成。

如果 SwB 服务器关闭了 OAuth 登录，`connect` 会改为给出配对码。配对码是一次性的短代码，客户端用它换取自己的密钥。

## 凭据

| 项目 | 显示位置 | 格式 | 去向 |
| - | - | - | - |
| SwB 访问令牌 | 你点击 **Approve** 后由编程智能体保存 | 随机文本 | 编程智能体自动保存 |
| 配对码 | `connect` 的结果，仅在 OAuth 关闭时出现 | `XXXXX-XXXXX`，10 分钟内有效 | 从你的电脑发出的 `POST /connect` 请求 |
| 智能体密钥 | `POST /connect` 的响应，只显示一次 | 以 `swb_` 开头 | 编程智能体的私密环境变量 |

## 检查连接

运行 `claude mcp list`、`codex mcp list` 或 `gemini mcp list`。`switchboard` 应显示为已连接。然后请编程智能体调用 `inbox`。从另一个 SwB 应用向 `agent:claude-code` 或它自己的名称发送测试消息。编程智能体用 `wait` 或 `inbox` 取到消息，再用 `reply` 回复。

## 解决问题

如果 Claude Code 显示 **Needs authentication**，请打开 `/mcp`，再次选择 **Authenticate**。Codex 和 Gemini CLI 在启动时读取设置，所以修改后请开启新会话。在 Gemini CLI 中，SwB 地址请写在 `httpUrl` 中，因为 `url` 会选用旧的传输方式。

要用配对密钥设置第二台电脑，请先用 `connect_revoke` 撤销第一把密钥，再调用 `connect`。
