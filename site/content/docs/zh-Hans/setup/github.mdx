SwB 从你注册的 GitHub App 接收仓库事件。有了应用的私钥，智能体还可以给 issue 加标签、发表评论和新建 issue。

## 开始之前

你需要一个 GitHub 账号和要接入的仓库。在组织中操作时，你需要组织所有者角色或 GitHub App 管理者角色。你还需要以所有者身份登录 SwB 服务器，例如 `https://swb.example.com`。

GitHub 必须能访问你服务器上的 `https://swb.example.com/github/webhook`。

## 你的步骤

<Steps>
<Step>
### 打开 GitHub App 设置

点击头像 → **Settings** → **Developer settings** → **GitHub Apps**。点击 **New GitHub App**。
</Step>
<Step>
### 命名应用

填写 **GitHub App name** 和 **Homepage URL**。主页可以填仓库地址。
</Step>
<Step>
### 设置 webhook

在 **Webhook** 下保持选中 **Active**。在 **Webhook URL** 中填写 `https://swb.example.com/github/webhook`。
</Step>
<Step>
### 设置 webhook 密钥

将随机密钥生成到私有文件中。

```bash
(umask 077; set -C; openssl rand -hex 32 > "$HOME/.swb-github-secret")
```

将生成的密钥存入密码管理器。把密钥填入 **Webhook secret**。SwB 接受至少 16 个字符的密钥。
</Step>
<Step>
### 设置权限

在 **Repository permissions** 中，按下表设置权限。
</Step>
<Step>
### 订阅事件

在 **Subscribe to events** 下，选中下表中的事件。
</Step>
{/* unverified */}
<Step>
### 创建应用

在 **Where can this GitHub App be installed?** 下选择 **Only on this account**。点击 **Create GitHub App**。
</Step>
<Step>
### 生成私钥

在 **Private keys** 下点击 **Generate a private key**。浏览器会下载一个 `.pem` 文件，只下载一次。
</Step>
{/* unverified */}
<Step>
### 保存凭据

打开智能体给你的各个 SwB 领取链接。保存同一个 webhook 密钥、**App ID** 和完整的 `.pem` 文件。保存密钥后删除私有文件。
</Step>
<Step>
### 安装应用

点击 **Install App** → 你的账号旁边的 **Install**。选择 **Only select repositories**。
</Step>
<Step>
### 选择仓库

选中你的仓库。点击 **Install**。
</Step>

| 仓库资源 | 访问权限 | 事件 |
| --- | --- | --- |
| **Issues** | **Read & write** | `issues`、`issue_comment` |
| **Pull requests** | **Read & write** | `pull_request`、`pull_request_review`、`pull_request_review_comment`、`pull_request_review_thread` |
| **Contents** | **Read-only** | `push` |
| **Checks** | **Read-only** | `check_run`、`check_suite` |

| **Metadata** | 自动设为 **Read-only** | |

在组织中，GitHub 可能把 **Install** 显示为 **Request**。这时由组织所有者批准请求。

## 智能体的工作

智能体调用 `connect`，参数为 `what="github"`。SwB 显示 webhook 地址、webhook 密钥的状态和仓库路由数量。路由把一个仓库的事件发送给一个目标。

智能体将仓库添加到 `config/switchboard.yaml` 中的 `blocks.github.spaces`。空间为仓库指定模式、项目和目标。此示例将项目 `demo` 中仓库 `acme/app` 的观察摘要送到 `agent:beta`。

```yaml
blocks:
  github:
    use: github
    spaces:
      acme/app:
        mode:
          mode: watch
          target: agent:beta
        project: demo
```

通过领取链接保存同一个 webhook 密钥。智能体重启 SwB，载入密钥并应用路由。

智能体再次调用 `connect(what="github")`，获取仍需填写的 App ID 或私钥链接。若要把已有的个人访问令牌改为 GitHub App 凭据，选用 `choose={"credential":"app"}`。

重启后，智能体调用 `github_status` 检查安装及其权限。

智能体调用 `space_mode(block="github", space="acme/app", mode="triage", target="agent:beta")`，绑定分流目标。使用 `mode="assist"` 可切换到协助模式。请从 `targets` 返回的列表中选择目标。关联项目的路由是备用选项。分流模式默认允许 `github_reply`。

要接收外部用户的事件，请开放 `channel:github/acme/app` 和 `target:beta`。详情见[频道可见性](/zh-Hans/docs/channel-modes#允许外部-github-用户访问)。

观察模式按 `modes.digest_minutes` 的间隔将摘要送入目标邮箱。累积到 50 个事件时，SwB 提前发送摘要。所有者可在控制台的 **Inbox** 中查看所有摘要，也可调用 MCP 工具 `inbox` 或 `wait`。

## 凭据

| 令牌 | GitHub 显示位置 | 格式 | 填写位置 |
| --- | --- | --- | --- |
| Webhook 密钥 | 用 `openssl rand -hex 32` 生成 | 至少 16 个字符 | SwB 领取链接 |
| App ID | 应用设置中的 **App ID** | 一串数字 | SwB 领取链接 |
| 私钥 | 点击 **Generate a private key** 后下载一次 | `.pem` 文件 | SwB 领取链接 |

SwB 用私钥自行生成安装令牌。每个安装令牌有效一小时。

## 检查连接

请智能体再次调用 `connect`。设置完成后，它会报告 `connected`。`github_status` 显示 `secret_present` 和安装的权限。

在 GitHub 上打开应用设置 → **Advanced** → **Recent deliveries**。打开最新一次投递，确认 SwB 返回了成功代码。

## 解决问题

出现签名错误时，请用 `openssl rand -hex 32` 生成新的 webhook 密钥。在 GitHub 应用的设置中填入新密钥。请智能体调用 `connect(what="github", choose={"replace":"secret"})`。通过领取链接保存同一个密钥。重启 SwB。在 **Recent deliveries** 中重新发送该事件。

如果 `connect` 要求 **Issues** 写入权限，请打开应用设置 → **Permissions & events**。把 **Issues** 设为 **Read & write**，并在安装上接受这项变更。
