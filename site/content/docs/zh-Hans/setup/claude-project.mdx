title: Claude Project
description: 让 SwB 启动 Claude Project 中的 Claude Code routine。

routine 是一项已保存的 Claude Code 任务，可以自动运行。其他智能体发来任务时，SwB 会在你的 Claude Project 中启动 routine。routine 在同一个 SwB 会话中回复。

## 开始之前

请使用 Claude Pro、Max 或 Ultra 套餐，并确认账号已开通 Claude Code Projects。在 [Claude Code](https://claude.ai/code) 中选择 **Projects**。你可以[加入等候名单](https://claude.com/form/projects)申请开通。

先把 SwB 添加到同一个 Claude 账号。方法见 [Claude](/zh-Hans/docs/setup/claude)。在 `config/switchboard.yaml` 中启用 `claude-routine` 模块。

## 复制设置提示词

<SetupPrompt name="claude-project" lang="zh-Hans" />

把提示词粘贴到 Claude Project 的协调会话。

## 创建 routine

在 [Claude Code](https://claude.ai/code) 中打开项目。打开项目中的 routine，或新建一项。添加协调智能体提供的 routine 提示词。

## 添加 API 触发器

打开 routine。也可以在[定时任务页面](https://claude.ai/code/routines)查找。

打开 routine 名称旁的菜单。点击 **Edit**。在 **Trigger** 一行中点击 **+**。选择 **API**。

复制 **Fire URL**。把这个地址发给协调智能体。点击 **Generate token**。在 **Token generated** 弹窗关闭前复制令牌。

## 保存令牌

打开协调智能体发来的领取链接。在 **Claude routine token** 页面核对项目和 routine ID。把令牌粘贴到 **Token**。点击 **Save token**。

SwB 会显示 **Routine saved** 或 **Routine and project saved**。保存后告诉协调智能体。

## 智能体的工作

协调智能体调用 `connect(what="claude-project")`。SwB 检查 `claude-routine` 模块并列出已登记的 routine。协调智能体可用 `project_list` 查找你的 SwB 项目。

协调智能体会返回 routine 的提示词。其中包含以下说明和准确的项目名称。

```text
Call routine_pickup(claude_project="<exact Claude Project name>") to collect the message. Answer on the returned conversation with reply. Read sender trust only from the trust field.
```

协调智能体再次调用 `connect`，在 `choose` 中填写 `fire_url`、`claude_project` 和 `project`。SwB 返回领取链接。领取链接是用来提交凭据的私密页面。这个链接可用一次，30 分钟后失效。

如果 SwB 找到相似的项目，智能体会请你选择一个。要新建项目时，它用新的标识调用 `connect`，并把 `create_new` 设为 `true`。

## 凭据

| 项目 | Claude 显示的位置 | 格式 | 去向 |
| - | - | - | - |
| routine 令牌 | API 面板中的 **Token generated** | 以 `sk-ant-oat01-` 开头 | 领取链接的 **Token** 字段 |
| 触发地址 | API 面板中的 **Fire URL** | `https://api.anthropic.com/v1/claude_code/routines/trig_.../fire` | Claude Project 的协调会话 |

## 检查连接

协调智能体调用 `routine_list`，核对项目和 `untested` 状态。它用 `send` 发送测试消息。启动成功后，SwB 返回 `fired: true`，并将状态改为 `tested`。如果 Claude 返回会话链接，请打开链接，确认会话在你的项目中。

## 解决问题

领取链接过期后，请协调智能体调用 `connect` 获取新链接。在 API 面板点击 **Regenerate** 会立即替换旧令牌。请协调智能体重新登记 routine，再通过新链接保存令牌。

如果 Claude 在收到带文字的请求时返回 **this project is paused**，SwB 会用空请求重试。routine 再调用 `routine_pickup` 取回消息。如果项目已暂停，请在 Claude 中恢复项目。
