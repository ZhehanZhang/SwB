Grok Bot 是 xAI 的桌面智能体应用。这个连接把 SwB 添加到 Grok Bot，并创建一个由 SwB 通过 Webhook 启动的 routine。routine 是一项保存好的任务。Webhook 是一个网址，SwB 调用它就能启动 routine。

## 开始之前

在 macOS、Windows 或 Linux 上安装 Grok Bot。你需要包含 Grok Bot 的套餐，例如 X 订阅或 Grok Business 席位。

你的 SwB 服务器需要公网 HTTPS 地址、所有者登录、一个 SwB 项目和 `grok-routine` 模块。OAuth 是一种登录方式，你在浏览器中的 SwB 页面上批准访问。请用你自己的所有者登录来完成设置。

## 智能体的工作

Grok Bot 调用 `connect(what="grok-bot")`。SwB 返回 MCP 地址、OAuth 状态和一段 routine 提示词。routine 提示词要求每次运行以 Webhook 中的 `trust` 字段为准，并用 `reply` 答复。

Grok Bot 用这段提示词创建 routine。然后它调用 `connect(what="grok-bot", choose={"name":"<routine>","project":"<project>","auth":"key"})` 注册 routine。SwB 返回两个领取链接。你保存两项内容后，Grok Bot 运行 `send(to="grok-routine:routine:<routine>", task="switchboard setup test: reply pong")`。它再次调用 `connect`，查看 Grok 是否接受了这次调用。

Webhook 是这个连接的唤醒方式。每条发给该 routine 的 SwB 消息都会启动一次新的运行。

## 凭据

| 令牌 | 显示位置 | 格式 | 去向 |
| - | - | - | - |
| Webhook URL | routine **Details** 中 **Webhook** 下的 **POST to** | HTTPS 地址 | 对应 SwB 领取链接中的 **Webhook URL** |
| Webhook 密钥 | routine **Details** 中 **Webhook** 下的 **key** | 随机文本 | 对应 SwB 领取链接中的 **Token** |
| SwB 登录令牌 | 你登录时由 Grok Bot 获取 | 随机文本 | 由 Grok Bot 保存 |

领取链接是 SwB 上的一次性私密页面，每个页面对应一个令牌。每项内容只粘贴到对应的领取链接中。

## 检查连接

打开 routine 的 **Details**，检查 **Webhook** 触发器。让 Grok Bot 再次调用 `connect(what="grok-bot")`。状态行会显示该 routine。测试发送方会在 `inbox` 中收到 pong。

## 解决问题

复制 **key**，**header** 保持原样。SwB 会自己加上 `Authorization: Bearer` 部分。

发送到 `grok-routine:routine:<routine>` 才会启动 routine。发送到 `agent:grok` 只会把消息放入邮箱。

领取链接只能使用一次，30 分钟后过期。要获取新链接，请再次调用 `connect`。要更换已保存的内容，请调用 `connect` 并把 `choose.replace` 设为 `url` 或 `secret`。

[grok.com](https://grok.com) **Automations** 的 Webhook 使用另一种签名格式。请为 SwB 使用 Grok Bot routine。
