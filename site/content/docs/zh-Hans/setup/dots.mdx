**dot** 是 ChatGPT 的个人智能体，在两次对话之间也会继续工作。`dots` 模块默认通过 Slack 投递消息。本指南改用 SwB 邮箱。消息到达时，邮箱会通过 MCP 事件唤醒 dot。

## 开始之前

Pro 用户和部分年满 18 岁的 Plus 用户可以使用 dot。dot 仅在欧洲经济区、英国和瑞士以外的地区提供。受支持地区的 Business、Enterprise 和 Edu 成员可以创建一个个人 dot。

dot 权限和自定义 MCP 权限是两项独立权限，你需要同时具备。Business、Enterprise 和 Edu 提供完整的自定义 MCP 访问。MCP 服务器是供 AI 应用调用的工具服务器。

在 Enterprise 和 Edu 中，管理员在 **Workspace settings** → **Permissions & roles** → **Permissions** → **Workspace default** → **Workspace capabilities** → **Use dots** 中开启 dot。

你的 SwB 服务器需要公网 HTTPS 地址、所有者登录和 `dots` 模块。模块是 SwB 中的一个连接，你在配置文件中开启它。

## 你的步骤

<Steps>

<Step>

### 开启 dots 模块

把下面的模块加入 `config/switchboard.yaml`。然后重启 SwB。

```yaml
blocks:
  dots:
    delivery: mailbox
    dots:
      dot:
        mailbox: chatgpt
```

</Step>

<Step>

### 打开 Plugins

在桌面浏览器中打开 [chatgpt.com/plugins](https://chatgpt.com/plugins)。即使你平时在桌面应用中使用 dot，这一步也请使用网页版。

</Step>

<Step>

### 添加服务器

选择 **+**。然后选择 **Add custom MCP server**。

</Step>

<Step>

### 输入地址

名称填写 `SwB`。在 **Connection** 下的 **Server URL** 中输入 `https://swb.example.com/mcp`。

</Step>

<Step>

### 创建插件

选择 **OAuth**。选择 **I understand and want to continue**。然后选择 **Create as a plugin**。

</Step>

<Step>

### 安装并登录

安装插件。以所有者身份登录 SwB。然后批准访问。

</Step>

<Step>

### 打开你的 dot

在 [chatgpt.com](https://chatgpt.com) 打开你的 dot。把 SwB 插件添加到 dot。

</Step>

## 智能体的工作

dot 调用 `connect(what="chatgpt")`，确认 OAuth 登录。OAuth 是一种登录方式，你在 SwB 页面上批准访问。然后 dot 调用 `connect(what="dots")`，检查 `dots` 模块。它用 `send` 发送一条测试消息，再用 `inbox` 读取。

最后，dot 为自己的邮箱订阅 MCP 事件 `switchboard.message.created`，默认邮箱是 `chatgpt`。邮箱是一个智能体在 SwB 中的收件箱。MCP 事件是新消息到达时 SwB 对 dot 发起的调用。SwB 会先检查 dot 的回调地址。每次收到事件，dot 用 `get_message` 读取消息，再用 `reply` 答复。如果事件功能暂时缺失，dot 会调用 `wait` 或 `inbox`。

## 凭据

| 令牌 | 显示位置 | 格式 | 去向 |
| - | - | - | - |
| SwB 登录令牌 | 你登录时由 ChatGPT 获取 | 随机文本 | 由 ChatGPT 保存 |
| 事件签名密钥 | dot 订阅时发送 | `whsec_` 加随机文本 | 由 SwB 加密保存 |

其他令牌只通过 SwB 领取链接交给 SwB。领取链接是 SwB 上的一次性私密页面，每个页面对应一个令牌。

## 检查连接

让另一个 SwB 智能体运行 `send(to="dot", task="SwB setup test: reply pong")`。dot 会自动唤醒，并在该会话中答复 pong。`inbox` 读取成功只能证明登录有效。

## 解决问题

如果 `connect(what="dots")` 返回类型 `unknown`，说明 `dots` 模块处于关闭状态。添加该模块，然后重启 SwB。

如果 `connect` 要求连接 Slack 工作区，说明该模块使用 Slack 投递。设置 `delivery: mailbox`，然后重启 SwB。

请在浏览器中通过 [chatgpt.com](https://chatgpt.com) 添加服务器。桌面应用只能打开你已添加的插件。如果 dot 几天后停止唤醒，请重新登录插件。
