---
title: 凭据
description: 在一次性页面保存连接凭据。
---

SwB 需要凭据时，智能体会给你一个**领取链接**。链接会打开 SwB 上的一次性表单。凭据由浏览器直接提交给 SwB。

## 领取链接如何工作

请以所有者身份登录后使用链接。链接的有效期为 30 分钟，可使用一次。

![单个令牌的领取页面](/shots/token-handoff-light.webp)

SwB 用数据目录中的密钥加密凭据。模块可以用已保存的值代替环境变量。服务器上的环境变量优先于已保存的值。

| 页面 | 用途 |
| - | - |
| `/claim/{code}` | 保存连接所需的凭据。 |
| `/routines/claim/{code}` | 使用一次性领取链接保存 Claude routine 的令牌。 |
| `/routines/claim/owner/{registration}` | 从智能体页面保存待领取的 Claude routine 令牌。 |

## 保存凭据

在 Discord、Telegram、Claude routine 和 Grok Bot 的令牌表单中，粘贴令牌后点击 **Save token**。在 Grok Bot 的 webhook 表单中，输入网址后点击 **Save webhook url**。

设置 GitHub App 时，SwB 会为每项待填写的凭据提供单独的链接。在对应的表单中填写 **App ID**、**Private key** 或 **Webhook secret**。填写 **Private key** 时，点击 **Upload .pem file**，或粘贴 `.pem` 文件的完整内容。填写后点击 **Save**。

更改 GitHub webhook 密钥后，请重启 SwB。

Slack 工作区缺少令牌时，SwB 会为该工作区提供一个领取链接。在同一张表单中填写各个字段。点击 **Save**。

## 在终端领取

```bash
swb claim 'https://swb.example.com/claim/...'
```

命令在隐藏提示中询问令牌。它把令牌发送到你本地的 SwB 服务器，或用 `--url` 指定的服务器。

## 更换凭据

根据模块选择相应的方法。

| 模块 | 更换方法 |
| - | - |
| Grok Bot | 请智能体对 `grok-bot` 调用 `connect`。传入 routine 名称，并指定 `replace=url` 或 `replace=secret`。 |
| Muse | 请智能体对 `muse` 调用 `connect`，用 `replace=true` 更换桥接令牌。 |
| Slack | 工作区缺少已配置的令牌时，SwB 会为该工作区提供一个领取链接。 |
| GitHub | 请智能体调用 `connect(what="github", choose={"replace":"secret"})` 更换 webhook 密钥。`webhook_secret` 的作用相同。用 `all` 同时更换应用凭据或个人访问令牌 |

通过服务器环境变量提供的值，请在环境变量中更新。若通过 `blocks.github.app_id` 设置 App ID，请修改配置文件。更新配置或更换 GitHub webhook 密钥后，重启 SwB。
