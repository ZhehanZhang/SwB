智能体负责设置连接。SwB 需要令牌时，智能体会发给你一个**领取链接**。链接会打开 SwB 上的一次性页面。打开链接。将令牌粘贴到对应字段。点击 **Save token**。令牌从浏览器直接传到 SwB。

## 领取链接如何工作

智能体请求一个连接，例如 Discord。SwB 返回形如 `https://swb.example.com/claim/...` 的链接。智能体把链接交给你。该链接 30 分钟内有效，且只能使用一次。使用它时，你必须以所有者身份登录。

![单个令牌的领取页面](/shots/token-handoff-light.webp)

SwB 用数据目录中的密钥加密凭据。模块可以用已保存的值代替环境变量。服务器上的环境变量优先于已保存的值。

| 页面 | 用途 |
| - | - |
| `/claim/{code}` | 保存连接所需的凭据。 |
| `/routines/claim/{code}` | 使用一次性领取链接保存 Claude routine 的令牌。 |
| `/routines/claim/owner/{registration}` | 从智能体页面保存待领取的 Claude routine 令牌。 |

## GitHub 和 Slack 的领取链接

设置 GitHub App 时，每个缺失的值都有自己的领取链接。App ID、私钥和 webhook 密钥各用一个链接。填写私钥时，请粘贴 `.pem` 文件的完整内容。

更改 GitHub webhook 密钥后，请重启 SwB。

Slack 工作区缺少令牌时，SwB 会为该工作区提供一个领取链接。填写表单上的各个字段。点击 **Save**。

## 在终端领取

```bash
swb claim 'https://swb.example.com/claim/...'
```

命令在隐藏提示中询问令牌。它把令牌发送到你本地的 SwB 服务器，或用 `--url` 指定的服务器。

## 更换凭据

根据模块选择相应的方法。

| 模块 | 更换方法 |
| - | - |
| Grok Bot | 请智能体对 `grok-bot` 调用 `connect`。传入 routine 名称，并指定 `replace=url` 或 `replace=secret`。 |
| Muse | 请智能体对 `muse` 调用 `connect`，用 `replace=true` 更换桥接令牌。 |
| Slack | 工作区缺少已配置的令牌时，SwB 会为该工作区提供一个领取链接。 |
| GitHub | SwB 会检查已保存的值，并为设置所缺的每个值提供一个领取链接。 |

如果凭据来自服务器的环境变量，请更新该变量，然后重启 SwB。
