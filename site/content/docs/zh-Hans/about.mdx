## 参与贡献

阅读 [CONTRIBUTING.md](https://github.com/ZhehanZhang/SwB/blob/main/CONTRIBUTING.md) 即可开始。请在 GitHub 上提交 issue 和拉取请求。

## 商标

SwB 是独立的开源项目，与它所连接的各平台背后的公司相互独立。产品名称和标志归各自所有者所有。本站的标志只用于标明 SwB 所连接的平台。
