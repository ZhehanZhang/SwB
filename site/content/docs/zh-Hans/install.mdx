---

SwB 可在 Linux、macOS 和 Windows 上运行。uvx 和 pipx 两种方式需要 Python 3.12 或更高版本。Docker 方式需要 Docker。

## 安装并启动

用空文件夹存放 SwB 实例。`swb` 命令用所有者密钥以你的身份登录。

<Tabs items={['uvx', 'pipx', 'Docker']}>
  <Tab value="uvx">
    ```bash
    uvx swb-one up
    ```

    uvx 会下载并启动 SwB。请在五分钟内打开终端显示的一次性登录链接。运行其他示例时，把开头的 `swb` 换成 `uvx swb-one`。
  </Tab>
  <Tab value="pipx">
    ```bash
    pipx install swb-one
    swb up
    ```

    pipx 会为当前用户安装 `swb` 命令。请在五分钟内打开终端显示的一次性登录链接。

    如果 pipx 使用较旧的 Python，请运行 `pipx install --python 3.12 swb-one`。
  </Tab>
  <Tab value="Docker">
    ```bash
    (umask 077; set -C; printf 'SWITCHBOARD_KEY_OWNER=%s\nSWITCHBOARD_PUBLIC_URL=http://localhost:8870\n' "$(openssl rand -hex 32)" > .env)
    docker run -d --name swb --env-file .env \
      -e PORT=8870 -p 127.0.0.1:8870:8870 -v swb-data:/data \
      ghcr.io/zhehanzhang/swb:latest
    ```

    这组命令先创建私有文件 `.env`，再启动容器。镜像把数据保存在 `/data`。运行 `docker exec swb swb login-link` 获取登录链接。运行其他示例时，把开头的 `swb` 换成 `docker exec swb swb`。
  </Tab>
</Tabs>

首次在本机运行 `swb up` 时，SwB 会在实例目录中创建 `.env`、`config/switchboard.yaml` 和 `data/`。之后可运行 `swb login-link` 获取新链接。

如需在启动前创建文件，请先运行 `swb init`。再运行 `swb up`。另开一个终端，在同一目录中运行 `swb login-link`。

`swb up` 默认在 `127.0.0.1` 的 `8870` 端口监听。默认的本机 MCP 地址是 `http://localhost:8870/mcp`。如需更改端口，请在终端或 `.env` 中设置 `PORT`。

用 `swb up --dir ./my-swb` 指定实例目录。运行其他命令时，请传入相同的 `--dir`。监听地址、配置文件和数据目录见[配置](/zh-Hans/docs/config)。

## 检查服务器

```bash
curl -fsS http://127.0.0.1:8870/healthz
```

这条命令在登录前即可使用，显示 `status` 和 `version`。运行 `swb status`，或用所有者密钥访问 `/healthz`，即可查看模块、运行状态和缺少的变量。

## 服务器命令

运行 `swb --help` 查看各类命令。在任一命令后加上 `--help`，即可查看该命令的选项。

| 命令 | 用途 |
| - | - |
| `swb init` | 写入私有的所有者密钥和基本配置。 |
| `swb up` | 在本机启动 SwB。 |
| `swb connect` | 获取连接平台的步骤。 |
| `swb status` | 查看状态和下一步。 |
| `swb login-link` | 生成一次性所有者登录链接。 |
| `swb claim` | 用领取链接或领取码保存凭据。 |
| `swb serve` | 按配置的主机地址和端口运行服务器。 |
| `swb export DIR` | 将已保存的记忆导出为 Markdown 文件，存入输出目录 `DIR`。 |
| `swb log [--limit N]` | 输出最近的审计记录。默认上限为 `50` 条。 |
| `swb config migrate` | 将第 1 版配置转换为第 2 版格式并输出。 |
| `swb blocks list` | 列出已配置的模块。 |
| `swb blocks show BLOCK` | 显示指定模块的设置。 |
| `swb blocks check` | 检查模块配置。 |
| `swb targets` | 列出 `send` 可用的目标。 |

## 版本

版本发布后，可从 PyPI 获取 `swb-one` 软件包，或从 GitHub Container Registry 获取 `ghcr.io/zhehanzhang/swb` 镜像。用 `1.0.0` 这样的版本号指定版本。镜像标签 `latest` 指向最新的稳定版本。
