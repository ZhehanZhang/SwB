## Marques

SwB est un projet open source indépendant. Il est distinct des entreprises qui gèrent ces plateformes. Les noms de produits et les logos appartiennent à leurs propriétaires. Les logos de ce site identifient les plateformes auxquelles SwB se connecte. Consultez la [politique de SwB sur les marques](/fr/docs/trademarks).
