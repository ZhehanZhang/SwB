title: Identifiants
description: Enregistrez les identifiants de connexion sur une page à usage unique.
---

Un **identifiant** est une valeur qui donne accès à une application. Votre agent envoie un **lien de dépôt** quand SwB a besoin d'un identifiant. Le lien ouvre un formulaire à usage unique. Le formulaire envoie la valeur de votre navigateur à SwB.

## Fonctionnement d'un lien de dépôt

Connectez-vous en tant que propriétaire pour ouvrir le formulaire. Si le formulaire affiche **SwB owner key**, saisissez la clé sur cette page. Le lien fonctionne une seule fois et expire après 30 minutes.

![Une page de dépôt pour un jeton](/shots/token-handoff-light.webp)

SwB chiffre la valeur avec une clé de son dossier de données. Le bloc peut utiliser la valeur enregistrée à la place d'une variable d'environnement. Si vous définissez les deux, SwB utilise d'abord la variable d'environnement.

| Page | Usage |
| - | - |
| `/claim/{code}` | Enregistrer les identifiants d'une connexion. |
| `/routines/claim/{code}` | Utiliser un lien de dépôt à usage unique pour enregistrer un jeton de routine Claude. |
| `/routines/claim/owner/{registration}` | Enregistrer un jeton de routine Claude en attente depuis la page Agents. |

## Enregistrer des identifiants

Collez le jeton dans le formulaire de Discord, de Telegram, d'une routine Claude ou de Grok Bot. Sélectionnez **Save token**. Pour le formulaire de webhook de Grok Bot, saisissez l'adresse. Sélectionnez **Save webhook url**.

Pour la configuration d'une GitHub App, SwB vous donne un lien pour chaque valeur manquante. Remplissez **App ID**, **Private key** ou **Webhook secret** dans le formulaire correspondant. Pour **Private key**, sélectionnez **Upload .pem file** ou collez tout le contenu du fichier `.pem`. Sélectionnez **Save** dans chaque formulaire.

Redémarrez SwB après une modification du secret de webhook GitHub.

Pour Slack, SwB vous donne un lien de dépôt par espace de travail quand un jeton manque. Remplissez les champs du formulaire commun. Sélectionnez **Save**.

## Déposer depuis le terminal

```bash
swb claim 'https://swb.example.com/claim/...'
```

Utilisez la commande pour un seul champ texte sur `/claim/{code}` ou `/routines/claim/{code}`. Utilisez le navigateur pour un formulaire à plusieurs champs ou avec un fichier. La commande masque votre saisie. Par défaut, elle utilise le serveur local. Pour un serveur distant, donnez à `--url` l'adresse de base de son SwB.

## Remplacer un identifiant


| Bloc | Remplacement d'une valeur |
| - | - |
| Grok Bot | Demandez à un agent d'appeler `connect` pour `grok-bot` avec le nom de la routine et `replace=url` ou `replace=secret`. |
| Slack | SwB crée un lien de dépôt pour un espace de travail quand un jeton configuré manque. |
| GitHub | Demandez à votre agent d'appeler `connect(what="github", choose={"replace":"secret"})` pour remplacer le secret de webhook. `webhook_secret` a le même effet. Utilisez `all` pour remplacer aussi les identifiants de l'App ou le jeton d'accès personnel |

Pour remplacer une valeur définie dans l'environnement du serveur, mettez à jour la variable d'environnement. Pour un App ID défini dans `blocks.github.app_id`, modifiez le fichier de configuration. Redémarrez SwB après une modification de la configuration ou du secret de webhook GitHub.
