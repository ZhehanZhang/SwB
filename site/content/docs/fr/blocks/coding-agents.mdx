## Obtenir les réglages

```bash
swb connect coding-agent --choose agent=codex
```

La commande indique comment ajouter SwB comme serveur MCP distant. Utilisez OAuth quand SwB et le client le prennent tous les deux en charge. Suivez les instructions d'appairage quand la commande les affiche.

| Client | Configuration |
| - | - |
| Claude Code | `claude mcp add` |
| Codex | `config.toml` |
| Gemini CLI et Qwen Code | `settings.json` |
| Goose | `config.yaml` |
| OpenCode | `opencode.json` |
| Cline et Kiro | Leurs réglages MCP |
| Autres clients | Streamable HTTP avec un code d'appairage |

Pour utiliser MCP Tasks avec Capy, consultez [MCP Tasks](/fr/docs/blocks/capy#mcp-tasks).

## Canal Claude Code

Le canal transmet les messages de la boîte aux lettres `claude-code` à une session Claude Code ouverte. Les canaux Claude Code sont un aperçu de recherche.

Générez une clé aléatoire d'au moins 24 caractères. Enregistrez-la sous `SWB_KEY_CHANNEL` dans le fichier `.env` privé du serveur. Redémarrez SwB pour charger la clé. Cette clé donne un accès en lecture à la boîte aux lettres `claude-code`. Installez [Bun](https://bun.sh). Ajoutez le plugin dans Claude Code.

```text
/plugin marketplace add ZhehanZhang/SwB
/plugin install swb@swb
```

Saisissez l'URL de base de SwB dans **SwB URL**. Saisissez la valeur de `SWB_KEY_CHANNEL` dans **Channel key**. Lancez Claude Code avec le canal.

```bash
claude --dangerously-load-development-channels plugin:swb@swb
```

Au premier lancement, le canal commence par les nouveaux messages. Aux lancements suivants, il reprend à partir de sa position enregistrée. Pour répondre via SwB, utilisez `reply` depuis la connexion MCP distincte.
