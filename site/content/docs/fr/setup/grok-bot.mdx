Grok Bot est l'application d'agent de xAI pour ordinateur. Une routine est une tâche enregistrée. Cette connexion utilise un webhook, une adresse web que SwB appelle pour lancer la routine.

## Avant de commencer

Installez [Grok Bot](https://x.ai/bot) sur un ordinateur compatible. Connectez-vous avec une offre qui inclut Grok Bot.

Configurez une adresse publique HTTPS et la connexion propriétaire pour SwB. Activez le bloc `grok-routine`. Choisissez un projet SwB. Avec OAuth, vous approuvez l'accès dans votre navigateur.

## Connecter Grok Bot

### Créer un Bot

Utilisez le Bot créé à la prise en main, ou sélectionnez **New Bot** avec **+** dans la barre latérale. Saisissez un nom. Sélectionnez **Create**.

### Ouvrir Connect apps

Dans la barre latérale, ouvrez **Connect apps**. Sélectionnez **Add a custom connector**.

### Saisir l'adresse

Saisissez `SwB` dans **Name**. Sous **Type**, sélectionnez **Remote HTTPS**. Saisissez `https://swb.example.com/mcp` dans **Server URL**. Sélectionnez **Add plugin**.

### Se connecter

Laissez vides les champs facultatifs du client OAuth. Si Grok Bot ouvre la connexion SwB, connectez-vous en tant que propriétaire. Approuvez l'accès. {/* unverified */}

### Ouvrir la routine

Dans la discussion de votre Bot, ouvrez la routine sous **Details**. Vérifiez le déclencheur **Webhook**.

### Enregistrer l'URL du webhook

Ouvrez le lien de dépôt de l'adresse du webhook. Copiez **POST to** depuis la routine. Collez cette valeur dans **Webhook URL**. Sélectionnez **Save webhook url**.

### Enregistrer la clé

Ouvrez le lien de dépôt de la clé du webhook. Copiez **key** depuis la routine. Collez cette valeur dans **Token**. Sélectionnez **Save token**.

### Prévenir Grok Bot

Écrivez « terminé » dans la discussion du Bot. Grok Bot teste alors la routine.

## Ce que fait l'agent

Demandez à un agent doté de l'accès propriétaire d'appeler `connect(what="grok-bot")`. SwB renvoie l'adresse MCP, l'état OAuth et un prompt de routine. Ce prompt s'appuie sur le champ `trust` du webhook pour indiquer à la routine les requêtes qu'elle peut traiter. La routine répond avec `reply`.

Demandez à Grok Bot de créer la routine avec ce prompt. Dans votre client propriétaire, enregistrez-la avec `connect(what="grok-bot", choose={"name":"<routine>","project":"<project>","auth":"key"})`. SwB crée un lien de dépôt pour l'adresse et un autre pour la clé. Une fois les deux valeurs enregistrées, exécutez l'appel `send` que renvoie `connect`.

Quand vous envoyez un message à la routine, SwB appelle son webhook pour la lancer.

## Identifiants

| Jeton | Où il apparaît | Format | Destination |
| - | - | - | - |
| URL du webhook | **POST to** sous **Webhook** dans **Details** de la routine | Adresse HTTPS | **Webhook URL** sur son lien de dépôt SwB |
| Clé du webhook | **key** sous **Webhook** dans **Details** de la routine | Texte aléatoire | **Token** sur son lien de dépôt SwB |
| Jeton de connexion SwB | Grok Bot l'obtient à votre connexion | Texte aléatoire | Grok Bot le conserve pour vous |

Un lien de dépôt est une page SwB privée à usage unique, réservée à un seul jeton. Collez chaque valeur uniquement à cet endroit.

## Vérifier la connexion

Ouvrez **Details** dans la routine. Vérifiez le déclencheur **Webhook**. Depuis votre client propriétaire, appelez de nouveau `connect(what="grok-bot")`. La ligne d'état indique le nom de la routine. Sur le client expéditeur, consultez `inbox` pour trouver la réponse de test.

## Résoudre les problèmes

Si la connexion OAuth échoue, enregistrez la routine depuis un autre client propriétaire SwB. Si le connecteur accepte une clé bearer, utilisez [une clé appairée](/fr/docs/setup/mcp-client#appairer-un-client).

Copiez la valeur de **key**. Avec l'en-tête par défaut, SwB ajoute `Authorization: Bearer`.

Utilisez `grok-routine:routine:<routine>` pour lancer la routine. Utilisez `agent:grok` pour écrire dans la boîte aux lettres de Grok.

Un lien de dépôt sert une seule fois et expire au bout de 30 minutes. Pour obtenir un nouveau lien, appelez de nouveau `connect`. Pour remplacer une valeur enregistrée, appelez `connect` avec `choose.replace` réglé sur `url` ou `secret`.
