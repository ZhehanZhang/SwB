---
title: 認証情報
description: 接続用の認証情報を、1 回限りのページで保存します。
---

**認証情報**とは、アプリへのアクセスを与える値です。SwB が認証情報を必要とするとき、エージェントが**受け取りリンク**を送ります。このリンクは、1 回限りのフォームを開きます。フォームは、ブラウザーから SwB に値を送ります。

## 受け取りリンクのしくみ

フォームを開くには、オーナーとしてサインインしてください。フォームに **SwB owner key** が表示された場合は、そのページでキーを入力してください。リンクは 1 回だけ使えて、30 分で期限が切れます。

![1 つのトークン用の受け取りページ](/shots/token-handoff-light.webp)

SwB は、データフォルダーにあるキーで値を暗号化します。ブロックは、環境変数の代わりに保存済みの値を使えます。両方を設定した場合、SwB は環境変数を優先します。

| ページ | 用途 |
| - | - |
| `/claim/{code}` | 接続用の認証情報を保存します。 |
| `/routines/claim/{code}` | ワンタイムの受け取りリンクで Claude ルーティンのトークンを保存します。 |
| `/routines/claim/owner/{registration}` | 保留中の Claude ルーティンのトークンを Agents ページから保存します。 |

## 認証情報を保存する

Discord、Telegram、Claude ルーティン、Grok Bot では、フォームにトークンを貼り付けてください。**Save token** を選択してください。Grok Bot の Webhook フォームでは、アドレスを入力してください。**Save webhook url** を選択してください。

GitHub App のセットアップでは、SwB が不足している値ごとに別のリンクを渡します。各フォームで **App ID**、**Private key**、**Webhook secret** を入力してください。**Private key** では、**Upload .pem file** を選択するか、`.pem` ファイルの内容全体を貼り付けてください。各フォームで **Save** を選択してください。

GitHub の Webhook シークレットを変更したら、SwB を再起動してください。

Slack では、トークンが不足しているとき、SwB がワークスペースごとに受け取りリンクを 1 つ渡します。共通のフォームの各欄を入力してください。**Save** を選択してください。

## ターミナルから受け取る

```bash
swb claim 'https://swb.example.com/claim/...'
```

このコマンドは、`/claim/{code}` か `/routines/claim/{code}` にある、テキスト欄が 1 つのフォームに使います。欄が複数あるフォームやファイルを扱うフォームには、ブラウザーを使ってください。このコマンドは、入力した内容を隠します。既定ではローカルのサーバーを使います。リモートのサーバーでは、`--url` にその SwB のベースアドレスを指定してください。

## 認証情報を置き換える


| ブロック | 値を置き換える方法 |
| - | - |
| Grok Bot | ルーティン名と `replace=url` か `replace=secret` を指定し、`grok-bot` 向けに `connect` を呼び出すよう、エージェントに頼みます。 |
| Slack | 設定済みのトークンが不足しているとき、SwB がワークスペース用の受け取りリンクを発行します。 |
| GitHub | Webhook シークレットを置き換えるときは、`connect(what="github", choose={"replace":"secret"})` の呼び出しをエージェントに頼みます。`webhook_secret` でも同じ結果になります。App の認証情報か個人用アクセストークンも置き換えるときは `all` を使います |

サーバーの環境で設定した値を置き換えるときは、その環境変数を更新してください。設定ファイルの `blocks.github.app_id` で設定した App ID は、設定ファイルで変更してください。設定か GitHub の Webhook シークレットを変更したら、SwB を再起動してください。
