## パソコンで実行する

[インストール](/ja/docs/install)の手順に従ってください。初めてローカルで起動すると、SwB がワンタイムのサインインリンクを表示します。そのリンクを開いてください。新しいリンクは `swb login-link` で取得できます。ローカルでのセットアップはデプロイ用プロンプトでも案内します。

## SwB をデプロイする

このプロンプトを Claude Code や Codex などのコーディングエージェントに貼り付けてください。エージェントが、ローカルまたはホスティングでのセットアップを案内します。

<SetupPrompt name="deploy" lang="ja" />

## サインインする

サービスのログに出るサインイン用アドレスを開いてください。`SWB_SETUP_CODE` をコピーします。この値は、サービスの設定か、デプロイコマンドが示す非公開ファイルにあります。その値を **Setup code** に貼り付けてください。**Sign in** を選択します。次回からのサインイン用に[パスキー](/ja/docs/owner-login#パスキー)を追加してください。

## エージェントを接続する

[SwB をエージェントに 1 つ接続](/ja/docs/connect)します。次に、このプロンプトをそのエージェントに貼り付けてください。ほかのアプリの接続もそのエージェントに頼んでください。
