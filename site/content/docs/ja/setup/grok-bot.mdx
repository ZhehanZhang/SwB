Grok Bot は、xAI のデスクトップ用エージェントアプリです。ルーティンとは、保存したタスクです。この接続では Webhook を使います。Webhook とは、SwB がルーティンを開始するために呼び出す Web アドレスです。

## 始める前に

対応しているパソコンに [Grok Bot](https://x.ai/bot) をインストールしてください。Grok Bot を含むプランでサインインしてください。

SwB の公開 HTTPS アドレスと、オーナーのサインインを設定してください。`grok-routine` ブロックを有効にしてください。SwB のプロジェクトを選んでください。OAuth では、ブラウザーでアクセスを承認します。

SwB を追加したあと、このプロンプトを Bot のチャットに貼り付けてください。

## Grok Bot を接続する

### Bot を作成する

オンボーディングで作った Bot を使うか、サイドバーの **+** から **New Bot** を選択します。名前を入力してください。**Create** を選択します。

### Connect apps を開く

サイドバーで **Connect apps** を開いてください。**Add a custom connector** を選択します。

### アドレスを入力する

**Name** に `SwB` と入力してください。**Type** で **Remote HTTPS** を選択します。**Server URL** に `https://swb.example.com/mcp` と入力してください。**Add plugin** を選択します。

### サインインする

任意入力の OAuth クライアントの欄は空のままにしてください。Grok Bot が SwB のサインインを開いたら、オーナーとしてサインインしてください。アクセスを承認してください。{/* unverified */}

### ルーティンを開く

Bot のチャットの **Details** からルーティンを開いてください。**Webhook** のトリガーを確認してください。

### Webhook の URL を保存する

Webhook のアドレス用の受け取りリンクを開いてください。ルーティンの **POST to** をコピーしてください。**Webhook URL** に貼り付けてください。**Save webhook url** を選択します。

### キーを保存する

Webhook のキー用の受け取りリンクを開いてください。ルーティンの **key** をコピーしてください。**Token** に貼り付けてください。**Save token** を選択します。

### Grok Bot に伝える

Bot のチャットで、完了したことを伝えてください。すると、Grok Bot がルーティンをテストします。

## エージェントの動作

オーナー権限を持つエージェントで `connect(what="grok-bot")` を呼び出してください。SwB は、MCP アドレス、OAuth の状態、ルーティン用のプロンプトを返します。このプロンプトは、Webhook の `trust` 欄を使って、ルーティンが対応できるリクエストを伝えます。ルーティンは `reply` で回答します。

このプロンプトでルーティンを作成するよう、Grok Bot に頼んでください。オーナー用クライアントで、`connect(what="grok-bot", choose={"name":"<routine>","project":"<project>","auth":"key"})` を使ってルーティンを登録してください。SwB は、アドレスとキーについて別々の受け取りリンクを作ります。両方を保存したら、`connect` が返す `send` の呼び出しを実行してください。

ルーティンに送ると、SwB はその Webhook を呼び出してルーティンを開始します。

## 認証情報

| トークン | 表示される場所 | 形式 | 入力する場所 |
| - | - | - | - |
| Webhook の URL | ルーティンの **Details** の **Webhook** にある **POST to** | HTTPS アドレス | SwB の受け取りリンクの **Webhook URL** |
| Webhook のキー | ルーティンの **Details** の **Webhook** にある **key** | ランダムな文字列 | SwB の受け取りリンクの **Token** |
| SwB のサインイントークン | サインイン時に Grok Bot が受け取ります | ランダムな文字列 | Grok Bot が保管します |

受け取りリンクとは、1 つのトークンを入力するための、SwB の 1 回限りの非公開ページです。各値はそのページにだけ貼り付けてください。

## 接続を確認する

ルーティンの **Details** を開いてください。**Webhook** のトリガーを確認してください。オーナー用クライアントから、もう一度 `connect(what="grok-bot")` を呼び出してください。状態の行にルーティン名が出ます。送信側のクライアントで `inbox` を確認し、テストの返信を探してください。

## 問題を解決する

OAuth のサインインに失敗したら、別の SwB のオーナー用クライアントでルーティンを登録してください。コネクターがベアラーキーを受け付ける場合は、[ペアリング済みのキー](/ja/docs/setup/mcp-client#クライアントをペアリングする)を使ってください。

**key** の値をコピーしてください。既定のヘッダーでは、SwB が `Authorization: Bearer` を付けます。

ルーティンの開始には `grok-routine:routine:<routine>` を使います。Grok のメールボックスに送るときは `agent:grok` を使います。

受け取りリンクは 1 回だけ使えて、30 分で期限が切れます。新しいリンクが必要なときは、もう一度 `connect` を呼び出してください。保存した値を変えるときは、`choose.replace` を `url` か `secret` にして `connect` を呼び出してください。
