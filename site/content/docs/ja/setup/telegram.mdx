SwB は、BotFather で作成したボットを通じて Telegram とやり取りします。SwB が新しいメッセージを Telegram に問い合わせるので、SwB サーバーは非公開のアドレスでも使えます。

## 始める前に

Telegram のアカウントを使ってください。グループを接続するときは、メンバーを追加できるアカウントを使ってください。オーナーとして SwB にサインインしてください。

## セットアップ用プロンプトをコピーする

このプロンプトを、SwB のオーナー用クライアントに貼り付けてください。

## Telegram のボットを設定する

### BotFather を開く

Telegram で https://t.me/BotFather を開いてください。BotFather と初めてチャットする場合は、**Start** をタップしてください。
### ボットを作成する

`/newbot` を送ってください。表示名を返信してください。

### ユーザー名を選ぶ

`bot` で終わるユーザー名を返信してください。BotFather がトークンを返信します。
### トークンを保存する

エージェントから届いた SwB の受け取りリンクを開いてください。欄にトークンを貼り付けてください。
### 個人チャットを始める

ボットとの個人チャットで **Start** をタップしてください。SwB があなたのユーザー ID を見つけられるように、メッセージを 1 つ送ってください。
### ボットをグループに追加する

エージェントから届いたグループ用のリンクを開いてください。グループを選んでください。

### セットアップ用のコマンドを送る

グループで `/swb@<bot username>` を送ってください。これで、SwB がグループの ID を把握します。
### グループのすべてのメッセージを読む

ボットにすべてのメッセージを読ませたいグループがある場合は、BotFather に `/setprivacy` を送ってください。あなたのボットを選んでください。**Disable** を選択します。

### ボットをもう一度追加する

各グループからボットを削除してください。そのグループに、もう一度ボットを追加してください。

## エージェントの動作

エージェントは `connect(what="telegram")` を呼び出します。必要に応じて `telegram` ブロックを有効にします。ブロックが有効になると、`connect` か `telegram_provision` がボットトークン用の受け取りリンクを返します。

あなたがトークンを保存すると、エージェントは `telegram_status` を呼び出します。ボットとプライバシーモードを確認します。グループへの招待は `setup.add_to_group_url` にあります。最近のチャット ID は `setup.seen_chats` にあります。

エージェントは、`config/switchboard.yaml` の `blocks.telegram.spaces` でスペースを設定します。スペースは、チャットのまとまりを SwB のプロジェクトに結び付けます。グループの ID を `chats` に設定してください。あなたのユーザー ID を `owner_ids` に設定してください。ファイルを編集したら、SwB を再起動してください。

## 認証情報

| トークン | Telegram で表示される場所 | 形式 | 入力する場所 |
| --- | --- | --- | --- |
| ボットトークン | `/newbot` か `/token` のあとの BotFather からの返信 | 数字、コロン記号、英数字の順に並んだ文字列 | SwB の受け取りリンク |

## 接続を確認する

もう一度 `connect` を呼び出すよう、エージェントに頼んでください。セットアップが完了すると、`connected` と報告します。

`owner_ids` にある Telegram アカウントを使ってください。個人チャットで、ボットに `/swb <target> hello` を送ってください。`<target>` を、`targets` にある送信先の名前に置き換えてください。返信が届くことを確認してください。

## 問題を解決する

グループでボットがコマンドだけを読む場合は、BotFather でプライバシーモードをオフにしてください。そのあと、ボットを削除して、もう一度追加してください。

Webhook とは、Telegram がメッセージを送る Web アドレスです。古い Webhook が残っている場合は、Telegram の `deleteWebhook` メソッドで削除するよう、ボットのオーナーに頼んでください。
