> [Section 6 of the Apache License 2.0](https://github.com/ZhehanZhang/SwB/blob/release/1.0/LICENSE#L139-L142) grants no trademark rights. It permits customary use to credit the source and reproduce `NOTICE`.

上の条項は Apache License 2.0 の原文です。商標の権利は、この条項の範囲外です。出典の表示と `NOTICE` の複製には、慣例どおり名称を使えます。

フォークとは、プロジェクトを別に複製したものです。別のプロジェクト、フォーク、サービスでは、次のような声明を使ってください。ZhehanZ から書面で許可を得た場合は、その条件に従ってください。

> This project is separate from SwB. It is not affiliated with SwB and has no endorsement from SwB.

上の声明は英語の原文です。そのプロジェクトが SwB とは別のもので、SwB の提携先でも推薦を受けたものでもあることを示します。

「SwB に対応」のように、事実にもとづいて SwB に言及できます。

SwB への貢献を歓迎します。フォークよりも貢献をおすすめします。フォークには、SwB と区別できる独自の名前とロゴを付けてください。`LICENSE` と `NOTICE` はそのまま残してください。「[Based on SwB](https://github.com/ZhehanZhang/SwB)」のように、リンク付きで SwB を出典として示してください。
