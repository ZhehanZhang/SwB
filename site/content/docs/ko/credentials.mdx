---

**자격 증명**은 앱에 접근하게 해 주는 값입니다. SwB에 자격 증명이 필요하면 에이전트가 **등록 링크**를 보냅니다. 이 링크는 일회용 양식을 엽니다. 양식은 브라우저에서 SwB으로 값을 직접 보냅니다.

## 등록 링크의 작동 방식

양식을 열려면 소유자로 로그인하세요. 양식에 **SwB owner key**가 보이면 그 페이지에 소유자 키를 입력하세요. 링크는 한 번만 쓸 수 있고 30분 뒤에 만료됩니다.

![토큰 하나를 등록하는 페이지](/shots/token-handoff-light.webp)

SwB은 데이터 폴더에 있는 키로 값을 암호화합니다. 블록은 환경 변수 대신 저장된 값을 쓸 수 있습니다. 두 값을 모두 설정하면 SwB은 환경 변수를 먼저 사용합니다.

| 페이지 | 용도 |
| - | - |
| `/claim/{code}` | 연결용 자격 증명을 저장합니다. |
| `/routines/claim/{code}` | 일회용 등록 링크로 Claude 루틴 토큰을 저장합니다. |
| `/routines/claim/owner/{registration}` | Agents 페이지에서 대기 중인 Claude 루틴 토큰을 저장합니다. |

## 자격 증명 저장

Discord, Telegram, Claude 루틴, Grok Bot은 양식에 토큰을 붙여 넣으세요. **Save token**을 선택하세요. Grok Bot 웹훅 양식에는 주소를 입력하세요. **Save webhook url**을 선택하세요.

GitHub App을 설정하면 SwB이 빠진 값마다 별도의 링크를 줍니다. 각 양식에서 **App ID**, **Private key**, **Webhook secret**을 채우세요. **Private key**는 **Upload .pem file**을 선택하거나 `.pem` 파일의 전체 내용을 붙여 넣으세요. 각 양식에서 **Save**를 선택하세요.

GitHub 웹훅 시크릿을 바꾼 뒤에는 SwB을 다시 시작하세요.

Slack은 토큰이 빠진 워크스페이스마다 SwB이 등록 링크를 하나씩 줍니다. 공유 양식의 필드를 채우세요. **Save**를 선택하세요.

## 터미널에서 등록

```bash
swb claim 'https://swb.example.com/claim/...'
```

`/claim/{code}`나 `/routines/claim/{code}`에서 텍스트 필드가 하나일 때 이 명령을 사용하세요. 필드가 여러 개이거나 파일이 필요한 양식은 브라우저를 사용하세요. 이 명령은 입력하는 내용을 화면에 가립니다. 기본적으로 로컬 서버를 사용합니다. 원격 서버는 `--url`에 그 서버의 SwB 기본 주소를 설정하세요.

## 자격 증명 교체

| 블록 | 값을 바꾸는 방법 |
| - | - |
| Grok Bot | 에이전트에게 루틴 이름과 `replace=url` 또는 `replace=secret`을 넣어 `grok-bot`에 `connect`를 호출하도록 요청하세요. |
| Slack | 설정된 토큰이 빠진 워크스페이스에 SwB이 등록 링크를 발급합니다. |
| GitHub | 웹훅 시크릿을 바꾸려면 에이전트에게 `connect(what="github", choose={"replace":"secret"})` 호출을 요청하세요. `webhook_secret`도 같은 효과를 냅니다. App 자격 증명이나 개인 액세스 토큰까지 바꾸려면 `all`을 사용하세요. |

서버 환경에 설정한 값은 환경 변수를 업데이트해서 바꾸세요. 설정 파일의 `blocks.github.app_id`에 둔 App ID는 설정 파일에서 바꾸세요. 설정이나 GitHub 웹훅 시크릿을 바꾼 뒤에는 SwB을 다시 시작하세요.
