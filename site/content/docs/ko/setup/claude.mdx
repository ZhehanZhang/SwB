커넥터는 Claude가 외부 서비스의 도구를 쓰게 해 줍니다. SwB 커넥터를 쓰면 Claude가 프로젝트를 읽고, 다른 에이전트에게 작업을 보내고, 메시지에 답합니다.

## 시작하기 전에

Claude Free 플랜에서는 사용자 지정 커넥터를 하나 쓸 수 있습니다. Pro, Max, Ultra, Team, Enterprise도 사용자 지정 커넥터를 지원합니다.

SwB에 소유자 로그인을 설정하세요. Claude가 `/mcp`에 접속할 수 있도록 443 포트의 공개 HTTPS 주소를 사용하세요.

이 프롬프트를 Claude 채팅에 붙여 넣으세요.

## Claude에 SwB 추가

<Tabs items={['Personal plan', 'Team or Enterprise']}>
<Tab value="Personal plan">
### 사용자 지정 커넥터 추가

Claude에서 [Customize → Connectors](https://claude.ai/customize/connectors)를 여세요.
**+ Add**를 선택하세요. **Add custom connector**를 선택하세요.
### 주소 입력

이름에 `SwB`을 입력하세요. `https://swb.example.com/mcp` 같은 SwB MCP 주소를 입력하세요.
### 기본 로그인 설정 유지

로그인 설정을 검토하려면 **Continue**를 선택하세요. **Authentication**에서 **Sign in now**를 선택하세요. **OAuth client**에서 **Use Claude’s published identity (Recommended)**를 선택하세요. **Request headers**는 비워 두세요.
### 추가하고 연결

**Add**를 클릭하세요. 목록에서 SwB에 **Connect**가 보이면 **Connect**를 클릭하세요.
### SwB에서 승인

**Sign in to SwB** 페이지에서 로그인하세요. **Connect to SwB** 페이지에서 이름을 확인하고 **Approve**를 클릭하세요.
</Tab>
<Tab value="Team or Enterprise">
### 관리자 페이지 열기

사용자 지정 커넥터를 추가할 권한이 있는 계정으로 [Organization settings → Connectors](https://claude.ai/admin-settings/connectors)를 여세요. Team에서는 Owner나 Primary Owner 계정을 사용하세요.
### 웹 커넥터 추가

**Add**를 클릭하세요. **Custom**을 가리킨 다음 **Web**을 클릭하세요.
### 주소 입력

이름에 `SwB`을 입력하세요. SwB MCP 주소를 입력하세요. **Continue**를 선택하세요. 로그인 설정을 검토하세요. **Sign in now** 또는 **Sign in when needed**를 선택하세요. **Use Claude’s published identity (Recommended)**를 선택하세요. **Add**를 선택하세요.
### 계정 연결

**Customize** → **Connectors**를 여세요. `SwB`을 찾아 **Connect**를 클릭하세요.
### SwB에서 승인

**Sign in to SwB** 페이지에서 로그인하세요. **Connect to SwB** 페이지에서 **Approve**를 클릭하세요.
</Tab>
</Tabs>

### 채팅에서 SwB 켜기

채팅에서 **+** → **Connectors**를 선택하세요. SwB을 켜세요. Claude Project에서는 코디네이터 채팅을 사용하세요.

## 에이전트가 하는 일

에이전트가 `connect(what="claude")`를 호출합니다. SwB은 MCP 주소와 OAuth 사용 가능 여부를 돌려줍니다. OAuth를 쓰면 브라우저에서 접근을 승인합니다.

에이전트는 클릭 경로와 주소를 알려 줍니다. 승인하면 에이전트가 `connect`를 다시 호출합니다. SwB은 클라이언트가 로그인했다고 답합니다.

## 자격 증명

| 항목 | 표시되는 곳 | 형식 | 입력할 곳 |
| - | - | - | - |
| MCP 주소 | SwB 설정과 `connect` 결과 | `https://swb.example.com/mcp` | Claude 커넥터의 URL 필드 |
| SwB 액세스 토큰 | **Approve**를 클릭하면 Claude가 받아 둡니다 | 임의 텍스트 | Claude가 대신 저장합니다 |

## 연결 확인

**Customize** → **Connectors**를 열고 `SwB`이 연결됨으로 표시되는지 확인하세요. Claude에게 `project_list` 호출을 요청하세요. SwB 프로젝트 목록이 나오면 연결된 것입니다.

## 문제 해결

`/mcp`로 끝나는 공개 HTTPS 주소를 사용하세요. Claude가 `/mcp`에 직접 접속할 수 있게 하세요. SwB 주소가 바뀌면 커넥터를 제거하세요. 새 주소로 커넥터를 다시 추가하세요.
