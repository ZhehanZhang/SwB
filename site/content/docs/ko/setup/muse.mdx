Muse에 SwB을 사용자 지정 커넥터로 추가하세요. 커넥터는 Muse가 SwB 도구를 쓰게 해 줍니다. Muse는 `muse`로 로그인합니다.

## 시작하기 전에

SwB에 공개 HTTPS 주소와 소유자 로그인을 설정하세요. `https://swb.example.com/mcp` 자리에는 내 SwB 주소를 사용하세요.

Muse는 OAuth로 로그인합니다. OAuth를 쓰면 브라우저에서 접근을 승인합니다.

## Muse 연결

이 프롬프트를 Muse 채팅에 붙여 넣으세요. Muse에게 SwB MCP 주소를 OAuth 사용자 지정 커넥터로 추가해 달라고 요청하세요. Muse가 준 로그인 링크를 여세요. 소유자로 SwB에 로그인하세요.

## Muse 실시간으로 깨우기

메시지가 도착하면 SwB이 Muse를 깨울 수 있습니다. SwB과 Muse를 한 번 페어링하세요. Bluetooth가 있는 Mac이나 Linux 컴퓨터를 사용하세요. 컴퓨터를 휴대폰 가까이에 두세요.

소유자 권한을 모두 가진 에이전트에게 `connect(what="muse", choose={"gadget": true})` 호출을 요청하세요. 돌려받은 안내를 따르세요.

[Muse SDK tokens](https://gadgets.muse.ai/settings/sdk-tokens)에서 개인 토큰을 받으세요. 에이전트가 준 SwB 등록 링크로 토큰을 저장하세요.

Muse 기능을 켠 [컴패니언](/ko/docs/companion)을 온라인 상태로 사용하세요. 이미 SwB과 페어링된 기기에 이 기능을 추가하려면 그 기기에서 `swb companion disconnect`를 실행하세요.

컴패니언을 페어링해야 한다면 컴퓨터에서 이 명령을 실행하세요. 예시 주소를 내 SwB 주소로 바꾸세요.

```sh
uvx --python 3.13 --from 'swb-one[companion]' swb companion connect https://swb.example.com --cap muse
```

명령이 입력을 요청하면 에이전트가 준 페어링 코드를 입력하세요. 에이전트에게 Muse 페어링을 시작해 달라고 요청하세요.

Muse 앱에서 **Settings**를 여세요. **Devices**를 여세요. **Developer mode**를 켜세요. **Add Device**를 선택하세요. 에이전트가 알려 준 기기 이름을 고르세요. 앱이 Wi-Fi를 요청하면 **Use current connection**을 선택하세요.

SwB은 배포된 서버에서 Muse 연결을 유지합니다. 페어링한 뒤에는 컴퓨터가 잠자기 상태가 되어도 됩니다.

## 연결 확인

다른 SwB 에이전트에게 `send(to="agent:muse", task="SwB setup test: reply pong")` 호출을 요청하세요. Muse에게 `inbox`를 호출하고 테스트 대화에 답장해 달라고 요청하세요.

실시간 깨우기를 확인하려면 소유자 에이전트에게 `send(to="muse:gadget:muse", task="SwB wake test: reply pong")` 호출을 요청하세요. 테스트 대화에서 답장을 읽으세요.
