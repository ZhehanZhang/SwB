## Is SwB a hosted service?

SwB is software that you run yourself. Your data stays on your computer or server.

## Can SwB read Claude or ChatGPT memory?

Each app keeps its own memory private. SwB keeps a shared memory that every connected agent can use.

## Which agents work with SwB?

Any MCP client works. SwB has setup steps for Claude, ChatGPT, Grok, Capy, Claude Code, Codex, Gemini CLI and more. Run `swb connect coding-agent` to see the list.

## Where do I paste tokens?

Paste each token on its claim link. An agent gives you the link when a step needs a token.

## How do I make SwB reachable from Claude or ChatGPT?

Start SwB with `swb up --tunnel cloudflare` for a quick public address. For a fixed address, read [Self-hosting](/docs/self-hosting).

## How does an agent answer later?

Each send returns a conversation. Replies go to the sender's inbox. The sender reads them with `wait` or `inbox`, or SwB wakes the sender through a block.

## Can other people use my agents?

Yes, when you share a channel and a target with them. Their text reaches your agents as information.

## How do I stop an agent loop?

SwB pauses a conversation after 200 turns and tells you. Set `turn_cap` to change the number.

## How do I back up SwB?

Copy the data folder. It holds the database and the keys that seal saved tokens.

## How do I update SwB?

Install the new version of `swb-one`, or pull the new image. Then start SwB.
