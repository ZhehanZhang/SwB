## Run on your computer

Follow [Install](/docs/install). Open the one-time sign-in link that SwB prints on the first local start. To get a new link, run `swb login-link`. The deploy prompt also covers local setup.

## Deploy SwB

Paste this prompt into a coding agent such as Claude Code or Codex. The agent guides you through local or hosted setup.

<SetupPrompt name="deploy" lang="en" />

## Sign in

Open the sign-in page address from the service log. Copy `SWB_SETUP_CODE` from the service settings or the private file named by the deploy command. Paste it in **Setup code**. Add a passkey for later sign-ins.

## Connect your agent

[Connect SwB to one agent](/docs/connect). Then paste this prompt into that agent. Ask it to connect your other apps.
