This page is for people who work through agents. You deploy SwB on a cloud platform, sign in one time, and give your agent the setup prompt.

<DeployLive>

## Deploy SwB

[![Deploy to Render](https://render.com/images/deploy-to-render-button.svg)](https://render.com/deploy?repo=https://github.com/ZhehanZhang/SwB)

<Steps>
<Step>
### Start the deploy

Click **Deploy to Render**. Sign in to Render. Keep the default settings and click **Deploy**. {/* unverified */}
</Step>
<Step>
### Wait for the service

Render builds SwB in a few minutes. The service page shows **Live** when SwB is ready.
</Step>
<Step>
### Copy your address

Copy the service URL at the top of the page, for example `https://swb-example.onrender.com`. Your MCP address is this URL with `/mcp` at the end.
</Step>
</Steps>

## Sign in

<Steps>
<Step>
### Copy the setup code

Open **Environment** in your Render service. Copy the value of `SWB_SETUP_CODE`.
</Step>
<Step>
### Open the sign-in page

Open **Logs** in your Render service. Open the sign-in page address that the log shows. {/* unverified */}
</Step>
<Step>
### Enter the code

Paste the code in **Setup code**. Add a passkey to sign in again. The setup code works one time.
</Step>
</Steps>

</DeployLive>

## Deploy SwB

Paste this prompt into a coding agent, for example Claude Code or Codex. The agent deploys SwB on Fly.io, Koyeb or your server with Docker. It tells you the private file that holds your setup code.

<SetupPrompt name="deploy" lang="en" />

## Sign in

Open the sign-in page address from the service log. Paste the code from the private file in **Setup code**. Add a passkey to sign in again. The setup code works one time.

</DeployHeld>
