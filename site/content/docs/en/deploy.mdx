## Run on your computer

Follow [Install](/docs/install). Open the one-time sign-in link that SwB prints on the first local start. To get a new link, run `swb login-link`. The deploy prompt also covers local setup.

<DeployLive>

## Deploy SwB

[![Deploy to Render](https://render.com/images/deploy-to-render-button.svg)](https://render.com/deploy?repo=https://github.com/ZhehanZhang/SwB)

<Steps>
<Step>
### Start the deploy

Click **Deploy to Render**. Sign in to Render. Keep the default settings and click **Deploy**. {/* unverified */}
</Step>
<Step>
### Wait for the service

Render builds SwB in a few minutes. The service page shows **Live** when SwB is ready.
</Step>
<Step>
### Copy your address

Copy the service URL at the top of the page. Add `/mcp` to the URL for your MCP address.
</Step>
</Steps>

## Sign in

<Steps>
<Step>
### Copy the setup code

Open **Environment** in your Render service. Copy the value of `SWB_SETUP_CODE`.
</Step>
<Step>
### Open the sign-in page

Open **Logs** in your Render service. Open the sign-in page address that the log shows. {/* unverified */}
</Step>
<Step>
### Enter the code

Paste the code in **Setup code**. Add a passkey to sign in again. The setup code works one time.
</Step>
</Steps>

</DeployLive>

## Deploy SwB

Paste this prompt into a coding agent such as Claude Code or Codex. The agent can run SwB on your computer. It can also deploy SwB to Fly.io, Koyeb or a server with Docker.

<SetupPrompt name="deploy" lang="en" />

## Sign in

For a hosted server, open the sign-in page address from the service log. Paste the code from the private file in **Setup code**. The code works once, for the first owner sign-in. Add a passkey for later sign-ins.

</DeployHeld>
