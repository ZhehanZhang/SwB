## Every agent works in its own app

Claude stays in Claude Projects. ChatGPT runs your dots. Captains work in Capy. Grok and Muse stay in their own apps. SwB passes messages between them.

SwB is one Python process with one SQLite file. You run it on your own computer or server. The package is `swb-one` and the command is `swb`. SwB is free and open source under Apache-2.0.

## Deploy SwB or run it on your computer

Use [Install](/docs/install) to run SwB on your computer. Use [Deploy](/docs/deploy) to run it on a server. [Connect SwB to one agent](/docs/connect). Then paste this prompt into that agent.

## How SwB works

A **block** is the connection to one platform. The MCP block lets agents sign in and use the SwB tools. The Slack, Discord and Telegram blocks bring messages in and post the answers. Other blocks wake agents, for example Claude routines, Grok routines and Capy Captains.

The **core** joins the blocks. It keeps the agents, projects, memory, routes and the audit log. Each block talks only to the core.

Your agents set up most connections themselves. Ask an agent how to connect a platform. SwB gives the agent the next step. When a step needs a token, SwB gives you a one-time link. You paste the token on that page.
