---
title: Muse
description: Wake Meta Muse through a paired device.
---

SwB sends text to [Meta Muse](https://muse.ai/) and returns the answer to the sender. A small Linux device carries the messages. You pair this device with your own Muse account, and it shows as SwB in the Muse app. This is a personal integration. Read [Meta's Gadget SDK Token Terms](https://gadgets.muse.ai/sdk-terms) first.

## Set up the server

Add `muse: {use: muse}` under `blocks` in `config/switchboard.yaml` and restart SwB. Run `swb connect muse`. You can also ask your agent to call `connect(what="muse")`.

SwB returns a claim link. A claim link is a one-time page where you paste a secret. Make a bridge token of 64 random letters and digits in a password manager. Save it at the claim link. The device uses this token to connect to SwB.

## Set up the device

Use a Linux device with Bluetooth LE. Use a separate user account on it. The device must reach Muse and your SwB address. On Ubuntu 24.04, install `bluez`, `python3-dbus`, `python3-gi` and `python3-venv`. Then install SwB with the Muse SDK.

```bash
/usr/bin/python3 -m venv --system-site-packages .venv-muse
.venv-muse/bin/pip install swb-one 'musegadget @ git+https://github.com/facebookincubator/muse-gadget-sdk.git@a5f809f621c4cbdbd37336fe17e7cdb74cebf3fe#subdirectory=linux'
```

Get a [personal Gadget SDK token](https://gadgets.muse.ai/settings/sdk-tokens). Start the bridge.

```bash
.venv-muse/bin/swb muse-bridge --url https://swb.example.com --setup
```

Enter the bridge token and the Meta token at the hidden prompts. The Meta token and the pairing data stay on the device.

## Pair in the Muse app

Open the Muse app. Turn on Settings → Devices → Developer mode. Tap Add Device. Pick the Bluetooth name that SwB prints.

Keep the bridge running. After a restart, start it again with `swb muse-bridge --url https://swb.example.com`.

## Send to Muse

Run `swb connect muse` again for a test message. Then use `send(to="muse", task="...")`, or set a route to `muse:gadget:muse`. The answer comes back to the sender's inbox and to `result` on the same conversation. SwB sends only messages from the owner to Muse.

SwB holds messages while the device is offline. Each wake opens a new chat in Muse.

To change the bridge token, run `swb connect muse --choose replace=true`. Then start the bridge with `--setup`.
