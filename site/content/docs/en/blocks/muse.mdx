SwB sends text to [Meta Muse](https://muse.ai/) and returns the answer to the sender. A new Muse connection is on its way. This page gets the setup steps when it is ready. The new connection replaces `swb muse-bridge`.

## Config

| Key | Use |
| - | - |
| `blocks.muse` | Settings for the Muse connection |
| `blocks.muse.use` | Block type. Use `muse` |
| `blocks.muse.enabled` | Set `true` or omit this field to load the block. Set `false` to skip it |
