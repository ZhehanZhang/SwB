## Add the connector

In grok.com, open Connectors → New Connector → Custom. Enter your public MCP address and sign in with OAuth.

## Wake Grok Bot with a routine

Ask an agent to connect Grok Bot. From a terminal, run `swb connect grok-bot` for the routine prompt.

Create a Grok Bot routine with the prompt and a custom webhook trigger. Register the routine with SwB. Use your project name in place of `example`.

```bash
swb connect grok-bot --choose name=project-triage project=example auth=key
```

SwB gives you separate claim links for the webhook address and key. Paste each value in its claim link. Run the same command again to get the test send. A `pong` in your inbox confirms the routine works.

## How a wake works

SwB sends a webhook request to start the routine. With `auth=key`, SwB sends the key as a bearer token by default. With `auth=signature`, SwB signs the request. The request gives the text, conversation, project, sender and trust level. The routine answers through its SwB connector.

```yaml
blocks:
  grok-routine:
    routines:
      project-triage: {project: example, url_env: GROK_ROUTINE_URL, auth: key, secret_env: GROK_ROUTINE_SECRET}
```

Send to a routine by its name, or to `grok:<slug>` for the main routine of a project.

## Config

| Key | Use |
| - | - |
| `blocks.grok-routine` | Settings for waking Grok Bot routines |
| `blocks.grok-routine.use` | Block type. Use `grok-routine` |
| `blocks.grok-routine.enabled` | Set `false` to skip this block |
| `blocks.grok-routine.routines` | Map from routine names to settings |
| `blocks.grok-routine.routines.*.project` | SwB project short name. Use `null` for a general routine |
| `blocks.grok-routine.routines.*.primary` | Set `true` to choose this routine first for its project |
| `blocks.grok-routine.routines.*.auth` | Use `key` to send a key or `signature` to sign the request. Default `key` |
| `blocks.grok-routine.routines.*.header` | HTTP header for the key or signature. Defaults are `Authorization` for `key` and `Webhook-Signature` for `signature` |
| `blocks.grok-routine.routines.*.url_env` | Name of the variable that holds the public HTTPS webhook address |
| `blocks.grok-routine.routines.*.secret_env` | Name of the variable that holds the key or signing secret |
