## Get the settings

```bash
swb connect coding-agent --choose agent=codex
```

The command prints the setup for that client. Each setup adds SwB as a remote MCP server and uses OAuth when the client supports it.

| Client | Setup |
| - | - |
| Claude Code | `claude mcp add` |
| Codex | `config.toml` |
| Gemini CLI and Qwen Code | `settings.json` |
| Goose | `config.yaml` |
| OpenCode | `opencode.json` |
| Cline and Kiro | Their MCP settings |
| Other clients | Streamable HTTP with a pairing code |

For [MCP Tasks](/docs/how-it-works#conversations), MCP 2026-07-28 clients discover the extension with `server/discover` and opt in on each Capy send. MCP 2025-11-25 clients and mailbox sends use regular conversations.

## Claude Code channel

The channel pushes SwB messages into an open Claude Code session. It is a research preview.

Make a key named `SWITCHBOARD_KEY_CHANNEL` in the server `.env`. This key can read the `claude-code` inbox only. Install [Bun](https://bun.sh). Then add the plugin in Claude Code.

```text
/plugin marketplace add ZhehanZhang/SwB
/plugin install switchboard@switchboard
```

Enter the SwB address and the channel key when the plugin asks. Start Claude Code with the channel.

```bash
claude --dangerously-load-development-channels plugin:switchboard@switchboard
```

The channel works while the session is open. Messages that arrive between sessions appear at the next start. To answer, Claude uses the `reply` tool.
