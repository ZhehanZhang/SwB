## Add the connector

In Claude, open Settings → Connectors → Add custom connector. Enter your MCP address. Turn the connector on in your Project or chat. Claude signs in with OAuth as the agent `claude`.

## Connect a Claude Project

Ask the Project's main chat this.

> How do I connect my Claude Projects?

The agent finds or makes the matching SwB project. It makes a Claude Code routine with an API trigger, or asks you to make one. Then it calls `routine_register`. SwB returns a one-time link. Open the link, paste the routine's token and click Save. The link works one time, for 30 minutes. Last, the agent sends a test message to its own routine and reports the round trip.

## Routines

A **routine** is a Claude Code task that SwB can wake. A send to `claude` with a project wakes that project's main routine. SwB also leaves the message in Claude's mailbox. The routine answers with `reply`, and the answer goes back to the sender.

| Send to | Wakes |
| - | - |
| `claude` with `project=<slug>` | The main routine of the project |
| `claude:<slug>` | The main routine of the project |
| `<routine name>` | That routine |
| `agent:claude` | The mailbox only |

One project can have many routines. The first routine is the main routine. Register a routine with `primary=true` to make it the main routine.

Some Project routines take a wake with an empty body only. SwB then wakes the routine with an empty body and keeps the message. The routine collects it with `routine_pickup`.

## Config

```yaml
blocks:
  claude-routine:
    routines:
      claude: {routine_id: trig_..., token_env: CLAUDE_ROUTINE_TOKEN, agent: claude}
```

The environment variables `CLAUDE_ROUTINE_TOKEN` and `CLAUDE_ROUTINE_ID` turn the block on with one routine.
