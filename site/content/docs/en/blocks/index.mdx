A block adds a connection or feature to SwB. Set up blocks in the config file. SwB detects some blocks from environment variables when it uses the default config. Run `swb status` for block status and setup guidance. Sign in as the owner to see details at `/healthz`.

| Connection | Connects with | How SwB passes messages |
| - | - | - |
| [Claude](/docs/blocks/claude) | Custom connector and Claude routines | `wait`, `inbox` and routine wakes |
| [ChatGPT](/docs/blocks/chatgpt) | Custom MCP server and ChatGPT dots | MCP Events |
| [Capy](/docs/blocks/capy) | Capy API key | The Capy thread stream |
| [Grok](/docs/blocks/grok) | MCP connector and Grok Bot routines | `wait`, `inbox` and routine wakes |
| [Coding agents](/docs/blocks/coding-agents) | OAuth or a pairing code | `wait`, `inbox` and the Claude Code channel |
| [Local sessions](/docs/blocks/local-sessions) | Paired device | Mailbox or direct delivery to an open session |
| [Slack](/docs/blocks/slack) | Slack app over Socket Mode | Replies in the thread |
| [Discord](/docs/blocks/discord) | Bot token | Replies in the thread |
| [Telegram](/docs/blocks/telegram) | Bot token | Replies in the thread |
| [GitHub](/docs/blocks/github) | Webhook secret | Signed webhooks |
| [Muse](/docs/setup/muse) | MCP connector and paired Muse gadget | Mailbox and gadget wakes |
| [Other MCP clients](/docs/setup/mcp-client) | OAuth or a pairing code | `wait` and `inbox` |

## Trust and access

SwB checks platform IDs to set message trust. In Slack, Discord and Telegram, use `known` to help SwB decide whose messages to accept. Messages from people other than the owner carry `external` trust. See [Trust](/docs/security#trust).

Targets, channels and memory scopes are private by default. Share a resource to give others access.

## Add your own block

A block is a Python class with a manifest. The manifest describes what the block can do, where it can send messages and which secrets it uses. Register your block in the `switchboard.blocks` entry point group. Run `swb blocks list` to see the blocks configured on your server.
