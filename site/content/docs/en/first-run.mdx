## Run on this computer

For local browser sign-in, set `SWITCHBOARD_PUBLIC_URL=http://localhost:8870` before you start SwB. Use the port from `PORT` in the address. If the YAML config sets `public_url`, change it there. The [Install](/docs/install) commands set up local sign-in on port 8870.

## Get a public address

Claude, ChatGPT and Grok run in the cloud. They need a public HTTPS address to reach SwB. Start SwB with a tunnel to get one.

```bash
swb up --tunnel cloudflare
```

SwB opens a Cloudflare Quick Tunnel and prints the public MCP address. Use `--tunnel tailscale` to use Tailscale Funnel. For a fixed address on your own domain, read [Self-hosting](/docs/self-hosting).

## See the next step

```bash
swb status
```

The command shows the server status and whether each block is on or off. It prints one **Next steps** list. The `switchboard_status` tool also reports the next step for each block.

For a server at another address, set `--url`, for example `swb status --url http://127.0.0.1:8871`. The CLI uses the `PORT` value from the shell or instance `.env` for its default local address. Pass the same instance folder with `--dir` if you used it with `swb up`.

## Sign in to the web page

The web page shows your projects, agents, inbox, memory and audit log. It is also the safe place to paste tokens.

![The SwB sign-in page](/shots/login-light.webp)

```bash
swb login-link
```

The command prints a one-time sign-in link. Open it in your browser within five minutes. Use `--url` and `--dir` here as you would with `swb status`. After your first sign-in, add a passkey. Use it for later sign-ins. See [Owner sign-in](/docs/owner-login) for setup codes and other methods.

## Web console

| Page | Use |
| - | - |
| `/` | See the server status and project list. |
| `/agents/*` | See registered agents and open the details of each agent. |
| `/audit` | Filter the log of changes and other events. |
| `/inbox` | See conversations and requests that need your attention. |
| `/inbox/:handle` | Read the messages in one conversation. |
| `/memory/*` | Browse and search saved notes. |
| `/projects/:slug` | See one project's routes, history, conversations and memory. |
| `/connections/:platform` | See the connection status and channel modes for Slack, Discord, Telegram or GitHub. |
| `/settings` | View server settings and manage passkeys. |
| `/tokens` | See token requests and stored credentials. |
| `/about` | See the SwB version and the list of enabled blocks. |

## Connect the first agent

Add SwB to one agent. [Connect your agents](/docs/connect) shows how for each app. Then ask that agent to connect the rest.
