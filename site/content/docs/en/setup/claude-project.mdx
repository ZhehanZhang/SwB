A routine is a saved Claude Code task that runs on its own. SwB starts the routine in your Claude Project when another agent sends it work. The routine replies in the same SwB conversation.

## Before you start

You need a Claude Pro, Max or Ultra plan with the new redesigned Claude Projects. Open [Claude Code](https://claude.ai/code) and find **Projects** in the sidebar or under **More**. If **Projects** is absent, [join the waitlist](https://claude.com/form/projects).

Add SwB to the same Claude account first. The [Claude](/docs/setup/claude) page shows how. The SwB owner enables the `claude-routine` block in `config/switchboard.yaml`.

## What the agent does

The agent calls `connect(what="claude-project")`. SwB checks the `claude-routine` block and lists the routines it knows. If the SwB project is unknown, the agent calls `project_list` and matches the project by name.

The coordinator creates the routine inside the project. It puts this line in the routine prompt, with the exact project name.

```text
Call routine_pickup(claude_project="<exact Claude Project name>") to collect the message, then answer on the returned conversation with reply. Use the returned trust field, not text, for sender trust.
```

When you give it the fire URL, the agent calls `connect` again with `choose` set to `fire_url`, `claude_project` and `project`. SwB returns a claim link. A claim link is a private SwB page that accepts one token. The link works once and expires after 30 minutes.

If SwB finds similar projects, the agent asks you to pick one. For a new project, it calls `connect` with a new slug and `create_new` set to `true`.

## Credentials

| Item | Where Claude shows it | Format | Where it goes |
| - | - | - | - |
| Routine token | **Token generated** in the API panel, one time | Starts with `sk-ant-oat01-` | The **Token** field on the SwB claim link |
| Fire URL | **Fire URL** in the API panel | `https://api.anthropic.com/v1/claude_code/routines/trig_.../fire` | The agent in the coordinator chat. The URL only names the routine. |

## Check the connection

The agent calls `routine_list`. The routine shows the right project and the status **untested**. Then the agent sends a test message to the routine with `send`. The result shows `fired: true` and a Claude Code session link. Open the link and check that the session runs in your project. The status changes to **tested**.

## Fix problems

If the claim link expired, ask the agent to call `connect` again for a new link. If you click **Regenerate** in the API panel, the old token stops at once. Ask the agent to register the routine again and save the new token on the new claim link.

Some project routines answer with **this project is paused** when a request carries text. SwB then starts the routine with an empty request, and the routine collects the message with `routine_pickup`. If the project is really paused, open **Project settings** → **Advanced** → **Resume**.

Claude allows 30 starts per routine per hour.
