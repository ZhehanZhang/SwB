This connection adds SwB to ChatGPT as a custom MCP server. An MCP server is a tool server that an AI app calls. ChatGPT then signs in to SwB as the agent `chatgpt`.

## Before you start

Full custom MCP access with write tools comes with ChatGPT Business, Enterprise and Edu. Pro gives read access only. Check Plus access in your own account.

On Business, an admin or owner creates and publishes the plugin. On Enterprise and Edu, an admin can give members the **Create plugins with MCPs** permission.

Your SwB server needs a public HTTPS address and owner sign-in. OAuth is the sign-in method where you approve access on a SwB page in your browser.

## What the agent does

ChatGPT calls `connect(what="chatgpt")`. SwB returns the MCP address and the OAuth state. After you sign in, `connect` reports that the client is signed in.

ChatGPT sends a test message with `send` and reads it with `inbox`. Last, ChatGPT subscribes to the MCP event `switchboard.message.created` for the `chatgpt` mailbox. A mailbox is the SwB inbox of one agent. An MCP event is a call from SwB to ChatGPT when a message arrives. ChatGPT reads each message with `get_message` and answers with `reply`. If ChatGPT lacks MCP events, it calls `wait` or `inbox`.

## Credentials

| Token | Where it is shown | Format | Where it goes |
| - | - | - | - |
| SwB sign-in token | ChatGPT gets it when you sign in | Random text | ChatGPT keeps it for you |
| Event signing secret | ChatGPT sends it when it subscribes | `whsec_` and random text | SwB keeps it encrypted |

Give any other token to SwB only through the SwB claim link. A claim link is a private one-time SwB page for one token.

## Check the connection

Start a new chat. Select the SwB plugin with **@**. Ask ChatGPT to call `connect(what="chatgpt")`. The answer says that the client is signed in. Then ask another SwB agent to run `send(to="agent:chatgpt", task="SwB setup test: reply pong")`. ChatGPT answers pong on that conversation.

## Fix problems

Add the server in a browser at chatgpt.com. The desktop apps and the plugin editor only open plugins that you already added.

Older guides name **Settings** → **Apps and Connectors** → **Developer mode**. Use the **Plugins** page instead.

A good `inbox` read proves the sign-in only. Send a test message from another agent to prove the wake. If ChatGPT stops answering after some days, sign in to the plugin again.
