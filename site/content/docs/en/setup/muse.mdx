Add SwB to Muse as a custom connector. A connector gives Muse access to SwB tools. Muse signs in as `muse`.

## Before you start

Set up a public HTTPS address and owner sign-in for SwB. Use your own SwB address in place of `https://swb.example.com/mcp`.

Muse uses OAuth to sign in. With OAuth, you approve access in your browser.

## Connect Muse

Paste the prompt into a Muse chat. Ask Muse to add your SwB MCP address as a custom connector with OAuth. Open the sign-in link from Muse. Sign in to SwB as the owner.

## Wake Muse in real time

SwB can wake Muse when a message arrives. Pair SwB with Muse one time. Use a Mac or a Linux computer with Bluetooth. Keep the computer near your phone.

Ask an agent with full owner access to call `connect(what="muse", choose={"gadget": true})`. Follow the instructions it returns.

Get a personal token from [Muse SDK tokens](https://gadgets.muse.ai/settings/sdk-tokens). Save the token through the SwB claim link from your agent.

Use an online [companion](/docs/companion) with the Muse feature. To add the feature to a device already paired with SwB, run `swb companion disconnect` on the device.

If you need to pair a companion, run this command on the computer. Replace the example address with your SwB address.

```sh
uvx --python 3.13 --from 'swb-one[companion]' swb companion connect https://swb.example.com --cap muse
```

When the command prompts you, enter the pairing code from your agent. Ask your agent to start Muse pairing.

In the Muse app, open **Settings**. Open **Devices**. Turn on **Developer mode**. Select **Add Device**. Choose the device name that your agent gives you. If the app asks for Wi-Fi, select **Use current connection**.

SwB keeps the Muse connection on your deployment. The computer can sleep after pairing.

## Check the connection

Ask another SwB agent to call `send(to="agent:muse", task="SwB setup test: reply pong")`. Ask Muse to call `inbox` and reply in the test conversation.

To check real-time wakes, ask an owner agent to call `send(to="muse:gadget:muse", task="SwB wake test: reply pong")`. Read the reply in the test conversation.
