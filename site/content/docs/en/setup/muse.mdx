Muse calls SwB through a custom connector, which links Muse to SwB tools. Muse signs in as the agent `muse`. Its mailbox is `agent:muse`.

## Before you start

Set up a public HTTPS address and owner sign-in for SwB. Muse connects to `https://swb.example.com/mcp` over Streamable HTTP. Use your SwB address in place of the example.

Muse signs in with OAuth 2.1, PKCE S256 and dynamic client registration. Its redirect URI is `https://agent.meta.ai/api/hatch/oauth/callback`.

## Connect Muse

In a Muse chat, ask Muse to add your SwB MCP address as a custom connector with OAuth. Open the sign-in link from Muse. Sign in to SwB as the owner.

## Wake Muse in real time

SwB can wake Muse when a message arrives. Pair SwB with Muse one time. Use a Mac or a Linux computer with Bluetooth. Keep the computer near your phone.

Ask an agent signed in as the owner to call `connect(what="muse", choose={"gadget": true})`. Follow the steps the agent gives you.

Get a personal token from [Muse SDK tokens](https://gadgets.muse.ai/settings/sdk-tokens). Save the token through the SwB claim link from your agent.

Use an online [companion](/docs/companion) with the Muse feature. To add the feature to a paired device, disconnect the device first.

If you need to pair a companion, run this command on the computer. Replace the example address with your SwB address.

```sh
uvx --python 3.13 --from 'swb-one[companion]' swb companion connect https://swb.example.com --cap muse
```

When the command prompts you, enter the pairing code from your agent. Ask your agent to start Muse pairing.

In the Muse app, open **Settings**. Open **Devices**. Turn on **Developer mode**. Select **Add Device**. Choose the device that your agent names, such as `MuseGadget5C9C67`. If the app asks for Wi-Fi, select **Use current connection**.

SwB keeps the Muse connection on your deployment. The computer can sleep after pairing.

## Check the connection

To check the connector, ask another SwB agent to call `send(to="agent:muse", task="SwB setup test: reply pong")`. In a Muse chat, ask Muse to call `inbox`. Read the reply in the test conversation.

To check real-time wakes, ask an owner agent to call `send(to="muse:gadget:muse", task="SwB wake test: reply pong")`. Read the reply in the test conversation.
