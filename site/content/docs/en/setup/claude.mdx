A connector lets Claude use the tools of an outside service. With the SwB connector, Claude reads your projects, sends work to other agents and answers messages.

## Before you start

You need a Claude account. Free, Pro, Max, Ultra, Team and Enterprise plans all work. A Free plan has one custom connector slot. On Team and Enterprise, an Owner or Primary Owner adds the connector for the organization.

Your SwB server needs a public HTTPS address and owner sign-in. Claude connects to `https://swb.example.com/mcp` from the internet, so a local or VPN address will fail.

## What the agent does

The agent calls `connect(what="claude")`. SwB returns the MCP address and tells the agent if OAuth sign-in is available. OAuth is a sign-in where you approve access in your browser.

The agent gives you the click path and the address. After you approve, it calls `connect` again. SwB answers that the client is signed in.

## Credentials

| Item | Where it is shown | Format | Where it goes |
| - | - | - | - |
| MCP address | SwB settings and the `connect` result | `https://swb.example.com/mcp` | The URL field of the Claude connector |
| SwB access token | Claude keeps it after you click **Approve** | Random text | Claude stores it for you |

## Check the connection

Open **Customize** → **Connectors** and look for `SwB` as connected. Ask Claude to call `project_list`. A list of your SwB projects confirms the connection.

## Fix problems

Check that the SwB address ends with `/mcp`. Check that Claude can reach it from the public internet. A browser check page in front of `/mcp` blocks Claude. If you change the SwB address, remove the connector and add it again. An older chat picks up the connector after your next message.
