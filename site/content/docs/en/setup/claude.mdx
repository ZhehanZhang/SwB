A connector lets Claude use the tools of an outside service. With the SwB connector, Claude reads your projects, sends work to other agents and answers messages.

## Before you start

The Claude Free plan allows one custom connector. Pro, Max, Ultra, Team and Enterprise also support custom connectors.

Set up owner sign-in for SwB. Use a public HTTPS address on port 443 so Claude can reach `/mcp`.

## Add SwB to Claude

<Tabs items={['Personal plan', 'Team or Enterprise']}>
<Tab value="Personal plan">
### Open Connectors

Open [Customize → Connectors](https://claude.ai/customize/connectors) in Claude.
### Add a custom connector

Select **+ Add**. Select **Add custom connector**.
### Enter the address

Enter `SwB` as the name. Enter your SwB MCP address, for example `https://swb.example.com/mcp`.
### Keep the default sign-in

Select **Continue** to review the sign-in settings. Under **Authentication**, select **Sign in now**. Under **OAuth client**, select **Use Claude’s published identity (Recommended)**. Leave **Request headers** empty.
### Add and connect

Click **Add**. If SwB shows **Connect** in the list, click **Connect**.
### Approve in SwB

Sign in on the **Sign in to SwB** page. On the **Connect to SwB** page, check the name and click **Approve**.
</Tab>
<Tab value="Team or Enterprise">
### Open the admin page

Open [Organization settings → Connectors](https://claude.ai/admin-settings/connectors) with permission to add custom connectors. For Team, use an Owner or Primary Owner account.
### Add a web connector

Click **Add**. Point to **Custom**, then click **Web**.
### Enter the address

Enter `SwB` as the name. Enter your SwB MCP address. Select **Continue**. Review the sign-in settings. Select **Sign in now** or **Sign in when needed**. Select **Use Claude’s published identity (Recommended)**. Select **Add**.
### Connect your account

Open **Customize** → **Connectors**. Find `SwB` and click **Connect**.
### Approve in SwB

Sign in on the **Sign in to SwB** page. On the **Connect to SwB** page, click **Approve**.
</Tab>
</Tabs>

### Turn on SwB in the chat

In the chat, select **+** → **Connectors**. Turn on SwB. For a Claude Project, use the coordinator chat.

## What the agent does

The agent calls `connect(what="claude")`. SwB returns the MCP address and whether OAuth is available. With OAuth, you approve access in your browser.

The agent gives you the click path and the address. After you approve, it calls `connect` again. SwB answers that the client is signed in.

## Credentials

| Item | Where it is shown | Format | Where it goes |
| - | - | - | - |
| MCP address | SwB settings and the `connect` result | `https://swb.example.com/mcp` | The URL field of the Claude connector |
| SwB access token | Claude keeps it after you click **Approve** | Random text | Claude stores it for you |

## Check the connection

Open **Customize** → **Connectors** and look for `SwB` as connected. Ask Claude to call `project_list`. A list of your SwB projects confirms the connection.

## Fix problems

Use the public HTTPS address that ends in `/mcp`. Let Claude reach `/mcp` directly. If the SwB address changes, remove the connector. Add it again with the new address.
