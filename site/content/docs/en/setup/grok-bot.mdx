Grok Bot is the xAI desktop agent app. This connection adds SwB to Grok Bot and makes a routine that SwB starts with a webhook. A routine is a saved task, and a webhook is a web address that starts the routine.

## Before you start

Install Grok Bot on macOS, Windows or Linux. You need a plan that includes Grok Bot, such as an X subscription or a Grok Business seat.

Your SwB server needs a public HTTPS address, owner sign-in, a SwB project and the `grok-routine` block. OAuth is the sign-in method where you approve access on a SwB page in your browser. Run the setup from your own owner sign-in.

## What the agent does

Grok Bot calls `connect(what="grok-bot")`. SwB returns the MCP address, the OAuth state and a routine prompt. The routine prompt tells each run to trust the `trust` field of the webhook and to answer with `reply`.

Grok Bot creates the routine with that prompt. Then it registers the routine with `connect(what="grok-bot", choose={"name":"<routine>","project":"<project>","auth":"key"})`. SwB returns two claim links. After you save both, Grok Bot runs `send(to="grok-routine:routine:<routine>", task="SwB setup test. Reply pong.")`. It calls `connect` again to see if Grok accepted the call.

The webhook is the wake path for this connection. Each SwB message for the routine starts a new run.

## Credentials

| Token | Where it is shown | Format | Where it goes |
| - | - | - | - |
| Webhook URL | **POST to** under **Webhook** in the routine **Details** | HTTPS address | **Webhook URL** on its SwB claim link |
| Webhook key | **key** under **Webhook** in the routine **Details** | Random text | **Token** on its SwB claim link |
| SwB sign-in token | Grok Bot gets it when you sign in | Random text | Grok Bot keeps it for you |

A claim link is a private one-time SwB page for one token. Paste each value there only.

## Check the connection

Open the routine **Details** and check the **Webhook** trigger. Ask Grok Bot to call `connect(what="grok-bot")` again. The status line names the routine. The test sender gets pong in its `inbox`.

## Fix problems

Copy **key**, and leave **header**. SwB adds the `Authorization: Bearer` part itself.

Send to `grok-routine:routine:<routine>` to start the routine. A send to `agent:grok` only fills the mailbox.

Claim links work one time and expire after 30 minutes. For a new link, call `connect` again. To change a saved value, call `connect` with `choose.replace` set to `url` or `secret`.

Grok.com **Automations** webhooks use another signature format. Use the Grok Bot routine for SwB.
