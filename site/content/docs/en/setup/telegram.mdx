SwB talks to Telegram through a bot that you make in BotFather. SwB asks Telegram for new messages, so your SwB server can stay on a private address.

The Telegram connection page shows chats and groups under **Channels**.

## Before you start

You need a Telegram account. For groups, you need the right to add members. You also need the owner sign-in to your SwB server, for example https://swb.example.com.

## Your steps

<Steps>
<Step>
### Open BotFather

Open https://t.me/BotFather in Telegram. Tap **Start** if this is your first chat with BotFather.
</Step>
<Step>
### Create the bot

Send `/newbot`. Reply with a display name.
</Step>
{/* unverified */}
<Step>
### Choose the username

Reply with a username that ends in `bot`. BotFather replies with the token.
</Step>
<Step>
### Save the token

Open the SwB claim link from your agent. Paste the token into the field.
</Step>
<Step>
### Start a private chat

Tap **Start** in the private chat with your bot. Send one message so SwB can find your user ID.
</Step>
<Step>
### Add the bot to a group

Open the group link from your agent. Select the group.
</Step>
{/* unverified */}
<Step>
### Send the setup command

Send `/swb@<bot username>` in the group. SwB then knows the group ID.
</Step>
<Step>
### Turn off privacy mode

Send `/setprivacy` to BotFather. Choose your bot → **Disable**.
</Step>
{/* unverified */}
<Step>
### Add the bot again

Remove the bot from each group. Add the bot to the group again.
</Step>
</Steps>

The last two steps are for groups where the bot reads every message. A bot for direct messages and commands only can skip them.

## What the agent does

The agent calls `connect` with `what="telegram"`. SwB returns a claim link for the bot token. `telegram_provision` also returns a claim link.

After you save the token, the agent calls `telegram_status`. This shows the bot name, the connection, the privacy mode and the group link in `setup.add_to_group_url`. The chat IDs that SwB saw are in `setup.seen_chats`.

The agent adds a space under `blocks.telegram.spaces` in `config/switchboard.yaml`. A space is a set of Telegram chats that SwB routes to one project. The agent puts the group IDs in `chats` and your user ID in `owner_ids`. Last, it sends a test message with `telegram_post`.

## Credentials

| Token | Where Telegram shows it | Format | Where it goes |
| --- | --- | --- | --- |
| Bot token | Reply from BotFather after `/newbot`, or after `/token` | Digits, a colon, then letters and digits | SwB claim link |

Group IDs and user IDs are names for chats. They are safe to put in the config file.

## Check the connection

Ask the agent to call `connect` again. It reports `connected` when the setup is complete.

Send `/swb <target> hello` to the bot in a private chat. Check that the reply comes back from the bot.

## Fix problems

If the bot reads only commands in a group, turn off privacy mode in BotFather. Then remove the bot and add it again.

A webhook is a web address where Telegram sends messages. If the bot has a webhook from an earlier setup, the webhook stops SwB from getting messages. Remove it with the Telegram method `deleteWebhook`.
