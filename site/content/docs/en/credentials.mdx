When SwB needs a credential, your agent gives you a **claim link**. It opens a one-time form on your SwB host. The form sends the credential directly from your browser to SwB.

## How a claim link works

Sign in as the owner to use the link. The link works once and expires after 30 minutes.

![A claim page for one token](/shots/token-handoff-light.webp)

SwB encrypts the value with a key in its data folder. The block can use the saved value in place of an environment variable. An environment variable on the server wins over a saved value.

| Page | Use |
| - | - |
| `/claim/{code}` | Save the credentials for a connection. |
| `/routines/claim/{code}` | Use a one-time claim link to save a Claude routine token. |
| `/routines/claim/owner/{registration}` | Save a pending Claude routine token from the Agents page. |

## Save credentials

On the Discord, Telegram, Claude routine and Grok Bot token forms, paste the token and select **Save token**. On the Grok Bot webhook form, enter the URL and select **Save webhook url**.

For GitHub App setup, SwB gives you a separate link for each missing value. Fill in **App ID**, **Private key** or **Webhook secret** on its form. For **Private key**, select **Upload .pem file** or paste the full contents of the `.pem` file. Select **Save** on each form.

Restart SwB after you change the GitHub webhook secret.

For Slack, SwB gives you one claim link per workspace when a token is missing. Fill in the fields on the shared form. Select **Save**.

## Claim from the terminal

```bash
swb claim 'https://swb.example.com/claim/...'
```

The command asks for the token at a hidden prompt. It sends the token to your local SwB server, or to the server you name with `--url`.

## Replace a credential

Use the instructions for your block.

| Block | How to replace a value |
| - | - |
| Grok Bot | Ask an agent to call `connect` for `grok-bot` with the routine name and `replace=url` or `replace=secret`. |
| Slack | SwB issues a claim link for a workspace when a configured token is missing. |
| GitHub | Ask your agent to call `connect(what="github", choose={"replace":"secret"})` to replace the webhook secret. `webhook_secret` has the same effect. Use `all` to also replace the App credentials or personal access token |

Update values from the server environment in that environment. Change an App ID set in `blocks.github.app_id` in the config file. Restart SwB after you change the configuration or the GitHub webhook secret.
