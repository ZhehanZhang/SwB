Agents set up connections. When SwB needs a token, your agent gives you a **claim link**. A claim link opens a one-time page on your SwB host. Open the link. Paste the token in the correct field. Click **Save token**. The token goes directly from your browser to SwB.

## How a claim link works

An agent asks for a connection, for example Discord. SwB returns a link such as `https://swb.example.com/claim/...`. The agent gives you the link. The link works one time, for 30 minutes. You must be signed in as the owner to use it.

![A claim page for one token](/shots/token-handoff-light.webp)

SwB encrypts the value with a key in its data folder. The block can use the saved value in place of an environment variable. An environment variable on the server wins over a saved value.

| Page | Use |
| - | - |
| `/claim/{code}` | Save the credentials for a connection. |
| `/routines/claim/{code}` | Use a one-time claim link to save a Claude routine token. |
| `/routines/claim/owner/{registration}` | Save a pending Claude routine token from the Agents page. |

## Claim links for GitHub and Slack

For GitHub App setup, SwB gives you a separate claim link for each missing value. The App ID, private key and webhook secret each have their own link. Paste the full contents of the `.pem` file in the private key field.

Restart SwB after you change the GitHub webhook secret.

For Slack, SwB gives you one claim link per workspace when a token is missing. Fill in the fields on the grouped form. Click **Save**.

## Claim from the terminal

```bash
swb claim 'https://swb.example.com/claim/...'
```

The command asks for the token at a hidden prompt. It sends the token to your local SwB server, or to the server you name with `--url`.

## Replace a credential

Use the instructions for your block.

| Block | How to replace a value |
| - | - |
| Grok Bot | Ask an agent to call `connect` for `grok-bot` with the routine name and `replace=url` or `replace=secret`. |
| Muse | Ask an agent to call `connect` for `muse` with `replace=true` to replace the bridge token. |
| Slack | SwB issues a claim link for a workspace when a configured token is missing. |
| GitHub | SwB checks saved values and issues a separate claim link for each missing value required by the setup. |

If the server environment supplies the value, update it there and restart SwB.
