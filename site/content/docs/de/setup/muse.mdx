Fügen Sie SwB als Custom Connector zu Muse hinzu. Ein Connector gibt Muse Zugriff auf die Tools von SwB. Muse meldet sich als `muse` an.

## Voraussetzungen

Richten Sie eine öffentliche HTTPS-Adresse und die Inhaber-Anmeldung für SwB ein. Verwenden Sie Ihre eigene SwB-Adresse anstelle von `https://swb.example.com/mcp`.

Muse meldet sich per OAuth an. Mit OAuth geben Sie den Zugriff in Ihrem Browser frei.

## Muse verbinden

Fügen Sie den Prompt in einen Muse-Chat ein. Bitten Sie Muse, Ihre MCP-Adresse von SwB als Custom Connector mit OAuth hinzuzufügen. Öffnen Sie den Anmeldelink aus Muse. Melden Sie sich als Inhaber bei SwB an.

## Muse in Echtzeit wecken

SwB weckt Muse, wenn eine Nachricht eintrifft. Koppeln Sie SwB einmalig mit Muse. Verwenden Sie einen Mac oder einen Linux-Computer mit Bluetooth. Halten Sie den Computer in der Nähe Ihres Telefons.

Bitten Sie einen Agenten mit vollem Inhaberzugriff, `connect(what="muse", choose={"gadget": true})` aufzurufen. Folgen Sie den Anweisungen, die er zurückgibt.

Holen Sie ein persönliches Token unter [Muse SDK tokens](https://gadgets.muse.ai/settings/sdk-tokens). Speichern Sie das Token über den Claim-Link von SwB, den Ihnen Ihr Agent gibt.

Verwenden Sie einen verbundenen [Companion](/de/docs/companion) mit der Funktion Muse. Um die Funktion zu einem Gerät hinzuzufügen, das bereits mit SwB gekoppelt ist, führen Sie `swb companion disconnect` auf dem Gerät aus.

Wenn Sie einen Companion koppeln müssen, führen Sie diesen Befehl auf dem Computer aus. Ersetzen Sie die Beispieladresse durch Ihre SwB-Adresse.

```sh
uvx --python 3.13 --from 'swb-one[companion]' swb companion connect https://swb.example.com --cap muse
```

Wenn der Befehl Sie auffordert, geben Sie den Kopplungscode von Ihrem Agenten ein. Bitten Sie Ihren Agenten, die Kopplung mit Muse zu starten.

Öffnen Sie in der Muse-App **Settings**. Öffnen Sie **Devices**. Aktivieren Sie **Developer mode**. Wählen Sie **Add Device**. Wählen Sie den Gerätenamen, den Ihr Agent Ihnen nennt. Wenn die App nach WLAN fragt, wählen Sie **Use current connection**.

SwB hält die Verbindung zu Muse auf Ihrer Bereitstellung. Der Computer darf nach der Kopplung in den Ruhezustand gehen.

## Verbindung prüfen

Bitten Sie einen anderen SwB-Agenten, `send(to="agent:muse", task="SwB setup test: reply pong")` aufzurufen. Bitten Sie Muse, `inbox` aufzurufen und in der Testunterhaltung zu antworten.

Um das Wecken in Echtzeit zu prüfen, bitten Sie einen Inhaber-Agenten, `send(to="muse:gadget:muse", task="SwB wake test: reply pong")` aufzurufen. Lesen Sie die Antwort in der Testunterhaltung.
