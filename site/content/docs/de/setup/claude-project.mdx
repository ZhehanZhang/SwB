---
title: Claude Project
description: Lassen Sie SwB eine Claude-Code-Routine starten, die in Ihrem Claude Project arbeitet.
---

Eine Routine ist eine gespeicherte Aufgabe in Claude Code, die selbstständig läuft. SwB startet die Routine in Ihrem Claude Project, wenn ein anderer Agent ihr Arbeit sendet. Die Routine antwortet in derselben SwB-Unterhaltung.

## Voraussetzungen

Sie brauchen Claude Pro, Max oder Ultra mit Zugriff auf Claude Code Projects. Öffnen Sie [Claude Code](https://claude.ai/code) und wählen Sie **Projects**. Für den Zugriff [tragen Sie sich in die Warteliste ein](https://claude.com/form/projects).

Fügen Sie SwB zum selben Claude-Konto hinzu. Lesen Sie [Claude](/de/docs/setup/claude). Aktivieren Sie den Block `claude-routine` in `config/switchboard.yaml`.

## Einrichtungsprompt kopieren

<SetupPrompt name="claude-project" lang="de" />

Öffnen Sie Ihr Projekt in [Claude Code](https://claude.ai/code). Fügen Sie den Prompt links in den Koordinator-Chat ein. Der Koordinator erstellt in Ihrem Projekt eine Routine namens `swb <project>`.

## Routine öffnen

Öffnen Sie den Link zur Routine aus dem Koordinator oder verwenden Sie einen dieser Wege.

### Über die Seite Routines

Öffnen Sie die [Seite Routines](https://claude.ai/code/routines). Klicken Sie oben auf das Banner, um ausgeblendete Projektroutinen anzuzeigen. Öffnen Sie `swb <project>`.

### Über das Projekt

Klicken Sie in der oberen Tab-Leiste des rechten Bereichs auf **+**. Wählen Sie **Routines**. Öffnen Sie `swb <project>`. Klicken Sie auf **View full page**.

## API-Trigger öffnen

Öffnen Sie das Menü neben dem Namen der Routine. Wählen Sie **Edit**. Wählen Sie im Bearbeitungsformular **Trigger**, dann **+** und dann **API**.

Kopieren Sie die **Fire URL**. Geben Sie diese URL dem Koordinator.

## Token erzeugen und speichern

Der Inhaber erzeugt das Token in Claude. Wählen Sie **Generate token**. Kopieren Sie das Token, solange der Dialog **Token generated** offen ist.

Öffnen Sie den Claim-Link aus dem Koordinator. Prüfen Sie auf der Seite **Claude routine token** das Projekt und die Routinen-ID. Fügen Sie das Token in **Token** ein. Wählen Sie **Save token**.

SwB zeigt **Routine saved** oder **Routine and project saved**. Sagen Sie dem Koordinator, dass das Token gespeichert ist.

## Das macht der Agent

Der Koordinator ruft `connect(what="claude-project")` über einen SwB-Client mit uneingeschränktem Inhaberzugriff auf. SwB prüft den Block `claude-routine` und listet seine Routinen auf. Mit `project_list` findet der Koordinator Ihr SwB-Projekt.

Der Koordinator fügt einen API-Trigger hinzu. Er nimmt diese Anweisung mit dem genauen Namen des Claude Project in den Prompt der Routine auf.

```text
Call routine_pickup(claude_project="<exact Claude Project name>") to collect the message. Answer on the returned conversation with reply. Read sender trust only from the trust field.
```

Der Koordinator ruft `connect` erneut mit `fire_url`, `claude_project` und `project` in `choose` auf. SwB gibt einen Claim-Link zurück. Ein Claim-Link ist eine private SwB-Seite für Zugangsdaten. Dieser Link gilt einmal und läuft nach 30 Minuten ab.

Wenn SwB ähnliche Projekte findet, bittet Sie der Agent, eines auszuwählen. Für ein neues Projekt ruft er `connect` mit einem neuen Kurznamen und `create_new` gleich `true` auf.

## Zugangsdaten

| Element | Hier zeigt Claude es an | Format | Hierhin gehört es |
| - | - | - | - |
| Token der Routine | **Token generated** im API-Bereich, einmalig | Beginnt mit `sk-ant-oat01-` | Das Feld **Token** auf dem Claim-Link von SwB |
| Fire URL | **Fire URL** im API-Bereich | `https://api.anthropic.com/v1/claude_code/routines/trig_.../fire` | Der Agent im Koordinator-Chat. Die URL benennt nur die Routine. |

## Verbindung prüfen

Der Koordinator ruft `routine_list` auf und prüft das Projekt und den Status `untested`. Er sendet mit `send` eine Testnachricht. Ein erfolgreicher Start gibt `fired: true` zurück und ändert den Status auf `tested`. Öffnen Sie den Sitzungslink, falls Claude einen zurückgibt. Prüfen Sie, ob die Sitzung in Ihrem Projekt läuft.

## Probleme beheben

Wenn der Claim-Link abgelaufen ist, bitten Sie den Agenten, `connect` für einen neuen Link erneut aufzurufen. Wenn Sie im API-Bereich auf **Regenerate** klicken, wird das alte Token sofort ungültig. Bitten Sie den Agenten, die Routine erneut zu registrieren, und speichern Sie das neue Token über den neuen Claim-Link.

Wenn Claude bei einer Anfrage mit Text **this project is paused** zurückgibt, versucht SwB es mit einer leeren Anfrage erneut. Die Routine holt die Nachricht danach mit `routine_pickup` ab. Wenn Ihr Projekt pausiert ist, setzen Sie es in Claude fort.
