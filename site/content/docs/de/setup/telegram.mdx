SwB kommuniziert mit Telegram über einen Bot, den Sie in BotFather erstellen. SwB fragt neue Nachrichten bei Telegram ab. Ihr SwB-Server kann daher eine private Adresse behalten.

## Voraussetzungen

Verwenden Sie ein Telegram-Konto. Um eine Gruppe zu verbinden, verwenden Sie ein Konto, das Mitglieder hinzufügen darf. Melden Sie sich als Inhaber bei SwB an.

## Telegram-Bot einrichten

### BotFather öffnen

Öffnen Sie https://t.me/BotFather in Telegram. Tippen Sie auf **Start**, wenn dies Ihr erster Chat mit BotFather ist.
### Bot erstellen

Senden Sie `/newbot`. Antworten Sie mit einem Anzeigenamen.

### Benutzernamen wählen

Antworten Sie mit einem Benutzernamen, der auf `bot` endet. BotFather antwortet mit dem Token.
### Token speichern

Öffnen Sie den Claim-Link von SwB, den Ihnen Ihr Agent gibt. Fügen Sie das Token in das Feld ein.
### Privaten Chat starten

Tippen Sie im privaten Chat mit Ihrem Bot auf **Start**. Senden Sie eine Nachricht, damit SwB Ihre Benutzer-ID findet.
### Bot zu einer Gruppe hinzufügen

Öffnen Sie den Gruppenlink von Ihrem Agenten. Wählen Sie die Gruppe.

### Einrichtungsbefehl senden

Senden Sie `/swb@<bot username>` in der Gruppe. SwB kennt danach die Gruppen-ID.
### Alle Gruppennachrichten lesen

Für Gruppen, in denen der Bot jede Nachricht braucht, senden Sie `/setprivacy` an BotFather. Wählen Sie Ihren Bot. Wählen Sie **Disable**.

### Bot erneut hinzufügen

Entfernen Sie den Bot aus jeder Gruppe. Fügen Sie den Bot erneut zur Gruppe hinzu.

## Das macht der Agent

Der Agent ruft `connect(what="telegram")` auf. Bei Bedarf aktiviert er den Block `telegram`. Bei aktivem Block geben `connect` oder `telegram_provision` einen Claim-Link für das Bot-Token zurück.

Nachdem Sie das Token gespeichert haben, ruft der Agent `telegram_status` auf. Er prüft den Bot und den Privatsphäremodus. Die Gruppeneinladung steht in `setup.add_to_group_url`. Die letzten Chat-IDs stehen in `setup.seen_chats`.

Der Agent konfiguriert einen Raum unter `blocks.telegram.spaces` in `config/switchboard.yaml`. Ein Raum verbindet eine Gruppe von Chats mit einem SwB-Projekt. Tragen Sie die Gruppen-IDs in `chats` ein. Tragen Sie Ihre Benutzer-ID in `owner_ids` ein. Starten Sie SwB nach der Bearbeitung der Datei neu.

## Zugangsdaten

| Token | Hier zeigt Telegram es an | Format | Hierhin gehört es |
| --- | --- | --- | --- |
| Bot-Token | Antwort von BotFather nach `/newbot` oder nach `/token` | Ziffern, ein Doppelpunkt, danach Buchstaben und Ziffern | Claim-Link von SwB |

## Verbindung prüfen

Bitten Sie den Agenten, `connect` erneut aufzurufen. Nach abgeschlossener Einrichtung meldet er `connected`.

Verwenden Sie das Telegram-Konto aus `owner_ids`. Senden Sie dem Bot in einem privaten Chat `/swb <target> hello`. Ersetzen Sie `<target>` durch einen Zielnamen aus `targets`. Prüfen Sie, ob eine Antwort kommt.

## Probleme beheben

Wenn der Bot in einer Gruppe nur Befehle liest, schalten Sie in BotFather den Privatsphäremodus ab. Entfernen Sie danach den Bot und fügen Sie ihn erneut hinzu.

Ein Webhook ist eine Webadresse, an die Telegram Nachrichten sendet. Bitten Sie den Inhaber des Bots, alte Webhooks mit der Telegram-Methode `deleteWebhook` zu entfernen.
