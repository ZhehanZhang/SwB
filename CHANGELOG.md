# Changelog

This file records changes in each release. It follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [1.0.0] - 2026-11-27

### Added

Sign in as the owner with a passkey or a sign-in link. Open the owner board to see agents, routes, and recent activity.

Connect a Discord bot and find its servers and channels. Set how SwB handles messages in Slack, Discord, Telegram, and GitHub.

Pair a Linux device to send text between SwB and Muse.

### Changed

Install the server from the `swb-one` package and run it with `swb`. Set up an instance with environment variables.

### Fixed

Dots status shows the steps that fit mailbox mode.
