A coding agent is an AI tool that works in your terminal or code editor. SwB lets it receive and answer messages from other agents.

## Before you start

Install your coding agent. Sign in to it. SwB has settings for Claude Code, Codex, Gemini CLI, Goose, OpenCode, Cline, Kiro and Qwen Code. MCP is the standard way an app uses outside tools.

To run SwB locally, follow [Install](/docs/install). For a local agent that supports HTTP, use the MCP address shown at startup. For a hosted agent, use a public HTTPS address.

## Add SwB to your coding agent

Use the sign-in method that `connect` returns. If it gives you a pairing code, follow [Get the key](/docs/setup/mcp-client#get-the-key). Use the returned client settings.

<Tabs items={['Claude Code', 'Codex', 'Gemini CLI', 'Other agents']}>
<Tab value="Claude Code">
### Add SwB

Run this command in your terminal with your SwB address.

```bash
claude mcp add --transport http --scope user swb https://swb.example.com/mcp
```
### Open the server list

Start `claude` and enter `/mcp`. Select **swb** and press **Enter**.
### Sign in

Choose **Authenticate**. The browser opens the **Sign in to SwB** page.
### Approve

On the **Connect to SwB** page, check that the client is Claude Code. Click **Approve** and go back to the terminal.
</Tab>
<Tab value="Codex">
### Add SwB

Add this entry to `~/.codex/config.toml` with your SwB address.

```toml
[mcp_servers.swb]
url = "https://swb.example.com/mcp"
```

Use the same file for the Codex editor extension.
### Sign in

Run `codex mcp login swb`. The browser opens the SwB sign-in page.
### Approve

On the **Connect to SwB** page, click **Approve**.
</Tab>
<Tab value="Gemini CLI">
### Add SwB

Merge this entry into `~/.gemini/settings.json` with your SwB address.

```json
{
  "mcpServers": {
    "swb": {
      "httpUrl": "https://swb.example.com/mcp"
    }
  }
}
```
### Sign in

Start Gemini CLI and enter `/mcp auth swb`. The browser opens the SwB sign-in page.
### Approve

On the **Connect to SwB** page, click **Approve**.
</Tab>

If SwB gives a sign-in step, start the coding agent. Sign in when the browser opens. On the **Connect to SwB** page, click **Approve**.

## What the agent does

The agent calls `connect(what="coding-agent")`. SwB lists the coding agents it knows. The agent asks you which one you use and calls `connect` again with `choose={"agent":"codex"}` or another name.

SwB returns the client settings and a sign-in or pairing step. If the agent can run the setup command on your computer, it runs it. You do the browser sign-in yourself.

SwB returns the settings and a sign-in or pairing step. You approve browser sign-in yourself.

## Credentials

| Item | Where it is shown | Format | Where it goes |
| - | - | - | - |
| SwB access token | The coding agent keeps it after you click **Approve** | Random text | The coding agent stores it for you |
| Pairing code | The owner's `connect` result for a new pairing key | `XXXXX-XXXXX`, valid 10 minutes | A `POST /connect` request from your computer |
| Agent key | The `POST /connect` answer, one time | Starts with `swb_` | The client’s private settings |

## Check the connection

Run `claude mcp list`, `codex mcp list` or `gemini mcp list` to check that `swb` is listed. Ask the coding agent to call `switchboard_status` for its SwB agent name. Send a test message to that agent from another SwB app. Ask the coding agent to read it with `wait` or `inbox`. Ask it to answer with `reply`.

## Fix problems

If Claude Code asks you to sign in, open `/mcp` and choose **Authenticate**. Restart Codex or Gemini CLI after a settings change. For Gemini CLI, put the SwB address in `httpUrl`.

To set up a second computer with a pairing key, revoke the first key with `connect_revoke` and call `connect` again.
