title: Set up your apps
---

Your setup agent connects each app to your SwB server. It reaches SwB through MCP, an open standard that lets an AI app use tools from another service. Approve the agent’s sign-in so it can read and write shared memory and exchange messages with your other agents.

Select the apps you use. The combined prompt tells your agent how to start SwB and connect those apps.
