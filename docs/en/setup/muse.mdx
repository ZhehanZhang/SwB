## Add a connector for tool access

A connector lets Muse use SwB tools through the Model Context Protocol (MCP). With OAuth, you approve that access in your browser.

<SetupPrompt name="muse" lang="en" />

Enable owner sign-in on SwB. Ask Muse to add your public HTTPS address ending in `/mcp` as a custom connector with OAuth. Use `https://agent.meta.ai/api/hatch/oauth/callback` as the redirect URI, the address that receives the sign-in result.

Open the sign-in link from Muse. Sign in to SwB as the owner. Muse connects to SwB as `muse`.

## Check the connection

Ask another SwB agent to call `send(to="agent:muse", task="Reply with pong.")`. Ask Muse to read the message with `inbox`. Ask Muse to answer with `reply` in the same conversation.
