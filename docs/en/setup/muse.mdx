## Wake Muse in real time

SwB recommends the Muse gadget to start work when a message arrives. The gadget is a device that pairs with the Muse app.

A [companion](/docs/companion) is a SwB program that runs on your own device. It acts as the gadget over Bluetooth during pairing. After pairing, your SwB server keeps the connection to Muse open. You can stop the companion after pairing.

Set up a public HTTPS address for SwB. Paste this prompt into a SwB agent with full owner access.

<SetupPrompt name="muse" lang="en" />

Ask the agent to call `connect(what="muse", choose={"gadget": true})`. Follow the instructions it returns.

Create a personal token on the [Muse SDK tokens page](https://gadgets.muse.ai/settings/sdk-tokens). Save it through the one-time SwB claim link from your agent.

Use a Mac or Linux computer with Bluetooth near your phone. On macOS, use Terminal and allow Bluetooth access when macOS asks. On Linux, give the companion access to BlueZ, the system service for Bluetooth.

If you need to add Muse to a paired companion, run `swb companion disconnect` first. Get a [companion pairing code](/docs/companion#pair-a-device). The code works once and expires after 10 minutes.

Replace the example address with your SwB address. Run this command on the computer.

```sh
uvx --python 3.13 --from 'swb-one[companion]' swb companion connect https://swb.example.com --cap muse
```

Enter the code at the hidden prompt. Keep the companion running while you pair Muse. Ask your agent to start Muse pairing.

In the Muse app, open **Settings**. Open **Devices**. Turn on **Developer mode**. Select **Add Device**. Select the device name from your agent. If the app asks for Wi-Fi, select **Use current connection**.

## Add a connector for tool access

A connector lets Muse use SwB tools through the Model Context Protocol (MCP). With OAuth, you approve that access in your browser.

Enable owner sign-in on SwB. Ask Muse to add your public HTTPS address ending in `/mcp` as a custom connector with OAuth. Use `https://agent.meta.ai/api/hatch/oauth/callback` as the redirect URI, the address that receives the sign-in result.

Open the sign-in link from Muse. Sign in to SwB as the owner. Muse connects to SwB as `muse`.

## Check the connection

For the gadget, ask an agent with owner access to call `send(to="muse:gadget:muse", task="Reply with pong.")`. Check the reply in the test conversation.

For the connector, ask another SwB agent to call `send(to="agent:muse", task="Reply with pong.")`. Ask Muse to read the message with `inbox`. Ask Muse to answer with `reply` in the same conversation.
