---
title: 凭据
description: 在一次性页面上保存连接凭据。
---

**凭据**是用来访问某个应用的值。SwB 需要凭据时，智能体会发给你一个**认领链接**。链接会打开一个一次性表单，表单把这个值从你的浏览器发送给 SwB。

## 认领链接的工作方式

先以所有者身份登录，再打开表单。如果表单显示 **SwB owner key**，在该页面输入这个密钥。链接只能使用一次，30 分钟后过期。

![单个令牌的认领页面](/shots/token-handoff-light.webp)

SwB 用数据目录中的一个密钥加密这个值。模块可以用保存的值代替环境变量。如果两处都设置了值，SwB 优先使用环境变量。

| 页面 | 用途 |
| - | - |
| `/claim/{code}` | 保存某个连接的凭据。 |
| `/routines/claim/{code}` | 用一次性认领链接保存 Claude routine 的令牌。 |
| `/routines/claim/owner/{registration}` | 从 Agents 页面保存待填写的 Claude routine 令牌。 |

## 保存凭据

在 Discord、Telegram、Claude routine 或 Grok Bot 的表单中粘贴令牌，然后选择 **Save token**。在 Grok Bot 的 Webhook 表单中输入地址，然后选择 **Save webhook url**。

设置 GitHub App 时，每缺少一个值，SwB 就给你一个单独的链接。在对应的表单中填写 **App ID**、**Private key** 或 **Webhook secret**。填写 **Private key** 时，选择 **Upload .pem file**，或粘贴 `.pem` 文件的全部内容。在每个表单上选择 **Save**。

更改 GitHub Webhook 密钥后，重启 SwB。

Slack 缺少令牌时，SwB 为每个工作区提供一个认领链接。在这个共用的表单中填写各个字段，然后选择 **Save**。

## 在终端中认领

```bash
swb claim 'https://swb.example.com/claim/...'
```

`/claim/{code}` 或 `/routines/claim/{code}` 上只有一个文本字段时，使用这条命令。如果表单有多个字段或要上传文件，改用浏览器。命令会隐藏你输入的内容。它默认使用本地服务器。如果是远程服务器，把 `--url` 设为它的 SwB 基础地址。

## 替换凭据

| 模块 | 如何替换值 |
| - | - |
| Grok Bot | 让智能体针对 `grok-bot` 调用 `connect`，传入 routine 名称以及 `replace=url` 或 `replace=secret`。 |
| Slack | 某个已配置的令牌缺失时，SwB 会为对应的工作区签发认领链接。 |
| GitHub | 让智能体调用 `connect(what="github", choose={"replace":"secret"})` 替换 Webhook 密钥。`webhook_secret` 的效果相同。使用 `all` 可以同时替换 App 凭据或个人访问令牌。 |

要替换在服务器环境中设置的值，更新对应的环境变量。在 `blocks.github.app_id` 中设置的 App ID 要在配置文件中修改。更改配置或 GitHub Webhook 密钥后，重启 SwB。
