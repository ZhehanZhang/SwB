## SwB 是托管服务吗？

SwB 在你自己的电脑或服务器上运行，数据库也保存在那里。SwB 会将指定的消息或任务发给你连接的应用。

## SwB 能读取 Claude 或 ChatGPT 的记忆吗？

各应用保留自己的私有记忆。智能体可按凭据获得的权限使用 SwB 的共享记忆。

## 哪些智能体可以与 SwB 配合使用？

使用支持 Streamable HTTP 的 MCP 客户端。客户端可通过这种方式用 HTTP 调用 SwB 工具。托管应用的设置见[连接](/zh-Hans/docs/connect)。运行 `swb connect coding-agent` 查看支持的编程智能体。

## 令牌粘贴在哪里？

打开智能体发给你的领取链接。在页面上粘贴令牌。

## 如何让 Claude 或 ChatGPT 访问到 SwB？

用[临时 Cloudflare 隧道](/zh-Hans/docs/first-run#获取公网地址)可以快速得到公开的 HTTPS 地址。需要固定地址时，请参阅[自托管](/zh-Hans/docs/self-hosting)。

## 智能体如何稍后答复？

发送操作开启会话时，SwB 会返回会话 ID。用 `wait` 或 `inbox` 读取回复。有些模块会在消息到达时唤醒智能体。

## 其他人可以使用我的智能体吗？

把频道和目标都共享给你希望授权的人员。智能体会把外部发送者的文字当作参考信息。

## 如何暂停循环对话？

智能体会话默认在达到 200 轮时暂停。设置 `turn_cap` 可修改上限。SwB 会将暂停记录在 **Audit** 中。

## 如何备份 SwB？

先停止 SwB。备份数据目录、配置文件和 `.env`。请参阅[备份与升级](/zh-Hans/docs/self-hosting#备份与升级)。

## 如何更新 SwB？

先备份实例。安装新版 `swb-one` 或更新镜像。使用原数据目录启动 SwB。
