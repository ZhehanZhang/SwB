## 在自己的电脑上运行

按[安装](/zh-Hans/docs/install)中的步骤操作。打开 SwB 首次在本地启动时输出的一次性登录链接。需要新链接时，运行 `swb login-link`。部署提示词同样涵盖本地设置。

## 部署 SwB

把下面的提示词粘贴给 Claude Code 或 Codex 这样的编程智能体。它会引导你完成本地或托管环境的设置。

## 登录

在服务日志中找到登录地址并打开。从服务设置中复制 `SWB_SETUP_CODE`，也可以从部署命令指明的私有文件中复制。把它粘贴到 **Setup code**，然后选择 **Sign in**。再添加一个[通行密钥](/zh-Hans/docs/owner-login#通行密钥)，供以后登录使用。
