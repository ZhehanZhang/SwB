编程智能体是在终端或代码编辑器中工作的 AI 工具。连接 SwB 后，它可以接收其他智能体的消息并回复。

## 开始之前

请安装编程智能体并登录。SwB 提供 Claude Code、Codex、Gemini CLI、Goose、OpenCode、Cline、Kiro 和 Qwen Code 的配置。MCP 是应用调用外部工具的标准。

要在本机运行 SwB，请参阅[安装指南](/zh-Hans/docs/install)。如果本机智能体支持 HTTP，请使用启动时显示的 MCP 地址。托管的智能体需使用公网 HTTPS 地址。

把提示词粘贴到编程智能体。

## 为编程智能体添加 SwB

使用 `connect` 返回的登录方式。如果它给出配对码，请[换取密钥](/zh-Hans/docs/setup/mcp-client#换取密钥)。使用返回的客户端配置。

<Tabs items={['Claude Code', 'Codex', 'Gemini CLI', '其他智能体']}>
<Tab value="Claude Code">
### 添加 SwB

在终端中运行下面的命令，换成你的 SwB 地址。

```bash
claude mcp add --transport http --scope user swb https://swb.example.com/mcp
```
### 打开服务器列表

启动 `claude`，输入 `/mcp`。选择 **swb**，按 **Enter**。
### 登录

选择 **Authenticate**。浏览器会打开 **Sign in to SwB** 页面。
### 批准

在 **Connect to SwB** 页面确认客户端是 Claude Code。点击 **Approve**，然后回到终端。
</Tab>
<Tab value="Codex">
### 添加 SwB

将以下配置项加入 `~/.codex/config.toml`。使用你的 SwB 地址。

```toml
[mcp_servers.swb]
url = "https://swb.example.com/mcp"
```

Codex 编辑器扩展使用同一个文件。
### 登录

运行 `codex mcp login swb`。浏览器会打开 SwB 登录页面。
### 批准

在 **Connect to SwB** 页面点击 **Approve**。
</Tab>
<Tab value="Gemini CLI">
### 添加 SwB

将以下配置项合并到 `~/.gemini/settings.json`。使用你的 SwB 地址。

```json
{
  "mcpServers": {
    "swb": {
      "httpUrl": "https://swb.example.com/mcp"
    }
  }
}
```
### 登录

启动 Gemini CLI，输入 `/mcp auth swb`。浏览器会打开 SwB 登录页面。
### 批准

在 **Connect to SwB** 页面点击 **Approve**。
</Tab>
<Tab value="其他智能体">
### 获取配置

告诉智能体你用的是哪个客户端。选择 `other` 可获取通用的 Streamable HTTP 配置。
### 添加 SwB

如果 SwB 给出配对码，请用它[换取密钥](/zh-Hans/docs/setup/mcp-client#换取密钥)。把密钥填入返回的配置中。

应用 SwB 给出的配置。Goose 使用 `~/.config/goose/config.yaml`。
### 登录

如果 SwB 提示登录，请启动编程智能体。浏览器打开后登录。在 **Connect to SwB** 页面点击 **Approve**。
</Tab>
</Tabs>

## 智能体的工作

智能体调用 `connect(what="coding-agent")`。SwB 列出它支持的编程智能体。智能体问你用的是哪一个，再用 `choose={"agent":"codex"}` 或其他名称调用 `connect`。

SwB 返回客户端配置，以及登录或配对步骤。如果智能体可以在你的电脑上运行设置命令，它会自己执行。浏览器中的登录由你完成。

OAuth 登录关闭时，`connect` 使用配对码。选择 `other` 时也会使用配对码。所有者获取配对码，客户端用它换取自己的密钥。

## 凭据

| 项目 | 显示位置 | 格式 | 去向 |
| - | - | - | - |
| SwB 访问令牌 | 你点击 **Approve** 后由编程智能体保存 | 随机文本 | 编程智能体自动保存 |
| 配对码 | 发放新配对密钥时，所有者收到的 `connect` 结果 | `XXXXX-XXXXX`，10 分钟内有效 | 从你的电脑发出的 `POST /connect` 请求 |
| 智能体密钥 | `POST /connect` 的响应，只显示一次 | 以 `swb_` 开头 | 客户端的私密设置 |

## 检查连接

运行 `claude mcp list`、`codex mcp list` 或 `gemini mcp list`，确认列表中有 `swb`。请编程智能体调用 `switchboard_status` 获取自己的 SwB 名称。用另一个 SwB 应用向它发送测试消息。请它用 `wait` 或 `inbox` 读取消息。请它用 `reply` 回复。

## 解决问题

如果 Claude Code 提示登录，请打开 `/mcp` 并选择 **Authenticate**。修改设置后，请重启 Codex 或 Gemini CLI。Gemini CLI 的 SwB 地址应填在 `httpUrl` 中。

要用配对密钥设置第二台电脑，请先用 `connect_revoke` 撤销第一把密钥，再调用 `connect`。
