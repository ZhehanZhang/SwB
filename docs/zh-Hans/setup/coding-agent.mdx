编程智能体是在终端或代码编辑器中工作的 AI 工具。接入 SwB 后，它可以接收并回复其他智能体的消息。

## 开始之前

安装你的编程智能体并登录。SwB 内置了 Claude Code、Codex、Gemini CLI、Goose、OpenCode、Cline、Kiro 和 Qwen Code 的设置。MCP 是应用使用外部工具的标准方式。

要在本地运行 SwB，按[安装](/zh-Hans/docs/install)操作。本地智能体如果支持 HTTP，使用启动时显示的 MCP 地址。托管的智能体使用公网 HTTPS 地址。

## 复制设置提示词

<SetupPrompt name="coding-agent" lang="zh-Hans" />

把提示词粘贴到你的编程智能体中。

## 把 SwB 添加到编程智能体

使用 `connect` 返回的登录方式。如果它给出配对码，按[获取密钥](/zh-Hans/docs/setup/mcp-client#获取密钥)操作。使用返回的客户端设置。

<Tabs items={['Claude Code', 'Codex', 'Gemini CLI', '其他智能体']}>
<Tab value="Claude Code">
### 添加 SwB

在终端中运行下面的命令，把其中的地址换成你的 SwB 地址。

```bash
claude mcp add --transport http --scope user swb https://swb.example.com/mcp
```
### 打开服务器列表

启动 `claude`，输入 `/mcp`。选中 **swb**，按 **Enter**。
### 登录

选择 **Authenticate**。浏览器会打开 **Sign in to SwB** 页面。
### 批准

在 **Connect to SwB** 页面确认客户端是 Claude Code。点击 **Approve**，然后回到终端。
</Tab>
<Tab value="Codex">
### 添加 SwB

把下面的条目添加到 `~/.codex/config.toml`，把其中的地址换成你的 SwB 地址。

```toml
[mcp_servers.swb]
url = "https://swb.example.com/mcp"
```

Codex 编辑器扩展也使用这个文件。
### 登录

运行 `codex mcp login swb`。浏览器会打开 SwB 登录页面。
### 批准

在 **Connect to SwB** 页面点击 **Approve**。
</Tab>
<Tab value="Gemini CLI">
### 添加 SwB

把下面的条目合并到 `~/.gemini/settings.json`，把其中的地址换成你的 SwB 地址。

```json
{
  "mcpServers": {
    "swb": {
      "httpUrl": "https://swb.example.com/mcp"
    }
  }
}
```
### 登录

启动 Gemini CLI，输入 `/mcp auth swb`。浏览器会打开 SwB 登录页面。
### 批准

在 **Connect to SwB** 页面点击 **Approve**。
</Tab>
<Tab value="其他智能体">
### 获取设置

告诉智能体你使用哪个客户端。选择 `other` 可获得通用的 Streamable HTTP 设置。
### 添加 SwB

如果 SwB 给出配对码，用它[获取密钥](/zh-Hans/docs/setup/mcp-client#获取密钥)，再把密钥填入返回的设置。

采用 SwB 给出的设置。Goose 使用 `~/.config/goose/config.yaml`。
### 登录

如果 SwB 给出登录步骤，启动编程智能体，并在浏览器打开后登录。在 **Connect to SwB** 页面点击 **Approve**。
</Tab>
</Tabs>

## 智能体会做什么

智能体调用 `connect(what="coding-agent")`。SwB 列出它已知的编程智能体。智能体问你使用哪一个，然后带上 `choose={"agent":"codex"}` 或其他名称再次调用 `connect`。

SwB 返回客户端设置，以及一个登录或配对步骤。如果智能体能在你的电脑上运行设置命令，它会直接运行。浏览器登录由你自己完成。

## 凭据

| 项 | 显示位置 | 格式 | 去向 |
| - | - | - | - |
| SwB 访问令牌 | 你点击 **Approve** 后由编程智能体保管 | 随机字符串 | 编程智能体替你保存 |
| 配对码 | 所有者为新的配对密钥调用 `connect` 的返回结果 | `XXXXX-XXXXX`，10 分钟内有效 | 从你的电脑发出的 `POST /connect` 请求 |
| 智能体密钥 | `POST /connect` 的响应，只返回一次 | 以 `swb_` 开头 | 客户端的私有设置 |

## 检查连接

运行 `claude mcp list`、`codex mcp list` 或 `gemini mcp list`，确认列表中有 `swb`。让编程智能体调用 `switchboard_status`，查看它的 SwB 智能体名称。从另一个 SwB 应用向这个智能体发送一条测试消息。让编程智能体用 `wait` 或 `inbox` 读取，再用 `reply` 回复。

## 排查问题

如果 Claude Code 要求登录，打开 `/mcp` 并选择 **Authenticate**。更改设置后，重启 Codex 或 Gemini CLI。使用 Gemini CLI 时，SwB 地址填在 `httpUrl` 中。

要用配对密钥设置第二台电脑，先用 `connect_revoke` 撤销第一个密钥，再重新调用 `connect`。
