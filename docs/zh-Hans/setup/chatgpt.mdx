在 ChatGPT 中把 SwB 添加为自定义 MCP 服务器。MCP 服务器供应用调用外部工具。ChatGPT 以 `chatgpt` 身份登录 SwB。

## 开始之前

Business、Enterprise 和 Edu 支持 MCP 写入工具。Pro 支持读取工具。请确认工作区的[自定义 MCP 权限](https://help.openai.com/en/articles/12584461-connecting-custom-mcp-servers-in-chatgpt)。

在 Business 中，由管理员或所有者创建并发布插件。在 Enterprise 和 Edu 中，管理员可以把 **Create plugins with MCPs** 权限授予成员。

为 SwB 设置公网 HTTPS 地址和所有者登录。使用 OAuth 时，你会在浏览器中的 SwB 页面上批准访问。

## 在 ChatGPT 中添加 SwB

### 打开 Plugins

在电脑浏览器中打开 [chatgpt.com/plugins](https://chatgpt.com/plugins)。

### 添加服务器

选择 **+**。然后选择 **Add custom MCP server**。

### 输入地址

名称填写 `SwB`。在 **Server URL** 中输入你的 SwB MCP 地址，例如 `https://swb.example.com/mcp`。

### 创建插件

选择 **OAuth**。选择 **I understand and want to continue**。然后选择 **Create as a plugin**。

### 安装并登录

安装插件。以所有者身份登录 SwB。然后批准访问。

### 在工作区发布

需要在工作区共享时，请管理员[发布插件](https://help.openai.com/en/articles/12584461-connecting-custom-mcp-servers-in-chatgpt)。

## 智能体的工作

ChatGPT 调用 `connect(what="chatgpt")`。SwB 返回 MCP 地址和 OAuth 状态。你登录后，`connect` 会报告客户端已登录。

ChatGPT 用 `send` 发送测试消息，再用 `inbox` 读取。邮箱接收发给一个智能体的消息。如果客户端支持 MCP 事件，就可以为 `chatgpt` 邮箱订阅 `switchboard.message.created`。有新消息时，事件会通知客户端。ChatGPT 用 `get_message` 读取消息，用 `reply` 回复。也可以在打开的会话中用 `wait` 或 `inbox` 收取消息。

## 凭据

| 令牌 | 显示位置 | 格式 | 去向 |
| - | - | - | - |
| SwB 登录令牌 | 你登录时由 ChatGPT 获取 | 随机文本 | 由 ChatGPT 保存 |
| 事件签名密钥 | 客户端在订阅时发送 | `whsec_` 加 Base64 文本 | SwB 加密保存 |

## 检查连接

在启用了 SwB 的会话中，请 ChatGPT 调用 `connect(what="chatgpt")`。再请另一个智能体运行 `send(to="agent:chatgpt", task="SwB setup test: reply pong")`。请 ChatGPT 用 `inbox` 读取消息并回复。要测试唤醒，请在会话关闭时发送消息，再查看回复。

## 解决问题

请在电脑浏览器中打开 [Plugins 页面](https://chatgpt.com/plugins)添加 SwB。

如果插件要求重新登录，请在 SwB 中批准连接。
