连接器让 Claude 可以使用外部服务的工具。有了 SwB 连接器，Claude 就能读取你的项目、向其他智能体发送任务，并回复消息。

## 开始之前

Claude 免费套餐可以添加一个自定义连接器。Pro、Max、Ultra、Team 和 Enterprise 套餐同样支持自定义连接器。

为 SwB 设置所有者登录。使用 443 端口上的公网 HTTPS 地址，让 Claude 能访问 `/mcp`。

## 把 SwB 添加到 Claude

<Tabs items={['个人套餐', 'Team 或 Enterprise']}>
<Tab value="个人套餐">
### 添加自定义连接器

在 Claude 中打开 [Customize → Connectors](https://claude.ai/customize/connectors)。选择 **+ Add**，再选择 **Add custom connector**。
### 填写地址

名称填 `SwB`。地址填你的 SwB MCP 地址。

```text
https://swb.example.com/mcp
```

### 保留默认登录设置

选择 **Continue**，查看登录设置。在 **Authentication** 下选择 **Sign in now**。在 **OAuth client** 下选择 **Use Claude’s published identity (Recommended)**。**Request headers** 留空。
### 添加并连接

点击 **Add**。如果列表中的 SwB 显示 **Connect**，点击 **Connect**。
### 在 SwB 中批准

在 **Sign in to SwB** 页面登录。在 **Connect to SwB** 页面核对名称，然后点击 **Approve**。
</Tab>
<Tab value="Team 或 Enterprise">
### 打开管理页面

用有权添加自定义连接器的账号打开 [Organization settings → Connectors](https://claude.ai/admin-settings/connectors)。Team 套餐需要使用 Owner 或 Primary Owner 账号。
### 添加 Web 连接器

点击 **Add**。把鼠标指针移到 **Custom** 上，然后点击 **Web**。
### 填写地址

名称填 `SwB`。地址填你的 SwB MCP 地址。选择 **Continue**，查看登录设置。选择 **Sign in now** 或 **Sign in when needed**。选择 **Use Claude’s published identity (Recommended)**，再选择 **Add**。
### 连接你的账号

打开 **Customize** → **Connectors**。找到 `SwB`，点击 **Connect**。
### 在 SwB 中批准

在 **Sign in to SwB** 页面登录。在 **Connect to SwB** 页面点击 **Approve**。
</Tab>
</Tabs>

### 在聊天中开启 SwB

在聊天中选择 **+** → **Connectors**，开启 SwB。如果是 Claude Project，在协调者聊天中操作。

## 智能体会做什么

智能体调用 `connect(what="claude")`。SwB 返回 MCP 地址，并说明 OAuth 是否可用。使用 OAuth 时，你在浏览器中批准访问。

智能体把点击路径和地址告诉你。你批准后，它再次调用 `connect`，SwB 会报告客户端已登录。

## 凭据

| 项 | 显示位置 | 格式 | 去向 |
| - | - | - | - |
| MCP 地址 | SwB 设置和 `connect` 的返回结果 | `https://swb.example.com/mcp` | Claude 连接器的 URL 字段 |
| SwB 访问令牌 | 你点击 **Approve** 后由 Claude 保管 | 随机字符串 | Claude 替你保存 |

## 检查连接

打开 **Customize** → **Connectors**，确认 `SwB` 显示为已连接。让 Claude 调用 `project_list`。能列出你的 SwB 项目，就说明连接成功。

## 排查问题

使用以 `/mcp` 结尾的公网 HTTPS 地址。让 Claude 能直接访问 `/mcp`。如果 SwB 地址变了，先移除连接器，再用新地址重新添加。
