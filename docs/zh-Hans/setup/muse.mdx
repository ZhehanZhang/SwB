## 实时唤醒 Muse

要让 Muse 在消息到达时立即开始工作，推荐使用 Muse gadget。gadget 是与 Muse 应用配对的设备。

[Companion](/zh-Hans/docs/companion) 是运行在你自己设备上的 SwB 程序。配对期间，它通过蓝牙充当 gadget。配对完成后，由 SwB 服务器保持与 Muse 的连接。这时可以停止 Companion。

为 SwB 设置公网 HTTPS 地址。把下面的提示词粘贴到一个以所有者身份登录、拥有完整权限的 SwB 智能体中。

<SetupPrompt name="muse" lang="zh-Hans" />

让智能体调用 `connect(what="muse", choose={"gadget": true})`，然后按它返回的说明操作。

在 [Muse SDK tokens 页面](https://gadgets.muse.ai/settings/sdk-tokens)创建一个个人令牌，再用智能体给出的一次性 SwB 认领链接保存它。

使用一台带蓝牙的 Mac 或 Linux 电脑。把电脑放在手机附近。

如果要把 Muse 添加到已配对的 Companion，先运行 `swb companion disconnect`。然后获取一个 [Companion 配对码](/zh-Hans/docs/companion#配对设备)。配对码只能使用一次，10 分钟后过期。

把示例地址换成你的 SwB 地址。

在 macOS 上，先登录桌面，再运行下面的命令。

```sh
uv tool install swb-one
swb companion connect https://swb.example.com --cap muse
```

SwB 会按需将已签名的 **SwB Companion** 应用安装到 `~/Applications`。macOS 首次提示时，请允许 **SwB Companion** 使用蓝牙。

在 Linux 上，确保 Companion 可以访问系统蓝牙服务 BlueZ。运行下面的命令。

```sh
uvx --python 3.13 --from 'swb-one[companion]' swb companion connect https://swb.example.com --cap muse
```

出现提示后输入配对码，输入的内容会隐藏。配对 Muse 期间，保持 Companion 运行。让智能体开始 Muse 配对。

在 Muse 应用中打开 **Settings**，再打开 **Devices**。开启 **Developer mode**。选择 **Add Device**，然后选择智能体给出的设备名称。如果应用询问 Wi-Fi，选择 **Use current connection**。

SwB 只在配对 Muse 时使用蓝牙。如果 SwB 提示某个应用占用了蓝牙信号的空间，先暂停该应用。重新打开 **Add Device**。配对结束后，再打开该应用。

## 添加连接器以使用工具

连接器让 Muse 可以通过模型上下文协议（MCP）使用 SwB 工具。使用 OAuth 时，你在浏览器中批准这项访问。

在 SwB 上启用所有者登录。让 Muse 把你的公网 HTTPS 地址添加为自定义连接器，并使用 OAuth。这个地址以 `/mcp` 结尾。重定向 URI 填 `https://agent.meta.ai/api/hatch/oauth/callback`，它是接收登录结果的地址。

打开 Muse 给出的登录链接，以所有者身份登录 SwB。Muse 以 `muse` 的身份连接 SwB。

## 检查连接

测试 gadget 时，让一个以所有者身份登录的智能体调用 `send(to="muse:gadget:muse", task="Reply with pong.")`，然后在测试对话中查看回复。

测试连接器时，让另一个 SwB 智能体调用 `send(to="agent:muse", task="Reply with pong.")`。让 Muse 用 `inbox` 读取消息，再用 `reply` 在同一个对话中回复。
