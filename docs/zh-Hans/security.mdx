## 一个所有者

SwB 只有一个所有者。所有者批准智能体登录，并在 SwB 控制台中管理访问权限、保存令牌。

## 智能体的登录

应用经所有者批准后，借助 OAuth 登录。SwB 使用 S256 方式的 PKCE，验证发起登录和完成登录的是同一个应用。SwB 把每个 OAuth 令牌绑定到一个 `/mcp` 地址。默认情况下，访问令牌的有效期为 1 小时，刷新令牌的有效期为 30 天。每个刷新令牌使用后，SwB 都会换发新的。SwB 保存的是 OAuth 令牌的 SHA-256 哈希，也就是用来校验令牌的指纹。智能体也可以使用已配置的密钥，或用配对码兑换密钥。

## 信任等级

SwB 检查平台提供的发送方 ID，据此设定消息的信任等级。

| 信任等级 | 适用对象 |
| - | - |
| `owner` | 你本人，以及你自己已登录的智能体 |
| `external` | 其他发送方，包括 `known` 中列出的人和机器人 |

在 Slack、Discord 和 Telegram 上，`known` 帮助 SwB 决定接受谁的消息。这些外部发送方的消息，信任等级仍为 `external`。SwB 如何核对 GitHub 作者，见 [GitHub 所有者账号](/zh-Hans/docs/blocks/github#所有者账号)。

**信任框架**是 SwB 加在外部文本上的头部和标记。如果文本中本来就含有同样的头部或标记，SwB 会先改写它们，再添加框架。标记是 `<<<swb-untrusted` 和 `swb-untrusted>>>`。智能体只把两个标记之间的文本当作信息。

Watch 模式生成的摘要，信任等级为 `external`。每段摘录都带有针对外部文本的信任框架。SwB 会核对每个 GitHub 文本字段的作者。

[Companion](/zh-Hans/docs/companion) 密钥只对所属设备的连接有效。SwB 只保存这个密钥的哈希，用来校验它。SwB 把设备返回的结果标记为 `external`，并把其中的自由文本放入信任框架。

## 可见性

资源可以是目标、频道、记忆范围、路由或工具。默认访问规则是 `private`，仅限所有者及其智能体访问。资源可以共享给某个工作区或选定的人。工具始终保持私有。频道规则和目标规则都允许时，外部发送方才能向目标发送消息。SwB 把一条消息保存为上下文时，这条消息作为信息进入收件箱，智能体保持休眠。

## 受限密钥

用 `auth.key_scopes` 限制路由、消息和对话的访问权限。在这些限制内，配对密钥只能读取所属智能体的消息和对话。

SwB 为每个配对密钥保存记忆授权。升级旧授权时，原先拥有宽泛访问权限且仍在使用的配对密钥会获得 `general` 以及当时已有的项目。如果 `auth.key_scopes` 为密钥列出了具体的范围，SwB 会原样复制这些范围。

权限完整的 OAuth 客户端或已配置密钥，都能以所有者身份访问全部记忆。用 `auth.key_scopes` 可以按智能体名称限制记忆访问权限。受限凭据要访问私有项目，需要一项针对该项目的授权。

`auth.key_tools` 限制密钥可以调用的工具，`auth.key_targets` 限制它可以发送到的目标。

## 令牌

令牌在各自的认领页面上输入。SwB 用数据目录中的一个密钥加密它保存的令牌。状态信息显示缺失变量的名称，并隐藏变量的值。Capy 密钥默认放在请求头中发送到 `api.capy.ai`。

打开 **Tokens**，可以查看每个配对密钥的记忆范围。选择某个范围旁的 **Remove scope**，可以移除这项授权。

新的配对密钥在兑换配对码时获得自己的智能体范围，同时获得配对码指定的项目，以及 `auth.key_scopes.<agent>` 中列出的范围。要扩大访问权限，先设置额外的范围，或在配对码中加入项目，然后配对一个新密钥。

## 限制

| 限制项 | 数值 |
| - | - |
| 无效的 Bearer 密钥 | 每个地址 10 分钟内 20 次尝试，之后返回 HTTP `429` |
| 所有者账号以外的发送方触发并进入路由的 GitHub 事件 | 每个发送方在最近 10 分钟内 5 个 |
| `/register` | 每个地址每小时 20 次 |
| `/token` | 每个地址 10 分钟内 120 次 |
| `/authorize` | 每个地址 10 分钟内 60 次 |
| `/companion/pair` 收到的错误配对码 | 每个地址 10 分钟内 10 次，之后返回 HTTP `429` |
| `/connect` 收到的错误配对码 | 每个地址 10 分钟内 10 次，之后返回 HTTP `429` |
| 默认请求体上限 | 1 MiB |
| `/mcp` 和 `/companion/results` 的请求体 | 16 MiB |
| `/companion/emit` 的请求体 | 16,640 字节 |
| `/auth/setup` 的请求体 | 1,024 字节 |
| 每个智能体对话的轮数 | 200 |

Bearer 密钥的限制同样适用于来自同一地址的有效密钥。限制解除之前，SwB 在受影响的端点上返回 HTTP `429`。

对话达到轮数上限时，SwB 会暂停它，并把这次暂停记入审计日志。如果 Slack 处于启用状态，SwB 还会给所有者发一条私信。

任务和目标都相同时，Capy 模块可以返回之前的对话。时间窗口用 `blocks.capy.duplicate_window_s` 设置，默认值为 600 秒。

## 客户端地址

SwB 默认按连接地址执行限制并写入审计记录。把你的代理添加到 `trusted_proxies` 或 `SWB_TRUSTED_PROXIES` 后，SwB 改用代理传来的客户端地址。配置代理时，让它根据自己验证过的来源设置客户端地址请求头。

客户端地址解析失败时，SwB 按转发请求头分开限流。含有无效地址的请求头使用 `invalid-forwarded`。只含受信任代理地址的请求头使用 `trusted-only-forwarded`。

要添加 Cloudflare Tunnel 连接器或 Docker 网络中的反向代理，参阅[自托管指南](/zh-Hans/docs/self-hosting#受信任的代理)。

## 审计日志

访问规则拒绝的工具调用，SwB 会记录下来。浏览器登录失败也会记录，涵盖设置码、已用过的链接、过期链接、无效链接、通行密钥、CSRF 校验和 OIDC。

GitHub Webhook 签名缺失或无效时，SwB 也会记录。某些浏览器登录失败和 Webhook 拒收反复出现时，SwB 会限制记录的行数。失败记录给出原因，其中的一次性码、令牌和签名一律隐去。

SwB 拒绝 Cloudflare Access 凭据时，每 10 分钟为每个客户端地址记录一次。

SwB 页面在 **Audit** 下显示这些记录。运行 `swb log` 可以输出最近的记录。发送到邮箱的操作名为 `send`。SwB 丢弃投递时留下的记录见[频道模式](/zh-Hans/docs/channel-modes#检查投递)。

## 报告问题
