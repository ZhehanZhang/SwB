## 获取设置

```bash
swb connect coding-agent --choose agent=codex
```

这条命令显示如何把 SwB 添加为远程 MCP 服务器。SwB 和客户端都支持 OAuth 时，使用 OAuth。命令给出配对说明时，按配对说明操作。

| 客户端 | 设置方式 |
| - | - |
| Claude Code | `claude mcp add` |
| Codex | `config.toml` |
| Gemini CLI 和 Qwen Code | `settings.json` |
| Goose | `config.yaml` |
| OpenCode | `opencode.json` |
| Cline 和 Kiro | 各自的 MCP 设置 |
| 其他客户端 | Streamable HTTP 加配对码 |

要配合 Capy 使用 MCP Tasks，参阅 [MCP Tasks](/zh-Hans/docs/blocks/capy#mcp-tasks)。

## Claude Code 频道

频道把 `claude-code` 邮箱中的消息发送到打开的 Claude Code 会话。Claude Code 频道目前是研究预览版。

生成一个至少 24 个字符的随机密钥，以 `SWB_KEY_CHANNEL` 为名保存到服务器的私有 `.env` 文件中。重启 SwB 以加载密钥。这个密钥拥有 `claude-code` 邮箱的读取权限。然后安装 [Bun](https://bun.sh)，并在 Claude Code 中添加插件。

```text
/plugin marketplace add ZhehanZhang/SwB
/plugin install swb@swb
```

在 **SwB URL** 中填你的 SwB 基础地址。在 **Channel key** 中填 `SWB_KEY_CHANNEL` 的值。用下面的命令启动 Claude Code 并加载频道。

```bash
claude --dangerously-load-development-channels plugin:swb@swb
```

首次运行时，频道从新消息开始接收。之后每次运行，它从保存的位置继续。要通过 SwB 回复，使用另一条 MCP 连接中的 `reply`。
