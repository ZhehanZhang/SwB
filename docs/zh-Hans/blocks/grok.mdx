## 添加连接器

按 [Grok 设置](/zh-Hans/docs/setup/grok)连接浏览器中的 Grok。独立的桌面应用使用 [Grok Bot 设置](/zh-Hans/docs/setup/grok-bot)。

## 用 routine 唤醒 Grok Bot

让智能体连接 Grok Bot。在终端中运行 `swb connect grok-bot`。按它给出的设置说明获取 routine 提示词。

用这段提示词创建一个带 Webhook 触发器的 Grok Bot routine。SwB 向 Webhook 的 URL 发送请求时，Webhook 就会启动 routine。把 `example` 换成一个活跃 SwB 项目的短名称。运行下面的命令注册 routine。

```bash
swb connect grok-bot --choose name=project-triage project=example auth=key
```

SwB 会分别给出 Webhook 地址和密钥的认领链接。用每个链接保存对应的值。再次运行同一条命令，获取测试调用。让智能体运行这个调用，并确认收到 `pong` 回复。

## 唤醒的工作方式

使用 `auth=key` 时，SwB 默认把密钥放在 `Authorization` 请求头中发送。使用 `auth=signature` 时，SwB 为请求签名。请求包含文本、对话标识、发送方和信任等级，有项目时还包含项目。遇到信任等级为 `owner` 的请求，routine 调用 `reply`。

手动设置时，在服务器环境中设置 `url_env` 和 `secret_env` 所指的变量。

```yaml
blocks:
  grok-routine:
    routines:
      project-triage: {project: example, url_env: SWB_EXAMPLE_GROK_URL, auth: key, secret_env: SWB_EXAMPLE_GROK_SECRET}
```

按名称向 routine 发送，或发送到 `grok:<slug>`，后者指向项目的主 routine。

## 配置

| 键 | 用途 |
| - | - |
| `blocks.grok-routine` | 唤醒 Grok Bot routine 的设置 |
| `blocks.grok-routine.use` | 模块类型。填 `grok-routine` |
| `blocks.grok-routine.enabled` | 设为 `false` 可跳过这个模块 |
| `blocks.grok-routine.routines` | routine 名称到设置的映射 |
| `blocks.grok-routine.routines.*.project` | SwB 项目的短名称。通用 routine 填 `null` |
| `blocks.grok-routine.routines.*.primary` | 设为 `true` 时，它的项目优先选用这个 routine |
| `blocks.grok-routine.routines.*.auth` | 填 `key` 发送密钥，填 `signature` 为请求签名。默认为 `key` |
| `blocks.grok-routine.routines.*.header` | 携带密钥或签名的 HTTP 请求头。`key` 默认用 `Authorization`，`signature` 默认用 `Webhook-Signature` |
| `blocks.grok-routine.routines.*.url_env` | 保存公网 HTTPS Webhook 地址的变量名 |
| `blocks.grok-routine.routines.*.secret_env` | 保存密钥或签名密钥的变量名 |
