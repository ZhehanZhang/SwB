SwB 主动向 Telegram 查询新消息。你的 SwB 服务器使用内网地址即可。

## 创建机器人

在 [@BotFather](https://t.me/BotFather) 中发送 `/newbot`。让智能体连接 Telegram。智能体调用 `telegram_provision`，并给你一个认领链接。打开链接，粘贴 Bot 令牌。

## 把机器人添加到群组

把机器人添加到群组。在群组中发送 `/swb@<bot username>`。之后，`telegram_status` 会在 `setup.seen_chats` 中显示这个群组的聊天 ID。把这个 ID 填入空间的 `chats`。

与机器人发起私聊，并给它发一条消息。在 `setup.seen_chats` 中找到你的私聊 ID，把它填入 `owner_ids`。

```yaml
blocks:
  telegram:
    use: telegram
    agents: {claude: [home]}
    spaces:
      home:
        chats: [-100111222]
        owner_ids: [222222]
        default_target: claude
```

## 从 Telegram 发送

给机器人发私聊消息、提及机器人，或使用 `/swb <target> <message>`。要继续一段对话，回复机器人发出的那条消息。启用 `persona_prefix` 后，智能体的回复可以用粗体显示智能体的名称。

要让机器人读取群组的每条消息，在 @BotFather 中用 `/setprivacy` 关闭隐私模式。然后把机器人移出群组，再重新添加。

## 模块设置

在 **Settings** 中打开 Telegram，修改机器人的名称和头像。Telegram 在所有聊天中使用同一套名称和头像。

| 键 | 用途 |
| - | - |
| `blocks.telegram` | Telegram 机器人及其空间的设置 |
| `blocks.telegram.use` | 加载 `telegram` 模块 |
| `blocks.telegram.enabled` | 设为 `true` 加载模块，设为 `false` 关闭模块 |
| `blocks.telegram.token_env` | Bot 令牌的环境变量名 |
| `blocks.telegram.dm_space` | 为私聊提供路由和所有者设置的空间。默认为第一个已配置的空间 |
| `blocks.telegram.dm_mode` | 其他人所发私聊消息的模式。填 `watch` 收集摘要，填 `off` 忽略这些消息 |
| `blocks.telegram.ack_reaction` | 机器人收到发给它的消息后，用来确认收到的表情符号。设为 `null` 可关闭这项回应 |
| `blocks.telegram.persona_prefix` | 设为 `true` 时，在第一行用粗体显示智能体使用的名称 |
| `blocks.telegram.refresh_minutes` | 目标列表的更新间隔，单位为分钟。默认为 `30` |
| `blocks.telegram.target_aliases` | 把额外的目标名称映射到已有的目标 |
| `blocks.telegram.agents` | 每个智能体可以发布消息和接收事件的空间。填 `*` 表示所有空间 |

要通过项目路由唤醒智能体，使用[频道模式](/zh-Hans/docs/channel-modes)。

## 空间和群组

| 键 | 用途 |
| - | - |
| `blocks.telegram.spaces` | 把 SwB 中使用的名称映射到一组 Telegram 群组的设置 |
| `blocks.telegram.spaces.*.chats` | 这个空间中的群组聊天 ID。使用负整数。每个群组只放在一个空间中 |
| `blocks.telegram.spaces.*.owner_ids` | 视为所有者的 Telegram 用户 ID |
| `blocks.telegram.spaces.*.known` | 把已知的 Telegram 用户 ID 映射到显示名称 |
| `blocks.telegram.spaces.*.default_target` | 发给 SwB 的新消息省略目标名称时使用的目标 |
| `blocks.telegram.spaces.*.project` | 这个空间的默认 SwB 项目 |
| `blocks.telegram.spaces.*.channel_projects` | 按群组聊天 ID 设定 SwB 项目 |
| `blocks.telegram.spaces.*.mode` | 空间的模式。群组的模式可以覆盖它 |
| `blocks.telegram.spaces.*.channels` | 按群组聊天 ID 设定模式或更详细的设置 |
| `blocks.telegram.spaces.*.channels.*.mode` | 单个群组的模式 |
| `blocks.telegram.spaces.*.channels.*.project` | 单个群组的 SwB 项目。它优先于空间的项目 |
| `blocks.telegram.spaces.*.listen` | 旧版设置，列出使用 `assist` 模式的群组聊天 ID |
| `blocks.telegram.spaces.*.bot_posts_per_hour` | 机器人一小时内在每个对话中最多发布的消息数。默认为 `20` |
