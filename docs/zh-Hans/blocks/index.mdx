模块为 SwB 提供连接或功能。在配置文件中设置模块。使用默认配置时，SwB 会根据环境变量加载部分模块。运行 `swb status` 查看模块状态和设置提示。以所有者身份登录后，在 `/healthz` 查看详情。

| 连接 | 连接方式 | 消息传递方式 |
| - | - | - |
| [Claude](/zh-Hans/docs/blocks/claude) | 自定义连接器和 Claude routine | `wait`、`inbox` 和 routine 唤醒 |
| [ChatGPT](/zh-Hans/docs/blocks/chatgpt) | 自定义 MCP 服务器和 ChatGPT dot | MCP Events |
| [Capy](/zh-Hans/docs/blocks/capy) | Capy API 密钥 | Capy 话题串的事件流 |
| [Grok](/zh-Hans/docs/blocks/grok) | MCP 连接器和 Grok Bot routine | `wait`、`inbox` 和 routine 唤醒 |
| [编程智能体](/zh-Hans/docs/blocks/coding-agents) | OAuth 或配对码 | `wait`、`inbox` 和 Claude Code 频道 |
| [本地会话](/zh-Hans/docs/blocks/local-sessions) | 已配对的设备 | 邮箱或直接送达已打开的会话 |
| [Slack](/zh-Hans/docs/blocks/slack) | 经 Socket Mode 的 Slack 应用 | 话题串中的回复 |
| [Discord](/zh-Hans/docs/blocks/discord) | 机器人令牌 | 话题串中的回复 |
| [Telegram](/zh-Hans/docs/blocks/telegram) | 机器人令牌 | 话题串中的回复 |
| [GitHub](/zh-Hans/docs/blocks/github) | Webhook 密钥 | 带签名的 Webhook |
| [Muse](/zh-Hans/docs/setup/muse) | 已配对的 Muse 装置和 MCP 连接器 | 实时唤醒和邮箱消息 |
| [其他 MCP 客户端](/zh-Hans/docs/setup/mcp-client) | OAuth 或配对码 | `wait` 和 `inbox` |

## 信任与访问

SwB 根据平台的发送者 ID 标记消息的信任等级。在 Slack、Discord 和 Telegram 中，`known` 是接收设置。SwB 用它判断接收哪些发送者的消息。所有者之外的发送者即使通过 `known` 获准，消息的信任等级仍为 `external`。详见[信任](/zh-Hans/docs/security#信任等级)。

目标、频道和记忆范围默认为私有资源。共享资源后，其他人也能访问。

## 添加你自己的模块

模块是带有清单的 Python 类。清单说明模块能执行的操作、消息目标和所需密钥。在 `switchboard.blocks` 入口点组中注册模块。运行 `swb blocks list` 查看服务器上已配置的模块。
