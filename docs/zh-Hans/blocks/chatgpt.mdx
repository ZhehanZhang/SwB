## 把 SwB 添加到 ChatGPT

按 [ChatGPT 设置](/zh-Hans/docs/setup/chatgpt)把 SwB 添加为自定义 MCP 服务器。ChatGPT 用 OAuth 以 `chatgpt` 的身份登录。

## 接收新消息通知

MCP Events 在消息到达时发出通知。如果 ChatGPT 支持 MCP Events，让它订阅 `switchboard.message.created`，并把 `mailbox_id` 设为 `chatgpt`。SwB 用 Webhook 发送消息 ID，Webhook 是发往某个 URL 的请求。ChatGPT 用 `get_message` 读取正文，用 `reply` 回复。ChatGPT 也可以用 `wait` 或 `inbox` 检查新消息。

## ChatGPT dots

dot 是个人专属的 ChatGPT 智能体。`dots` 模块在一个 Slack 工作区中查找 dot，并把每个 dot 设为目标。在 Slack 中用 `@swb <dot name> <message>` 发送，或调用 `send(to="<dot name>", task="<message>")`。

默认的 Slack 投递使用私有频道 `#agents`。SwB 可以用你的用户令牌创建这个频道。在这个频道中用 `/invite` 添加 SwB 机器人和各个 dot。SwB 把 dot 的回复送回原来的对话。

```yaml
blocks:
  dots:
    delivery: slack
    workspace: home
    channel: "#agents"
    match: [dot]
```

把下面的内容粘贴到 dot 的指令中。把示例 ID 换成你的 SwB 机器人 ID 和应用 ID。

```text
In #agents, check the bot and app IDs on SwB posts that mention you. Use bot <BOT_ID> and app <APP_ID>. Answer matching posts in the same thread.
```

要直接投递到邮箱，按 [ChatGPT dots 设置](/zh-Hans/docs/setup/dots)操作。设置 `delivery: mailbox`，并在 `blocks.dots.dots` 下添加每个 dot。

## 配置

| 键 | 用途 |
| - | - |
| `blocks.dots` | 向 ChatGPT dots 发送消息的设置 |
| `blocks.dots.use` | 模块类型。填 `dots` |
| `blocks.dots.enabled` | 设为 `false` 可跳过这个模块 |
| `blocks.dots.delivery` | 填 `slack` 使用 Slack，填 `mailbox` 使用 MCP Events。默认为 `slack` |
| `blocks.dots.workspace` | 要扫描的 Slack 工作区。SwB 默认使用第一个工作区 |
| `blocks.dots.channel` | 向 dot 传递消息的 Slack 私有频道。默认为 `#agents` |
| `blocks.dots.create` | 设为 `true` 后，SwB 会在需要时以所有者身份创建这个频道。默认为 `true` |
| `blocks.dots.app_ids` | 用来识别 dot 的 Slack 应用 ID |
| `blocks.dots.match` | 在 Slack 机器人名称中查找的文本。默认为 `[dot]` |
| `blocks.dots.rescan_minutes` | 扫描 Slack dot 的间隔，单位为分钟。默认为 `30` |
| `blocks.dots.poll_seconds` | 检查 Slack 私信回复的间隔，单位为秒。默认为 `5` |
| `blocks.dots.default` | 目标名称 `dot` 指向的 dot。填它的简称或 ID |
| `blocks.dots.dots` | dot 定义的映射，供 `mailbox` 投递使用，也可以覆盖 Slack dot 的设置 |
| `blocks.dots.dots.*.name` | dot 的显示名称 |
| `blocks.dots.dots.*.mailbox` | 接收消息的邮箱。默认为 `chatgpt` |
| `blocks.dots.group_dm` | 设为 `true` 时，使用包含所有者、SwB 和 dot 的 Slack 群组私信 |
| `blocks.dots.owner_dm` | 设为 `true` 时，以所有者身份发布的消息发到所有者与 dot 的 Slack 私信中 |
| `blocks.dots.agents_as_owner` | 设为 `true` 时，所有者的智能体通过频道或私信投递时使用所有者的 Slack 账号 |
| `blocks.dots.owner_posts_as` | 把所有者的 Slack 消息转发给 dot 时使用的账号。默认为 `swb`。设为 `owner` 则使用所有者的账号 |
