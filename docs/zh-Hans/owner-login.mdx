title: 所有者登录
description: 用通行密钥、一次性链接、设置码或身份提供商登录。

所有者登录后管理 SwB。凭这项权限，所有者可以批准智能体登录并保存令牌。

| 页面 | 用途 |
| - | - |
| `/login` | 以所有者身份登录。 |
| `/authorize` | 审核智能体的连接请求。 |

## 一次性链接

```bash
swb login-link
```

这条命令会输出一个形如 `https://swb.example.com/login#t=...` 的链接。在 5 分钟内用浏览器打开它。链接只能使用一次。以所有者身份登录的智能体也可以用 `login_link` 工具生成链接。令牌始终留在链接中 `#` 之后的部分。

首次在本地启动时，`swb up` 会输出一个一次性链接。本地地址默认为 `http://localhost:8870`。如果设置了 `SWB_PORT`，地址中的端口会换成这个值。运行 `swb login-link` 时，用 `--url` 指定其他服务器，用 `--dir` 从其他实例文件夹读取所有者密钥。

如果用链接登录失败，再运行一次 `swb login-link`，然后用浏览器打开新链接。

## 设置码

设置码只能使用一次，供所有者首次登录。如果登录由 SwB 直接处理，就使用设置码。托管服务器的设置码从哪里获取，见[部署指南](/zh-Hans/docs/deploy)。

要自行指定设置码，先生成 32 个随机字节，再编码成 64 个小写十六进制字符或标准 Base64。下面的命令会向私有的 `.env` 文件追加一个十六进制设置码。运行 `swb init` 之后，在实例文件夹中运行它。

```bash
(umask 077; printf 'SWB_SETUP_CODE=%s\n' "$(openssl rand -hex 32)" >> .env)
```

设置好 `SWB_SETUP_CODE` 后启动 SwB。用浏览器打开 `/login`，把设置码粘贴到 **Setup code**，然后选择 **Sign in**。

## 通行密钥

**通行密钥**借助你的设备确认登录。首次登录后，在 **Passkey name** 中输入设备名称，然后选择 **Add a passkey**。

要添加其他设备，打开 **Settings**，在 **Sign-in** 下选择 **Add a passkey**。输入名称，选择 **Add passkey** 保存。以后用通行密钥登录。

## OIDC

OpenID Connect（OIDC）让 Google 这样的登录服务确认你的身份。把你的登录服务添加到配置文件中，并把 `SWB_OIDC_CLIENT_SECRET` 设为该服务提供的密钥。

```yaml
public_url: https://swb.example.com
auth:
  owner_emails: [owner@swb.example.com]
  oidc:
    name: Google
    issuer: https://accounts.google.com
    client_id: 1234.apps.googleusercontent.com
    client_secret_env: SWB_OIDC_CLIENT_SECRET
```

在身份提供商处，把重定向地址设为 `https://swb.example.com/auth/oidc/callback`。登录页面会显示该服务的按钮。SwB 接受 `auth.owner_emails` 中经过验证的电子邮件地址。也可以在 `auth.oidc.owner_subjects` 中列出该服务的账号 ID。

## Cloudflare Access

按 [Cloudflare 设置](/zh-Hans/docs/setup/cloudflare)中的步骤，用 Cloudflare Access 保护控制台。SwB 会校验 Access 令牌，并把其中的电子邮件地址与 `auth.owner_emails` 或 `SWB_OWNER_EMAILS` 比对。

## 智能体登录

应用经你批准后，借助 OAuth 连接 SwB。在 `/authorize` 页面批准连接。应用会获得 OAuth 权限范围 `switchboard`，这是它所请求的访问权限的名称。应用通过 `/token` 获取或续期令牌。

应用收到 OAuth 错误时，在 `error_description` 中查看详情。

| 错误 | 含义 |
| - | - |
| `access_denied` | 所有者拒绝了连接。 |
| `invalid_client` | SwB 拒绝了应用的身份或凭据。 |
| `invalid_client_metadata` | SwB 拒绝了应用的注册设置。 |
| `invalid_redirect_uri` | 注册时要提供 SwB 允许的回调地址。 |
| `invalid_request` | 请求格式无效，或某个必填值无效。 |
| `invalid_grant` | SwB 拒绝了授权码或刷新令牌。 |
| `invalid_target` | 请求指定的 MCP 地址有误。 |
| `unsupported_response_type` | 使用 `response_type=code`。 |
| `unsupported_grant_type` | 使用 `grant_type=authorization_code` 或 `grant_type=refresh_token`。 |
| `temporarily_unavailable` | 设置 `public_url`，或检查客户端注册数量上限。 |

SwB 拒绝[配对码](/zh-Hans/docs/connect#用配对码连接)时，`/connect` 也会返回 `invalid_grant`。

## 会话

**Cookie** 是浏览器保存的一个值，让你保持登录状态。SwB 会为这个 Cookie 设置 `Secure` 标志。公网地址要使用 HTTPS。

你更改设置时，浏览器会发送一个令牌，SwB 用它校验请求。要退出登录，打开 **Settings**。

浏览器从 `/auth/session` 读取你当前的登录状态。

## 登录错误

SwB 把浏览器登录失败记录在 **Audit** 下。每一行都显示失败原因，设置码、配对码这类一次性码和令牌一律隐去。某些失败重复出现时，SwB 会限制记录的行数。

| 错误 | 含义 |
| - | - |
| `link_used` | 链接过期前已有人用它登录。 |
| `link_expired` | 链接已过期。 |
| `link_invalid` | SwB 拒绝了这个链接。 |
| `setup_failed` | 设置码格式有误，或与 `SWB_SETUP_CODE` 不同。 |
| `setup_closed` | 设置码登录已关闭。改用其他登录方式。 |
| `passkey_failed` | 通行密钥的设置或验证失败。 |
| `last_method` | OIDC 和 Cloudflare Access 都处于停用状态时，SwB 会保留最后一个通行密钥。 |
| `not_found` | 通行密钥 ID 有误，或这个通行密钥已移除。 |
| `oidc_failed` | 经身份提供商登录失败。 |
| `signed_out` | 这个请求需要所有者会话。 |
| `csrf` | SwB 拒绝了页面地址或安全令牌。 |
| `slow_down` | 登录尝试次数达到上限。等待 `Retry-After` 给出的时间。 |
