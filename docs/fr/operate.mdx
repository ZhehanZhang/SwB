## Sauvegardes et mises à jour [#backups-and-upgrades]

Arrêtez SwB. Copiez le dossier de données complet. Ainsi, la base de données et ses clés restent ensemble. Les clés comprennent `mcp-events.key` et `claim-key`. Copiez vos fichiers de configuration et `.env`. Gardez la sauvegarde privée.

Installez ou compilez la nouvelle version. Démarrez SwB avec le même dossier de données.

<span id="exporter-la-mémoire" />

## Exporter la mémoire [#export-memory]

Exécutez l'export dans le conteneur Compose.

```bash
docker compose exec -T switchboard swb export /data/export
```

L'export enregistre des fichiers Markdown classés par portée dans `./data/export` sur l'hôte. Ouvrez `INDEX.md` pour trouver les fichiers. Définissez `memory.mirror_dir` pour garder une copie Markdown à jour.
