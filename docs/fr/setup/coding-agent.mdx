Un agent de code est un outil d'IA qui travaille dans votre terminal ou votre éditeur de code. SwB lui permet de recevoir des messages d'autres agents et d'y répondre.

## Avant de commencer

Installez votre agent de code. Connectez-vous à celui-ci. SwB fournit des paramètres pour Claude Code, Codex, Gemini CLI, Goose, OpenCode, Cline, Kiro et Qwen Code. MCP est la méthode standard qui permet à une application d'utiliser des outils externes.

Pour exécuter SwB en local, suivez [Installer](/fr/docs/install). Pour un agent local compatible HTTP, utilisez l'adresse MCP affichée au démarrage. Pour un agent hébergé, utilisez une adresse HTTPS publique.

## Ajouter SwB à votre agent de code

Utilisez la méthode de connexion que renvoie `connect`. S'il vous donne un code d'appairage, suivez [Obtenir la clé](/fr/docs/setup/mcp-client#obtenir-la-clé). Utilisez les paramètres client renvoyés.

<Tabs items={['Claude Code', 'Codex', 'Gemini CLI', 'Autres agents']}>
<Tab value="Claude Code">
### Ajouter SwB

Exécutez cette commande dans votre terminal avec votre adresse SwB.

```bash
claude mcp add --transport http --scope user swb https://swb.example.com/mcp
```
### Ouvrir la liste des serveurs

Lancez `claude` et saisissez `/mcp`. Sélectionnez **swb** et appuyez sur **Enter**.
### Se connecter

Choisissez **Authenticate**. Le navigateur ouvre la page **Sign in to SwB**.
### Approuver

Sur la page **Connect to SwB**, vérifiez que le client est Claude Code. Cliquez sur **Approve** et revenez au terminal.
</Tab>
<Tab value="Codex">
### Ajouter SwB

Ajoutez cette entrée à `~/.codex/config.toml` avec votre adresse SwB.

```toml
[mcp_servers.swb]
url = "https://swb.example.com/mcp"
```

L'extension Codex pour éditeur utilise le même fichier.
### Se connecter

Exécutez `codex mcp login swb`. Le navigateur ouvre la page de connexion SwB.
### Approuver

Sur la page **Connect to SwB**, cliquez sur **Approve**.
</Tab>
<Tab value="Gemini CLI">
### Ajouter SwB

Fusionnez cette entrée dans `~/.gemini/settings.json` avec votre adresse SwB.

```json
{
  "mcpServers": {
    "swb": {
      "httpUrl": "https://swb.example.com/mcp"
    }
  }
}
```
### Se connecter

Lancez Gemini CLI et saisissez `/mcp auth swb`. Le navigateur ouvre la page de connexion SwB.
### Approuver

Sur la page **Connect to SwB**, cliquez sur **Approve**.
</Tab>
<Tab value="Autres agents">
### Obtenir les paramètres

Indiquez à l'agent le client que vous utilisez. Choisissez `other` pour les paramètres génériques en Streamable HTTP.
### Ajouter SwB

Si SwB fournit un code d'appairage, utilisez-le pour [obtenir une clé](/fr/docs/setup/mcp-client#obtenir-la-clé). Reportez la clé dans les paramètres renvoyés.

Appliquez les paramètres que SwB vous donne. Pour Goose, utilisez `~/.config/goose/config.yaml`.
### Se connecter

Si SwB indique une étape de connexion, lancez l'agent de code. Connectez-vous quand le navigateur s'ouvre. Sur la page **Connect to SwB**, cliquez sur **Approve**.
</Tab>

## Ce que fait l'agent

L'agent appelle `connect(what="coding-agent")`. SwB liste les agents de code qu'il connaît. L'agent vous demande lequel vous utilisez, puis rappelle `connect` avec `choose={"agent":"codex"}` ou un autre nom.

SwB renvoie les paramètres client et une étape de connexion ou d'appairage. Si l'agent peut exécuter la commande de configuration sur votre ordinateur, il l'exécute. Vous effectuez vous-même la connexion dans le navigateur.

## Identifiants

| Élément | Où il apparaît | Format | Destination |
| - | - | - | - |
| Jeton d'accès SwB | L'agent de code le conserve après votre clic sur **Approve** | Texte aléatoire | L'agent de code le stocke pour vous |
| Code d'appairage | Le résultat `connect` du propriétaire pour une nouvelle clé appairée | `XXXXX-XXXXX`, valable 10 minutes | Une requête `POST /connect` depuis votre ordinateur |
| Clé d'agent | La réponse à `POST /connect`, une seule fois | Commence par `swb_` | Les paramètres privés du client |

## Vérifier la connexion

Exécutez `claude mcp list`, `codex mcp list` ou `gemini mcp list` et vérifiez que `swb` figure dans la liste. Demandez à l'agent de code d'appeler `switchboard_status` pour connaître son nom d'agent SwB. Envoyez un message de test à cet agent depuis une autre application SwB. Demandez à l'agent de code de le lire avec `wait` ou `inbox`. Demandez-lui de répondre avec `reply`.

## Résoudre les problèmes

Si Claude Code vous demande de vous connecter, ouvrez `/mcp` et choisissez **Authenticate**. Redémarrez Codex ou Gemini CLI après un changement de paramètres. Pour Gemini CLI, placez l'adresse SwB dans `httpUrl`.

Pour configurer un second ordinateur avec une clé appairée, révoquez la première clé avec `connect_revoke` et rappelez `connect`.
