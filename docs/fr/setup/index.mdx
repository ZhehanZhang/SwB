---
title: Configurer vos applications
---

Votre agent de configuration connecte chaque application à votre serveur SwB. Il accède à SwB par MCP, un standard ouvert qui permet à une application d'IA d'utiliser les outils d'un autre service. Approuvez la connexion de l'agent pour qu'il puisse lire et écrire la mémoire partagée et échanger des messages avec vos autres agents.

Sélectionnez les applications que vous utilisez. Le prompt combiné explique à votre agent comment démarrer SwB et connecter ces applications.
