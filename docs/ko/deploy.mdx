## 내 컴퓨터에서 실행

[설치](/ko/docs/install)를 따르세요. 로컬에서 처음 시작하면 SwB이 일회용 로그인 링크를 출력합니다. 그 링크를 여세요. 새 링크를 받으려면 `swb login-link`를 실행하세요. 배포 프롬프트는 로컬 설정도 함께 안내합니다.

## SwB 배포

Claude Code나 Codex 같은 코딩 에이전트에 이 프롬프트를 붙여 넣으세요. 에이전트가 로컬 설정이나 호스팅 설정을 안내합니다.

## 내 서버에서 실행

### Docker Compose [#docker-compose]

Docker Compose 2.24 이상을 설치하세요. 데이터 폴더를 소유한 일반 사용자로 이 명령을 실행하세요.

```bash
git clone --branch release/1.0 https://github.com/ZhehanZhang/SwB.git
cd SwB
(umask 077; cp .env.example .env)
{
  printf 'SWB_UID=%s\n' "$(id -u)"
  printf 'SWB_KEY_OWNER='
  openssl rand -hex 32
} >> .env
printf 'SWB_PUBLIC_URL=http://localhost:8870\n' >> .env
mkdir -p data
docker compose up -d --build --wait
curl -fsS http://127.0.0.1:8870/healthz
docker compose exec -T switchboard swb login-link --url http://127.0.0.1:8000
```

터미널에 나온 일회용 로그인 링크를 5분 안에 여세요. 링크는 비공개로 유지하세요.

브라우저는 소유자 로그인에 `http://localhost:8870`을 사용합니다. 컨테이너 안의 명령은 `8000` 포트를 사용합니다. Compose는 데이터를 `./data`에 보관합니다. `.env`를 바꾼 뒤에는 `docker compose up -d`를 다시 실행하세요.

원격 서버라면 링크를 열기 전에 서버의 `8870` 포트를 로컬 `8870` 포트로 포워딩하세요.

로그인 전에 `/healthz`에 요청하면 `status`와 `version`을 돌려받습니다. 전체 상태 정보는 소유자 세션이나 소유자 키로 확인하세요.

### <ProviderMark name="cloudflare" /> Cloudflare Tunnel [#cloudflare-tunnel]

Cloudflare Tunnel은 SwB에 공개 HTTPS 주소를 줍니다. Cloudflare는 무료 플랜에서도 터널을 제공합니다.

SwB을 구성하고 소유자와 클라이언트 요청에 대한 접근 규칙을 정하려면 [Cloudflare 설정 가이드](/ko/docs/cloudflare)를 따르세요.

## 호스팅 플랫폼

`/data`에 영구 디스크를 마운트한 SwB 인스턴스 하나를 사용하세요. Railway, Render, Fly.io 템플릿과 Koyeb 스크립트는 [배포 가이드](https://github.com/ZhehanZhang/SwB/tree/release/1.0/deploy)를 참고하세요.

### 원클릭 배포

<DeployProviders lang="ko" />

### Fly.io [#fly]

[Docker Compose 예제](#docker-compose)에서 받은 SwB 릴리스 체크아웃을 사용하세요. [Fly.io 명령줄 도구](https://docs.fly.io/flyctl/)를 설치하세요. Fly.io에 로그인하세요.

SwB 폴더에서 `sh deploy/fly.sh my-swb`를 실행하세요. `my-swb`는 고유한 앱 이름으로 바꾸세요. 이 스크립트는 `fly deploy --ha=false`로 Machine 하나를 시작합니다.

앱의 로그인 페이지를 여세요. 체크아웃 폴더의 `.env.swb-setup-fly-my-swb`에서 `SWB_SETUP_CODE`를 복사하세요. 그 값을 **Setup code**에 입력하세요. 로그인한 뒤 이 파일을 삭제하세요.

요금 정보는 [Fly.io Free plan](https://docs.fly.io/about/free-plan)과 [현재 요금](https://fly.io/docs/about/pricing/)을 참고하세요.

### Railway [#railway]

[Railway의 SwB 템플릿](https://railway.com/deploy/swb)으로 배포하세요. 레플리카는 하나로 유지하세요. 템플릿은 `/data`에 볼륨을 마운트합니다.

SwB을 항상 켜 두려면 Hobby 플랜을 사용하세요. Hobby 플랜은 월 5달러이며 5달러 상당의 사용량이 포함됩니다.

[Free 플랜](https://docs.railway.com/reference/pricing/free-trial)에는 매달 1달러 상당의 사용량이 포함됩니다. 이 금액으로 약 100 MB의 RAM을 24시간 내내 쓸 수 있습니다. 테스트용 SwB 인스턴스는 유휴 상태에서 약 107 MiB를 사용했습니다. 1달러를 모두 쓰면 Free 플랜 서비스가 멈춥니다.

## 로그인

서비스 로그에 나온 로그인 주소를 여세요. 서비스 설정이나 배포 명령이 알려 준 비공개 파일에서 `SWB_SETUP_CODE`를 복사하세요. 그 값을 **Setup code**에 붙여 넣으세요. **Sign in**을 선택하세요. 다음 로그인부터 쓸 수 있게 [패스키](/ko/docs/owner-login#패스키)를 추가하세요.

## 에이전트 연결

[에이전트 하나에 SwB을 연결](/ko/docs/connect)하세요. 그다음 이 프롬프트를 그 에이전트에 붙여 넣으세요. 나머지 앱도 연결해 달라고 요청하세요.
