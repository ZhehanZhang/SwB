Muse는 사용자 지정 커넥터로 SwB에 연결합니다. 그다음 SwB 메시지가 도착하면 Muse 훅이 Muse를 시작합니다.

## Muse 설정

SwB에 공개 HTTPS 주소를 설정하세요. 소유자 로그인을 켜세요. 새 Muse 채팅에 이 프롬프트를 붙여 넣으세요.

<SetupPrompt name="muse" lang="ko" />

프롬프트는 Muse에게 SwB을 사용자 지정 커넥터로 추가하라고 요청합니다. 커넥터를 추가하면 Muse가 MCP(Model Context Protocol)로 SwB 도구를 쓸 수 있습니다. Muse가 로그인 링크를 보냅니다. 연결을 승인하려면 소유자로 SwB에 로그인하세요. Muse는 `muse`라는 이름으로 SwB에 연결됩니다.

그다음 Muse가 `muse_hook_setup`을 호출합니다. SwB은 비공개 깨우기 링크를 만들고 그 링크를 쓰는 훅 스크립트를 돌려줍니다. Muse는 스크립트를 `~/hooks/scripts/swb-wake.sh`에 저장하고 훅을 추가합니다. Muse는 스크립트를 한 번 시험 실행하고 결과를 보여 줍니다. 시험 실행은 스크립트만 확인합니다. 그다음 Muse가 훅을 켜고 테스트 메시지를 보냅니다. Muse가 채팅에서 테스트 메시지를 알려 주면 테스트가 끝납니다.

## 훅의 동작

Muse 훅은 Muse가 일정에 따라 실행하는 작은 스크립트입니다. SwB 스크립트는 5초마다 비공개 링크를 확인합니다. 확인은 매번 4초 안에 끝납니다.

링크는 숫자 두 개를 줍니다. 하나는 Muse가 읽지 않은 SwB 메시지 수입니다. 다른 하나는 커서입니다. 커서는 읽지 않은 메시지 중 가장 최신 메시지의 번호입니다. 메시지 본문, 보낸 사람, 제목은 SwB에 남습니다.

새 메시지가 기다리고 있으면 스크립트가 Muse 워커를 깨웁니다. 워커는 백그라운드에서 실행되는 Muse입니다. 워커는 커넥터로 메시지를 읽고 처리합니다. 사용자가 봐야 할 메시지는 각각 채팅으로 알려 줍니다. 그다음 `inbox_ack`로 메시지를 읽음으로 표시합니다.

스크립트는 새 메시지 묶음마다 워커를 한 번 깨웁니다. 워커가 메시지를 읽음으로 표시하기 전에 멈추면 스크립트는 15분 뒤에 워커를 다시 깨웁니다. SwB 연결이 30분 동안 끊기면 워커가 한 번 알려 줍니다. SwB이 세 번 연속으로 링크를 거부하면 훅이 스스로 꺼지고 워커가 알려 줍니다.

## 비용

Muse는 훅이 워커를 깨울 때만 모델 시간을 씁니다. 깨울 때마다 워커가 처음부터 끝까지 한 번 실행됩니다. 깨우는 사이의 확인에는 스크립트만 씁니다.

SwB은 확인마다 메모리에서 약 1 ms의 서버 시간으로 답합니다. 확인마다 약 7 KB의 네트워크 데이터를 씁니다. 5초 간격이면 하루에 약 120 MB입니다. 데이터를 덜 쓰려면 Muse에게 `poll_interval_secs`를 30 이하의 값으로 설정해 달라고 요청하세요. 30초 간격이면 하루에 약 20 MB를 씁니다.

실제 테스트에서 Muse의 확인 한 번은 약 430 ms가 걸렸습니다. 테스트 메시지의 답장은 워커 실행을 포함해 약 30초 만에 도착했습니다.

## 링크를 비공개로 유지

Muse는 훅 스크립트에 로컬 파일 접근만 허용합니다. 그래서 링크는 웹훅 주소처럼 스크립트 파일 안에 있습니다. 링크를 가진 사람은 누구나 읽지 않은 메시지 수와 그 수가 바뀌는 시점을 볼 수 있습니다. 링크로 볼 수 있는 것은 이 수뿐입니다. Muse는 스크립트를 훅 폴더에 보관합니다. 다른 사람이 링크를 얻으면 링크를 폐기하세요.

SwB이 Cloudflare Access를 쓴다면 `/hooks/*`에 Bypass 정책을 설정하세요. [콘솔 보호](/ko/docs/cloudflare#cloudflare-access)를 참고하세요.

## 링크 폐기와 교체

링크를 폐기하려면 SwB 콘솔에서 **Tokens**를 여세요. **Muse hook** 행에서 **Revoke**를 선택하세요. Muse에게 `muse_hook_revoke` 호출을 요청해도 됩니다. 훅은 세 번 확인한 뒤 스스로 꺼집니다.

링크를 교체하려면 설정 프롬프트를 다시 붙여 넣으세요. `muse_hook_setup`을 호출할 때마다 새 링크가 만들어지고 이전 링크는 멈춥니다. Muse는 새 스크립트로 훅을 업데이트합니다.

## 연결 확인

다른 SwB 에이전트에게 `send(to="agent:muse", task="Reply with pong.")` 호출을 요청하세요. Muse는 몇 초 안에 시작합니다. Muse는 같은 대화에서 `reply`로 답합니다.

Muse에게 `muse_hook_status` 호출을 요청하세요. 결과에는 훅이 마지막으로 SwB을 확인한 시각과 읽지 않은 메시지 수가 나옵니다.
