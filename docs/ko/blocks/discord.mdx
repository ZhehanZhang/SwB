## 봇 만들기

[Discord 설정](/ko/docs/setup/discord)을 따라 봇을 만드세요. 텍스트와 후속 메시지를 받으려면 Message Content Intent를 켜세요.

에이전트에게 Discord 연결을 요청하세요. 에이전트가 `discord_provision`을 호출하고 등록 링크를 줍니다. 링크를 열고 봇 토큰을 붙여 넣으세요.

## 서버에 봇 추가

봇이 연결되면 `discord_status`를 호출하세요. `setup.invite_url`의 링크를 여세요. 서버에 봇을 추가하세요. 이 링크는 켜 둔 기능에 필요한 권한을 요청합니다.

`discord_status`의 `discovered.guilds`에서 서버 ID를 찾으세요. 설정 파일의 공간에 서버 ID를 추가하세요. 공간에는 Discord 서버 하나의 설정이 들어 있습니다.

```yaml
blocks:
  discord:
    use: discord
    spaces:
      home:
        guild_id: "100000000000000001"
        owner_ids: ["100000000000000002"]
        default_target: claude
    agents: {claude: [home]}
```

소유자를 정하려면 봇에게 다이렉트 메시지를 보내세요. `discord_status`의 `discovered.dm_users`에서 내 사용자 ID를 찾으세요. 그 ID를 `owner_ids`에 넣으세요.

## Discord에서 보내기

`@swb claude check the build`처럼 봇을 멘션하고 대상의 짧은 이름을 적으세요. 스레드를 켜 두면 SwB이 내 메시지에서 스레드를 시작하고 나를 그 스레드에 추가합니다. SwB은 그 스레드에 답을 올립니다. 후속 메시지는 스레드의 대상을 다시 쓸 수 있습니다. 페르소나를 켜 두면 조건에 맞는 답장에 에이전트의 이름과 그림이 쓰입니다.

## 다른 사람과 공유

채널과 대상은 기본적으로 비공개입니다. 다른 사람에게 접근 권한을 주려면 채널과 대상을 모두 공유하세요. `channel:<space>/<channel id>`와 `target:<slug>`를 사용하세요. 특정 사용자에게 접근 권한을 주려면 접근 목록에 `discord:<user id>`를 추가하세요.

## 블록 설정

| 키 | 용도 |
| - | - |
| `blocks.discord` | Discord 봇과 공간 설정 |
| `blocks.discord.use` | `discord` 블록을 불러옵니다 |
| `blocks.discord.enabled` | 블록을 불러오려면 `true`, 끄려면 `false`로 설정합니다 |
| `blocks.discord.token_env` | 봇 토큰의 환경 변수 이름 |
| `blocks.discord.application_id` | 초대 링크에 쓰는 Discord 애플리케이션 ID. SwB이 Discord에서 ID를 읽어 올 수도 있습니다 |
| `blocks.discord.connect` | Discord에서 실시간 이벤트를 받으려면 `true`로 설정합니다. API 호출만 따로 테스트하려면 `false`로 설정합니다 |
| `blocks.discord.message_content` | 스레드의 후속 메시지를 포함해 메시지 내용을 읽으려면 `true`로 설정합니다. Developer Portal에서 Message Content Intent를 켜세요 |
| `blocks.discord.threads` | 서버 텍스트 채널에서 답장할 때 공개 스레드를 시작하려면 `true`로 설정합니다 |
| `blocks.discord.personas` | 웹훅으로 보내는 서버 게시물에 에이전트 이름과 그림을 쓰려면 `true`로 설정합니다. 봇에 Manage Webhooks 권한을 주세요 |
| `blocks.discord.avatar` | 봇 프로필 그림의 파일 이름 |
| `blocks.discord.ack_reaction` | 봇에게 온 메시지를 받았다고 표시할 이모지. 이 반응을 끄려면 `null`로 설정합니다 |
| `blocks.discord.dm_space` | 다이렉트 메시지에 라우팅 설정과 소유자 설정을 적용할 공간. 기본값은 처음 설정한 공간입니다 |
| `blocks.discord.dm_mode` | 다른 사람이 보낸 다이렉트 메시지의 모드. 요약본으로 모으려면 `watch`, 건너뛰려면 `off`를 사용합니다 |
| `blocks.discord.daily_cap` | 도구로 게시하거나 답장하는 동작마다 적용되는 하루 한도. 한도를 해제하려면 `null`로 설정합니다 |
| `blocks.discord.refresh_minutes` | 대상 목록을 업데이트하는 간격(분). 기본값은 `30`입니다 |
| `blocks.discord.target_aliases` | 추가 대상 이름을 기존 대상에 연결합니다 |
| `blocks.discord.agents` | 에이전트별로 게시하고 이벤트를 받을 수 있는 공간. 모든 공간에는 `*`를 사용합니다 |

프로젝트 라우트로 에이전트를 깨우려면 [채널 모드](/ko/docs/channel-modes)를 사용하세요.

## 공간과 채널

| 키 | 용도 |
| - | - |
| `blocks.discord.spaces` | SwB에서 쓰는 이름을 Discord 서버 설정에 연결합니다 |
| `blocks.discord.spaces.*.guild_id` | Discord 서버 ID. 서버를 자동으로 찾게 하려면 공간 하나에서 이 값을 생략합니다. 이때 공간 소유자가 소유한 사용 가능한 서버가 정확히 하나 있어야 합니다 |
| `blocks.discord.spaces.*.owner_ids` | 소유자로 취급할 Discord 사용자 ID. 기본값은 Discord 앱 소유자입니다 |
| `blocks.discord.spaces.*.known` | 알고 있는 Discord 사용자 ID를 표시 이름에 연결합니다 |
| `blocks.discord.spaces.*.default_target` | 대상 이름을 생략하고 SwB에 보낸 새 메시지의 대상 |
| `blocks.discord.spaces.*.project` | 이 공간의 기본 SwB 프로젝트 |
| `blocks.discord.spaces.*.channel_projects` | 채널 ID나 `#`로 시작하는 이름별로 SwB 프로젝트를 정합니다 |
| `blocks.discord.spaces.*.mode` | 공간의 모드. 채널 모드나 스레드 모드가 이 값보다 우선할 수 있습니다 |
| `blocks.discord.spaces.*.channels` | 채널 ID나 스레드 ID별로 모드나 세부 설정을 정합니다 |
| `blocks.discord.spaces.*.channels.*.mode` | 채널 하나나 스레드 하나의 모드 |
| `blocks.discord.spaces.*.channels.*.actions` | `triage` 모드에서 허용할 동작. 예를 들면 `reply`와 `notify_owner` |
| `blocks.discord.spaces.*.listen` | `assist` 모드를 쓰는 채널 ID나 스레드 ID를 지정하던 이전 설정 |
| `blocks.discord.spaces.*.bot_posts_per_hour` | 스레드당 1시간에 올릴 수 있는 최대 봇 게시물 수. 기본값은 `20`입니다 |
