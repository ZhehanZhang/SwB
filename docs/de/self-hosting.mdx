## Docker Compose

Installieren Sie Docker Compose 2.24 oder neuer. Führen Sie diese Befehle als normaler Benutzer aus, dem der Datenordner gehört.

```bash
git clone --branch release/1.0 https://github.com/ZhehanZhang/SwB.git
cd SwB
(umask 077; cp .env.example .env)
{
  printf 'SWB_UID=%s\n' "$(id -u)"
  printf 'SWB_KEY_OWNER='
  openssl rand -hex 32
} >> .env
printf 'SWB_PUBLIC_URL=http://localhost:8870\n' >> .env
mkdir -p data
docker compose up -d --build --wait
curl -fsS http://127.0.0.1:8870/healthz
docker compose exec -T switchboard swb login-link --url http://127.0.0.1:8000
```

Öffnen Sie innerhalb von fünf Minuten den Einmal-Anmeldelink aus dem Terminal. Behandeln Sie den Link vertraulich.

Der Browser verwendet `http://localhost:8870` für die Anmeldung des Inhabers. Der Befehl im Container verwendet Port `8000`. Compose speichert die Daten in `./data`. Nachdem Sie `.env` geändert haben, führen Sie `docker compose up -d` erneut aus.

Bei einem entfernten Server leiten Sie dessen Port `8870` auf den lokalen Port `8870` weiter, bevor Sie den Link öffnen.

Eine Anfrage ohne Anmeldung an `/healthz` gibt `status` und `version` zurück. Für vollständige Statusdetails verwenden Sie eine Inhabersitzung oder den Inhaberschlüssel.

## <ProviderMark name="cloudflare" /> Cloudflare Tunnel [#cloudflare-tunnel]

Ein Cloudflare Tunnel gibt SwB eine öffentliche HTTPS-Adresse. Cloudflare bietet Tunnel im kostenlosen Plan an.

### Quick Tunnel

Mit einem Quick Tunnel testen Sie SwB unter einer temporären Adresse. Führen Sie diesen Befehl auf dem Host mit `cloudflared` aus, dem Programm, das SwB mit Cloudflare verbindet.

```bash
cloudflared tunnel --url http://localhost:8870
```

Setzen Sie `SWB_PUBLIC_URL` auf die HTTPS-Adresse aus dem Terminal. Wenn Ihre Konfiguration `public_url` enthält, aktualisieren Sie diese Einstellung ebenfalls. Starten Sie SwB neu. Die Adresse ändert sich bei jedem Start des Tunnels. OAuth-Anmeldungen und Passkeys sind an diese Adresse gebunden. Für eine dauerhafte Adresse verwenden Sie einen benannten Tunnel.

### Benannter Tunnel

Verwenden Sie ein kostenloses Cloudflare-Konto mit Ihrer Domain. Folgen Sie der [Anleitung zur Cloudflare-Einrichtung](/de/docs/setup/cloudflare), um den Tunnel zu erstellen und Access einzurichten. Setzen Sie `SWB_PUBLIC_URL` auf Ihre öffentliche Adresse, zum Beispiel `https://swb.example.com`. Aktualisieren Sie die Adresse in `public_url`, wenn Ihre Konfiguration diese Einstellung enthält.

Für einen Tunnel auf dem SwB-Host setzen Sie seine Dienstadresse auf `http://localhost:8870`. Setzen Sie `SWB_TRUSTED_PROXIES` auf die Adresse des Connectors, zum Beispiel `127.0.0.1/32` für eine IPv4-Loopback-Verbindung.

Für den Tunnel in Compose setzen Sie seine Dienstadresse auf `http://switchboard:8000`. Tragen Sie das Tunnel-Token in `.env` als `TUNNEL_TOKEN` ein. Tragen Sie die Adresse oder das dedizierte Netzwerk des Connectors in `trusted_proxies` ein. Starten Sie Compose mit dem Profil `tunnel`.

```bash
docker compose --profile tunnel up -d
```

## Vertrauenswürdige Proxys

Ein Reverse Proxy leitet Anfragen an SwB weiter. Tragen Sie die Adresse oder das dedizierte Netzwerk des Proxys in `trusted_proxies` in `config/switchboard.yaml` ein. Schreiben Sie Netzbereiche in CIDR-Notation, zum Beispiel `192.0.2.0/24`.

Sie können auch `SWB_TRUSTED_PROXIES` in `.env` setzen. Trennen Sie die Einträge durch Kommas. Die YAML-Einstellung hat Vorrang.

Für einen Cloudflare Tunnel auf dem SwB-Host oder im Docker-Netzwerk tragen Sie die Adresse oder das dedizierte Netzwerk des Tunnel-Connectors ein. Der Connector verbindet sich direkt mit SwB. Für direkte Verbindungen von Cloudflare-Edge-Servern verwenden Sie den Eintrag `cloudflare`.

## Gehostete Plattformen

Verwenden Sie eine einzelne SwB-Instanz mit einem persistenten Datenträger unter `/data`. Die Vorlagen für Railway, Render und Fly.io sowie das Skript für Koyeb finden Sie in der [Bereitstellungsanleitung](https://github.com/ZhehanZhang/SwB/tree/release/1.0/deploy).

## Railway [#railway]

Stellen Sie SwB über die [SwB-Vorlage auf Railway](https://railway.com/deploy/swb) bereit. Verwenden Sie genau ein Replikat. Die Vorlage hängt ein Volume unter `/data` ein.

Für ein dauerhaft laufendes SwB verwenden Sie den Hobby-Plan. Er kostet 5 $ im Monat und enthält Nutzung im Wert von 5 $.

Der [Free-Plan](https://docs.railway.com/reference/pricing/free-trial) enthält Nutzung im Wert von 1 $ pro Monat. Das reicht für etwa 100 MB RAM rund um die Uhr. Eine SwB-Testinstanz belegte im Leerlauf etwa 107 MiB. Dienste im Free-Plan stoppen, sobald das Guthaben von 1 $ aufgebraucht ist.

## Fly.io [#fly]

Verwenden Sie den Release-Checkout von SwB aus dem [Docker-Compose-Beispiel](#docker-compose). Installieren Sie das [Kommandozeilenwerkzeug von Fly.io](https://docs.fly.io/flyctl/). Melden Sie sich bei Fly.io an.

Führen Sie `sh deploy/fly.sh my-swb` im SwB-Ordner aus. Ersetzen Sie `my-swb` durch einen eindeutigen App-Namen. Das Skript startet mit `fly deploy --ha=false` eine einzelne Machine.

Öffnen Sie die Anmeldeseite Ihrer App. Kopieren Sie `SWB_SETUP_CODE` aus `.env.swb-setup-fly-my-swb` in Ihrem Checkout. Geben Sie den Code in **Setup code** ein. Löschen Sie die Datei nach der Anmeldung.

Details zur Abrechnung finden Sie im [Free-Plan von Fly.io](https://docs.fly.io/about/free-plan) und in den [aktuellen Preisen](https://fly.io/docs/about/pricing/).

## Sicherungen und Upgrades

Beenden Sie SwB, bevor Sie den Datenordner kopieren. Kopieren Sie den Ordner vollständig, mit der Datenbank und ihren Schlüsseln einschließlich `mcp-events.key` und `claim-key`. Sichern Sie auch Ihre Konfigurationsdateien und `.env`. Bewahren Sie die Sicherung vertraulich auf. Installieren oder bauen Sie die neue Version. Starten Sie SwB mit demselben Datenordner.

## Gedächtnis exportieren

Führen Sie den Export im Compose-Container aus.

```bash
docker compose exec -T switchboard swb export /data/export
```

Der Export speichert Markdown-Dateien nach Bereich unter `./data/export` auf dem Host. Er enthält eine Datei `INDEX.md`. Setzen Sie `memory.mirror_dir`, um eine stets aktuelle Markdown-Kopie zu behalten.
