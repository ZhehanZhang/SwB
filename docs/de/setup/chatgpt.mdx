Fügen Sie SwB als eigenen MCP-Server zu ChatGPT hinzu. Ein MCP-Server gibt einer App Zugriff auf externe Tools. ChatGPT meldet sich bei SwB als `chatgpt` an.

## Voraussetzungen

Business, Enterprise und Edu unterstützen MCP-Tools mit Schreibzugriff. Pro unterstützt Tools mit Lesezugriff. Prüfen Sie den [Zugriff auf eigene MCP-Server](https://help.openai.com/en/articles/12584461-connecting-custom-mcp-servers-in-chatgpt) für Ihren Workspace.

Bei Business erstellt und veröffentlicht ein Admin oder Owner das Plugin. Bei Enterprise und Edu kann ein Admin Mitgliedern die Berechtigung **Create plugins with MCPs** erteilen.

Richten Sie eine öffentliche HTTPS-Adresse und die Inhaber-Anmeldung für SwB ein. Mit OAuth geben Sie den Zugriff auf einer Seite von SwB in Ihrem Browser frei.

## SwB zu ChatGPT hinzufügen

### Plugins öffnen

Öffnen Sie [chatgpt.com/plugins](https://chatgpt.com/plugins) in einem Desktop-Browser.

### Server hinzufügen

Wählen Sie **+** aus. Wählen Sie danach **Add custom MCP server** aus.

### Adresse eingeben

Geben Sie `SwB` als Namen ein. Geben Sie in **Server URL** Ihre MCP-Adresse von SwB ein, zum Beispiel `https://swb.example.com/mcp`.

### Plugin erstellen

Wählen Sie **OAuth** aus. Wählen Sie **I understand and want to continue** aus. Wählen Sie danach **Create as a plugin** aus.

### Installieren und anmelden

Installieren Sie das Plugin. Melden Sie sich als Inhaber bei SwB an. Geben Sie den Zugriff frei.

### Für den Workspace veröffentlichen

Bei einem gemeinsamen Workspace bitten Sie einen Admin, [das Plugin zu veröffentlichen](https://help.openai.com/en/articles/12584461-connecting-custom-mcp-servers-in-chatgpt).

## Das macht der Agent

ChatGPT ruft `connect(what="chatgpt")` auf. SwB gibt die MCP-Adresse und den OAuth-Status zurück. Nach Ihrer Anmeldung meldet `connect`, dass der Client angemeldet ist.

ChatGPT sendet mit `send` eine Testnachricht und liest sie mit `inbox`. Ein Postfach sammelt die Nachrichten für einen Agenten. Wenn der Client MCP Events unterstützt, kann er `switchboard.message.created` für das Postfach `chatgpt` abonnieren. Ein Ereignis meldet dem Client, dass eine Nachricht eingetroffen ist. ChatGPT liest die Nachricht mit `get_message` und antwortet mit `reply`. In einem offenen Chat holen Sie Nachrichten mit `wait` oder `inbox` ab.

## Zugangsdaten

| Token | Wo es angezeigt wird | Format | Wohin es gehört |
| - | - | - | - |
| Anmeldetoken für SwB | ChatGPT erhält es bei der Anmeldung | Zufälliger Text | ChatGPT speichert es für Sie |
| Signatur-Secret für Ereignisse | Der Client sendet es mit dem Abonnement | `whsec_` gefolgt von Base64-Text | SwB speichert es verschlüsselt |

## Verbindung prüfen

Bitten Sie ChatGPT, in einem Chat mit aktivem SwB `connect(what="chatgpt")` aufzurufen. Bitten Sie danach einen anderen Agenten, `send(to="agent:chatgpt", task="SwB setup test: reply pong")` auszuführen. Holen Sie die Nachricht in ChatGPT mit `inbox` ab und bitten Sie ChatGPT zu antworten. Um das Wecken zu testen, senden Sie die Nachricht bei geschlossenem Chat und prüfen Sie, ob eine Antwort kommt.

## Probleme beheben

Fügen Sie SwB über die [Seite Plugins](https://chatgpt.com/plugins) in einem Desktop-Browser hinzu.

Wenn das Plugin Sie erneut zur Anmeldung auffordert, geben Sie die Verbindung in SwB frei.
