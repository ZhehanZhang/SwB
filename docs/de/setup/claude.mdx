Mit einem Connector kann Claude die Tools eines externen Dienstes nutzen. Mit dem SwB-Connector liest Claude Ihre Projekte, sendet Aufgaben an andere Agenten und beantwortet Nachrichten.

## Voraussetzungen

Der Claude-Free-Plan erlaubt einen Custom Connector. Pro, Max, Ultra, Team und Enterprise unterstützen ebenfalls Custom Connectors.

Richten Sie die Inhaber-Anmeldung für SwB ein. Verwenden Sie eine öffentliche HTTPS-Adresse auf Port 443, damit Claude `/mcp` erreichen kann.

## SwB zu Claude hinzufügen

<Tabs items={['Persönlicher Plan', 'Team oder Enterprise']}>
<Tab value="Persönlicher Plan">
### Custom Connector hinzufügen

Öffnen Sie in Claude [Customize → Connectors](https://claude.ai/customize/connectors).
Wählen Sie **+ Add** aus. Wählen Sie **Add custom connector** aus.
### Adresse eingeben

Geben Sie `SwB` als Namen ein. Geben Sie Ihre MCP-Adresse von SwB ein.

```text
https://swb.example.com/mcp
```
### Standardanmeldung beibehalten

Wählen Sie **Continue** aus, um die Anmeldeeinstellungen zu prüfen. Wählen Sie unter **Authentication** die Option **Sign in now** aus. Wählen Sie unter **OAuth client** die Option **Use Claude’s published identity (Recommended)** aus. Lassen Sie **Request headers** leer.
### Hinzufügen und verbinden

Klicken Sie auf **Add**. Wenn SwB in der Liste **Connect** anzeigt, klicken Sie auf **Connect**.
### In SwB freigeben

Melden Sie sich auf der Seite **Sign in to SwB** an. Prüfen Sie auf der Seite **Connect to SwB** den Namen und klicken Sie auf **Approve**.
</Tab>
<Tab value="Team oder Enterprise">
### Admin-Seite öffnen

Öffnen Sie [Organization settings → Connectors](https://claude.ai/admin-settings/connectors) mit der Berechtigung, Custom Connectors hinzuzufügen. Verwenden Sie bei Team ein Konto mit der Rolle Owner oder Primary Owner.
### Web-Connector hinzufügen

Klicken Sie auf **Add**. Zeigen Sie auf **Custom** und klicken Sie dann auf **Web**.
### Adresse eingeben

Geben Sie `SwB` als Namen ein. Geben Sie Ihre MCP-Adresse von SwB ein. Wählen Sie **Continue** aus. Prüfen Sie die Anmeldeeinstellungen. Wählen Sie **Sign in now** oder **Sign in when needed** aus. Wählen Sie **Use Claude’s published identity (Recommended)** aus. Wählen Sie **Add** aus.
### Konto verbinden

Öffnen Sie **Customize** → **Connectors**. Suchen Sie `SwB` und klicken Sie auf **Connect**.
### In SwB freigeben

Melden Sie sich auf der Seite **Sign in to SwB** an. Klicken Sie auf der Seite **Connect to SwB** auf **Approve**.
</Tab>
</Tabs>

### SwB im Chat aktivieren

Wählen Sie im Chat **+** → **Connectors** aus. Aktivieren Sie SwB. Bei einem Claude Project verwenden Sie den Koordinator-Chat.

## Das macht der Agent

Der Agent ruft `connect(what="claude")` auf. SwB gibt die MCP-Adresse zurück und meldet, ob OAuth verfügbar ist. Mit OAuth geben Sie den Zugriff in Ihrem Browser frei.

Der Agent nennt Ihnen den Klickpfad und die Adresse. Nach Ihrer Freigabe ruft er `connect` erneut auf. SwB meldet, dass der Client angemeldet ist.

## Zugangsdaten

| Element | Wo es angezeigt wird | Format | Wohin es gehört |
| - | - | - | - |
| MCP-Adresse | Einstellungen von SwB und das Ergebnis von `connect` | `https://swb.example.com/mcp` | Das URL-Feld des Claude-Connectors |
| Zugriffstoken für SwB | Claude erhält es, nachdem Sie auf **Approve** geklickt haben | Zufälliger Text | Claude speichert es für Sie |

## Verbindung prüfen

Öffnen Sie **Customize** → **Connectors** und prüfen Sie, ob `SwB` als verbunden erscheint. Bitten Sie Claude, `project_list` aufzurufen. Eine Liste Ihrer SwB-Projekte bestätigt die Verbindung.

## Probleme beheben

Verwenden Sie die öffentliche HTTPS-Adresse, die auf `/mcp` endet. Claude muss `/mcp` direkt erreichen können. Wenn sich die Adresse von SwB ändert, entfernen Sie den Connector. Fügen Sie ihn mit der neuen Adresse erneut hinzu.
