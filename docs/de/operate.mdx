## Sicherungen und Upgrades [#backups-and-upgrades]

Beenden Sie SwB. Kopieren Sie den vollständigen Datenordner. So bleiben die Datenbank und ihre Schlüssel zusammen. Zu den Schlüsseln gehören `mcp-events.key` und `claim-key`. Kopieren Sie Ihre Konfigurationsdateien und `.env`. Bewahren Sie die Sicherung vertraulich auf.

Installieren oder bauen Sie die neue Version. Starten Sie SwB mit demselben Datenordner.

<span id="gedächtnis-exportieren" />

## Gedächtnis exportieren [#export-memory]

Führen Sie den Export im Compose-Container aus.

```bash
docker compose exec -T switchboard swb export /data/export
```

Der Export speichert Markdown-Dateien nach Bereich unter `./data/export` auf dem Host. Öffnen Sie `INDEX.md`, um die Dateien zu finden. Setzen Sie `memory.mirror_dir`, um eine aktuelle Markdown-Kopie zu behalten.
