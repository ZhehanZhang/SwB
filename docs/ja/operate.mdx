## バックアップとアップグレード [#backups-and-upgrades]

SwB を停止してください。データフォルダー全体をコピーしてください。こうすると、データベースとそのキーがまとめて残ります。キーには `mcp-events.key` と `claim-key` も含まれます。設定ファイルと `.env` もコピーしてください。バックアップは安全な場所に保管してください。

新しいバージョンをインストールまたはビルドしてください。同じデータフォルダーを使って SwB を起動してください。

<span id="メモリを書き出す" />

## メモリを書き出す [#export-memory]

Compose のコンテナー内で書き出しを実行してください。

```bash
docker compose exec -T switchboard swb export /data/export
```

書き出すと、ホストの `./data/export` に、スコープごとの Markdown ファイルが保存されます。ファイルを探すときは `INDEX.md` を開いてください。常に最新の Markdown コピーを保つときは、`memory.mirror_dir` を設定してください。
