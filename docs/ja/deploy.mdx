## 自分のサーバーで実行する

### Docker Compose [#docker-compose]

Docker Compose 2.24 以降をインストールしてください。Docker Compose は、SwB をコンテナーで実行します。これらのコマンドは、データフォルダーを所有するユーザーとして実行してください。

```bash
git clone --branch release/1.0 https://github.com/ZhehanZhang/SwB.git
cd SwB
(umask 077; cp .env.example .env)
{
  printf 'SWB_UID=%s\n' "$(id -u)"
  printf 'SWB_KEY_OWNER='
  openssl rand -hex 32
} >> .env
printf 'SWB_PUBLIC_URL=http://localhost:8870\n' >> .env
mkdir -p data
docker compose up -d --build --wait
curl -fsS http://127.0.0.1:8870/healthz
docker compose exec -T switchboard swb login-link --url http://127.0.0.1:8000
```

リモートのサーバーでは、サーバーのポート `8870` を、手元のパソコンのポート `8870` に転送してください。ワンタイムのサインインリンクを 5 分以内に開いてください。リンクは自分だけで使ってください。

サインインには、ブラウザーで `http://localhost:8870` を使います。コンテナー内のコマンドはポート `8000` を使います。Compose はデータを `./data` に保存します。`.env` を変更したら、`docker compose up -d` を実行してください。

`/healthz` へのリクエストは、サインイン前でも `status` と `version` を返します。ヘルスチェックの詳細をすべて見るときは、オーナーのセッションかオーナーキーを使ってください。

### <ProviderMark name="cloudflare" /> Cloudflare Tunnel [#cloudflare-tunnel]

トンネルは、サーバーを Cloudflare につなぎ、SwB に公開 HTTPS アドレスを用意します。トンネルの設定は、[Cloudflare](/ja/docs/cloudflare) の手順に従ってください。

## クラウドで実行する

`/data` にディスクをマウントした SwB のインスタンスを 1 つ使ってください。インスタンスが再起動しても、ディスクにデータが残ります。プラットフォームごとのテンプレートとスクリプトは、[デプロイガイド](https://github.com/ZhehanZhang/SwB/tree/release/1.0/deploy)にあります。

### Fly.io [#fly]

[Docker Compose の例](#docker-compose)で取得した SwB のファイルを使ってください。Python 3.11 以降か [uv](https://docs.astral.sh/uv/) をインストールしてください。[Fly.io のコマンドラインツール](https://docs.fly.io/flyctl/)をインストールしてください。Fly.io にサインインしてください。

支払い用のカードを登録すると、[Fly.io の Free プラン](https://docs.fly.io/about/free-plan)で毎月 $5 分の利用枠を使えます。このプランには個人用の組織を使ってください。$5 を使い切ると、Fly はその月全体を通常料金で請求します。この構成の費用は、Ashburn で 30 日間に約 $3.84 です。データ転送の料金は別です。

SwB のフォルダーで `sh deploy/fly.sh my-swb` を実行してください。`my-swb` を、固有のアプリ名に置き換えてください。スクリプトは `fly deploy --ha=false` を使って、Machine を 1 つ起動します。スクリプトは、Machine、ボリューム、アドレスを確認します。

アプリのサインインページを開いてください。SwB のフォルダーにある `.env.swb-setup-fly-my-swb` から `SWB_SETUP_CODE` をコピーしてください。その値を **Setup code** に入力してください。サインインしたら、このファイルを削除してください。

料金の詳細は、[現在の料金](https://fly.io/docs/about/pricing/)をご覧ください。

### Render [#render]

[Render Blueprint](https://render.com/deploy?repo=https://github.com/ZhehanZhang/SwB/tree/release/1.0) を開いてください。Blueprint は、有料の Web サービスと 1 GB のディスクを作成します。サービスの **Environment** を開いてください。`SWB_SETUP_CODE` をコピーしてください。

### Railway [#railway]

[Railway の SwB テンプレート](https://railway.com/deploy/swb)からデプロイしてください。レプリカは 1 つのままにしてください。1 GB のボリュームを 1 つ `/data` にマウントしてください。

SwB を常時稼働させるときは、Hobby プランを使ってください。Hobby プランは月額 $5 で、$5 分の利用枠が含まれます。

[Free プラン](https://docs.railway.com/pricing/free-plan)では、0.5 GB のボリュームを使えます。Free プランのサービスは、アイドル状態のときにスリープします。このプランには、月 $1 分の利用枠が含まれます。この額で、約 100 MB の RAM を常時使えます。SwB のテストでは、待機中に約 107 MiB の RAM を使いました。

## サインインする

サービスのログに表示されるサインイン用アドレスを開いてください。`SWB_SETUP_CODE` をコピーしてください。この値は、サービスの設定か、デプロイコマンドが示す非公開ファイルにあります。その値を **Setup code** に貼り付けてください。**Sign in** を選択してください。次回からのサインイン用に[パスキー](/ja/docs/owner-login#パスキー)を追加してください。
