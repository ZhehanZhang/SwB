## Muse をリアルタイムで起こす

メッセージが届いたときに Muse が作業を始められるよう、SwB では Muse ガジェットをおすすめします。ガジェットとは、Muse のアプリとペアリングするデバイスです。

[コンパニオン](/ja/docs/companion)とは、パソコン上で動く SwB のプログラムです。ペアリングの間、コンパニオンが Bluetooth でガジェットとして動きます。ペアリングのあとは、SwB サーバーが Muse との接続を保ちます。ペアリングが終わったら、コンパニオンを停止できます。

SwB の公開 HTTPS アドレスを設定してください。オーナーの全権限を持つ SwB のエージェントに、このプロンプトを貼り付けてください。

<SetupPrompt name="muse" lang="ja" />

`connect(what="muse", choose={"gadget": true})` の呼び出しをエージェントに頼んでください。返ってきた手順に従ってください。

[Muse SDK tokens のページ](https://gadgets.muse.ai/settings/sdk-tokens)で個人用のトークンを作成してください。エージェントから届いた SwB のワンタイムの受け取りリンクで、そのトークンを保存してください。

Bluetooth 付きの Mac か Linux のパソコンを、スマートフォンの近くで使ってください。macOS ではターミナルを使い、Bluetooth へのアクセスを求められたら許可してください。Linux では、コンパニオンに BlueZ へのアクセスを許可してください。BlueZ は、Bluetooth を扱うシステムサービスです。

ペアリング済みのコンパニオンに Muse を追加するときは、先に `swb companion disconnect` を実行してください。[コンパニオンのペアリングコード](/ja/docs/companion#デバイスをペアリングする)を取得してください。コードは 1 回だけ使えて、10 分で期限が切れます。

例のアドレスを、実際の SwB のアドレスに置き換えてください。パソコンでこのコマンドを実行してください。

```sh
uvx --python 3.13 --from 'swb-one[companion]' swb companion connect https://swb.example.com --cap muse
```

入力内容を隠すプロンプトに、コードを入力してください。Muse をペアリングする間は、コンパニオンを動かしたままにしてください。Muse のペアリングを始めるよう、エージェントに頼んでください。

Muse のアプリで **Settings** を開いてください。**Devices** を開いてください。**Developer mode** を有効にしてください。**Add Device** を選択してください。エージェントが伝えたデバイス名を選択してください。アプリが Wi-Fi を求めたら、**Use current connection** を選択してください。

## ツールを使うためのコネクターを追加する

コネクターを使うと、Muse は Model Context Protocol（MCP）を通じて SwB のツールを使えます。OAuth では、ブラウザーでそのアクセスを承認します。

SwB でオーナーのサインインを有効にしてください。`/mcp` で終わる公開 HTTPS アドレスを、OAuth 付きのカスタムコネクターとして追加するよう、Muse に頼んでください。リダイレクト URI には `https://agent.meta.ai/api/hatch/oauth/callback` を使ってください。リダイレクト URI とは、サインインの結果を受け取るアドレスです。

Muse から届いたサインインリンクを開いてください。オーナーとして SwB にサインインしてください。Muse は `muse` として SwB に接続します。

## 接続を確認する

ガジェットを確認するときは、オーナー権限を持つエージェントに `send(to="muse:gadget:muse", task="Reply with pong.")` の呼び出しを頼んでください。テストの会話で返信を確認してください。

コネクターを確認するときは、ほかの SwB エージェントに `send(to="agent:muse", task="Reply with pong.")` の呼び出しを頼んでください。`inbox` でメッセージを読むよう、Muse に頼んでください。同じ会話で `reply` を使って回答するよう、Muse に頼んでください。
