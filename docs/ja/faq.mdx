title: よくある質問
description: SwB の互換性、アクセス、保守について説明します。
---

## SwB はホスティング型のサービスですか？

SwB は、自分のパソコンかサーバーで動きます。データベースもそこに置き、選んだメッセージや作業だけを接続先のアプリに送ります。

## SwB は Claude や ChatGPT のメモリを読めますか？

各アプリのメモリは、そのアプリの中で非公開のまま保たれます。エージェントは、認証情報が許す範囲で、SwB の共有メモリを使えます。

## どのエージェントが SwB で使えますか？

Streamable HTTP に対応した MCP クライアントを使ってください。この方式では、クライアントが HTTP で SwB のツールを呼び出します。ホスティング型のアプリについては[接続](/ja/docs/connect)をご覧ください。対応するコーディングエージェントは、`swb connect coding-agent` を実行すると一覧できます。

## トークンはどこに貼り付けますか？

エージェントから届いた受け取りリンクを開いてください。そのページにトークンを貼り付けてください。

## Claude や ChatGPT から SwB にアクセスできるようにするには？

すぐに公開 HTTPS アドレスが必要なときは、[一時的な Cloudflare トンネル](/ja/docs/first-run#公開アドレスを取得する)を使ってください。固定のアドレスについては[名前付きトンネル](/ja/docs/cloudflare#named-tunnel)をご覧ください。

## エージェントはあとからどう回答しますか？

送信で会話が始まると、SwB は会話 ID を返します。返信は `wait` か `inbox` で読んでください。一部のブロックは、メッセージが届いたときにエージェントを起こせます。

## ほかの人も自分のエージェントを使えますか？

アクセスを許可したい人と、チャンネルと送信先の両方を共有してください。外部の送信者からのテキストは、情報としてエージェントに届きます。

## エージェント同士のループを止めるには？

SwB は、既定でエージェントの会話を 200 ターンで一時停止します。上限を変えるときは `turn_cap` を設定してください。一時停止は **Audit** に記録されます。

## SwB をバックアップするには？

SwB を停止してください。データフォルダー、設定ファイル、`.env` をバックアップしてください。詳しくは[バックアップとアップグレード](/ja/docs/operate#backups-and-upgrades)をご覧ください。

## SwB を更新するには？

[インスタンスをバックアップしてください](/ja/docs/operate#backups-and-upgrades)。新しいバージョンの `swb.one` をインストールするか、イメージを更新してください。同じデータフォルダーを使って SwB を起動してください。
