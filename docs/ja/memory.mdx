title: メモリ
description: エージェントが学んだことを共有し、すべてを自分で管理します。
---

**メモリ**は、エージェントが SwB を通じて共有するノートの集まりです。1 件のノートが 1 つの**項目**です。項目には、タイトル、Markdown の本文、すべての変更の履歴があります。

## スコープ

**スコープ**は、同じアクセスルールを持つ項目のグループです。各項目は 1 つのスコープに属します。

| スコープ | フォルダー | 用途 |
| --- | --- | --- |
| `general` | `/memories/general/` | すべてのプロジェクトに当てはまる、あなたについての情報 |
| `project:<slug>` | `/memories/projects/<slug>/` | 1 つのプロジェクトについての情報 |
| `agent:<name>` | `/memories/agents/<name>/` | 1 つのエージェント専用のメモ |

オーナーとしてサインインしたエージェントは、すべてのスコープを読めます。ペアリング済みのキーは、あなたがグラントを与えたスコープだけを読み書きします。ペアリング済みのキーには、必ず専用のエージェントスコープが付きます。

## ファイルとフォルダー

エージェントには、メモリが `/memories` の下のファイルとして見えます。スコープ内のフォルダーが**トピック**です。たとえば `decisions` や `notes/meetings` です。ファイル名が項目のキーです。

これらのツールは、Claude のメモリツールと同じコマンドを使います。Claude のモデルは、これらのコマンドをすでに知っています。

| ツール | 用途 |
| --- | --- |
| `memory_summary` | セッションの開始時に、メモリの短い索引を読み込みます |
| `memory_view` | フォルダーを表示します。ファイルは行番号付きで表示します |
| `memory_create` | ファイルを作ります |
| `memory_str_replace` | ファイル内の 1 つの文字列を正確に置き換えます |
| `memory_insert` | 行の後にテキストを追加します |
| `memory_rename` | ファイルを新しい名前、トピック、スコープに移します |
| `memory_delete` | ファイルを削除します |
| `memory_search` | 単語で項目を探し、一致度の高い順に返します |
| `memory_list` | 項目を新しい順に表示します |
| `memory_history` | 項目の変更をすべて表示します |
| `memory_restore` | 項目を以前のバージョンに戻します |

以前のツールの `memory_write`、`memory_read`、`memory_move`、`memory_promote` も引き続き使えます。

SwB は、1 つのスコープに同じ事実を 1 件だけ保存します。エージェントが同じテキストをもう一度保存すると、既存の項目が返ります。

## メモリ同期

**メモリ同期**は、エージェントが自分のメモリに保存した内容を SwB にコピーします。これで、すべてのエージェントがその内容を使えます。Claude のメモリ、ChatGPT のメモリ、Grok のメモリ、Claude Code のメモリファイル、そのほかのメモリシステムで動作します。

各セットアップ用プロンプトは、エージェントに同期を求めます。セットアップの後、エージェントはあなたについて覚えている内容を `memory_sync` で送ります。送るのは、すべてのエージェントと共有してよい事実だけです。パスワード、キー、機密性の高い個人情報は、エージェント自身のメモリに残します。その後は、新しい記憶を同じ応答の中で同期します。

`memory_sync` は何度実行しても安全です。毎回同じ項目を更新します。SwB でのあなたの編集と削除が優先されます。後の同期では、あなたのバージョンが残り、エージェントに競合が知らされます。

`--cap hooks` を付けた[コンパニオン](/ja/docs/companion)は、Claude Code のメモリファイルを保存のたびに同期します。

メモリ同期は、既定でオンです。オフにするには、コンソールで **Memory** を開き、**Memory sync** をオフにします。オーナーとしてサインインしたエージェントは、`memory_settings` で同じ設定を切り替えられます。

## 来歴

**来歴**は、だれがいつ項目を書いたかの記録です。SwB は、項目を作ったエージェントと、最後に変更したエージェントを記録します。

SwB は、エージェントが書いたテキストを別のエージェントに渡すとき、そのテキストに印を付けます。印には、書いたエージェントと日付が入ります。エージェントは、印の付いたテキストを情報としてだけ使います。エージェントを動かすのは、あなた自身の指示だけです。

## メモリを管理する

コンソールで **Memory** を開くと、すべての項目を確認できます。項目を選ぶと、編集できます。**History** を選ぶと、すべての変更を確認できます。変更の **Restore** を選ぶと、そのバージョンに戻せます。項目の移動と削除もできます。

エージェントによる変更は、すべて **History** と監査ログに記録されます。どの変更も元に戻せます。

## ダウンロードと復元

**Memory** ページで **Download** を選ぶと、すべてのメモリを zip ファイルに保存できます。このファイルには、項目ごとに 1 つの Markdown ファイルが、スコープとトピックごとのフォルダーに入っています。各項目の履歴と来歴を記録した `manifest.json` も入っています。

**Restore from file** を選ぶと、zip ファイルを読み込みます。復元では、zip ファイルにだけある項目を追加し、変更された項目を更新します。ほかの項目はすべて残ります。同じファイルを何度読み込んでも安全です。

オーナーとしてサインインしたエージェントは、同じ作業に `memory_export` と `memory_import` を使えます。

## Git にバックアップする

SwB は、あなたが所有する非公開の Git リポジトリにメモリをコピーできます。変更ごとに 1 つのコミットができます。コミットメッセージは「Claude updated projects/swb/decisions/ownership.md」のようになります。

メモリの内容は、すべてこのリポジトリに入ります。非公開のリポジトリを使ってください。

コンソールで **Memory** を開きます。**Git backup** に、リポジトリのアドレスとブランチを入力します。HTTPS のアドレスには、そのリポジトリへの書き込み権限があるトークンを貼り付けます。SSH のアドレスには、書き込み権限があるデプロイキーを貼り付けます。SwB は、トークンやキーを暗号化して保存します。

SwB は、変更の後 30 秒待ってから、その間の変更をまとめて 1 つのコミットにします。すぐにコミットするには、**Back up now** を選びます。プッシュに失敗したときは、SwB が後で再試行します。ステータス行には、最後のバックアップと最後のエラーが表示されます。

**Restore from repository** を選ぶと、最新のコミットからメモリを読み込みます。

オーナーとしてサインインしたエージェントは、`memory_backup_configure`、`memory_backup_status`、`memory_backup_now`、`memory_backup_restore` を使えます。`memory_backup_configure` は、トークンやキー用の受け取りリンクを返します。
