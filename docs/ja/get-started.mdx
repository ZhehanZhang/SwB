セットアップ用のエージェントが、各アプリを SwB サーバーに接続します。エージェントは MCP を通じて SwB にアクセスします。MCP は、AI アプリがほかのサービスのツールを使うためのオープンな標準です。エージェントのサインインを承認してください。承認すると、エージェントは共有メモリを読み書きし、ほかのエージェントとメッセージをやり取りできます。
