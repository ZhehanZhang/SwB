# SwB 1.0.0

SwB 是 AI 智能体的总机。它通过一个 MCP 服务器，把你的智能体连接到 Slack、Discord、Telegram 和 GitHub。每个智能体保留自己的身份。消息、记忆和路由都保存在你自己管理的地方。

## 安装

```sh
uvx swb-one up
```

也可以用 `pipx install swb-one` 安装，或者运行镜像 `ghcr.io/zhehanzhang/swb:1.0.0`。MCP 地址是 `http://127.0.0.1:8870/mcp`。

## 新功能

| 方面 | 变化 |
|---|---|
| 登录 | 所有者用通行密钥或一次性链接登录。也可以选用 OIDC。 |
| 网页界面 | 新的所有者控制台显示连接、路由、智能体和已保存的令牌。 |
| Discord | 机器人自动找到它所在的服务器和频道。每个智能体用自己的名字和头像发言。 |
| Telegram | 机器人自动找到它的聊天和所有者，并以各个智能体的身份发言。 |
| 频道模式 | 每个频道、空间或项目有一个模式。模式包括关闭、旁听、协助、分拣和工作。 |
| GitHub | SwB 以 GitHub App 身份登录。分拣可以加标签、评论、新建议题和关联重复议题。 |
| 凭据 | 一个链接保存服务商需要的全部凭据。密钥字段可以上传文件。 |
| Muse | 在 Muse 中添加 SwB 自定义连接器并通过 OAuth 登录。 |
| 头像 | 每个 Captain 和智能体在各个应用里都有自己的头像。内置各服务商的标志。 |

## 频道模式

旁听模式记录消息，并把摘要发到你的收件箱。机器人保持安静。协助模式让被路由的智能体在话题里回答。分拣模式在此基础上加入关联仓库的 GitHub 操作。工作模式为所有者提供完整的智能体对话。私聊中其他人的消息默认使用旁听模式。

## 升级

先停止旧版本。安装 1.0.0。用现有的配置和数据文件夹启动。SwB 会保留已保存的令牌。

新增环境变量时请使用 `SWB_` 前缀。现有名称仍然有效。
