# SwB 1.0.0

SwB 是 AI 代理的總機。它透過一個 MCP 伺服器，把你的代理連接到 Slack、Discord、Telegram 和 GitHub。每個代理保留自己的身分。訊息、記憶和路由都保存在你自己管理的地方。

## 安裝

```sh
uvx swb-one up
```

也可以用 `pipx install swb-one` 安裝，或執行映像檔 `ghcr.io/zhehanzhang/swb:1.0.0`。MCP 位址是 `http://127.0.0.1:8870/mcp`。

## 新功能

| 方面 | 變化 |
|---|---|
| 登入 | 擁有者用通行金鑰或一次性連結登入。也可以選用 OIDC。 |
| 網頁介面 | 新的擁有者主控台顯示連線、路由、代理和已儲存的權杖。 |
| Discord | 機器人自動找到它所在的伺服器和頻道。每個代理用自己的名稱和頭像發言。 |
| Telegram | 機器人自動找到它的聊天和擁有者，並以各個代理的身分發言。 |
| 頻道模式 | 每個頻道、空間或專案有一個模式。模式包括關閉、旁聽、協助、分流和工作。 |
| GitHub | SwB 以 GitHub App 身分登入。分流可以加標籤、留言、建立議題和連結重複議題。 |
| 憑證 | 一個連結儲存服務商需要的全部憑證。金鑰欄位可以上傳檔案。 |
| Muse | 新的模組把 Muse 裝置與你的代理配對。 |
| 頭像 | 每個 Captain 和代理在各個應用程式裡都有自己的頭像。內建各服務商的標誌。 |

## 頻道模式

旁聽模式記錄訊息，並把摘要送到你的收件匣。機器人保持安靜。協助模式讓被路由的代理在討論串裡回答。分流模式在此基礎上加入關聯儲存庫的 GitHub 操作。工作模式為擁有者提供完整的代理對話。私訊中其他人的訊息預設使用旁聽模式。

## 升級

先停止舊版本。安裝 1.0.0。用現有的設定和資料夾啟動。SwB 會保留已儲存的權杖。
