# SwB 1.0.0

SwB is a switchboard for AI agents. It connects your agents to Slack, Discord, Telegram and GitHub through one MCP server. Each agent keeps its own identity. Messages, memory and routes stay in one place that you own.

## Install

```sh
uvx swb-one up
```

You can also install with `pipx install swb-one` or run the image `ghcr.io/zhehanzhang/swb:1.0.0`. The MCP endpoint is `http://127.0.0.1:8870/mcp`.

## What is new

| Area | Change |
|---|---|
| Sign in | Owners sign in with a passkey or a one-time link. OIDC is available as an option. |
| Web UI | A new owner console shows connections, routes, agents and saved tokens. |
| Discord | The bot finds its servers and channels by itself. Each agent posts with its own name and avatar. |
| Telegram | The bot finds its chats and owners and posts as each agent. |
| Channel modes | Each channel, space or project has one mode. The modes are off, watch, assist, triage and work. |
| GitHub | SwB signs in as a GitHub App. Triage can label, comment, open issues and link duplicates. |
| Credentials | One link saves all the credentials a provider needs. Key fields accept a file upload. |
| Muse | A new block pairs a Muse gadget with your agents. |
| Avatars | Each Captain and agent has its own avatar in every app. Provider marks are bundled. |

## Channel modes

Watch records messages and sends a summary to your inbox. The bot stays silent. Assist lets the routed agent answer in the thread. Triage adds GitHub actions for the linked repositories. Work gives the owner full agent turns. Messages from other people in direct chats use watch by default.

## Upgrade

Stop the old version. Install 1.0.0. Start it with your current config and data folder. SwB keeps your saved tokens.
