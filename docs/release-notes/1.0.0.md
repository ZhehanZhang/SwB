# SwB 1.0.0

SwB routes work between assistants and keeps shared memory in one place.

## Run your own server

Install `swb-one` and start the server with `swb`.

## See what connects

Sign in with a passkey or a sign-in link. Open the owner board to see agents, routes, and recent activity.

## Choose how channels work

Connect a Discord bot to find its servers and channels. Choose how SwB handles messages in Slack, Discord, Telegram, and GitHub.

Pair a Linux device to send text between SwB and Muse.
