## Copias de seguridad y actualizaciones [#backups-and-upgrades]

Detén SwB antes de copiar su carpeta de datos. Mantén toda la carpeta junta, con la base de datos y sus claves, incluidas `mcp-events.key` y `claim-key`. Copia también tus archivos de configuración y `.env`. Mantén la copia en privado. Instala o compila la versión nueva. Inicia SwB con la misma carpeta de datos.

<span id="exportar-la-memoria" />

## Exportar la memoria [#export-memory]

Ejecuta la exportación dentro del contenedor de Compose.

```bash
docker compose exec -T switchboard swb export /data/export
```

La exportación guarda archivos Markdown por ámbito en `./data/export` en el host. Incluye un `INDEX.md`. Configura `memory.mirror_dir` para mantener una copia actualizada en Markdown.
