## Copias de seguridad y actualizaciones [#backups-and-upgrades]

Detén SwB. Copia la carpeta de datos completa. Así la base de datos y sus claves quedan juntas. Las claves incluyen `mcp-events.key` y `claim-key`. Copia tus archivos de configuración y `.env`. Mantén la copia de seguridad en privado.

Instala o compila la versión nueva. Inicia SwB con la misma carpeta de datos.

<span id="exportar-la-memoria" />

## Exportar la memoria [#export-memory]

Ejecuta la exportación dentro del contenedor de Compose.

```bash
docker compose exec -T switchboard swb export /data/export
```

La exportación guarda archivos Markdown por ámbito en `./data/export` en el host. Abre `INDEX.md` para encontrar los archivos. Configura `memory.mirror_dir` para mantener una copia actualizada en Markdown.
