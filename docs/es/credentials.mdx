title: Credenciales
description: Guarda las credenciales de conexión en una página de un solo uso.
---

Una **credencial** es un valor que da acceso a una app. Tu agente envía un **enlace de entrega** cuando SwB necesita una. El enlace abre un formulario de un solo uso. El formulario envía el valor desde tu navegador a SwB.

## Cómo funciona un enlace de entrega

Inicia sesión como propietario para abrir el formulario. Si el formulario muestra **SwB owner key**, escribe la clave en esa página. El enlace funciona una sola vez y caduca a los 30 minutos.

![Una página de entrega para un token](/shots/token-handoff-light.webp)

SwB cifra el valor con una clave de su carpeta de datos. El bloque puede usar el valor guardado en lugar de una variable de entorno. Si defines los dos valores, SwB usa primero la variable de entorno.

| Página | Uso |
| - | - |
| `/claim/{code}` | Guardar las credenciales de una conexión. |
| `/routines/claim/{code}` | Usar un enlace de entrega de un solo uso para guardar el token de una rutina de Claude. |
| `/routines/claim/owner/{registration}` | Guardar desde la página Agents el token pendiente de una rutina de Claude. |

## Guardar credenciales

Pega el token en el formulario de Discord, Telegram, una rutina de Claude o Grok Bot. Selecciona **Save token**. En el formulario de webhook de Grok Bot, escribe la dirección. Selecciona **Save webhook url**.

Para configurar una GitHub App, SwB te da un enlace distinto para cada valor que falta. Rellena **App ID**, **Private key** o **Webhook secret** en su formulario. Para **Private key**, selecciona **Upload .pem file** o pega todo el contenido del archivo `.pem`. Selecciona **Save** en cada formulario.

Reinicia SwB después de cambiar el secreto del webhook de GitHub.

Para Slack, SwB te da un enlace de entrega por espacio de trabajo cuando falta un token. Rellena los campos del formulario compartido. Selecciona **Save**.

## Entregar desde la terminal

```bash
swb claim 'https://swb.example.com/claim/...'
```

Usa el comando para un único campo de texto en `/claim/{code}` o `/routines/claim/{code}`. Usa el navegador para un formulario con varios campos o con un archivo. El comando oculta lo que escribes. Usa el servidor local de forma predeterminada. Para un servidor remoto, indica en `--url` su dirección base de SwB.

## Sustituir una credencial


| Bloque | Cómo sustituir un valor |
| - | - |
| Grok Bot | Pide a un agente que llame a `connect` para `grok-bot` con el nombre de la rutina y `replace=url` o `replace=secret`. |
| Slack | SwB genera un enlace de entrega para un espacio de trabajo cuando falta un token configurado. |
| GitHub | Pide a tu agente que llame a `connect(what="github", choose={"replace":"secret"})` para sustituir el secreto del webhook. `webhook_secret` tiene el mismo efecto. Usa `all` para sustituir también las credenciales de la App o el token de acceso personal |

Para sustituir un valor definido en el entorno del servidor, actualiza la variable de entorno. Para cambiar un App ID definido en `blocks.github.app_id`, edita el archivo de configuración. Reinicia SwB después de cambiar la configuración o el secreto del webhook de GitHub.
