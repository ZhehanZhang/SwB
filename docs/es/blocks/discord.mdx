## Crear el bot

Sigue la [configuración de Discord](/es/docs/setup/discord) para crear un bot. Activa Message Content Intent para los textos y los mensajes de seguimiento.

Pide a un agente que conecte Discord. El agente llama a `discord_provision` y te da un enlace de entrega. Abre el enlace y pega el token del bot.

## Añadir el bot a un servidor

Llama a `discord_status` cuando el bot se conecte. Abre el enlace de `setup.invite_url`. Añade el bot a tu servidor. El enlace pide los permisos de las funciones que tienes activas.

Busca el ID del servidor en `discovered.guilds` dentro de `discord_status`. Añade el ID del servidor a un espacio de tu configuración. Un espacio contiene los ajustes de un servidor de Discord.

```yaml
blocks:
  discord:
    use: discord
    spaces:
      home:
        guild_id: "100000000000000001"
        owner_ids: ["100000000000000002"]
        default_target: claude
    agents: {claude: [home]}
```

Para definir el propietario, envía un mensaje directo al bot. Busca tu ID de usuario en `discovered.dm_users` dentro de `discord_status`. Pon ese ID en `owner_ids`.

## Enviar desde Discord

Menciona al bot y escribe el nombre corto del destino, como en `@swb claude check the build`. Con los hilos activos, SwB puede abrir un hilo a partir de tu mensaje y añadirte a él. SwB publica allí la respuesta. Los mensajes de seguimiento pueden reutilizar el destino del hilo. Con `personas` activo, las respuestas que cumplan los requisitos usan el nombre y la imagen del agente.

## Compartir con otras personas

Los canales y los destinos son privados de forma predeterminada. Para dar acceso a otras personas, comparte el canal y también el destino. Usa `channel:<space>/<channel id>` y `target:<slug>`. Para dar acceso a un usuario concreto, añade `discord:<user id>` a la lista de acceso.

## Ajustes del bloque

Abre Discord en Settings para cambiar el nombre y la imagen del bot. Usa una identidad de espacio para un servidor concreto. Da al bot el permiso Change Nickname para que pueda poner su nombre en el servidor.

Activa **Post every agent as this bot** para usar la identidad del espacio en todas las respuestas de los agentes en ese servidor. Audit muestra el agente que envió cada respuesta.

| Clave | Uso |
| - | - |
| `blocks.discord` | Ajustes del bot de Discord y de sus espacios |
| `blocks.discord.use` | Carga el bloque `discord` |
| `blocks.discord.enabled` | Usa `true` para cargar el bloque o `false` para desactivarlo |
| `blocks.discord.token_env` | Nombre de la variable de entorno del token del bot |
| `blocks.discord.application_id` | ID de la aplicación de Discord para el enlace de invitación. SwB también puede leer el ID desde Discord |
| `blocks.discord.connect` | Usa `true` para recibir eventos en directo de Discord. Usa `false` para probar solo las llamadas a la API |
| `blocks.discord.message_content` | Usa `true` para leer el contenido de los mensajes, también los de seguimiento en hilos. Activa Message Content Intent en el Developer Portal |
| `blocks.discord.threads` | Usa `true` para abrir un hilo público para cada respuesta en un canal de texto del servidor |
| `blocks.discord.personas` | Usa `true` para mostrar los nombres y las imágenes de los agentes en las publicaciones del servidor enviadas por webhooks. Da al bot el permiso Manage Webhooks |
| `blocks.discord.avatar` | Nombre del archivo de imagen del perfil del bot |
| `blocks.discord.ack_reaction` | Emoji que confirma la recepción de un mensaje dirigido al bot. Usa `null` para desactivar esta reacción |
| `blocks.discord.dm_space` | Espacio cuyos ajustes de enrutamiento y de propietario se aplican a los mensajes directos. El valor predeterminado es el primer espacio configurado |
| `blocks.discord.dm_mode` | Modo para los mensajes directos de otras personas. Usa `watch` para reunirlos en un resumen u `off` para ignorarlos |
| `blocks.discord.daily_cap` | Límite diario de cada acción que publica o responde a través de una herramienta. Usa `null` para quitar el límite |
| `blocks.discord.refresh_minutes` | Minutos entre actualizaciones de la lista de destinos. El valor predeterminado es `30` |
| `blocks.discord.target_aliases` | Asigna nombres de destino adicionales a destinos existentes |
| `blocks.discord.agents` | Espacios donde cada agente puede publicar y recibir eventos. Usa `*` para todos los espacios |

Usa los [modos de canal](/es/docs/channel-modes) para despertar a un agente a través de la ruta de un proyecto.

## Espacios y canales

| Clave | Uso |
| - | - |
| `blocks.discord.spaces` | Asigna los nombres usados en SwB a los ajustes de los servidores de Discord |
| `blocks.discord.spaces.*.guild_id` | ID del servidor de Discord. Omítelo en un espacio para la asociación automática. SwB necesita exactamente un servidor disponible que pertenezca a un propietario del espacio |
| `blocks.discord.spaces.*.owner_ids` | IDs de usuario de Discord que se tratan como propietarios. El valor predeterminado es el propietario de la app de Discord |
| `blocks.discord.spaces.*.known` | Asigna nombres visibles a IDs conocidos de usuarios de Discord |
| `blocks.discord.spaces.*.default_target` | Destino de un mensaje nuevo dirigido a SwB que omite el nombre del destino |
| `blocks.discord.spaces.*.project` | Proyecto de SwB predeterminado de este espacio |
| `blocks.discord.spaces.*.channel_projects` | Define el proyecto de SwB por ID de canal o por un nombre que empieza por `#` |
| `blocks.discord.spaces.*.mode` | Modo del espacio. Un modo de canal o de hilo puede sustituirlo |
| `blocks.discord.spaces.*.channels` | Define un modo o ajustes más detallados por ID de canal o de hilo |
| `blocks.discord.spaces.*.channels.*.mode` | Modo de un canal o hilo |
| `blocks.discord.spaces.*.channels.*.actions` | Acciones permitidas en el modo `triage`, como `reply` y `notify_owner` |
| `blocks.discord.spaces.*.listen` | Ajuste antiguo para los IDs de canal o de hilo que usan el modo `assist` |
| `blocks.discord.spaces.*.bot_posts_per_hour` | Número máximo de publicaciones del bot por hilo en una hora. El valor predeterminado es `20` |
