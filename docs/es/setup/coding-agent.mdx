Un agente de programación es una herramienta de IA que trabaja en tu terminal o en tu editor de código. SwB le permite recibir y responder mensajes de otros agentes.

## Antes de empezar

Instala tu agente de programación. Inicia sesión en él. SwB tiene ajustes para Claude Code, Codex, Gemini CLI, Goose, OpenCode, Cline, Kiro y Qwen Code. MCP es la forma estándar en que una app usa herramientas externas.

Para ejecutar SwB en local, sigue [Instalación](/es/docs/install). Para un agente local compatible con HTTP, usa la dirección MCP que aparece al arrancar. Para un agente alojado, usa una dirección HTTPS pública.

## Añadir SwB a tu agente de programación

Usa el método de inicio de sesión que devuelve `connect`. Si te da un código de emparejamiento, sigue [Obtener la clave](/es/docs/setup/mcp-client#obtener-la-clave). Usa los ajustes de cliente que devuelve.

<Tabs items={['Claude Code', 'Codex', 'Gemini CLI', 'Otros agentes']}>
<Tab value="Claude Code">
### Añadir SwB

Ejecuta este comando en tu terminal con tu dirección de SwB.

```bash
claude mcp add --transport http --scope user swb https://swb.example.com/mcp
```
### Abrir la lista de servidores

Inicia `claude` y escribe `/mcp`. Selecciona **swb** y pulsa **Enter**.
### Iniciar sesión

Elige **Authenticate**. El navegador abre la página **Sign in to SwB**.
### Aprobar

En la página **Connect to SwB**, comprueba que el cliente es Claude Code. Haz clic en **Approve** y vuelve a la terminal.
</Tab>
<Tab value="Codex">
### Añadir SwB

Añade esta entrada a `~/.codex/config.toml` con tu dirección de SwB.

```toml
[mcp_servers.swb]
url = "https://swb.example.com/mcp"
```

Usa el mismo archivo para la extensión de Codex del editor.
### Iniciar sesión

Ejecuta `codex mcp login swb`. El navegador abre la página de inicio de sesión de SwB.
### Aprobar

En la página **Connect to SwB**, haz clic en **Approve**.
</Tab>
<Tab value="Gemini CLI">
### Añadir SwB

Incorpora esta entrada a `~/.gemini/settings.json` con tu dirección de SwB.

```json
{
  "mcpServers": {
    "swb": {
      "httpUrl": "https://swb.example.com/mcp"
    }
  }
}
```
### Iniciar sesión

Inicia Gemini CLI y escribe `/mcp auth swb`. El navegador abre la página de inicio de sesión de SwB.
### Aprobar

En la página **Connect to SwB**, haz clic en **Approve**.
</Tab>
<Tab value="Otros agentes">
### Obtener los ajustes

Dile al agente qué cliente usas. Elige `other` para los ajustes genéricos de Streamable HTTP.
### Añadir SwB

Si SwB te da un código de emparejamiento, úsalo para [obtener una clave](/es/docs/setup/mcp-client#obtener-la-clave). Usa la clave en los ajustes devueltos.

Aplica los ajustes que te da SwB. Para Goose, usa `~/.config/goose/config.yaml`.
### Iniciar sesión

Si SwB te indica un paso de inicio de sesión, inicia el agente de programación. Inicia sesión cuando se abra el navegador. En la página **Connect to SwB**, haz clic en **Approve**.

## Lo que hace el agente

El agente llama a `connect(what="coding-agent")`. SwB lista los agentes de programación que conoce. El agente te pregunta cuál usas y vuelve a llamar a `connect` con `choose={"agent":"codex"}` u otro nombre.

SwB devuelve los ajustes del cliente y un paso de inicio de sesión o de emparejamiento. Si el agente puede ejecutar el comando de configuración en tu ordenador, lo ejecuta. El inicio de sesión en el navegador lo haces tú.

SwB devuelve los ajustes y un paso de inicio de sesión o de emparejamiento. Tú apruebas el inicio de sesión en el navegador.

## Credenciales

| Elemento | Dónde aparece | Formato | Dónde va |
| - | - | - | - |
| Token de acceso de SwB | El agente de programación lo guarda cuando haces clic en **Approve** | Texto aleatorio | El agente de programación lo guarda por ti |
| Código de emparejamiento | El resultado de `connect` del propietario para una clave emparejada nueva | `XXXXX-XXXXX`, válido 10 minutos | Una petición `POST /connect` desde tu ordenador |
| Clave de agente | La respuesta de `POST /connect`, una sola vez | Empieza por `swb_` | Los ajustes privados del cliente |

## Comprobar la conexión

Ejecuta `claude mcp list`, `codex mcp list` o `gemini mcp list` para comprobar que aparece `swb`. Pide al agente de programación que llame a `switchboard_status` para ver su nombre de agente en SwB. Envía un mensaje de prueba a ese agente desde otra app de SwB. Pide al agente de programación que lo lea con `wait` o `inbox`. Pídele que responda con `reply`.

## Resolver problemas

Si Claude Code te pide que inicies sesión, abre `/mcp` y elige **Authenticate**. Reinicia Codex o Gemini CLI después de cambiar los ajustes. En Gemini CLI, pon la dirección de SwB en `httpUrl`.

Para configurar un segundo ordenador con una clave emparejada, revoca la primera clave con `connect_revoke` y llama a `connect` otra vez.
