## 在電腦上執行

依照[安裝指南](/zh-Hant/docs/install)啟動 SwB。開啟首次在本機啟動時顯示的一次性登入連結。若要取得新連結，請執行 `swb login-link`。部署提示詞也適用於本機。

## 部署 SwB

將提示詞貼到 Claude Code 或 Codex 等程式開發代理。請代理引導你在本機或託管平台部署 SwB。

<SetupPrompt name="deploy" lang="zh-Hant" />

## 登入

開啟服務記錄中的登入位址。從服務設定或部署指令指定的私密檔案複製 `SWB_SETUP_CODE`。將它貼到 **Setup code**。選取 **Sign in**。新增[通行金鑰](/zh-Hant/docs/owner-login#通行金鑰)供日後登入。

## 連接你的代理

先[將 SwB 連接到一個代理](/zh-Hant/docs/connect)。再將提示詞貼給它。請它連接其他應用程式。

提示詞保留英文，供代理使用。
