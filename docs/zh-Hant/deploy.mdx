## 在自己的伺服器上執行

### Docker Compose [#docker-compose]

安裝 Docker Compose 2.24 或更新版本，用它在容器中執行 SwB。以資料目錄所屬的使用者身分執行下面的指令。

```bash
git clone --branch release/1.0 https://github.com/ZhehanZhang/SwB.git
cd SwB
(umask 077; cp .env.example .env)
{
  printf 'SWB_UID=%s\n' "$(id -u)"
  printf 'SWB_KEY_OWNER='
  openssl rand -hex 32
} >> .env
printf 'SWB_PUBLIC_URL=http://localhost:8870\n' >> .env
mkdir -p data
docker compose up -d --build --wait
curl -fsS http://127.0.0.1:8870/healthz
docker compose exec -T switchboard swb login-link --url http://127.0.0.1:8000
```

如果是遠端伺服器，把它的 `8870` 連接埠轉送到你電腦上的 `8870` 連接埠。在 5 分鐘內開啟這個一次性登入連結。妥善保管這個連結。

瀏覽器透過 `http://localhost:8870` 登入，容器內的指令則使用 `8000` 連接埠。Compose 把資料存放在 `./data`。變更 `.env` 後，執行 `docker compose up -d`。

對 `/healthz` 的匿名請求只會回傳 `status` 和 `version`。要取得完整的健康狀態資訊，使用擁有者工作階段或擁有者金鑰。

### <ProviderMark name="cloudflare" /> Cloudflare Tunnel [#cloudflare-tunnel]

通道把你的伺服器連接到 Cloudflare，並為 SwB 提供公開的 HTTPS 網址。依照 [Cloudflare](/zh-Hant/docs/cloudflare) 的說明設定通道。

## 在雲端執行

使用單一 SwB 執行個體，並在 `/data` 掛載一個磁碟。執行個體重新啟動後，資料仍保留在這個磁碟上。各平台的範本和指令碼見[部署指南](https://github.com/ZhehanZhang/SwB/tree/release/1.0/deploy)。

### Fly.io [#fly]

使用 [Docker Compose 範例](#docker-compose)中的 SwB 檔案。安裝 Python 3.11 或更新版本，或改為安裝 [uv](https://docs.astral.sh/uv/)。安裝 [Fly.io 命令列工具](https://docs.fly.io/flyctl/)，再登入 Fly.io。

綁定一張付款卡後，[Fly.io 免費方案](https://docs.fly.io/about/free-plan)每月提供 5 美元的用量額度。在你的個人組織中使用這個方案。5 美元用完後，Fly 會依標準費率收取整個月的費用。這套設定在 Ashburn 執行 30 天約需 3.84 美元，資料傳輸費用另計。

在 SwB 資料夾中執行 `sh deploy/fly.sh my-swb`，並把 `my-swb` 換成一個唯一的應用程式名稱。這支指令碼會用 `fly deploy --ha=false` 啟動一台 Machine，再檢查 Machine、磁碟區和 IP 位址。

開啟應用程式的登入頁面。從 SwB 資料夾中的 `.env.swb-setup-fly-my-swb` 複製 `SWB_SETUP_CODE`，填入 **Setup code** 欄位。登入後刪除這個檔案。

計費細節見[目前的費率](https://fly.io/docs/about/pricing/)。

### Render [#render]

開啟 [Render Blueprint](https://render.com/deploy?repo=https://github.com/ZhehanZhang/SwB/tree/release/1.0)。Blueprint 會建立一個付費 Web 服務和一個 1 GB 的磁碟。在服務中開啟 **Environment**，複製 `SWB_SETUP_CODE`。

### Railway [#railway]

從 [Railway 上的 SwB 範本](https://railway.com/deploy/swb)部署，並維持單一複本。在 `/data` 掛載一個 1 GB 的磁碟區。

要讓 SwB 全天候運作，使用 Hobby 方案。這個方案每月 5 美元，內含 5 美元的用量額度。

[免費方案](https://docs.railway.com/pricing/free-plan)支援 0.5 GB 的磁碟區，服務閒置時會進入休眠。這個方案每月內含 1 美元的用量額度，大約可支應 SwB 持續使用 100 MB 記憶體。在一次測試中，閒置的 SwB 約使用 107 MiB 記憶體。

## 登入

開啟服務記錄中的登入網址。從服務設定或部署指令列出的私有檔案中複製 `SWB_SETUP_CODE`，貼到 **Setup code**。選取 **Sign in**。然後新增一組[密碼金鑰](/zh-Hant/docs/owner-login#密碼金鑰)，供日後登入使用。
