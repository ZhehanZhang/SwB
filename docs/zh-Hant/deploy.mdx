## 在自己的電腦上執行

依照[安裝](/zh-Hant/docs/install)的說明操作。SwB 第一次在本機啟動時會印出一次性登入連結，用瀏覽器開啟它。需要新連結時，執行 `swb login-link`。部署提示詞也涵蓋本機設定。

## 部署 SwB

把下面的提示詞貼給 Claude Code 或 Codex 這類程式開發代理。代理會引導你完成本機或託管環境的設定。

<SetupPrompt name="deploy" lang="zh-Hant" />

## 登入

開啟服務記錄中的登入網址。`SWB_SETUP_CODE` 存放在服務設定中，或部署指令指明的私有檔案中。複製它，貼到 **Setup code**，再選取 **Sign in**。然後新增一組[密碼金鑰](/zh-Hant/docs/owner-login#密碼金鑰)，供日後登入使用。
