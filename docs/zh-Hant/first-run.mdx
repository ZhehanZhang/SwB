## 在這台電腦上執行

{/* prepublication */}

套件發布後，在空資料夾中執行 `uvx swb-one up`，並在 5 分鐘內開啟終端機顯示的一次性登入連結。SwB 預設使用 `http://localhost:8870`。如果設定了 `SWB_PORT`，網址會改用該連接埠。其他啟動方式（包括從原始碼建置）見[安裝](/zh-Hant/docs/install)。

## 取得公開網址

Claude、ChatGPT 和 Grok 都在雲端執行，需要一個公開的 HTTPS 網址才能連到 SwB。通道可以為本機的 SwB 伺服器提供公開網址。

安裝 [cloudflared](https://developers.cloudflare.com/tunnel/downloads/)，並確認終端機可以執行 `cloudflared --version`。如果 SwB 正在執行，先停止它。然後在 SwB 執行個體資料夾中執行下面的指令。

```bash
uvx swb-one up --tunnel cloudflare
```

SwB 會開啟一條 Cloudflare Quick Tunnel，並印出公開的 MCP 網址。每次加上這個選項重新啟動，都會得到新的網址，這時要更新各個應用程式中的網址。

如果使用 Tailscale，先[安裝 Tailscale](https://tailscale.com/download) 並登入，再啟用 [Funnel](https://tailscale.com/docs/features/tailscale-funnel)。確認終端機可以執行 `tailscale version` 後，在上面的指令中改用 `--tunnel tailscale`。

如果要在自己的網域上使用固定網址，參閱[具名通道](/zh-Hant/docs/cloudflare#具名通道)。

## 查看下一步

```bash
swb status
```

這個指令會顯示伺服器狀態，以及哪些模組已經開啟。待完成的設定工作列在 **Next steps** 中。`switchboard_status` 工具也會回報後續步驟。

要檢查其他網址上的伺服器，加上 `--url`，例如執行 `swb status --url http://127.0.0.1:8871`。CLI 會依 shell 或執行個體 `.env` 中的 `SWB_PORT` 值決定預設的本機網址。如果執行 `swb up` 時用了 `--dir`，這裡也傳入同一個執行個體資料夾。

## 登入網頁

網頁會顯示你的專案、代理、收件匣、記憶和稽核記錄，也是可以安心貼上權杖的地方。

![SwB 登入頁面](/shots/login-light.webp)

需要新連結時，開啟第二個終端機，在同一個執行個體資料夾中執行下面的指令。

```bash
swb login-link
```

這個指令會印出一次性登入連結，要在 5 分鐘內用瀏覽器開啟。`--url` 和 `--dir` 的用法與 `swb status` 相同。第一次登入後，新增一組[密碼金鑰](/zh-Hant/docs/owner-login#密碼金鑰)，之後就用它登入。設定碼和其他登入方式見[擁有者登入](/zh-Hant/docs/owner-login)。

## 網頁主控台

| 頁面 | 用途 |
| - | - |
| `/` | 查看伺服器狀態和專案清單。 |
| `/agents/*` | 查看已註冊的代理，並開啟各個代理的詳細資料。 |
| `/audit` | 篩選變更和其他事件的記錄。 |
| `/inbox` | 查看需要你處理的對話和請求。 |
| `/inbox/:handle` | 閱讀單一對話中的訊息。 |
| `/memory/*` | 瀏覽並搜尋已儲存的筆記。 |
| `/projects/:slug` | 查看單一專案的路由、歷史記錄、對話和記憶。 |
| `/connections/:platform` | 查看 Slack、Discord、Telegram 或 GitHub 的連線狀態和 [**Channel modes**](/zh-Hant/docs/channel-modes)。 |
| `/settings` | 檢視伺服器設定並管理密碼金鑰。 |
| `/tokens` | 查看權杖請求和已儲存的憑證。 |
| `/about` | 查看 SwB 版本和已啟用模組的清單。 |

## 連接第一個代理

如果第一個代理要負責設定其他應用程式，授予它擁有者存取權。如果應用程式在伺服器上執行，在瀏覽器中核准它的 [OAuth 登入](/zh-Hant/docs/owner-login#代理登入)，並使用能存取所有 SwB 工具的連線。

在執行 SwB 的電腦上，設定[本機擁有者用戶端](/zh-Hant/docs/setup/mcp-client#本機擁有者用戶端)。用戶端登入時，使用執行個體 `.env` 中的 `SWB_KEY_OWNER`。這把金鑰只能傳送到本機的 `/mcp` 網址。

如果第一個代理使用配對金鑰，遇到僅限擁有者執行的步驟時，向它索取對應的終端機指令，並在 SwB 執行個體資料夾中執行，例如 `swb connect slack`。其他應用程式的連接方式見[連接你的代理](/zh-Hant/docs/connect)。
