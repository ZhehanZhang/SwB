## SwB 是託管服務嗎？

SwB 在你自己的電腦或伺服器上執行，資料庫也留在那裡。SwB 會將選定的訊息或工作傳給你連線的應用程式。

## SwB 能讀取 Claude 或 ChatGPT 的記憶嗎？

各應用程式各自保管內建記憶。代理可依憑證取得的權限使用 SwB 的共用記憶。

## 哪些代理能搭配 SwB？

使用支援 Streamable HTTP 的 MCP 用戶端。這種方式讓用戶端能透過 HTTP 呼叫 SwB 工具。託管應用程式的設定請參閱[連線](/zh-Hant/docs/connect)。執行 `swb connect coding-agent` 查看支援的程式開發代理。

## 我要在哪裡貼上權杖？

開啟代理傳給你的領取連結。在頁面上貼上權杖。

## 如何讓 Claude 或 ChatGPT 連到 SwB？

用[臨時 Cloudflare 通道](/zh-Hant/docs/first-run#取得公開位址)可快速取得公開的 HTTPS 位址。若要固定位址，請參閱[自行代管](/zh-Hant/docs/self-hosting)。

## 代理之後如何回答？

傳送動作開啟對話時，SwB 會傳回對話 ID。用 `wait` 或 `inbox` 讀取回覆。有些模組會在訊息送達時喚醒代理。

## 其他人可以使用我的代理嗎？

將頻道和目標都共用給要授權的人員。代理會把外部寄件者的文字當成參考資訊。

## 如何暫停循環對話？

代理對話預設在達到 200 個回合時暫停。設定 `turn_cap` 即可更改上限。SwB 會將暫停的記錄寫入 **Audit**。

## 如何備份 SwB？

先停止 SwB。備份資料夾、設定檔和 `.env`。請參閱[備份與升級](/zh-Hant/docs/self-hosting#備份與升級)。

## 如何更新 SwB？

先備份執行個體。安裝新版 `swb-one` 或更新映像檔。使用原本的資料夾啟動 SwB。
