擁有者登入後可以管理 SwB。擁有者可以核准代理登入，也可以儲存權杖。

| 頁面 | 用途 |
| - | - |
| `/login` | 以擁有者身分登入。 |
| `/authorize` | 審查代理發出的連線請求。 |

## 一次性連結

```bash
swb login-link
```

指令會印出類似 `https://swb.example.com/login#t=...` 的連結。請在五分鐘內用瀏覽器開啟。連結使用一次後就會失效。以擁有者身分登入的代理也可用 `login_link` 工具產生連結。權杖位於連結的 `#` 後方。

首次在本機執行 `swb up` 時，終端機會顯示一次性登入連結。本機位址預設為 `http://localhost:8870`。若有設定 `SWB_PORT`，SwB 會在位址中使用該連接埠。執行 `swb login-link` 時，用 `--url` 指定其他伺服器。用 `--dir` 從其他資料夾讀取擁有者金鑰。

用連結登入失敗時，請重新執行 `swb login-link`。在瀏覽器中開啟新連結。

## 設定碼

設定碼用於擁有者第一次登入，使用一次後即失效。由 SwB 直接處理登入時，可使用設定碼。請依[部署指南](/zh-Hant/docs/deploy)取得託管伺服器的設定碼。

若要自訂設定碼，請產生 32 個隨機位元組。將前述位元組編碼成 64 個小寫十六進位字元，或用標準 Base64 編碼。下列指令會將十六進位設定碼加到私有的 `.env`。先執行 `swb init`，再於執行個體的資料夾內執行此指令。

```bash
(umask 077; printf 'SWB_SETUP_CODE=%s\n' "$(openssl rand -hex 32)" >> .env)
```

設定好 `SWB_SETUP_CODE` 後啟動 SwB。在瀏覽器中開啟 `/login`。將設定碼貼到 **Setup code**。選取 **Sign in**。

## 通行金鑰

**通行金鑰**會透過裝置確認你的登入。首次登入後，請在 **Passkey name** 輸入裝置名稱。選取 **Add a passkey**。

若要在另一部裝置上新增通行金鑰，請開啟 **Settings**。在 **Sign-in** 下選取 **Add a passkey**。輸入名稱。選取 **Add passkey** 儲存。日後可用通行金鑰登入。

## OIDC

OpenID Connect（OIDC）讓 Google 等登入服務確認你的身分。請將登入服務加入設定檔。用 `SWB_OIDC_CLIENT_SECRET` 儲存該服務提供的金鑰。

```yaml
public_url: https://swb.example.com
auth:
  owner_emails: [owner@swb.example.com]
  oidc:
    name: Google
    issuer: https://accounts.google.com
    client_id: 1234.apps.googleusercontent.com
    client_secret_env: SWB_OIDC_CLIENT_SECRET
```

請在提供者端把重新導向位址設為 `https://swb.example.com/auth/oidc/callback`。登入頁會顯示該服務的登入按鈕。SwB 接受 `auth.owner_emails` 中已驗證的電子郵件地址。也可以在 `auth.oidc.owner_subjects` 填入登入服務的帳號識別碼。

## Cloudflare Access

依 [Cloudflare 設定指南](/zh-Hant/docs/setup/cloudflare)保護主控台。SwB 會檢查 Access 權杖，再用 `auth.owner_emails` 或 `SWB_OWNER_EMAILS` 核對電子郵件地址。

## 代理登入

OAuth 讓應用程式在你核准後連線到 SwB。請在 `/authorize` 核准連線。應用程式使用 `switchboard` 作為 OAuth 權限的名稱。應用程式會透過 `/token` 取得或更新權杖。

應用程式收到 OAuth 錯誤時，請在 `error_description` 中查看詳細資訊。

| 錯誤 | 含義 |
| - | - |
| `access_denied` | 擁有者拒絕了連線。 |
| `invalid_client` | SwB 拒絕了應用程式的身分或憑證。 |
| `invalid_client_metadata` | SwB 拒絕了應用程式的註冊設定。 |
| `invalid_redirect_uri` | 註冊時需要填入 SwB 允許的回呼位址。 |
| `invalid_request` | 請求格式或必填值有誤。 |
| `invalid_grant` | SwB 拒絕了授權碼或更新權杖。 |
| `invalid_target` | 請求中的 MCP 位址有誤。 |
| `unsupported_response_type` | 請使用 `response_type=code`。 |
| `unsupported_grant_type` | 請使用 `grant_type=authorization_code` 或 `grant_type=refresh_token`。 |
| `temporarily_unavailable` | 請設定 `public_url`，或檢查用戶端註冊數量是否已達上限。 |

SwB 拒絕[配對碼](/zh-Hant/docs/connect#用配對碼連接)時，`/connect` 也會傳回 `invalid_grant`。

## 工作階段

瀏覽器會儲存 **Cookie** 來維持登入狀態。SwB 會在 Cookie 上設定 `Secure` 標記。公開位址請使用 HTTPS。

變更設定時，瀏覽器會送出權杖供 SwB 檢查要求。請從 **Settings** 登出。

瀏覽器會透過 `/auth/session` 讀取目前的登入狀態。

## 登入錯誤

瀏覽器登入失敗時，SwB 會在 **Audit** 中記下原因。設定碼與權杖保持私密。部分錯誤會限制重複記錄的次數。

| 錯誤 | 含義 |
| - | - |
| `link_used` | 已有人透過這個連結登入。 |
| `link_expired` | 連結已過期。 |
| `link_invalid` | SwB 拒絕了這個連結。 |
| `setup_failed` | 設定碼的格式有誤，或與 `SWB_SETUP_CODE` 的值有差異。 |
| `setup_closed` | 設定碼登入已關閉。請改用其他登入方式。 |
| `passkey_failed` | 通行金鑰設定或驗證失敗。 |
| `last_method` | OIDC 和 Cloudflare Access 都停用時，SwB 會保留最後一個通行金鑰。 |
| `not_found` | 通行金鑰的 ID 有誤，或金鑰已移除。 |
| `oidc_failed` | 透過身分提供者登入失敗。 |
| `signed_out` | 此請求需要以擁有者身分登入。 |
| `csrf` | SwB 拒絕了頁面位址或安全權杖。 |
| `slow_down` | 登入嘗試次數已達上限。請依 `Retry-After` 指定的時間等候。 |
