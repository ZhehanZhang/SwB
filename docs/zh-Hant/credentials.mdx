---
title: 憑證
description: 在一次性頁面上儲存連線憑證。
---

**憑證**是用來存取某個應用程式的值。SwB 需要憑證時，你的代理會傳來一個**認領連結**。連結會開啟一次性表單，表單再把值從你的瀏覽器送到 SwB。

## 認領連結的運作方式

以擁有者身分登入，即可開啟表單。如果表單顯示 **SwB owner key**，就在該頁面輸入金鑰。連結只能使用一次，30 分鐘後過期。

![單一權杖的認領頁面](/shots/token-handoff-light.webp)

SwB 用資料目錄中的金鑰加密這個值。模組可以用儲存的值代替環境變數。兩者都有設定時，SwB 優先採用環境變數。

| 頁面 | 用途 |
| - | - |
| `/claim/{code}` | 儲存某個連線的憑證。 |
| `/routines/claim/{code}` | 用一次性認領連結儲存 Claude routine 權杖。 |
| `/routines/claim/owner/{registration}` | 從 Agents 頁面儲存待處理的 Claude routine 權杖。 |

## 儲存憑證

Discord、Telegram、Claude routine 或 Grok Bot 的權杖，貼到對應的表單後選取 **Save token**。在 Grok Bot 的 Webhook 表單中，輸入網址後選取 **Save webhook url**。

設定 GitHub App 時，每缺少一個值，SwB 就會給你一個獨立的連結。在各自的表單中填寫 **App ID**、**Private key** 或 **Webhook secret**。填寫 **Private key** 時，選取 **Upload .pem file**，或貼上 `.pem` 檔案的完整內容。每份表單都要選取 **Save**。

變更 GitHub Webhook 密鑰後，重新啟動 SwB。

Slack 缺少權杖時，SwB 會為每個工作空間各給一個認領連結。在共用表單中填寫各個欄位，再選取 **Save**。

## 在終端機認領

```bash
swb claim 'https://swb.example.com/claim/...'
```

`/claim/{code}` 或 `/routines/claim/{code}` 只有單一文字欄位時，使用這個指令。表單有多個欄位或檔案時，改用瀏覽器。這個指令會隱藏你輸入的內容，預設使用本機伺服器。如果是遠端伺服器，把 `--url` 設為它的 SwB 基底網址。

## 更換憑證


| 模組 | 如何更換 |
| - | - |
| Grok Bot | 請代理針對 `grok-bot` 呼叫 `connect`，並帶上 routine 名稱和 `replace=url` 或 `replace=secret`。 |
| Slack | 缺少已設定的權杖時，SwB 會為該工作空間核發認領連結。 |
| GitHub | 請代理呼叫 `connect(what="github", choose={"replace":"secret"})` 來更換 Webhook 密鑰。`webhook_secret` 的效果相同。使用 `all` 可一併更換 App 憑證或個人存取權杖。 |

如果值是在伺服器環境中設定的，更新環境變數即可更換。在 `blocks.github.app_id` 中設定的 App ID，要到設定檔中修改。變更設定或 GitHub Webhook 密鑰後，重新啟動 SwB。
