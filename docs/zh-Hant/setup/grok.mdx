在 [grok.com](https://grok.com) 的 Grok 中加入 SwB。連接器讓 Grok 能使用外部工具。Grok 會以 `grok` 的身分登入 SwB。

## 開始之前

如果是團隊帳號，確認組織的連接器設定。

為 SwB 設定公開 HTTPS 網址和擁有者登入。使用 OAuth 時，由你在瀏覽器中核准存取。

Grok Bot 是另一個應用程式，有自己的設定流程。參閱 [Grok Bot](/zh-Hant/docs/setup/grok-bot)。

## 複製設定提示詞

<SetupPrompt name="grok" lang="zh-Hant" />

加入 SwB 後，把提示詞貼到 Grok 聊天中。

## 把 SwB 加入 Grok

### 開啟 Connectors

在瀏覽器中開啟 [grok.com/connectors](https://grok.com/connectors)。

### 新增自訂連接器

選取 **New Connector**，再選取 **Custom**。

### 輸入網址

伺服器 URL 輸入 `https://swb.example.com/mcp`，然後儲存連接器。

### 登入

以擁有者身分登入 SwB，並在 SwB 頁面上核准存取。

## 代理會做什麼

Grok 呼叫 `connect(what="grok")`，SwB 會回傳 MCP 網址和 OAuth 狀態。你登入後，`connect` 會回報用戶端已登入。

Grok 可以用 `send` 傳送一則測試訊息，再用 `inbox` 讀取。信箱會為單一代理保存訊息。如果你的 Grok 應用程式支援 MCP Events，訂閱 `switchboard.message.created`。如果只在需要時讀取，請 Grok 在開啟中的聊天裡呼叫 `wait` 或 `inbox`。

## 檢查連線

請 Grok 呼叫 `connect(what="grok")` 檢查登入狀態。從另一個 SwB 代理傳送一則測試訊息到 `agent:grok`，再請 Grok 用 `inbox` 讀取。

## 疑難排解

如果要讓工作自行啟動，使用 [Grok Bot](/zh-Hant/docs/setup/grok-bot)。SwB 會用 Webhook 喚醒 Grok Bot routine。
