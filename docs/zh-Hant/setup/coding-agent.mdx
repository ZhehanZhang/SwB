程式開發代理是在終端機或程式碼編輯器中工作的 AI 工具。連到 SwB 後，它可以接收其他代理的訊息並回覆。

## 開始之前

請安裝程式開發代理並登入。SwB 提供 Claude Code、Codex、Gemini CLI、Goose、OpenCode、Cline、Kiro 和 Qwen Code 的設定。MCP 是應用程式呼叫外部工具的標準。

若要在本機執行 SwB，請參閱[安裝指南](/zh-Hant/docs/install)。如果本機代理支援 HTTP，請使用啟動時顯示的 MCP 位址。代管的代理須使用公開的 HTTPS 位址。

把提示詞貼到程式開發代理。

## 為程式開發代理加入 SwB

使用 `connect` 傳回的登入方式。如果它提供配對碼，請[換取金鑰](/zh-Hant/docs/setup/mcp-client#換取金鑰)。套用傳回的用戶端設定。

<Tabs items={['Claude Code', 'Codex', 'Gemini CLI', '其他代理']}>
<Tab value="Claude Code">
### 加入 SwB

在終端機執行下面的指令，並換成你的 SwB 位址。

```bash
claude mcp add --transport http --scope user swb https://swb.example.com/mcp
```
### 開啟伺服器清單

啟動 `claude`，輸入 `/mcp`。選擇 **swb**，按下 **Enter**。
### 登入

選擇 **Authenticate**。瀏覽器會開啟 **Sign in to SwB** 頁面。
### 核准

在 **Connect to SwB** 頁面確認用戶端是 Claude Code。按一下 **Approve**，再回到終端機。
</Tab>
<Tab value="Codex">
### 加入 SwB

將下列設定項目加入 `~/.codex/config.toml`。請使用你的 SwB 位址。

```toml
[mcp_servers.swb]
url = "https://swb.example.com/mcp"
```

Codex 編輯器擴充功能使用同一個檔案。
### 登入

執行 `codex mcp login swb`。瀏覽器會開啟 SwB 登入頁面。
### 核准

在 **Connect to SwB** 頁面按一下 **Approve**。
</Tab>
<Tab value="Gemini CLI">
### 加入 SwB

將下列設定項目合併到 `~/.gemini/settings.json`。請使用你的 SwB 位址。

```json
{
  "mcpServers": {
    "swb": {
      "httpUrl": "https://swb.example.com/mcp"
    }
  }
}
```
### 登入

啟動 Gemini CLI，輸入 `/mcp auth swb`。瀏覽器會開啟 SwB 登入頁面。
### 核准

在 **Connect to SwB** 頁面按一下 **Approve**。
</Tab>
<Tab value="其他代理">
### 取得設定

告訴代理你使用哪個用戶端。選擇 `other` 可取得通用的 Streamable HTTP 設定。
### 加入 SwB

如果 SwB 提供配對碼，請用它[換取金鑰](/zh-Hant/docs/setup/mcp-client#換取金鑰)。把金鑰填入傳回的設定。

套用 SwB 提供的設定。Goose 使用 `~/.config/goose/config.yaml`。
### 登入

如果 SwB 提示登入，請啟動程式開發代理。瀏覽器開啟後登入。在 **Connect to SwB** 頁面按一下 **Approve**。
</Tab>
</Tabs>

## 代理的工作

代理呼叫 `connect(what="coding-agent")`。SwB 會列出支援的程式開發代理。代理會問你使用哪一個，再以 `choose={"agent":"codex"}` 或其他名稱呼叫 `connect`。

SwB 會傳回用戶端設定，以及登入或配對步驟。如果代理能在你的電腦上執行設定指令，就會自行執行。瀏覽器中的登入由你完成。

OAuth 登入關閉時，`connect` 會使用配對碼。選擇 `other` 時也使用配對碼。擁有者取得配對碼，用戶端用它換取專屬金鑰。

## 憑證

| 項目 | 顯示位置 | 格式 | 去處 |
| - | - | - | - |
| SwB 存取權杖 | 你按一下 **Approve** 後由程式開發代理保存 | 隨機文字 | 程式開發代理自動保存 |
| 配對碼 | 發出新配對金鑰時，擁有者收到的 `connect` 結果 | `XXXXX-XXXXX`，10 分鐘內有效 | 從你的電腦送出的 `POST /connect` 請求 |
| 代理金鑰 | `POST /connect` 的回應，只顯示一次 | 以 `swb_` 開頭 | 用戶端的私人設定 |

## 檢查連線

執行 `claude mcp list`、`codex mcp list` 或 `gemini mcp list`，確認清單中有 `swb`。請程式開發代理呼叫 `switchboard_status` 以取得自己的 SwB 名稱。使用另一個 SwB 應用程式傳送測試訊息給它。請它用 `wait` 或 `inbox` 讀取訊息。請它用 `reply` 回覆。

## 解決問題

如果 Claude Code 提示登入，請開啟 `/mcp` 並選取 **Authenticate**。更改設定後，請重新啟動 Codex 或 Gemini CLI。Gemini CLI 的 SwB 位址應填在 `httpUrl`。

要用配對金鑰設定第二台電腦，請先用 `connect_revoke` 撤銷第一把金鑰，再呼叫 `connect`。
