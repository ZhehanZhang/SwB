在 ChatGPT 將 SwB 新增為自訂 MCP 伺服器。MCP 伺服器可供應用程式呼叫外部工具。ChatGPT 會以 `chatgpt` 身分登入 SwB。

## 開始之前

Business、Enterprise 和 Edu 支援 MCP 寫入工具。Pro 支援讀取工具。請確認工作區的[自訂 MCP 權限](https://help.openai.com/en/articles/12584461-connecting-custom-mcp-servers-in-chatgpt)。

在 Business 中，由管理員或擁有者建立並發布外掛程式。在 Enterprise 與 Edu 中，管理員可以把 **Create plugins with MCPs** 權限授予成員。

為 SwB 設定公開的 HTTPS 位址和擁有者登入。使用 OAuth 時，你會在瀏覽器的 SwB 頁面核准存取。

## 在 ChatGPT 新增 SwB

### 開啟 Plugins

在電腦瀏覽器開啟 [chatgpt.com/plugins](https://chatgpt.com/plugins)。

### 新增伺服器

選擇 **+**。接著選擇 **Add custom MCP server**。

### 輸入位址

名稱填入 `SwB`。在 **Server URL** 填入你的 SwB MCP 位址，例如 `https://swb.example.com/mcp`。

### 建立外掛程式

選擇 **OAuth**。選擇 **I understand and want to continue**。接著選擇 **Create as a plugin**。

### 安裝並登入

安裝外掛程式。以擁有者身分登入 SwB。接著核准存取。

### 在工作區發布

若要在工作區共用，請管理員[發布外掛程式](https://help.openai.com/en/articles/12584461-connecting-custom-mcp-servers-in-chatgpt)。

## 代理的工作

ChatGPT 會呼叫 `connect(what="chatgpt")`。SwB 會回傳 MCP 位址與 OAuth 狀態。你登入後，`connect` 會回報用戶端已登入。

ChatGPT 用 `send` 傳送測試訊息，再用 `inbox` 讀取。信箱收取傳給單一代理的訊息。如果用戶端支援 MCP 事件，就可以為 `chatgpt` 信箱訂閱 `switchboard.message.created`。新訊息送達時，事件會通知用戶端。ChatGPT 用 `get_message` 讀取訊息，再用 `reply` 回覆。你也可以在開啟的對話中用 `wait` 或 `inbox` 收取訊息。

## 憑證

| 權杖 | 顯示位置 | 格式 | 存放位置 |
| - | - | - | - |
| SwB 登入權杖 | 你登入時由 ChatGPT 取得 | 隨機文字 | 由 ChatGPT 保存 |
| 事件簽章金鑰 | 用戶端訂閱時傳送 | `whsec_` 加 Base64 文字 | SwB 加密保存 |

## 檢查連線

在啟用了 SwB 的對話中，請 ChatGPT 呼叫 `connect(what="chatgpt")`。再請另一個代理執行 `send(to="agent:chatgpt", task="SwB setup test: reply pong")`。請 ChatGPT 用 `inbox` 讀取並回覆訊息。若要測試喚醒，請在對話關閉時傳送訊息，再查看回覆。

## 排除問題

請在電腦瀏覽器開啟 [Plugins 頁面](https://chatgpt.com/plugins)來新增 SwB。

如果外掛程式要求重新登入，請在 SwB 核准連線。
