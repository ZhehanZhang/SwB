連接器讓 Claude 使用外部服務的工具。加入 SwB 連接器後，Claude 可以讀取你的專案、把工作交給其他代理，並回覆訊息。

## 開始之前

Claude 免費方案可用一個自訂連接器。Pro、Max、Ultra、Team 和 Enterprise 方案也支援自訂連接器。

先為 SwB 設定擁有者登入。請使用連接埠 443 上的公開 HTTPS 位址，讓 Claude 能連到 `/mcp`。

## 在 Claude 新增 SwB

<Tabs items={['個人方案', 'Team 或 Enterprise']}>
<Tab value="個人方案">
### 加入自訂連接器

在 Claude 開啟 [Customize → Connectors](https://claude.ai/customize/connectors)。
按一下 **+ Add**。選取 **Add custom connector**。
### 輸入位址

名稱輸入 `SwB`。位址輸入你的 SwB MCP 位址。

```text
https://swb.example.com/mcp
```
### 保留預設登入方式

選取 **Continue** 查看登入設定。在 **Authentication** 選取 **Sign in now**。在 **OAuth client** 選取 **Use Claude’s published identity (Recommended)**。將 **Request headers** 留白。
### 加入並連線

按一下 **Add**。如果清單中的 SwB 顯示 **Connect**，請按一下 **Connect**。
### 在 SwB 核准

在 **Sign in to SwB** 頁面登入。在 **Connect to SwB** 頁面核對名稱，再按一下 **Approve**。
</Tab>
<Tab value="Team 或 Enterprise">
### 開啟管理頁面

使用可新增自訂連接器的帳號開啟 [Organization settings → Connectors](https://claude.ai/admin-settings/connectors)。Team 需要 Owner 或 Primary Owner。
### 加入網頁連接器

按一下 **Add**。把滑鼠移到 **Custom** 上，再按一下 **Web**。
### 輸入位址

名稱填入 `SwB`。輸入你的 SwB MCP 位址。選取 **Continue**。檢查登入設定。選取 **Sign in now** 或 **Sign in when needed**。選取 **Use Claude’s published identity (Recommended)**。選取 **Add**。
### 連線你的帳號

開啟 **Customize** → **Connectors**。找到 `SwB`。按一下 **Connect**。
### 在 SwB 核准

在 **Sign in to SwB** 頁面登入。在 **Connect to SwB** 頁面按一下 **Approve**。
</Tab>
</Tabs>

### 在對話中啟用 SwB

在對話中按一下 **+** → **Connectors**。開啟 SwB。連線到 Claude Project 時，請使用協調對話。

## 代理的工作

代理呼叫 `connect(what="claude")`。SwB 會傳回 MCP 位址和 OAuth 的可用狀態。使用 OAuth 時，你會在瀏覽器中核准存取。

代理會提供點選路徑與位址。你核准後，代理會再次呼叫 `connect`。SwB 會回報用戶端已登入。

## 憑證

| 項目 | 顯示位置 | 格式 | 去處 |
| - | - | - | - |
| MCP 位址 | SwB 設定與 `connect` 的結果 | `https://swb.example.com/mcp` | Claude 連接器的 URL 欄位 |
| SwB 存取權杖 | 你按一下 **Approve** 後由 Claude 保存 | 隨機文字 | Claude 自動保存 |

## 檢查連線

開啟 **Customize** → **Connectors**，確認 `SwB` 顯示為已連線。請 Claude 呼叫 `project_list`。看到你的 SwB 專案清單，就表示連線成功。

## 解決問題

請使用以 `/mcp` 結尾的公開 HTTPS 位址。讓 Claude 直接連到 `/mcp`。變更 SwB 位址時，請移除原有的連接器，再用新位址加入。
