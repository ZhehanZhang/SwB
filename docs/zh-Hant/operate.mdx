## 備份與升級 [#backups-and-upgrades]

停止 SwB，再複製整個資料目錄，讓資料庫和它的金鑰保存在一起。這些金鑰包括 `mcp-events.key` 和 `claim-key`。接著複製設定檔和 `.env`。妥善保管備份。

安裝或建置新版本，再用同一個資料目錄啟動 SwB。

<span id="匯出記憶" />

## 匯出記憶 [#export-memory]

在 Compose 容器內執行匯出指令。

```bash
docker compose exec -T switchboard swb export /data/export
```

匯出的 Markdown 檔案會依範圍存放在主機的 `./data/export` 下。開啟 `INDEX.md` 即可找到各個檔案。要隨時保有最新的 Markdown 副本，設定 `memory.mirror_dir`。
