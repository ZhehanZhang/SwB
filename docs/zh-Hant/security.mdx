## 一位擁有者

SwB 有一位擁有者。擁有者核准代理登入，並在 SwB 主控台管理存取權和儲存權杖。

## 代理登入

OAuth 讓應用程式在擁有者核准後登入。SwB 用採用 S256 演算法的 PKCE 確認登入由同一個應用程式發起及完成。每個 OAuth 權杖都綁定一個 `/mcp` 位址。存取權杖預設有效一小時，更新權杖預設有效 30 天。SwB 在更新權杖用過後發給新權杖。SwB 儲存 OAuth 權杖的 SHA-256 雜湊值，並用它核對權杖。代理也可以使用預先設定的金鑰，或用配對碼換取金鑰。

## 信任等級

SwB 依平台提供的寄件者 ID 判定訊息的信任等級。

| 信任等級 | 對象 |
| - | - |
| `owner` | 你和以你的身分登入的代理 |
| `external` | 其他寄件者，包括 `known` 中的人員和機器人 |

Slack、Discord 和 Telegram 用 `known` 幫助 SwB 判斷要接受哪些寄件者的訊息。這些外部寄件者的訊息仍標為 `external`。GitHub 作者的判定方式請參閱[擁有者帳號](/zh-Hant/docs/blocks/github#擁有者帳號)。

**信任框**由 SwB 為外部文字加上的標頭與一對標記組成。SwB 先改寫內容中仿造的標頭與標記，再加上信任框。標記為 `<<<swb-untrusted` 和 `swb-untrusted>>>`。代理只把標記內的文字當成參考資訊。

觀察模式的摘要標為 `external`。每則摘錄內的外部文字都會加上信任框。SwB 依 GitHub 各欄位的作者判定信任等級。

[夥伴裝置](/zh-Hant/docs/companion)的金鑰僅用於該裝置的連線。SwB 只保留金鑰的雜湊，用來驗證金鑰。SwB 將裝置傳回的結果標為 `external`，並為結果中的自由文字加上信任框。

## 可見度

目標、頻道、記憶範圍、路由和工具都是資源。存取規則預設為 `private`，供擁有者及其代理使用。你可以與指定的工作區或人員共用資源。工具維持私有。頻道和目標的規則都允許時，外部寄件者可以聯絡該目標。SwB 會把當作背景資料保存的訊息送進收件匣。代理保持休眠。

## 受限金鑰

`auth.key_scopes` 限制路由、訊息和對話的存取範圍。配對金鑰只能在這些範圍內讀取所屬代理的訊息和對話。

SwB 依配對金鑰儲存記憶授權。移轉舊授權時，SwB 將 `general` 及當時已有的專案授予原本存取權限較廣的有效配對金鑰。如果 `auth.key_scopes` 列了指定的範圍，SwB 會複製這些範圍。

權限完整的 OAuth 用戶端或設定金鑰可以擁有者身分存取全部記憶。用 `auth.key_scopes` 依代理名稱限制記憶存取權。受限憑證需要取得指定私人專案的授權。

`auth.key_tools` 限制金鑰可呼叫的工具。`auth.key_targets` 限制傳送對象。

## 權杖

請在領取頁面輸入權杖。SwB 用資料夾裡的金鑰加密儲存的權杖。狀態會列出缺少的變數名稱，並隱藏值。Capy 金鑰預設會透過要求標頭傳給 `api.capy.ai`。

開啟 **Tokens** 查看各配對金鑰的記憶範圍。選取該範圍旁的 **Remove scope** 即可撤銷授權。

新金鑰在配對碼兌換成功後，可存取所屬代理的記憶。這把金鑰也可存取配對碼指定的專案，以及 `auth.key_scopes.<agent>` 指定的範圍。若要擴大權限，請設定額外範圍，或在配對碼中指定專案。接著配對一把新金鑰。

## 限制

| 限制 | 數值 |
| - | - |
| bearer 金鑰驗證失敗 | 每個位址 10 分鐘內可失敗 20 次，之後傳回 HTTP `429` |
| SwB 為擁有者以外的寄件者轉送的 GitHub 事件 | 每位寄件者在最近 10 分鐘內最多 5 個事件 |
| `/register` | 每個位址每小時 20 次 |
| `/token` | 每個位址 10 分鐘內 120 次 |
| `/authorize` | 每個位址 10 分鐘內 60 次 |
| `/companion/pair` 配對碼錯誤 | 每個位址 10 分鐘內可輸錯 10 次，之後傳回 HTTP `429` |
| `/connect` 配對碼錯誤 | 每個位址 10 分鐘內可輸錯 10 次，之後傳回 HTTP `429` |
| 請求本文的預設上限 | 1 MiB |
| `/mcp` 與 `/companion/results` 的請求本文 | 16 MiB |
| `/companion/emit` 的請求本文 | 16,640 位元組 |
| `/auth/setup` 的請求本文 | 1,024 位元組 |
| 每個代理對話的回合數 | 200 |

同一位址的有效金鑰也會受 bearer 金鑰限額影響。限額解除前，受影響的端點會傳回 HTTP `429`。

對話達到回合上限時，SwB 會暫停對話並寫入稽核記錄。Slack 啟用時，SwB 會傳送私訊給擁有者。

相同工作傳送到同一個目標時，Capy 模組可以傳回先前的對話。用 `blocks.capy.duplicate_window_s` 設定比對時間，預設為 600 秒。

## 用戶端位址

SwB 預設依連線位址限制要求次數並記錄操作。將代理加入 `trusted_proxies` 或 `SWB_TRUSTED_PROXIES`。接著，SwB 會採用代理提供的用戶端位址。請設定代理，讓它用查證過的位址填寫用戶端位址的要求標頭。

依照[自行代管指南](/zh-Hant/docs/self-hosting#信任的代理)加入 Docker 網路中的 Cloudflare 通道連接器或反向代理。

## 稽核記錄

工具呼叫因存取規則遭拒時，SwB 會寫入稽核記錄。瀏覽器登入失敗也會留下記錄，涵蓋設定碼、已用連結、過期連結、無效連結、通行金鑰、CSRF 檢查和 OIDC。

GitHub webhook 缺少簽章或簽章有誤時，SwB 會記下原因。部分瀏覽器錯誤和 webhook 拒絕記錄會限制重複次數。設定碼、權杖與簽章保持私密。

在 SwB 主控台開啟 **Audit** 查看記錄。執行 `swb log` 可印出近期的記錄。送到收件匣的操作記為 `send`。有關捨棄的訊息，請參閱[頻道模式](/zh-Hant/docs/channel-modes#檢查訊息傳送)。
