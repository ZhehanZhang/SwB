## 把 SwB 加入代理

應用程式如果和 SwB 在同一台電腦上，從[擁有者存取權或配對](/zh-Hant/docs/setup/mcp-client)中擇一。應用程式如果在伺服器上執行，把 SwB 新增為遠端 MCP 伺服器，並使用你的公開 MCP 網址，例如 `https://swb.example.com/mcp`。然後在 SwB 頁面上核准該應用程式的 [OAuth 登入](/zh-Hant/docs/owner-login#代理登入)。

| 應用程式 | 在哪裡新增 SwB |
| - | - |
| [本機 MCP 用戶端](/zh-Hant/docs/setup/mcp-client) | 使用擁有者金鑰，或用配對碼配對。在執行 SwB 的電腦上使用 `http://localhost:8870/mcp`。 |
| Claude 和 Claude Projects | Customize → Connectors → Add → Add custom connector |
| ChatGPT | [chatgpt.com/plugins](https://chatgpt.com/plugins) → Add a custom MCP server |
| Grok | [grok.com](https://grok.com) → Connectors → New Connector → Custom |
| Capy | Settings → MCP & plugins → Add a custom MCP server |
| Claude Code | `claude mcp add --transport http --scope user swb https://swb.example.com/mcp` |
| Codex、Gemini CLI 和其他程式開發代理 | `swb connect coding-agent --choose agent=codex` |

如果是程式開發代理，執行 `swb connect coding-agent` 列出支援的名稱，再把 `codex` 換成清單中的名稱。

## 交給代理處理

具有擁有者存取權的代理可以設定其他連線。如果代理使用配對金鑰，遇到僅限擁有者執行的步驟時，它會給你對應的終端機指令。

擁有者存取權需要經擁有者核准的 OAuth 登入，或來自 `SWB_KEY_<NAME>` 的金鑰。使用對範圍、工具和目標都有完整存取權的憑證。`auth.key_scopes`、`auth.key_tools` 和 `auth.key_targets` 這三項設定會限縮這項存取權。

| 你的要求 | 代理的動作 |
| - | - |
| 我的 Claude Projects 要怎麼連接？ | 為該專案註冊一個 Claude routine，並給你一個用來提交權杖的連結 |
| 把 Slack 連接到 SwB。 | 引導你前往 [Slack 設定](/zh-Hant/docs/setup/slack#應用程式資訊清單)中的 YAML 資訊清單，並在需要時取得認領連結 |
| 連接我的 Discord 機器人。 | 給你一個權杖連結和機器人邀請連結 |
| 把這個傳給我的 Capy Captain。 | 傳送任務並等待回覆 |
| 你可以傳送到哪些地方？ | 列出這個代理可以傳送到的目標 |

代理會呼叫 `connect` 工具，SwB 則回覆該平台的下一步。某個步驟需要權杖時，SwB 會提供一次性的認領連結，開啟連結後把權杖貼上。認領連結的說明見[憑證](/zh-Hant/docs/credentials)。

## 從終端機連接

在 SwB 執行個體資料夾中執行 `swb connect PLATFORM`，並把 `PLATFORM` 換成平台名稱，例如 `slack`。這個指令使用 `.env` 中的擁有者金鑰，預設使用本機的 SwB 網址。用 `--dir` 指定執行個體資料夾，用 `--url` 設定 SwB 網址。執行 `swb login-link` 可取得一次性的擁有者登入連結。

```bash
swb connect mcp-client
swb connect capy-captain
swb connect grok
```

## 用配對碼連接

配對會為新代理核發一把專屬金鑰。請一個以擁有者身分登入的代理呼叫 `connect_code`，並告訴它新代理的名稱。配對碼只能使用一次，10 分鐘內有效。新代理再用 `POST /connect` 以配對碼換取自己的金鑰。完整的配對流程見 [MCP 用戶端](/zh-Hant/docs/setup/mcp-client)。

要在主控台產生配對碼，開啟 **Tokens**，再開啟 **Pairing code**，輸入代理名稱後選取 **Create code**。SwB 會把表單送到 `POST /pairing/code`。

配對會授予 `agent:<name>` 的記憶存取權，以及 `auth.key_scopes` 中為該代理設定的所有範圍。配對碼如果指定了專案，也會授予該專案的記憶範圍。

`POST /connect` 會在 `project` 中回傳指定的專案。把它當作用戶端的預設專案，工具需要專案時，就把它傳入 `project`。

這把金鑰可以在自己的[對話範圍](/zh-Hant/docs/security#受限的金鑰)內，讀取所屬代理傳送或接收的訊息。

使用配對金鑰時，`tools/list` 會顯示配對代理這個角色可用的工具。`auth.key_tools` 設定可以進一步縮減這份清單。要使用擁有者專用的工具，改以擁有者身分登入。詳見[配對金鑰](/zh-Hant/docs/tools#配對金鑰)。

## 收件匣事件串流

`POST /connect` 會回傳 `inbox_events_url`，也就是 `GET /inbox/events` 的網址。開啟這個網址時，在 `Authorization: Bearer <key>` 中帶上配對代理的金鑰。SwB 會傳送該代理收件匣中的訊息，以金鑰的存取權為限。只要連線保持開啟，這些伺服器傳送事件（SSE）就會持續送達。Watch 摘要和脈絡項目改用 `inbox` 讀取。

串流以一個 `ready` 事件開始。每個 `item` 事件都帶有 JSON 資料，內含 `cursor`、對話的 `handle` 和訊息資料。事件 ID 就是這個 cursor，標示串流中的一個位置。

串流預設從最新的位置開始。要從中斷處接續，把最後一個事件 ID 放進 `Last-Event-ID` 標頭或 `after` 查詢參數。`reply` 和 `get_message` 的輸入見[訊息](/zh-Hant/docs/tools#訊息)。
