## 新增連接器

依 [Grok 設定](/zh-Hant/docs/setup/grok)在瀏覽器中連接 Grok。桌面版是另一個應用程式，請依 [Grok Bot 設定](/zh-Hant/docs/setup/grok-bot)操作。

## 用 routine 喚醒 Grok Bot

請代理連接 Grok Bot，也可以在終端機執行 `swb connect grok-bot`。依設定提示操作，取得 routine 的提示詞。

用提示詞建立帶有 Webhook 觸發條件的 Grok Bot routine。SwB 向該網址送出請求時，routine 就會啟動。將 `example` 換成仍在使用的 SwB 專案簡稱。執行下方指令註冊 routine。

```bash
swb connect grok-bot --choose name=project-triage project=example auth=key
```

Webhook 網址和金鑰各有一個領取連結。用對應的連結儲存各自的值。再次執行上方指令，取得測試呼叫。請代理執行測試並查看 `pong` 回覆。

## 喚醒如何運作

使用 `auth=key` 時，SwB 預設在 `Authorization` 標頭送出金鑰。使用 `auth=signature` 時，SwB 會為請求加上簽章。請求包含內文、對話 ID、傳送者和信任等級。有對應專案時，也會帶上專案。routine 用 `reply` 回覆信任等級為 `owner` 的請求。

手動設定時，在伺服器環境中設定 `url_env` 和 `secret_env` 指定的變數。

```yaml
blocks:
  grok-routine:
    routines:
      project-triage: {project: example, url_env: SWB_EXAMPLE_GROK_URL, auth: key, secret_env: SWB_EXAMPLE_GROK_SECRET}
```

用 routine 名稱傳送給它，或用 `grok:<slug>` 傳送給專案的主 routine。

## 設定

| 設定鍵 | 用途 |
| - | - |
| `blocks.grok-routine` | 用於喚醒 Grok Bot routine 的模組設定 |
| `blocks.grok-routine.use` | 模組類型，填 `grok-routine` |
| `blocks.grok-routine.enabled` | 設為 `false` 可略過此模組 |
| `blocks.grok-routine.routines` | 依名稱設定 routine |
| `blocks.grok-routine.routines.*.project` | SwB 專案的簡稱。通用 routine 填 `null` |
| `blocks.grok-routine.routines.*.primary` | 設為 `true` 後，優先選用此 routine 處理所屬專案的訊息 |
| `blocks.grok-routine.routines.*.auth` | 用 `key` 傳送金鑰，或用 `signature` 為請求加上簽章。預設為 `key` |
| `blocks.grok-routine.routines.*.header` | 攜帶金鑰或簽章的 HTTP 標頭。`key` 預設用 `Authorization`，`signature` 預設用 `Webhook-Signature` |
| `blocks.grok-routine.routines.*.url_env` | 存放公開 HTTPS webhook 位址的變數名稱 |
| `blocks.grok-routine.routines.*.secret_env` | 存放金鑰或簽章金鑰的變數名稱 |
