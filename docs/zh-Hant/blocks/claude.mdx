## 新增連接器

依照 [Claude 設定](/zh-Hant/docs/setup/claude)，把你的 SwB MCP 網址新增為自訂連接器。在你的 Project 或聊天中啟用連接器。Claude 會用 OAuth 以 `claude` 的身分登入。

## 連接 Claude Project

把 [Claude Project 設定提示詞](/zh-Hant/docs/setup/claude-project)貼到這個 Project 的聊天中。

代理會找出 SwB 專案，並設定一個帶有 API 觸發條件的 routine。它呼叫 `connect` 取得一次性認領連結，連結 30 分鐘後過期。開啟連結，把 routine 權杖貼到表單中，再儲存權杖。代理會傳送一則測試訊息，並檢查回覆。

## Routine

**routine** 是 SwB 可以啟動的 Claude Code 任務。SwB 也會把訊息留在 Claude 的信箱中。routine 用 `reply` 回覆傳送者。

| 傳送對象 | 目的地 |
| - | - |
| `claude`，加上 `project=<slug>` | 這個專案的主要 routine |
| `claude:<slug>` | 這個專案的主要 routine |
| `<routine name>` | 這個 routine |
| `agent:claude` | 只進信箱 |

一個專案可以有多個 routine。SwB 預設選取這個代理和專案的第一個 routine。註冊 routine 時設定 `primary=true`，SwB 就會優先選取它。

如果 Claude 回報專案已暫停，SwB 會改用空白請求再試一次，routine 再用 `routine_pickup` 讀取訊息。

## 設定

```yaml
blocks:
  claude-routine:
    routines:
      claude: {routine_id: trig_..., token_env: SWB_EXAMPLE_CLAUDE_TOKEN, agent: claude}
```

如果要手動設定，把 `token_env` 設為存放 routine 權杖的變數。範例使用 `SWB_EXAMPLE_CLAUDE_TOKEN`。

| 鍵 | 用途 |
| - | - |
| `blocks.claude-routine` | 喚醒 Claude Code routine 的設定 |
| `blocks.claude-routine.use` | 模組類型，填入 `claude-routine` |
| `blocks.claude-routine.enabled` | 設為 `false` 可略過這個模組 |
| `blocks.claude-routine.routines` | routine 名稱與設定的對應表 |
| `blocks.claude-routine.routines.*.agent` | 接收訊息的代理。預設為 `claude` |
| `blocks.claude-routine.routines.*.kind` | 有專案的 routine 填 `project`，通用 routine 填 `general` |
| `blocks.claude-routine.routines.*.project` | 專案 routine 所屬的 SwB 專案名稱 |
| `blocks.claude-routine.routines.*.name` | routine 的顯示名稱 |
| `blocks.claude-routine.routines.*.primary` | 設為 `true` 時，優先為它的代理和專案選取這個 routine |
| `blocks.claude-routine.routines.*.routine_id` | Claude API 觸發條件 ID，例如 `trig_...` |
| `blocks.claude-routine.routines.*.slugs` | 可以當作傳送對象的額外簡稱 |
| `blocks.claude-routine.routines.*.token_env` | 存放 routine 權杖的變數名稱 |
