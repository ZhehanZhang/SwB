## 新增連接器

依 [Claude 設定](/zh-Hant/docs/setup/claude)新增自訂連接器，並填入 SwB 的 MCP 位址。在 Claude Project 或聊天中啟用連接器。Claude 透過 OAuth 以 `claude` 身分登入。

## 連接 Claude Project

把 [Claude Project 設定提示詞](/zh-Hant/docs/setup/claude-project)貼到該 Project 的聊天中。

代理會找出對應的 SwB 專案，並設定帶有 API 觸發器的 routine。代理呼叫 `connect` 取得領取連結。連結可使用一次，30 分鐘後失效。開啟連結。把 routine 的權杖貼到表單。儲存權杖。代理會傳送測試訊息並檢查回覆。

## Routine

**routine**是 SwB 可以啟動的 Claude Code 任務。SwB 也會把訊息留在 Claude 的信箱。routine 用 `reply` 回覆傳送者。

| 傳送給 | 去向 |
| - | - |
| `claude` 加上 `project=<slug>` | 該專案的主 routine |
| `claude:<slug>` | 該專案的主 routine |
| `<routine name>` | 該 routine |
| `agent:claude` | 只有信箱 |

一個專案可以有多個 routine。SwB 預設選擇該代理在此專案中的第一個 routine。註冊時設為 `primary=true`，即可優先使用該 routine。

若 Claude 回報專案已暫停，SwB 會用空白請求重試。routine 用 `routine_pickup` 讀取訊息。

## 設定

```yaml
blocks:
  claude-routine:
    routines:
      claude: {routine_id: trig_..., token_env: SWB_EXAMPLE_CLAUDE_TOKEN, agent: claude}
```

手動設定時，用 `token_env` 指定存放 routine 權杖的變數。範例使用 `SWB_EXAMPLE_CLAUDE_TOKEN`。

| 設定鍵 | 用途 |
| - | - |
| `blocks.claude-routine` | 用於喚醒 Claude Code 任務的模組設定 |
| `blocks.claude-routine.use` | 模組類型，填 `claude-routine` |
| `blocks.claude-routine.enabled` | 設為 `false` 可略過此模組 |
| `blocks.claude-routine.routines` | 依任務名稱設定 routine |
| `blocks.claude-routine.routines.*.agent` | 接收訊息的代理，預設為 `claude` |
| `blocks.claude-routine.routines.*.kind` | 專案 routine 填 `project`，通用 routine 填 `general` |
| `blocks.claude-routine.routines.*.project` | 專案 routine 所屬 SwB 專案的簡稱 |
| `blocks.claude-routine.routines.*.name` | routine 的顯示名稱 |
| `blocks.claude-routine.routines.*.primary` | 設為 `true` 後，優先選用此代理在該專案中的這個 routine |
| `blocks.claude-routine.routines.*.routine_id` | Claude API 觸發器 ID，例如 `trig_...` |
| `blocks.claude-routine.routines.*.slugs` | 傳送時可使用的其他簡稱 |
| `blocks.claude-routine.routines.*.token_env` | 存放 routine 權杖的變數名稱 |
