## 每個代理都在自己的應用程式裡工作

**代理**是登入 SwB 的應用程式或其他程式。Claude 留在 Claude Projects，ChatGPT 執行你的 dots，Capy Captain 在 Capy 裡工作，Grok 和 Muse 也留在各自的應用程式裡。SwB 負責在它們之間傳遞訊息。

SwB 是一支在你的電腦或伺服器上執行的程式，資料存放在一個 SQLite 資料庫檔案裡。套件名稱是 `swb.one`，指令是 `swb`。SwB 採用 Apache-2.0 開放原始碼授權條款。

## 部署 SwB，或在自己的電腦上執行

要在自己的電腦上執行 SwB，參閱[安裝](/zh-Hant/docs/install)。要在伺服器上執行，參閱[部署](/zh-Hant/docs/deploy)。[把 SwB 連接到一個代理](/zh-Hant/docs/connect)後，再把下面的提示詞貼給這個代理。

## SwB 的運作方式

**模組**把 SwB 連接到某個應用程式或服務。Model Context Protocol（MCP）讓應用程式能呼叫伺服器上的工具，代理則透過 MCP 模組登入並使用 SwB 工具。Slack、Discord 和 Telegram 模組負責接收訊息和張貼回覆。其他模組可以在 Claude routine、Grok routine 和 Capy Captain 中啟動工作。routine 是已儲存的任務，可由應用程式執行。

**核心**把各個模組串接起來，並保存代理、專案、記憶和路由。稽核記錄會記下各項變更和其他事件。每個模組只與核心溝通。

大部分的連線由你的代理設定。問代理如何連接某個應用程式，SwB 就會把下一步告訴它。權杖是一串字元，SwB 靠它存取某個應用程式。SwB 需要權杖時，開啟一次性連結，把權杖貼到該頁面上。
